# 接手与维护项目记忆

缺上下文时读[HANDOFF](../../../docs/status/handoff.md)，用[记忆地图](../../../docs/README.md)定位本次领域；已有有效上下文就继续，只补缺失事实。不要重读整个项目。

稳定边界查[constraints](../../../docs/engineering/constraints.md)，当前任务、测量和实现分别由地图指定的原页维护。技能只提供方法，不扩大用户授权。

保存新结论前，用概念及代码标识搜索原owner；更新原页，别在AGENTS、skill、状态与计划同时复制。临时建议留在任务/候选，核实事实给出处；跨任务方法可精简既有skill，过期过程归档。具体取舍见[文档职责](../../../docs/DOCUMENTATION.md)，不因一次教训新增全局禁令或每轮总结任务。
