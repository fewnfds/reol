# 分支选择与叙事结果

本地重写原dialogue-systems；归属见[NOTICES](../../../THIRD_PARTY_NOTICES.md)。这是将来触及该领域时的检查，不代表当前已经有剧情对话引擎，也不要求现在实现。当前当面求助/授业仍沿`Society/Operations`，不能用剧情变量复制其权威事实。

- 先判断需要的是实际社会行动、事件显示，还是带持续选择的叙事流程；不要因为有几行台词就引入Ink/Yarn、第二世界或LLM。候选库先核纯GDScript/许可/目标版本，未采用的工具不能写成依赖。
- 台词/选项定义、当前会话位置与世界效果分开。用稳定节点/行ID做引用和本地化，显示文案不当存档键；插值显示与可执行命令分开，不对编辑器/模组字符串做裸`eval`。
- 选项条件只查询，实际选择由原owner复核并提交；重画面板、回看台词、双击或读档不能重复付费/奖励。扣钱、关系和任务结果是领域操作，不能在每次进入台词显示时无条件执行。
- 定义进入、等待选择、关闭/打断和结束；目标失效、角色离场及换档不保留悬空会话。需要保存的会话进度写入原状态合同，结果已提交不能在恢复后再执行。
- 检查缺失节点/变量/引用、起点不可达、无出口、条件互斥导致无选择和无限自动跳转。循环/死胡同可能是设计，识别并说明其出口，不盲目修成线性故事。

验证一条真实选择链及一个重入/取消或双击反例；断言世界只改变一次，展示长中文/缺译回退。当前无相关改动时不运行此流程。

候选资料：[Ink原项目](https://github.com/inkle/ink)、[Yarn Spinner原项目](https://github.com/YarnSpinnerTool/YarnSpinner)只作为叙事语言/运行态思路入口，不是已适配本项目的纯GDScript插件；引擎绑定、语言与版本另核，不按教程安装。
