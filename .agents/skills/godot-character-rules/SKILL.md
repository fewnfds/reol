# 主体数值与可逆来源

本地提取重写原rpg及survival-crafting中的数值检查，归属见[NOTICES](../../../THIRD_PARTY_NOTICES.md)。不沿用教程的DND属性、升级曲线、饥渴规则或职业表；产品规则以[生命与成长](../../../design/rules/lives-and-progression.md)为准。

- 分清作者定义、基础值、永久进展、暂时资源、可逆来源修饰和派生热列；查`Objects`、`Growth`、`Equipment`、`Effects`的现有owner。修饰不加写基础值，移除装备/来源后应能从源重算而不累计漂移；同质物品未有单件状态时不强加每件ID。
- 新数值链说明加算/乘算层、同层堆叠、优先顺序、钳制和舍入位置，沿已有规则保持必要的数值顺序；不能为“通用RPG公式”改掉现有语义。通常保留中间精度，在合同规定的提交边界舍入；已有分段/余数合同不能凭这一原则删掉。
- 区分发射时固定值与命中时读取值；源死亡后已经交付效果如何处理必须跟原动作合同一致。可叠加/刷新/替换/免疫和来源结束都要有可逆路径；不能清一个buff就误停另一个同名来源。
- 临时buff、来源维持的光环与强制压制不同：净化目标buff不销毁外部持续来源；来源终止撤销其贡献；压制按已定规则限制可获帮助。新增效果沿原来源/驱散/压制合同，不为一个技能另造特例状态表。
- 上限变化不默认赠送当前资源；降低上限、容量变化、卸装失败、死亡和身体槽复用都须处理。装备交换核最终库存容量后提交，失败不改变穿戴或物资。
- 需要/恢复按共同世界时间和实际活动积分，保留小数余量与已发生采样，不把渲染帧/读取面板当成长机会。新增派生缓存在源变化、恢复和槽复用处维护，不能靠推进一秒偷偷修复。

验证选择可逆与边界反例：反复穿脱/叠加撤销不漂移、两来源先后移除、改变上限不凭空回血、换装后在飞攻击、存读前后源值/派生值一致。数值正确不等于平衡或手感已经合格。
