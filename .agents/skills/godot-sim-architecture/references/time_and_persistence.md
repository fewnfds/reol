# 共同时间与持久化要点

以下是检查要点，不是新建时钟、调度器或存档格式的指令。先查当前状态所有者和相关版本合同。

## 时间推进

- 区分目标时间、已经结算的时间和待处理工作。限制每次处理预算时保留余量；恢复处理时不得重复消费已发生的事件或丢失到期事件。若允许处理中保存，明确一致的保存边界或保存必要的在途状态。
- 计算到下一规则边界再结算；同刻发生的消耗、完成、取消或冲突沿既有阶段顺序处理。跨区交互需要同步受影响区域，状态变化后失效的预测不能继续使用。
- 随机结果属于明确的状态或确定的事件；不要让场景加载顺序、视图刷新或无关随机调用改变已经决定的结果。

## 存档与验证

- 在途动作包含必要的参与者引用、进度、费用和取消语义；读档后恢复原状态所有者，避免复制身体、物品或资源。检查引用目标缺失、历史版本和混版候选的失败路径。
- 用同一起始状态比较整段推进与拆分推进，并覆盖关键中间保存/恢复、同时到期事件和已取消动作。比较哪些字段、精度与场景由当前合同决定，不能凭少数样本保证任意物理过程逐位一致。
- 性能问题先量测帧时间、热路径和实际工作量；优化时继续检查这些因果与状态不变量。
