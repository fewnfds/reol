# 接入Reol模拟功能

本项目以World和领域owner保存事实，身体使用Packed批页，显示消费Frame。沿实际调用定位接口；不要套用每NPC一个Node/Timer、另起JobBoard或第二份世界的通用教程。领域不清时查[职责](../../../docs/engineering/architecture/05-framework-domains.md)，不按领域表预建基类。

身体经`actor_slots`定位原页/行，片内位置使用对应时刻的World查询；不能用`actor_id - 1`、上帧显示位置或未声明时效的空间桶替代。

## 选择数据与执行接缝

- 写代码前从真实入口追到读取者，区分调用次数与每次访问量。个人/目标查询只取必要字段，既不顺手给通用本人视图加整域投影，也不在局部高频路径无条件调用已有完整视图；按默认约定核查其真实读集合。
- 沿原owner选择直接调用、相关变化唤醒、已知到期服务或必要全员批。具体方式与当前实现查[计算接入](../../../docs/engineering/execution-batches.md)；事件须算扇出、索引须算写入维护、异步须算输入与采用成本，不能只算工作函数。
- 先找已有局部/关联查询及其有效时刻、过滤条件。不同消费者可能需要活体、尸体、在途目的地等不同集合；复用索引前确认覆盖，不能用遗漏结果换速度。新派生数据从原事实重建，加载不保存第二份真值。
- 请求已受理、本人愿意、到场、预约和实际完成分别成立。工作/设施改动保留同资源竞争与释放路径，不能以提示或任务状态代替真实位置、库存和执行后果。

## 时间、取消与恢复

本次接口若改变共同时间或后台计算，区分请求时刻、已提交时刻与剩余工作；写明旧承诺在等待时如何继续。后台只算脱离的输入，owner采用时复核身份/代次与相关事实；不将旧候选覆盖新会话或新承诺。实际边界按[运行精度](../../../docs/engineering/simulation-pacing.md)选读，不默认一切必须当前帧算完。

取消、死亡/删除、目标失效及读档替换影响本次过程时，核对预约/资源释放、不可重放效果和派生数据重建；失败保留已提交事实，读档先验证独立候选。存读改动查[兼容与恢复](../../../docs/engineering/compatibility.md)，不扩大历史格式支持。

访问方式与索引权衡查[成本范式](../../../docs/engineering/simulation-costs.md)，本次反例与交付强度沿[开发循环](../../../docs/engineering/workflow/testing.md)。
