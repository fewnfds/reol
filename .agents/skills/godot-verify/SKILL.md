# 选择相关验证

现行强度、CI状态和命令只看[开发循环](../../../docs/engineering/workflow/testing.md)，本技能不另建门禁。

- 性能改动先确定相同负载和要减少的工作，测端到端结果；headless不能证明真实画面帧时。
- 规则/存读改动只核对本次可能破坏的原状态、顺序或失败路径；场景/输入改变时实际观察相关流程。
- 文档只核必要差异和链接；新class或资源不可见时按需导入，先处理首个真实错误。

有失败再读[排错要点](references/troubleshooting.md)。结果写回原事实/证据位置，不以通过数量代替规模性能。
