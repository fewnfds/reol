# Reol 验证

用户最新指令优先。旧CI、全量回归、分片和每包自动审查已退役；本技能不能重新要求它们。现行方法只看[开发与短验证](../../../docs/engineering/workflow/testing.md)。

- 性能改动：先找到最大成本，用同负载20–30秒实测判断整体收益；headless不能证明画面帧时。
- 规则改动：只跑受影响的短smoke或具体反例；`python tools/godot.py test`默认15秒上限，不装配全库/世界。
- 新资源或class无法识别：按需导入，先修首个真实错误，不重复启动完整工程验证。
- 存读、场景或交互：按本次改变运行相关路径；不自动检查全部旧档、停开场景或历史版本。
- 文档：看差异和必要链接，不启动引擎。

如实记录实际结果与未测范围，不以PASS数量证明性能。详细排错只在失败时按需读[要点](references/troubleshooting.md)。
