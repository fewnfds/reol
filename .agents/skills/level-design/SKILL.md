# 空间体验与可理解性

本地重写原level-design；归属见[NOTICES](../../../THIRD_PARTY_NOTICES.md)。保留可读性、尺度和试玩方法，不强加平台跳跃、线性关卡、Boss节奏或锯齿难度曲线；当前自由宗门生活也需要验证玩家能理解与使用空间。

- 先说明本次期望玩家看见、理解和做到什么，区分产品目标与助手设计。使用实际移动/身体净空、交互距离、视距、相机窗口与作业位置定尺度，不按贴图尺寸猜通行。
- 在现有真实场景先用低成本布局验证路线、关键服务可用、入口出口及主要观察方向，再细化美术；不为一个摆放修改新建独立demo或每次强制完整白盒阶段。
- 检查设施朝向、拥堵、多人交汇、被遮住的可交互物与地标。玩家路径、NPC工作流和不同身份的权限可以不同；可达不等于有资格/材料/知识，避免必需条件相互锁死。
- 教学和反馈让玩家识别规则与后果；重要不可逆选择可预见，关键状态不只用颜色表达。战斗挑战、空闲探索和生活空间的节奏按当前目标选，不套“必须先安静后Boss”的剧本。
- 观察真实试玩中迷路、误操作、长等、路线冲突与看不懂行动的原因；程序能自动完成不代表人能理解。缺少玩家试玩时明确只完成开发者走查，不把自动截图当体验认可。

验收按本次体验目标给一条可重复路线/操作与发现的问题；生成算法的连通校验不能替代人工空间设计，视觉装饰也不能掩盖不可用工位。素材风格由原二维资产管线负责。
