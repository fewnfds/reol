# 自然环境与组合式办事场所：参考核对

日期：2026-11-03。本轮用户要求补齐地块、自然环境、植物动物与五行，并用围建房间/区域、家具、实际办事者和记录载体替代演示场中的“一个功能一栋建筑”。本文是研究与范围建议；不是新功能完成清单。实现、测试与限制仍以[BASELINE](../../docs/status/baseline.md)为准。

## 2. 借鉴后的本项目取舍

这些是Reol的设计推论，不是参考游戏原有功能的转述。

- **地表与生境**：保留原水/草/岩通行和高度。其上派生土质、湿润背景、肥力和主要物性，决定自然群落的分布与可观察线索。背景湿润不是一桶可以取走的水，肥力不是立即发放的药草库存。
- **自然对象**：普通树、灌木、芦苇、野药与矿石有不同生境；关键可采对象仍需唯一身份、有限库存和原劳动。不能为了画面丰富，把每株装饰草都变成可无限采集的新来源。
- **动物与妖类**：先让已有雀妖的巢、籽实、岩隙与地貌看起来相符，让山兽出现在有足够净空的山地。已有具名生命继续沿用原状态，不为远景布景复制另一只“同名动物”。新物种繁衍、猎食、驯化和死亡不在本轮顺手扩成完整产业。
- **五行**：区分材料物性、地方亲和与有真实储量的灵源。岩石不统一等于金，树木不天然产出可吸收的无限木灵。五行先帮助解释材料、栖地与修行适性；吸收或转化仍必须通过原灵源、身体、方法与代价。
- **房间与区域**：墙门围合、屋面、可到达的工作位置、家具和授权组成场所。室外可以办理某些事务；下雨或没有档案时能否办理，取决于该事务需要的真实条件。
- **办理资格与记账**：办公桌提供操作位置，椅子提供坐席，档案柜提供保管位置，法器或账本提供记录载体；这些物件都不能自动产生机构授权。公账、私人记忆与个人账本仍需分开，摆放新柜子不补造历史功德，也不把私人记录升级为公认事实。

不照搬全套农业、病虫害、复杂牧场或每件家具的全局效率分。优先让环境能解释修炼地点、取材、避险、追踪、争夺与组织活动；凡人供给只补基本循环。

## 3. 现有代码的只读核对

以下是本轮研究时的起点；并行实施若增加了新代码，不用本节覆盖其最新验收。

| 已有代码 | 当前实际行为 | 对本轮的约束 |
|---|---|---|
| `scripts/world/terrain_visuals.gd` | 三种地面颜色、四个确定性纹理变体 | 可以丰富派生外观，不能因此改旧档的水域、通行和高度 |
| `scripts/sim/land_resources.gd` | 原库存拥有有限自然产物；本域保存生长相位、采出/雨水等账；药源已有温窗与土水过程 | 新自然画面不得重复发放原库存；不要再造平行植物产量表 |
| `scripts/runtime/village_runtime.gd`的`herb_phase_for`与`resource_is_observable` | 近旁/可见后才给原药源生长阶段 | 地块观察继续区分表面地貌与角色确实能理解的信息 |
| `scripts/sim/avian_life.gd`与`data/scenarios/avian_life.json` | 两地各一只雀妖、巢/籽实/岩隙/药地、有限食物和搬运、原世界时间 | 复用原鸟、原栖地与库存；不是全图动物生成或食物网 |
| `scripts/runtime/avian_life_runtime.gd`的`_draw` | 可见栖地画树巢、籽草或岩隙；鸟按原飞行状态/高度显示并可选中 | 栖地画面可融入环境；不能只加装饰鸟就声称生物群落模拟完成 |
| `scripts/sim/large_bodies.gd`与`large_bodies_runtime.gd` | 一只真实3×3山兽、完整净空、有限漫游和递食；有方向的几何图形 | 保留原扫掠占地与唯一身体；不是繁殖、猎食或妖怪势力 |
| `scripts/world/facility_visuals.gd` | `garden`画整齐苗圃，其他多数地点画一个完整小房子；由places ID分派外观 | 它是当前演示感的直接来源；替换外观还不等于办事条件已接通 |

## 4. 本轮建议的有限出口

1. 在原地图上看出至少几种自然生境，查询地块可获得地表、植被与环境线索；同一坐标重开/换显示区块不重抽。
2. 显示与原可采来源一致的野药、林料、泉水等自然位置。新增群落只读生成时，明确其尚无采伐/繁衍/死亡，不把视觉覆盖冒充完整生态。
3. 五行有数据与可解释的来源；已有火行灵源仍是唯一可交割来源。未实现的五行灵机不显示成五种免费资源条。
4. 办事地点能看见空间、家具和办理者。办理前核对在岗/权限、可到达位置与所需记录条件；人离场、载体缺失与房间受损应能给出各自原因。
5. 原NPC、库存、机构账和进行中事务可保存接续；旧档不得凭空补发报酬、复制人员或重建已发生历史。新持久状态若确需迁移，另写显式规则和兼容验证。

房间分工与机构权威不能靠改名完成。本轮只选择真实可接通的一组场所验证，其他功能仍诚实列为原型或待实施。
