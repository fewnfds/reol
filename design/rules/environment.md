# 环境、五行与风水

## 已确认

- 历法、季节、气候与天气影响世界环境。当地气候提供冷热的中性条件，环境变化应能对生命、物品和活动产生实际影响。
- 冷热等级是同一项有方向的属性：负值表示冷、正值表示热、零表示无冷热影响；普通单一来源不同时持有两个独立的冷热等级。绝对值比较对抗强度，摄氏温度由净等级和当地背景映射，不与五行火/水通道混为同一属性。
- 室外冷热来源向周围形成随欧氏距离衰减的圆形影响。每处分别取最强的有效热等级和冷等级，再按等级抵消；同等有效等级的冷热相互抵消，不直接平均来源的摄氏温度。
- 实际温度随环境目标逐渐变化。来源移动、消失或关闭时，原处的影响逐渐消散，新位置的影响逐渐建立，而不是把旧处的环境状态瞬间搬走。
- 来源真实经过一条路线时，沿途环境按实际受影响的时长变化。在来源强度、路线和其他条件相同时，慢速经过或停留通常比快速经过加热/冷却更多；经过后留下的是地块实际环境状态，不是一串复制的来源。只有真实瞬移才没有中间路径。携物整体对外暴露程度仍按后续规则确定。
- 冷热等级的对抗可以对称，等级与温度的映射可以不对称。温度下界不应变成冷源对抗更强热源的能力上限。
- 室内采用房间平均的简化方向，一间房有一个实际温度。分隔、合并或开敞空间时，变化应承接原有实际温度；火墙和冰墙可以作为真实来源参与。
- 万物按自身五行构成持续影响周围环境，影响有范围与衰减。环境影响按五行分别取各通道的最大值，不因多人修行或使用而被消耗。
- 可吸收灵气是物品另行持有的储量，和环境五行影响分开。物品可以在五行环境中积攒灵气，积攒本身不扣除环境影响。
- 不同物品的地面掉落分开摆放；同类且状态相容的物品可以成堆。一堆同类物品对外只计算一份来源强度，不按堆内数量放大；不同合法位置的来源各自影响环境。
- 风水与堪舆关注真实地形、水路、建筑、布局和来源形成的环境，不以一个全局吉凶分替代具体条件。
