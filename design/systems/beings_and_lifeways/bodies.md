# 众生与生活方式：身份、身体和可玩的处境：身体与身份

> 详细设计与候选：具体机制、参数、样本和验收意图须验证；已确认规则见[规则目录](../../rules/README.md)。

## 1. 什么使一种存在值得扮演

不是同一人物换一张鸟皮、鬼皮或大贴图，而是有不同的感官、行动方式、依赖、理解与交往渠道。差异能产生困难，也要产生独有机会。麻雀、寄魂者、古兽不必先化成人，才获得“正式游戏资格”。

每个可玩起点至少回答：如何维持自己；眼下关心什么；能察觉和影响什么；如何表达或合作；会被什么限制；失败后还有什么选择。创建角色可以提供这些处境的预览，不用“坦克/治疗/输出”概括其一生。

不是所有设定都必须同轮实现。先选几个最能暴露架构假设的样本，再增加种族内容。普通生命、妖化、修持和身份是不同维度，不能只用种族ID决定善恶、智力、阵营和所有动作。

## 2. 四件事必须分开

| 概念 | 负责什么 | 边界 |
|---|---|---|
| 主体 | 记忆、目的、经历、关系和个人承诺的连续性 | 不等于节点、皮肤、公开名字或唯一身份证件 |
| 身体/载体 | 形体、位置、感官、结构、损伤和物理/灵性承载 | 可以是生物身体、器物或有规则的灵体载体；无身体不等于无限穿墙 |
| 控制关系 | 此刻谁能指挥什么动作，经过何种通道 | 正常自身控制、契约代理、傀儡指令、附身争夺有不同语义 |
| 社会身份与被识别身份 | 名字、任职、师承、物权、他人认为你是谁 | 冒名不创造任职，换身体不自动使所有旁人认得你 |

稳定主体ID是模拟层的连续性工具，不是所有NPC都能查询的灵魂身份证。一个人用了假名，世界仍能存其经历，旁人却未必知道关联。社会对换身后债务或继承的承认可能有争议，不能从后台ID直接让全世界达成一致。

同一物品/载体的实际位置唯一；同一控制权限有明确范围与执行顺序。若一个主体能分心控制多处，必须有感知通道、命令延迟、注意代价和控制中断规则，不因多实例场景生成多个背包或免费劳动力。

### 2.1 换身、附身与死亡

- 换身先检查新载体是否可承载、原控制是否释放、物品放在哪里；变身不缩小行李的真实体积，也不复制伤势前的旧身体。
- 原身体损伤属于原载体；记忆缺损、魂伤与身份关系可能属于主体。哪些可以转移由具体方法定义，不用一项万能血量包办。
- 封魂术可以保住濒死主体，但需要适合载体、时间与施术能力。不能默认每个角色死后自动变成不受任何限制的幽灵。
- 附身涉及实际入口、防御、控制争夺与目标意志。仅持有戒指、签雇佣契约或成为掌门，不产生他人身体控制权。
- 真正主体死亡、载体毁坏、暂时休眠、意识失联分别表达。继承、遗物、职位和消息据实际结果处理。

第一轮只需“正常身体控制＋封魂戒指中的独立主体”，其余留为有边界的扩展，不一次写完整夺舍与多身系统。

2026-11-03用户确认：普通肉身死亡通常伴随灵魂消散，保魂、寄魂或转世需具体条件/方法。主角有有限重生机会，世界不回滚，可小幅前跳，从跨种族新生人选中接续；机会耗尽结束本局，高难度次数更少，当前不设计增加渠道。详见[有限重生与新生候选](../rebirth_and_new_lives.md)；这不泛化为全体NPC常规轮回。

### 2.2 主角的有限重生机会

已确定的概念是“通常有终结的世界＋主角有稀缺的例外”。这不意味着NPC永远不能保魂复生；NPC可使用已经定义的仙侠方法，但不自动拥有主角的同款机会计数或无限轮回。

机会属于本局主角连续性记录，和各世身体/身份分开；不是全体生命必填属性，也不能靠控制新角色复制。初始预算按难度决定，原型先不实现剧情补充。刷新、自选、提高稀有度是可设计扩展，需显式预算与规则，不能成为免费增命或屠杀筛选的旁路。

候选必须有实际孕育/群落出生来源，按有限机会域和前向时间窗匹配；不在所有幸存幼体中重新归一抽取。死亡、刷新、确认、跳时和绑定用持久事务记录保持幂等；详规与L1–L12未来验收统一在rebirth_and_new_lives，不在本文重复维护参数。

“主要角色有例外”不表示NPC全都知道它。亲历、传闻和证据可以改变旁人反应；后台特殊标记不会让仇人免费知道主角的复生条件，也不会让旧组织自动归还职位与财产。

普通读档与世界内重生分开。用户没有要求铁人或跨存档惩罚，本轮不暗设全局重生扣次、不修改用户存档策略；防利用首先约束当前续生事务、有限抽取与候选来源。机会耗尽后没有免费换新人继续的玩法。

## 3. 身体是一组可查询的条件

2026-11-03用户确认修行机会以开放为主：大多数生命有适合自身的方法路径，少数当前身体/载体不能直接修行，但可能经具体改造/迁载改变。它不是所有方法皆可学的承诺，也不自动让无心智物体成为可控主体；先天差异改变条件与代价，不一概折算成同一资质分。

| 方面 | 原型需要的表达 | 会产生的差异 |
|---|---|---|
| 几何与尺度 | 占地、通行净空、接触面、可伸达范围 | 进入缝隙、经过门桥、在边界递物 |
| 移动 | 步行/攀爬/飞行/依附等方式及条件 | 地面道路、屋脊、风带、水域与休息点 |
| 操作 | 手、喙、爪、触须、法术牵引等操作通道 | 抓取、拆装、携带、指点，精细操作可能需要工具或协作 |
| 感官 | 可接收的光、声音、气味、灵机等及范围 | 同处一室得到不同线索；感知不到不等于目标不存在 |
| 维持 | 适食对象、摄取方式、休养/休眠、环境耐受 | 人粮不是所有生物的食物，睡床不是所有主体的必需品 |
| 结构与承受 | 原型相关的损伤、行动受限、承载适配 | 伤翼影响飞行，裂戒影响封魂；未用到时不细算每片组织 |
| 表达与理解 | 声音/姿态/文字/神念等产生和接收条件 | 能看见字不一定识字，能传意不等于跨语言无损通信 |

这张表是设计检查表，不是七条全局属性条。某对象没有某结构就不存伪造数值；过程只查询需要的信息。不同形态共享“能否把这个对象移到这里”的问题，计算条件可以不同。

身体能力、学习过的方法与持有工具可以补足彼此。麻雀不会缝衣，但可请匠人做能用喙打开的扣；寄魂者不能抬炉，却可以指导愿意合作的持有者。合作方依然能拒绝或索价。
