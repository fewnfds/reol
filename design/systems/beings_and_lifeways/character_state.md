# 角色基础：素质、状态、修持与本领

性质：面向本地宗门与自主生命的设计方案，**尚未实现这些新增模型**。已有字段与演进接缝见文末。用户举例说明想表达的人物丰富度，不等于必须逐项新增属性；本页采用的中文名是项目设计用语，不冒充统一的修仙设定。

共同工作流归[自主生命](agency.md)，学习过程归[修行与学习](../cultivation_and_learning/learning.md)，关系与职务归[社会系统](../social_system.md)，首个宗门的运转样本归[宗门生活](../sect_life.md)。实施顺序只归[主计划](../../../docs/plans/foundation-priorities.md#下一阶段候选)。

## 一个人不是一张总属性表

角色由数种职责不同的状态组成。它们可以存成少量紧凑记录，不要求按表格新增同样数量的管理器、节点或数据库。

| 层次 | 要表达的事实 | 主要消费者 |
|---|---|---|
| 主体与当前载体 | 谁在持续经历世界，现在借什么身体/载体行动 | 经历、关系、感知与行动接续；详见[身体与身份](bodies.md) |
| 身体素质与适性 | 此身体能承受、施力、协调什么；对具体方法有什么相容条件 | 身体能力、负载、有关动作与恢复规则 |
| 当前资源与状况 | 生命危险、饱足、精力、体温、可用灵力，以及仍成立的伤病 | 实际消耗/恢复、行动准入和有因的自主关切 |
| 修持与已学本领 | 练过什么、掌握什么方法、有哪些实际能力边界 | 学习、准备、修炼、行动可用性与有效性能 |
| 认识、性情与情绪 | 本人知道什么、看重什么、如何理解当下经历 | 目标、选择、协作与反馈；不能直接改库存和他人态度 |
| 社会位置与财物引用 | 亲友师承、任职、责任、物权、随身物与使用安排 | 实际交往、履约、使用与取物；真值仍归相应owner |

稳定主体引用不等于公开身份证。身体、人物记录、移动热槽和显示实例之间用合法引用连接，不因本页设计预先做完整的多身、寄魂或转世运行时。

## 基础素质：少量数值，各有用途

人形首个样本采用以下候选。前三项主要表达身体条件，悟性表达学习能力倾向；身体/认知素质可以训练、变化或受损，不是不可改变的天赋点。其他形态按实际能力装配，不给一棵普通树强填人形四维；未来换身时怎样保留基础倾向另按主体/载体规则确定，不能顺手把已学本领与身体数值整包复制。

| 数值 | 含义与最早的实际用途 | 不包含什么 |
|---|---|---|
| 体魄 | 身体承受与休养条件；影响生命承受上限、适用的休养恢复 | 不等于当前HP、无病保证、所有环境免疫或修行资质 |
| 筋力 | 可施加的力与可承负载；影响需要施力的搬持、工具操作及明确引用它的武技 | 不自动提高术法、社交、炼丹和一切伤害 |
| 灵巧 | 肢体协调与精细操作；影响适用工艺的操作耗时、特定身法的执行条件/性能 | 不等于通用移速、随机闪避率，也不替代学过的身法 |
| 悟性 | 理解与形成相关心得的能力倾向；在有资料/指导和相关基础时影响学习投入效率 | 不传送知识、不识破未知事物，不代表人格价值、全局AI聪明等级 |

数值采用各项有明确定义的尺度与有界作用曲线，同项在适用身体之间可比较；体魄50和悟性50不因此具有相同价值。确切基准值、系数与成长曲线在对应纵切的对照中校准，**此时不填写一套缺乏消费者的1～100面板**。不能把悟性高者无条件设成所有领域的天才：相关经验、教学质量、练习与身体适配仍各自成立。属性只在相关活动中消费也是正常设计，不必为了让悟性每秒有用而额外附加所有术法降耗。

每项引入代码时必须同时接入至少一个实际消费者和可观察差异；若当前切片只涉及体魄与教学，就暂不落地另外两项的空字段。筋力/灵巧不为证明存在而改动原ACT的命中、动画或取消合同；需要调速的具体动作先声明可调整阶段及上下界。

**修仙差异主要来自方法与条件，不能靠属性改名完成。** 根骨、灵根、根基、神识和心性不再各增加一个同义六边形：

- 根基指已经形成的修持基础与可支撑能力，来源于真实经历和功法，不是一份独立总等级。
- 灵根等先天设定若采用，以具体适性、可用方法及改变条件表达；首轮不引入决定终身职业的单一资质总分。
- 神识属于有条件的感知/操控本领：说明通道、范围、分辨能力、可影响对象与持续控制条件。能探知异常不等于知道真名、真修为或内心。
- 心性由较稳定价值、取舍与相关经历表达；不以一条“道心”同时控制道德、听令、施法与精神健康。

## 当下资源、伤病和情绪

| 项目 | 设计语义 | 恢复、变化与边界 |
|---|---|---|
| 生命 | 当前急性受创承受量，保留战斗与既有死亡判定接缝 | 由伤害/治疗owner提交；不在本轮改成HP归零必然倒地待救 |
| 伤病 | 持续成立且有具体影响的状况，例如恢复受限或某类操作受限 | 只做闭环确需的少量条件；有来源、发展/消退条件，不展开器官级医学模拟 |
| 精力 | 当前长期活动/休养余量 | 正常生活和修炼可消耗；与睡眠习惯、住所偏好不同，不先另建第二根ACT体力条 |
| 饱足 | 已摄取供给的当前余量 | 对应现有`hunger`的实际方向，下降表示需要进食；名称纠正不等于立即改存档字段 |
| 体温与环境缓冲 | 身体当前温度，以及应对极端环境损伤的有限缓冲 | 现有`tolerance`不扩义为通用忍耐、抗毒、抗击退或心理韧性 |
| 灵力 | 能够实际调用的修仙资源储量 | 容量、取得方法和支付规则分别定义；汲取有数量来源的灵气，与环境五行持续影响分开 |
| 其他机制资源 | 怒气、护盾等仅在相应能力存在时装配 | 怒气池不等于愤怒情绪；护盾的作用与损耗继续归原防御合同 |

健康是对伤势、疾病、生命危险与行动条件的可读概括，首轮不增设一根同时管理以上真值的“健康值”。满HP但仍有未愈伤病可以成立；治疗定义须说明它恢复HP、处理哪类状况，还是两者兼有。不能让一个旧治疗按钮因命名“治疗”而自动医好所有病。

情绪是对具体事情的反应，不属于可支付的资源池。用有限的有因记录表达惦念、安心、焦躁、惧怕等体验：涉及谁/什么目标、当前意义、起因、何时复评/缓和。它可以改变当前重要性、风险理解和对人的应对，不能直接创造他人好感或给所有技能乘一个快乐系数。稳定性情、当前情绪、心理创伤与社会评价分别处理；首轮不同时建完整精神疾病与情感分类学。

供首片接入的最小记录是“有关关切/对象＋本人评价依据＋当前强度/时间条件＋影响哪个选择因素”。满足目标后的安心、被明确爽约后的失望可以共用这一责任；原因重新解释或状态改变时复评，淡去的情绪不自动撤销仍未履行的承诺。若目标评价已经表达某次损失，情绪不能把同一损失再完整计分一次；它改变后续关注或应对，而不是重复制造收益/惩罚。具体情绪词是界面表达，不要求内部按词各做一个系统。

### 灵力与现有资源怎样接续

当前`qi`在Objects人物记录，P4还有可选`mana/rage`资源定义。新修仙内容中若“法力/灵力/真气”只是同一种可用资源的不同叫法，采用**一个资源身份和一个可写owner**，由原资源访问接口读取/支付；不能同存三条可互相回复的账。若某种功法确实有异质储量，则作为具有不同来源和消费者的能力资源另立定义，而不是同义复制。

在实际接入时选择原`qi`的适配演进或显式版本迁移，并更新有关消费者；本设计不提前删除mana范例、不改format14。现有不同资源不因为名字相近便已被判为缺陷。汲取速率、持续输出和心神控制容量，只有真实方法需要独立限制时才成为模型；不先造三根无人消费的条。

有关方法通过资源身份查询当前量/上限、支出条件与实际支付结果，不直接猜字段在哪个表；原消费、恢复、费用准入和通知责任统一语义，物理数据可以继续按读写需要分布。预测成本只用于本人估计，不提前产生可花余额或默认可回滚；实际提交仍复核，失败不造资源。慢放在Objects不等于一定高效，热列也不等于必须并表，接入时按真实频度测量。

## 已学本领、修持与行动性能

生活/战斗、凡俗/修仙是检索与展示标签，不是四套互斥技能树。一次烹饪可同时使用识材、火候、工具和御火；做法的实际前提由相应方法声明。换职位不删除本领，拜师不自动教会，拿到秘籍不自动掌握，境界提升也不授予所有低阶招式。

本领记录至少能回答：取得何种依据、已达到什么执行能力、仍缺什么、实践进展是什么。学习状态及阶段详规只归[学习设计](../cultivation_and_learning/learning.md#4-学习是一个能中断能解释的过程)；旧六阶段、四招式、心神4点、主兼修数等均是候选，不是本次百人宗门必须实现的全套内容。

修持首先表现为能多做什么、用什么条件与代价做到。首轮只需真实入门与一次可使用的进展，不要求同时完成炼气至金丹的所有境界、突破、闭关和寿命数值。寿龄/寿元若进入内容，以共同世界时间和有关到期边界计算；没有实际衰老/长寿后果时不装饰一条倒数条。

派生性能由有关素质、修持、本领、实际装备与有效状态计算，保持变化时重建或按需查询：

- 移动速度只影响相应移动方式，不能绕过碰撞、路径、负载和动作承诺。
- 施术速度只调定义允许的施术阶段；不自动缩短冷却、工艺全部耗时或打乱已提交作用时刻。
- 武技/术法强度按具体作用选择来源，不能建立一个总攻击力同时解释刀伤、浇水和劝说。
- 有效性能的快照或缓存可重建；原始资源、装备实例、掌握与伤病不能同时再写一份派生真值。

## 穿戴、法器与储物

正式物品模型归[衣着与持物](../appearance_and_possessions/objects.md)。人形可以逐步增加帽冠、常服/下装、足部、佩饰和手持位置；当前四槽不等于所有生命都只有四槽，也不要求先补齐六栏界面。外观位置、持物/负载、身体适配、战斗防护和主动作用不是同一个概念。

法器须区分实物持有、使用本领、准备/祭炼状态、实际供能、持续控制，以及社会允许。认主若存在，是器物可执行的控制条件；宗门许可则是社会事实。借来的飞剑可获准保管但尚不会用，也可能已会用却不获准外借。被动功能可以成立，须有明确的生效/失效条件，不要求每件法器都靠主动按键维持。

普通材料继续按同质数量堆叠，公私归属、实际状态或受托用途不相容时区分批次；细则只归[物资批次合同](../appearance_and_possessions/objects.md#52-堆叠物的公私与受托用途)。有内容、磨损、借用或独特变化的东西采用稳定实例。普通背包与储物法器共用：

| 共用合同 | 具体内容可以有差别 |
|---|---|
| 唯一位置与内容归属 | 穿戴、手持、地面、容器内互斥；显示“全部随身物”只列引用 |
| 可容纳条件与容量 | 重量、体积/类别、数量，采用该内容真正需要的尺度，不给全部物品预造复杂几何 |
| 开合/访问与实际取放 | 普通翻找、法诀开启、距离/操控条件可以不同；不会因为有权限就已到手 |
| 放下、损坏与回收 | 容器离身不复制/销毁内容；损坏按定义留下内容/掉落实物或承担明确损失 |
| 恢复与查询边界 | 检查无循环、无双亲、无重复实例与合法位置；查候选不预留整个世界 |

首轮有内容容器暂不相互套装，保留扩展点；这是有界实现范围，不是空间法器永远不能嵌套的宇宙法则。储物法器若改变搬运方式，应允许玩法改变，并核对来源、条件和代价；不为保住搬运岗位而额外制造无意义负担。背包实例化随真实取物/借物样本接入，不阻塞先让已有数量库存参与自主活动。

## 功德、气运与社会评价

| 玩家常用说法 | 此方案的处理 |
|---|---|
| 功德 | 可以是某信仰/组织对行为的评价或未来明确的超常机制；首轮不默认全知天道自动裁判 |
| 气运 | 若引入，需定义影响哪类机会、谁能察觉、怎样变化；首轮不做无所不包的幸运倍率 |
| 名声/威望 | 特定群体经过传播形成的认识与预期，不是全世界即时共享的战力认证 |
| 人情 | 具体人物的经历、感激、期待与承诺，不能任意转让或统一兑换 |
| 宗门贡献 | 机构承认的履职/交付记录；可花额度若需要则另有发行与兑现条件，详见[宗门生活](../sect_life.md) |

这不是永久排除功德、因果与气运设定。日后若要让宇宙客观奖励善恶、能改变所有随机结果或跨生清算，将构成需用户选择的世界规则分叉，不能从几个例子暗推出来。
