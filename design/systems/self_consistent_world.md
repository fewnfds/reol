# 众生自行其道：Reol 世界总纲

成文：2026-11-02。**本文是共同理念与目标规则，完整世界仍待实现。** 当前可玩内容见[FEATURES](../../docs/FEATURES.md)，构建/证据见[BASELINE](../../docs/BASELINE.md)，当前授权见[HANDOFF](../../docs/HANDOFF.md)。

单角色人生、地方术法文明、日常与可打断快进已确认；正式接续沿[有限转生](rebirth_and_new_lives.md)。[W0-a状态目录](../../docs/plans/world_state_contracts.md)是当时的静态调查，不替代当前架构/进度。当前世界引擎接入顺序见[执行计划](../../docs/plans/world_engine_execution.md)，研究依据见[沙盒参考](../research/emergent_sandbox_world_references.md)。

## 1. 我们要做的不是几条并排的职业线

一个世界中，练剑的人需要药师，药师需要供货，供货依靠道路、劳动和信用；山里的鸟妖可能比任何人都知道断桥的位置，闭关的高手可能依赖一个不会斗法的旧友照料产业。各方有自己的生活，不以是否为主角提供任务判断存在价值。

玩家可以追求力量、安定、亲密、声望、发现、手艺、审美、经营、传承、复仇或隐居，也可以改变想法。系统不要求这些目标最终折算成同一个等级、产值或战力，更不要求“先打完一套战斗内容，才有资格种田、办学或做妖”。

自由来自三件事：**事物有独立用途；用途能与其他规则相接；后果会留下来。** 玩家想到用御火术烘干染布，系统检查热量、衣料、火候和劳动，而不只检查“是否购买裁缝职业”。意外的好办法可以成为当地人的新做法。

不承诺无限动作，也不把写满名词的百科当完整游戏。每项新规则都应产生可亲手尝试的选择，至少接入另一个领域，并有可观察的成功或失败。

## 2. 从文字角色扮演借来开放的看法

先像描述一个可生活的地方那样设计：这里有什么，谁依靠什么活着，谁知道什么，谁害怕失去什么，什么变化会迫使他们行动。不要先填满“力量、智力、敏捷、魅力”和八件装备，再给这些数值找故事。

但描述须分清三种用途：

| 层次 | 例子 | 在游戏中的地位 |
|---|---|---|
| 可执行的世界规则 | 木梁可燃；某种火会消耗燃料并伤及邻物 | 能被行动检查、模拟、保存和复验 |
| 有来源的认识与说法 | 老人说此戒避水；商人宣称它是仙器 | 属于说话者的知识或主张，可以错误 |
| 风味与表达 | 刻纹像失落王朝的云纹；河谷流传一首旧歌 | 营造意义；若成为解谜、权属或能力依据，须补具体关系与规则 |

一段文字可以表达意图、知识和秘密，不能仅凭“此人天下无敌”在后台跳过执行。未来AI可辅助理解自由文字，脚本/动作对象补全提供无AI可玩兜底；有支持的意图进入规则，没有支持的意图明确说明缺少哪种作用，不能编造已经发生的结果。当前游戏不接运行时语言模型，未来接入方式、版本和成本另行设计。

## 3. 世界里有哪些东西

不用一个万能“角色对象”容纳整个宇宙，也不要求每块石头运行一套心理模型。

| 对象 | 最少要回答的问题 | 例子 |
|---|---|---|
| 有意图的主体 | 谁在感知、记忆、选择，维持什么生活 | 凡人、鸟妖、寄魂者、具有意志的器灵 |
| 身体或载体 | 什么在占据空间、受影响、承载能力 | 人身、鸟身、巨兽躯体、封魂戒指 |
| 物与环境 | 有什么材料、结构、位置和变化条件 | 木门、药炉、河流、废墟、灵脉 |
| 行动与过程 | 谁在什么时候，以什么方式改变什么 | 求助、搬运、疗伤、炼制、夺舍尝试 |
| 关系与组织 | 谁与谁有何经历；谁有权要求什么 | 师徒、雇佣、宗门、村落、临时盟约 |
| 记录与信息 | 什么被谁记录，谁能通过什么渠道获知 | 私记、功德簿、假路引、传闻、观察 |

主体、身体、操控者和物主分别表达。戒指是物，戒中老人是主体；持有戒指不等于拥有老人的意志。一个主体可以换载体，一副载体也可能存在争夺控制的问题，但必须有明确的承载、感知与控制规则，不能复制同一主体或物资。

这里“不复制”指同一实例/事务不能被重复记账或提交，不是禁止设定中的造物、分魂、复制和多身。若方法允许这些变化，须明确产生的新实例/主体或控制关联、来源与持续条件；命名、转交和读档不能洗掉其限制。后台ID只用于保持连续，不是NPC可无条件读取的灵魂真名。

不是每一对象都具备上述全部字段。无心智树木有生长过程；树妖才增加记忆、意图和交流。普通蚁群可先作为群落过程，玩家接触并赋予持久关系的具体蚁妖才需要稳定个体记录。

## 4. 共同规则：问“能怎样做”，而不是“属于哪个职业”

### 4.1 能力依处境查询

一次行动检查执行者的感知、移动、操物、表达、理解、承载与维持条件。它们来自身体、已学方法、器物、场所和协作，不是一张全体生命共用且永久不变的属性表。

麻雀有飞行和喙爪，没有人类双手；巨兽有巨大牵引力，但过不了小桥；戒中人能传意，却未必能移动戒指。修士的神识可能发现凡人看不见的印记，凡人工匠却能凭材料与工艺识破修士不熟悉的赝品。

内部使用尺寸、重量、距离、耗时、可用能量、风险等数值。每个数值属于具体作用和对象，按需出现；前台优先说明“翅膀受伤，无法越过山口”“气机不合，强行驱动会灼伤载体”。不强制把一切藏成谜语：自己数得清的粮食、约定价钱、交货期限应准确显示。

### 4.2 意图与执行分开

所有执行入口遵循同一链条：

    产生目的 → 根据所知找办法 → 选择对象与方法 → 检查条件与代价
       → 预约/取得控制 → 花时间执行 → 提交变化 → 有限观察与后续行动

玩家直接选择自己的意图；NPC从已知可用办法中选。让他人办事通常是提出请求、合同、命令或威胁，不是直接接管其意识。已接受职责内的普通动作无需每一步重新掷社交骰；任务变质、风险变化或违背底线时才重新判断。

行动说明至少包含：执行者、实际目标、所用方法、媒介/工具、作用范围、开始和结束条件、资源、可能故障与可观察痕迹。并发冲突由明确的预约、到达和结算顺序处理，不能由界面先刷新谁决定。

一个过程可以有多个参与者与设备，但只有一个权威提交负责人。共同抬木、器灵指导和合作炼制按参与角色及阶段处理；个人行动按实际占用的移动、操物、表达、注意等通道判断冲突，不把“只结算一次”误写成“一个人同时只能存在一个过程”。持续术法有自己的来源与维持条件，首次确有需要时做最小实现。

### 4.3 小量通用作用，加上领域专用规则

先采用能够跨域复用的作用族：移动/施力、转移/容纳、热/冷、湿润/干燥、遮挡/照明/发声、供能/引导/封存、信号/消息、授权/承诺。具体作用仍有明确类型、目标和适用条件。

“可燃”不能意味着所有火都瞬烧所有材料；“会飞”不意味着能带走整座山；“具有幻术”不意味着能改写机构账本。药性、灵性、印契、神识等超自然机制需要自己的作用协议，不能只靠标签联想自动判定一切。

同一种有边界的效果可以服务多种用途：引火可战斗、烧水、烘干，也会暴露位置和损坏载体；驱虫可护药田，也会影响靠虫谋生的鸟妖。先把这些相接点做实，不追求像素级流体或完整化学。

组合规则须声明目标类型、通道/范围、量与单位、持续时间及相互作用。防护、穿透、叠加、抵消和局部例外由对应领域规定，不能靠标签词面或加载顺序决定。先让两个用途共用一种完整作用，再扩大语法。

## 5. 世界的骨架是相互依赖的循环

| 循环 | 过程 | 缺口如何变成玩法 |
|---|---|---|
| 生境与生计 | 水土/季候→植物/动物→采收/捕食→消耗/再生 | 枯水、栖地改变、过度采集、迁徙；觅食、灌溉、协商、搬迁都可介入 |
| 劳动与流通 | 原料→加工→储存→运输→使用/修补/废弃 | 工具、工艺、仓储、道路和劳力互相制约；不只增加产量 |
| 知识与传承 | 察觉→解释→试验→传授/记录→失传/修订 | 误认、保密、语言隔阂、旧书缺页；研究、翻译、拜师、行骗都有空间 |
| 人际与制度 | 相遇→经历→期待/关系→请求/承诺→履约或争议 | 尊敬不等于信任，信任不等于愿意冒险；组织承诺需要有人兑现 |
| 修持与异变 | 获取适合的养分/灵机→练习/调节→能力变化→新需求与风险 | 环境、身体、方法和导师形成不同路径；不是所有生命统一刷杀敌经验 |
| 权力与历史 | 资源/成员/授权→组织行动→利益变化→冲突/继任/新秩序 | 掌门更替、旧账冻结、商路改道、圣地衰落；远方也有原因和后果 |

循环不必永远平稳。世界允许消亡、繁荣、失败的制度、被取代的工艺和暂时无人解决的问题。资源紧张可以驱动故事，但不让全世界无休止地饿到只剩劳动，挤掉社交、研究、创造和闲暇。

### 5.1 修仙世界的自然法则：先有可理解的来源与边界

建议用“物质、生命、灵机、心智、契约”描述不同作用，不立五个万能资源条：

- 物质有位置、构造和可追踪的转移；实体储物空间若扩展，须明确空间归属、出入口、容量与故障。
- 生命依不同结构维持，凡人吃饭、鸟妖觅食、寄魂者依赖载体稳定；不要求全体吃同一种粮或休息同一张床。
- 五行环境与可花费的灵气分别成立：万物按自身五行构成持续影响周围环境，影响有范围和衰减；修炼者受环境浓度促进，不消耗这份场强。可吸收、输送、储存的灵气由原物品等承载者另持储量，实际抽取才扣该储量，不能把同一余额花两遍。
- 心智有感知、注意与记忆边界。传音、梦境、幻觉分别规定传递/遮蔽的内容与痕迹，不默认全知读心。
- 契约的社会约束与天地强制是两种规则。若设置誓约法术，要有见证机制、可识别的违约条件及作用对象；普通口头承诺不能突然触发宇宙雷罚。

2026-11-05用户确认：所有物品的五行辐射类似催化环境的持续影响，不被外物或修炼吸收消耗，向周围扩散并在远处衰减、消散；每件物品的强度和范围可以不同。可吸收灵气是物品独立的一项状态，物品浸泡在五行辐射环境中可以积攒灵气。容量、积攒规律、吸取后的物品变化和相应玩法后置，先验证大世界框架；不能因现实守恒类比擅自禁止这条仙侠世界法则，也不能提前开放未实现的补气玩法。细则见[环境方案](../../docs/plans/world_environment.md#5-五行环境影响与可吸收灵气分开)。

同日追加边界：异类地面物铺开放，同类相容堆只算一份对外强度，数量账保留；五行逐通道max。冷热采用欧氏圆形场，热冷有效等级各取最大后抵消，再相对季节中性温度查表，不平均源摄氏值；等阶冰火对等，冷端温度下限不截断其抗热等级。室外逐格响应，室内按面积平均净等级、一房一温，火冰墙可作来源。原物本体与环境分开，移物后新建立/旧消散；人物/携物新增五行源暂缓。不逐格守恒热量，定向/聚光/反射后置。细则见[环境规范](../../docs/plans/world_environment.md#普通逸散与多来源换热)，当前代码未转换。

上述已确认部分约束后续实施，其余仍为推荐世界语法，不是全部境界或宗教的最终设定。允许真正的神迹和例外，但例外也须有可复验的作用范围、触发来源或隐藏条件；角色暂时不理解，不代表作者可以事后改口。

2026-11-03用户确认：大多数生命原则上有适合自身的修行路径；少数因当前先天身体/载体条件受限，可通过具体改造或迁载等途径改变。机会仍依方法、资源、经历与代价成立，不保证任何生命都能学会所有方法，也不把人形、同种灵根或固定职业作为全世界前提。具体比例、难度与成长曲线由开发验证。

“物资守恒”在本项目首先是账实一致，不要求所有超自然作用服从现实质量/能量守恒。允许法术产生新物质，但来源、成本或成立条件、持续/消散与实际影响须明确。便宜且可靠的造物若真的存在，应允许改变当地稀缺性和社会组织。

### 5.2 力量不均等，因果仍须一致

一只大妖可以远强于一村凡人；传世重宝可以改变地区格局；专家能轻易做到外行做不到的事。不要为竞技平衡抹平体量、知识和积累。

需要限制的是凭空复制资产、无条件全知、无成本重置失败、离场重掷和规则自相矛盾。非常有效的技巧可以保留：竞争者学习、材料涨价、消息传播、工序改造会自然改变处境。不是每个好办法都要偷偷加惩罚或刷一只更强的敌人。

凡人不必靠“每次攻击至少掉一血”证明有价值。强者也可能有完全成立的绝对防护；要说明防护的媒介和边界。对某个目标确实无能为力是允许的，但世界应仍有其他可生活、协作、迁居和改变条件的路径，不强迫每个角色单挑一切。

## 6. 众生为什么主动行动

先让有限决策产生有意义的生活，不声称几项权重就等同完整人类心理。

1. **维持处境**：感知身体/载体、居所、供给、安全和已承担职责中的紧迫问题。
2. **保留几个长短目标**：完成约定、恢复伤势、照料亲友、证明手艺、寻找失物、避开仇家等；并非人人同时追求财富与最强。
3. **从所知办法生成少量候选**：亲做、换方法、请求/雇人、等待、交换、欺骗、退让、迁移；不知道的办法不自动进入完美规划。
4. **比较处境中的收益和代价**：自己的把握、时间、资源、风险、关系、职责、价值偏好与其他方案。用惯性、承诺和重评条件避免每tick反复横跳。
5. **执行并更新认识**：结果可能与预期不同；他人也会拒绝、误会和改变主意。

性格是对待局面的稳定偏好，不是出生后永远锁定的职业AI。重诺者也会在濒死时违约，多疑者也可能相信多年同伴。变化需要经历和时间，不靠一次送礼把所有底线归零。

方法定义还须提供可用于有限规划的用途、效果与基础条件。NPC只从自己获知的办法、工具和合作者生成少量候选，允许估计失误、试探、求助与放弃；世界已支持一种组合，不代表每个NPC自动知道它。诊断要能显示为什么没想到、没选或没做成。

随机只放在确有不确定性的环节：感知噪声、行动精度、无法完全掌握的对方反应。先检查可行性，再判结果；既不以一骰跨越身体极限，也不让熟练的日常动作每次都赌命。同一未改变条件的交涉不会靠无限点击重新摇出成功。

选项不应只显示“成功/失败”。拒绝可能带出条件、替代人选、延期、部分帮助；试验可能留下副作用、笔记或改良线索。前台反馈人物能知道的理由，后台保留因果诊断供开发验收。

## 7. 组织也不是固定阵营面板

组织依赖资产、场所、劳动者、知识、职位、承认与强制力。外部看似一体，内部仍有利益、派别、忠诚和信息差。谁做了决定、谁保管记录、谁能动用实物要分别可追踪。

贡献归负责机构的账本；人情在具体人的经历里；名声在接收者听过的传闻里；礼数由场合与当地习惯产生。它们可以互相影响，但不能自由兑换，更不是全世界统一流通的代币。

银行式比喻适用于贡献等可记账的权利，不宜把友情、亲情、文化认同都做成可转卖证券。老人坐化后，新掌门可以保留客套、限制通行、审核旧账；老人的弟子也可能私下继续帮忙。政策改变与个人态度可以冲突。

妖族、凡人聚落、宗门和商队可以承认不同的物权、领地与誓言。没有一个“宇宙合法性数值”替所有人裁判对错；社会争议可能一直未解决，实际执行仍需要成员与能力。

## 8. 用共同局面验证多种活法

### 8.1 从一间屋檐接到整个天下

世界内容按相互依赖的生活圈建立，而不是依等级依次换练级地图：

| 尺度 | 应当存在什么 | 如何连接其他尺度 |
|---|---|---|
| 居所与街巷 | 做饭、买卖、休养、嬉游、邻里、修补、习惯与私事 | 食物和燃料来自别处；收货、拜访、婚丧、传话让地方与外界相连 |
| 河谷与一山一宗 | 农田、林地、药圃、水源、作坊、道路、野生群落、洞府 | 供给、劳动、领地和保护关系互相依靠；妖与人共享或争夺栖地 |
| 地区与人间秩序 | 集市、商路、迁居、家族、地方官署/自治组织、多个门派 | 税费、救济、贸易、学艺、避难、争端与文化传播带来流动 |
| 长寿者的社会 | 跨代师承、旧约、托付、长眠、失传、高手之间的牵制 | 普通人的一生会改变长期计划；老友的后人不自动继承感情和信任 |
| 异常之地与更广天地 | 不同生态、身体、语言、时间/灵机条件与古老遗存 | 异域不是高等级同款怪物区；进入、适应、交流与带回方法各有条件 |

这些是目标层次，不一次生成全部内容。先让局部供给与人际相接，再接地区；罕见强者、异族或异常遗物若已经进入局部，就必须承担它们带来的因果，不能只当未开放地图的广告。

用户已确认术法会因资源、知识与权力在各地形成不同普及程度。御火、储物、传音、疗伤和长寿若便宜可靠，就应真实影响作坊、道路、消息、医疗、人口与制度；不能只为保留传统职业而假设无人采用。成本、维护、适配、保密和控制权可以阻碍传播，但须在当地条件中成立。

### 8.2 凡间生活有自己的价值

凡人可以关心孩子与徒弟、口味、审美、屋宅、手艺、家乡、节日、信仰、名誉和邻里，并不以“尽快进入修仙主线”解释每次行动。修士也可以爱戏曲、养花、记账、做饭、照料朋友或研究没有杀伤力的方法。

不同社会承认不同的好生活：某地敬重守约的渡夫，某派看重清修，另一地尊敬带回新种子的旅者。仪式、作品与纪念物可以承载经历；不必都给予生产效率加成才有价值，也不靠统一幸福总分给人生排名。

种族、文化和生理分开设计。同种妖族可有不同家园与生活方式；人类组织可欢迎、排斥或依赖特定异类，成员还可有自己的意见。食物、称谓、礼节、居所、交流渠道与禁忌足以先形成差异，不用一次铺满族谱和几百个文化数值。

### 8.3 一个地方的内容档案

每个新增地点至少写出：

1. 地理与季候，哪些环境变化会影响生活。
2. 食物、水、燃料、材料/灵机来源，主要去向与消耗。
3. 居民与非居民，活动范围、语言/交流与栖地关系。
4. 生产、服务与闲暇场所，谁能用、谁维护、谁喜欢。
5. 正式权利与实际控制，成员如何承认、执行或违反规则。
6. 目前可影响选择的短缺、愿望、争议或未解之事；安稳地方也可有探索与创作机会。
7. 对外道路、消息、迁徙与交换渠道。
8. 近期有来源的变化，以及通过什么痕迹让来客察觉。
9. 玩家以几种不同身体/身份到达时，能靠什么生活和与谁建立关系。

人物内容则先写“处境、在意的事、经历、所知/误信、办法、关系、不可轻易放弃的东西”。只有行动需要才补数值和专门定义；这些描述为AI选行动提供约束与目的，不直接变成全知的叙事指令。

### 8.4 边角料怎样进入世界

一把木梳既可以梳发，也有材质、刻痕、持有人与来历；可能被送人、修补、典当或作为某人认物的线索。不是每把梳子都绑定惊天秘宝，也不因玩家拿起就自动生成传奇任务。

屋檐鸟鸣、作坊烟气、修好的桥、换了招牌的店、没人打扫的院落，应尽量来自活动、过程或状态的呈现。风景可以纯粹美丽；一旦玩家尝试使用它，给出符合其结构与世界条件的结果，不让能被看见的物体永远只是无响应贴图。

首次内容制作只为已支持作用声明清晰入口；不支持的交互如实说明。保留材质、归属和环境事实，日后增加规则时能继续使用旧物，而不是每扩一次玩法就把全部世界内容重写。

### 8.5 同一场局势，多种解法

建议首个世界样本叫“断桥、寒潮与旧炉”。河谷寒潮将至，桥坏后药材与粮食运输受阻。宗门库房有限，旧炉带有未理解的封存功能；鸟妖在桥头屋檐下筑巢，山外巨兽正在寻找越冬地。一份收货凭证存在争议，戒中寄魂者知道旧炉的一部分历史。

这不是每局强制刷出的完整任务链，而是一份用于检验共同规则的初始条件。人物依据供给、认识、关系和能力采取行动，局面可以被彻底改变，甚至无人修桥而改走别的生活。

| 可能的选择 | 需要成立的因果 | 会留下什么 |
|---|---|---|
| 护送者清出绕行道路 | 侦察、威胁、地形、供给和合作 | 新路线、伤势、报酬、被打扰者的反应 |
| 匠人搭临时索道 | 材料/受力/锚点、安装劳动与运输条件 | 索道本体、维护、收费权与其他人的使用 |
| 鸟妖带回小药包 | 体积/重量/天气、识路与交货渠道 | 实际到货、见证、报酬和鸟妖自己的食宿 |
| 商人调换供应 | 已知价格、库存、承诺与真实运力 | 新合同、市场依赖、赢家与受损者 |
| 《骗经》修士冒充使者 | 可见身份线索、守卫认知与核验方式 | 暂时放行、留下的伪证、延迟查证与追索 |
| 寄魂者以旧图交换修复 | 老人真的知道、愿意教；别人愿意兑现 | 协议、载体修复、知识传播与后续纠纷 |
| 巨兽与村人交换栖地 | 巨兽能表达/展示；双方有可供交换的东西 | 碾出的便道、粮耗、栖地、敬畏或敌意 |
| 工法创造者改进保温 | 已有作用、材料与试验，确有减少损耗 | 方法版本、工艺传播、利益与新的使用风险 |

不为每一行单独写“任务完成”捷径。应验证其中一项做法也能用于另一地点、另一人物或另一个目标。

## 9. 十个“这样也行？”的验收种子

这些是待实现测试，不是当前游戏功能。详细知识/法器规则见配套文档。

1. **打不过，先修屋顶**：替药师挡雨救下药材，换到治疗与介绍；没有战斗经验奖励也完成目标。雨停、药材状态和药师是否知道帮助来自谁分别成立。
2. **麻雀不举剑也能入局**：通过狭缝发现账页缺失，选择传递消息或换巢位；不能凭观察自动懂文字，需学过、记图或求译。
3. **低修为识破高阶赝品**：凡人工匠辨出错误铸痕，高阶修士仍可能不信；事实、信服和正式认定不是一步。
4. **仙器拿来保温**：在已确认安全档位下，旧炉持续温养药材；因此要付燃料或灵机、遮热和看守，不是战斗宝物只能砸人。
5. **骗子骗得人，不一定骗得法器**：伪装使者能骗守门人；核验印契的法器仍按绑定规则拒绝。另寻钥印、内应或离开，不能再掷一次魅力自动过关。
6. **戒中老人也会跳槽**：持有者违约，老人撤回指导并请求新合作者；转移戒指改变保管方，不自动解除封印或抹掉旧关系。
7. **巨兽不是大型人形模型**：在山口与商队谈出互助，选择拉走倒木；实际占地和负载改变通行，不能穿过民居只展示大贴图。
8. **失败的术法变成手艺**：没有成为好用的火弹，却能稳定缓慢供热；重新试验后成为染坊工序，原来的不稳定缺陷依然记录。
9. **强者不出剑也改变局势**：愿意在商路暂住，令知情劫匪改道；消息没传到的团伙不会凭空敬畏，强者也不自动获得道路所有权。
10. **离开后，发明不属于静止的橱窗**：学徒改进方法、商家购买或仿制、材料需求变化；回程能看见实际发生过的痕迹，未获知的人仍不知道源头。

## 10. 时间、远方和细节如何承载世界感

### 10.1 同一条时间线，不同精度

沿用已有双聚落连续性，逐步扩展共同提交点、稳定ID、在途状态与延迟消息。近处细算移动与接触，远处推进有条件的过程；材料耗尽、风险发生、消息抵达、关键人物改意都结束批算区间。玩家位置不决定世界是否拥有时间。

粗算必须保留会改变可行性的条件：麻雀不能跨越已知致命风带，巨兽不能走不承重的桥，寄魂者不能离开封印范围。结果不必复刻每一条实时轨迹，但不能让远近两种模式授予不同的物理或社会特权。

用户选择日常亲历与主动快进并存，可跨年。长行动保留预计终点、已发生投入、维持条件和可感知的打断渠道；推进到重要收讯或近身危险的提交边界再交回操作。远方秘密灾难不能因后台发生就自动让主角知道；消息未到、感官未察觉时不提前泄漏。具体节奏与时刻单位由P0试验确定。

尚未实现粗算的领域，先沿用可用的细算或限制可模拟规模；不能把离场冻结包装成已经完成的世界运转，也不能用一句“算法结算”跳过定义与验证。

### 10.2 看不见的细节也有位置，但无需全都逐帧演算

- **已建立联系的个体与物品**：稳定ID、状态、归属与重要经历持久化；再见仍是同一个。
- **背景群落与区域过程**：保留群落数量、可用资源、压力、迁移方向和关键变化；不为每根草建节点。
- **接触时细化**：从已存地区条件与确定种子生成尚未确定的具体细节；扣除对应群体或资源份额，不能额外复制。
- **过去已经约束的事实**：人物死亡、传出的消息、签发的凭据、见过的外观与路线不可重抽。新细节不能事后伪造导致既有结果成立的关键事件。

历史可以压缩，责任不能消失。至少保留未结合同、长期关系、争议、关键物权、方法来历与重大地理变化；日常步伐不用永久存日志。

### 10.3 世界不应为了热闹围着玩家起舞

事件呈现可以帮助玩家发现世界已有的矛盾和机会，也可以生成来源明确的天气、访客或生态扰动；不得为了戏剧节奏捏造无来源的军队或没发生过的旧交。某处暂时安稳、某人不想搭理玩家、某条大事与玩家无关，都是允许的。

### 10.4 一段人生结束，世界继续

玩家主要扮演一名角色。2026-11-03用户进一步确定：以有限重生机会从随机提供的跨种族新生人选接续，世界不回滚，可小幅向前跳时；高难度次数更少，机会耗尽结束本局，当前不设计补充机会的渠道。刷新、自选和升稀有度可以设计，但须防人口淘汰、定向繁育与重复自杀把候选变成免费极品保底。

规则详见[有限重生与新生候选](rebirth_and_new_lives.md)。旧身体死亡、遗物、职位、债务与未结事务仍在世界中；新生命有真实来源、身体成长与照护条件，不直接复制旧身体战力或正式权利。主角是否保留及保留多少跨生记忆仍属具体方案，即使保留也不让其他人物自动认出、信任或承认新身份。退隐不提供免费换人旁路，机会耗尽后没有无限普通新人接续。

普通存读与重生分开，不由此擅自加入铁人或跨存档扣次。新生候选来自有来源的入生机会，未选者仍进入世界；随机档位与有限搜索范围不按幸存者重新归一，不能靠删除其他幼体将极品概率推成必出。具体生命周期、随机与无候选边界须实现后通过对抗测试，不能只凭设计宣称无漏洞。

## 11. 玩家怎样看懂而不被百科淹没

默认展示当前身体/载体、眼前环境、自己知道的事与正在承担的事务。按行动呈现相关条件：搬运看体积/重量与抓持，读书看文字/媒介，交涉看对象和已知来历，修炼看适配、步骤与风险。需要时可以打开准确细项，没有全体众生统一的战力大面板。

感知不到、看不懂、没调查与此刻不关心分开。阅历带来的是领域方法和解释基础，不是统一鉴定等级；关注只调整默认重点。武学大家可看到已知的高级武用功能，普通衣食默认简述；准备远行、受伤或主动调查时仍可认真了解生活用途。详细规则见[人物视角](perception_and_understanding.md)，排序/比较/报价与拒绝理由也遵守同一知识边界。

交互入口分为“眼前可做”“已知可试但缺条件”“还不知道”。身体真实做不到的选项说明原因；隐藏功能不能提前泄露完整名字。提供观察、询问、请求示范、低功率试验、提出交换等发现办法。

反馈区分“我做了什么”“我看到了什么”“我推测了什么”。失败不暴露NPC全部动机或物品全部隐藏参数。危险往往能通过热、鸣声、裂纹、前人警告等察觉；已知足以摧毁角色的风险需要明确提示，未知危险应有逐步探查的机会。

不同身体可以有不同操作呈现；鸟妖能方便选择高处落点，巨兽能查看身体占地与转向，寄魂者主要处理载体附近感知、传意和协商。共用世界规则不等于强迫共用所有按钮。

## 12. 对原设计的修订

| 原有说法 | 现在如何理解 |
|---|---|
| 一人一身体一背包 | 现有人形Demo的简化；真正不变量是身份、承载/控制关系、实物位置和执行责任不重复 |
| 六个衣着位置、四个招式键、四点心神 | 首个人形动作原型的候选，不是生命本质；适用形态、方法与界面各自定义 |
| 40个学习节点与三境界 | 人类入门内容候选；知识可发现、分叉、失传、创造，其他生命可有不同路径 |
| 先建造、完整战斗，再谈其他生命 | 保留时间/存档/资源基础，提前用非人主体、器物认知和跨域解法检验架构 |
| 角色扮演是职业标签 | 生活目标、身体处境、所知、关系与经历共同产生可玩差异 |
| 不平衡一定要修掉 | 先修因果矛盾和死循环；有效而强大的方法可保留，数值平衡由试玩再定 |

这是对后续目标的修订，不宣称现有代码已改。已有日常、信息、账本、互助和远区连续性继续复用，不清空项目重写。

## 13. 世界方案的完成标准

一次小型构建应至少证明：

- 同一局面有三种跨领域解决路径，至少一种不以战斗、刷经验或经营据点为前置。
- 人类与至少一种非人形主体因身体/载体差异有不同但成立的生活；切换身份不复制世界。
- 物品认知、功能、使用能力与承受风险可分别不同；NPC也受这些约束。
- 一名NPC能因自己的短缺或目标使用同一批规则行动，既可能帮助也可能妨碍玩家。
- 一个新组合可迁移到第二处情境；设计者不为每个解法另写完成开关。
- 离场、归来、保存、恢复后物资、身份、知识边界与后果连续；不能靠离场清除麻烦。
- 玩家能从痕迹、当事人和记录了解关键变化，不必读后台真值才知道发生了什么。

其余规模、种族数量、境界名和天赋图大小都不替代这组证明。旧的[共同世界工作包](../../docs/plans/world_first_sandbox.md)保留最小规则的设计思路；现行顺序和授权见[执行计划](../../docs/plans/world_engine_execution.md)与[HANDOFF](../../docs/HANDOFF.md)。
