# ACT、弹幕与共同世界

近战武器强调ACT，远程武器强调弹幕；直接操作、鼠标瞄准、连招与技能发生在同一个持续世界。当前框架完成到P4，下一阶段尚未施工。

- [公共行动与作用](action_effect_framework.md)：战斗、工具与生活共享的协议，以及配置/机制/专用脚本的扩展方式。
- [可玩能力](../../docs/status/features.md)、[验证与构建](../../docs/status/baseline.md)、[下一阶段候选](../../docs/plans/foundation-priorities.md)。
- [参考来源](../research/act_barrage_references.md)、[编辑器与能力架构研究](../research/action_editor_references.md)。

战斗只是世界中的一种行动方式，生活、修行、创造与交往仍有独立价值。[已确认规则](../rules/README.md)定义产品方向；小队指挥、投降/救援、持久伤势、完整身体/功法差异等仍为长期候选，当前程序没有因此获得这些功能。旧三份战斗提案中的点击操作、通用治疗排序和资源假设已由当前合同替代，历史由Git追溯。
