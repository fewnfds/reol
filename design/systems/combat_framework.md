# 行动战斗：招式、处境与共同世界

成文：2026-11-02。本文是战斗目标设计；现有样本与完整能力边界见[FEATURES](../../docs/FEATURES.md)，验证见[BASELINE](../../docs/BASELINE.md)，当前授权见[HANDOFF](../../docs/HANDOFF.md)。

[世界总纲](self_consistent_world.md)与[众生](beings_and_lifeways.md)优先；以下身体、防护、准备资源与按键是人形原型建议，不是全体生命的面板或当前全部操作。允许力量悬殊与有机制的绝对防护。学习见[修行与学习](cultivation_and_learning.md)，穿戴见[衣着与物品](appearance_and_possessions.md)，细化工作包见[人物计划](../../docs/plans/combat_character_design.md)。

[最新交互原则](world_interaction_principles.md)补充玩家自动策略与下属命令：计划受本人所知、通信、控制与社会承诺约束。玩家策略编辑/运行器尚未实现，不能把现有对练NPC的有限接近AI当作可编程战斗交付。

## 1. 战斗在整个游戏里的位置

玩家可以成为擅长打斗的人，也可以以医术、生产、经营、关系和组织能力立足。战斗提供可学习、可协作、可避开的手段；不能把全部人生目标最终都结算成攻击力。

理想体验：看见敌人抬手，判断距离和退路，用一步侧移躲过重击；同伴护住伤员，自己以束缚术截住追兵；也可以事先雇护卫、交易通行或放弃货物。熟悉的招式、对局面的判断和准备形成差别。没有战斗专长的人仍有推开、躲避、求救、弃重物、退让与投降的动作。

四组参考分别取用：Hades的即时移动和动作衔接，DNF的招式关系与连招表达，LoL的技能识别/射程/施放承诺，Warcraft III的小队意图和战场层次。固定视角仍为正交俯视；不改成DNF横向纵深格斗，不加入竞技MOBA经济，也不让玩家每秒指挥全宗门。研究依据与推导边界见[一手参考](../research/combat_and_character_references.md)。

战斗状态属于原世界中的人物和事务。拔剑不会创建一个暂停城镇生活的独立副本；胜利不会把敌人全宗资产自动转给玩家。

## 2. 实力从哪里来

不存一项统治所有玩法的“战力”，也不规定“功法占60%、装备占20%”的固定份额。下面是能力的不同来源，实际贡献由具体动作决定。

| 来源 | 实际改变什么 | 不能替代什么 |
|---|---|---|
| 身体与健康 | 发力、负重、反应、行动范围、伤后限制 | 好身体不能自动会剑术、辨药或管账 |
| 境界与修炼根基 | 灵力储备/运转、可承载功法、某些新的行动方式 | 高境界不自动获得所有术法、政治权限与他人忠诚 |
| 功法及运转方式 | 恢复方式、护持、引导、擅长与代价 | 一本秘笈放包里不等于已练成 |
| 学会的招式/术法 | 明确的攻防、移动、控制、援助动作 | 穿同一套衣服不能复制对方本领 |
| 熟练与心得 | 执行稳定性、衔接选择、对特定招式的理解 | 杀人数量不能兑换全部学问 |
| 当下准备与处境 | 体力、灵力、伤势、距离、朝向、掩护、侦察、伙伴配合 | 用优势地形不等于永久加了人物属性 |
| 工具、兵器与法器 | 作用媒介、长度/质量/锋刃、防护覆盖、特殊功能 | 普通发簪、鞋、项链不普遍贡献攻击/暴击乘区 |
| 情报与协作 | 能否先察觉、打断、诱敌、分担风险和救援 | 组织尊敬不能让所有成员无条件赴死 |

器物允许很有力量。借来一件护山法器可以暂时改变战局，得到好兵器也能获得明显优势；它有来源、用途、操控条件、维护和损失风险。不为了保证人物属性至上，把宝物做得毫无作用；也不让八件普通服饰叠出来的统一数值取代人的修行。

境界差距需要可感知：高阶可能具备更长作用距离、持续护持、飞行或驱使法器；差距通过动作规则、资源和效果表现。首版不采用“跨境界所有攻击自动无效”的万能免疫。遇到暂不能对抗者，可侦察、逃离、借助守备/阵地、谈判或换目标；普通劳作和经营不要求先击败地区最强者。

## 3. 操作与指令

推荐一套主角直接操作＋可暂停小队指令。以下是未来输入映射，不是当前代码已具备的按键。

| 输入 | 现场默认意图 | 边界 |
|---|---|---|
| WASD | 主角移动 | 受地形、负重、动作承诺和身体状态约束 |
| 鼠标指向 | 朝向/瞄准/地点目标预览 | 瞄准方向与人物脚底位置分开 |
| 左键 | 平时选中；应战状态基础攻击 | 应战状态Alt＋左键仍可选中人物；点击UI不能误攻击 |
| 右键 | 应战状态架势动作，如格挡或蓄势 | 当前准备的一种基本变化，不自动拥有所有武器技巧 |
| Q/E/R/F | 四个准备好的招式/术法 | 是易操作的快捷准备，不是最多只能学四招；生活本领另有情境入口 |
| Shift | 当前身法/闪避动作 | 普通人有有限避让；进阶身法需学习，不默认无限穿人穿墙 |
| Space | 全世界暂停/继续 | 可观察和下令，不发生攻击、移动或资源恢复 |
| V | 改变应战/收势操作状态 | 改控制映射与意图，不创建或结束世界冲突 |
| G | 当地情境交互 | 行医、取物、交谈等依合法目标和条件执行 |
| Tab/小队栏 | 选择队友并发布有限指令 | 权限与合作约定仍成立，不变成随意操纵陌生人 |
| I / K | 物品穿戴 / 修行图 | 默认查看不暂停；可使用Space先暂停。受威胁时不能无耗时换装/重配 |

选中陌生人不立即攻击；主动对中立者用武需要先明确敌对意图，再正常操作，不逐次弹窗。被袭、护卫责任或已知敌对目标可直接应对。故意敌对、误伤、目击与合法自卫是世界判断的问题，不用按钮替玩家宣告“全世界都认可此战合法”。

普通攻击可以三段衔接，但不要求敲长串方向键。按住连击与逐次输入可在辅助设置中选择；短输入缓冲帮助正常衔接，不能排队十秒的自动连招。方向、技能取消与移动辅助可调，不能在隐藏规则中自动替玩家躲掉危险。

小队首批命令：跟随、守位、攻击指定目标、保护指定人物、撤到标记点、停止追击。战斗前可约定自主用药/施法/撤退条件。成员优先保命、遵守约定和完成命令；明显超约定风险可以提出异议。不是每次普通攻击都先做社会骰判，指令接受也不保证路径或资源足够。

V只改操作映射，不免费拔剑、收鞘、卸下药箱或腾出双手。第一次出招若需拔取武器，必须完成相应收放动作；恢复搬运/救治也要满足持物与手部占用，不能切个模式让工具自动回仓。

## 4. 一个动作怎样发生

每个动作实例有稳定ID、执行者、目标/方向、开始时刻、阶段、成本、命中记录和结束原因。流程为：

```text
提出意图 → 检查已知可选条件 → 执行时复核真值/取得执行权
  → 准备/前摇 → 作用阶段 → 收势/后摇 → 完成
                ↘ 被打断/取消/目标失效 → 明确清理与后果
```

### 4.1 阶段与承诺

- **准备**：确认可用身体、手段、灵力/体力、目标政策、距离/地点和导航。错误输入不扣费，不能用隐藏对象状态给出泄密错误。
- **前摇**：有可见动作，部分招式允许小幅转向，随后锁定朝向。敌人不能最后一帧瞬间180度追踪玩家。
- **作用**：产生接触、飞行物、范围或持续效果。每个命中对象/作用脉冲最多结算一次。
- **后摇**：暴露机会成本。可取消的阶段和可取消到的动作是显式定义，不是所有招式都可免费闪避取消。
- **结束**：完成、打断、失败或死亡。清理执行权与预约，已经发出的箭/术法按自身生命周期继续，不因施法者收手而自动消失。

每种动作需要定义：手持条件、目标类型、距离/形状、移动/转向允许、阶段时间、提交成本时点、取消窗口、打断等级、控制效果、友伤政策、声音/可见线索、冷却组以及离场执行方式。定义进入未来数据文件，不写入动画方法名作为规则。

### 4.2 成本与取消

体力通常在发力开始时支付；持续格挡/引导按有效持续时间付费；灵力在成术或各脉冲的明示时点消耗。高成本术式可以先付小量准备成本，再付成术成本。

取消不会退还已经付出的发力/准备消耗。尚未提交的阶段不扣后续成本。投掷物在实际发出时离开原容器，符纸在指定施放阶段实际消耗；失败清理不能既退符纸又保留飞行效果。冷却从明示提交时点开始，被打断不默认为完全免冷却。

人物的移动、操物、表达、注意等通道按实际能力和占用裁决：冲突的占用不能被两个执行器重复使用，但不冲突的活动可并行。例如运粮与挥剑若争用同一只手或互斥动作就需中断或调整，已经搬着的货物和可续用进度仍保留；停止追击后回原职责也需要实际移动和条件复核。

### 4.3 同刻顺序与输入持久化

首版采用固定阶段语义：到期/到达和消息先提交，持续效果使用`[开始,结束)`的有效区间；随后接纳命令/阶段成本、推进本阶段移动、按同一阶段快照收集接触效果，再汇总施加健康/资源/控制变化，最后处理倒地/死亡/中断清理和观察。具体固定步实现由P0试验决定，不能由字典遍历顺序决定谁永远抢先。

同阶段已经成立的互相命中可同时结算；已发射飞行物不因施法者同刻倒地被回滚。普通治疗与伤害按该阶段汇总后再判倒地，明确致命/不可逆事件有自己的可见优先规则。精准格挡、无敌或护持只在有效区间内参与这一阶段，不能靠显示帧的先后获得额外生效时间。

已经受理的待执行意图与短缓冲保存为世界命令：序号、目标/方向、最早执行时刻、到期时刻和取消标记。存读后至多执行一次，不能重新延长缓冲。未提交的鼠标悬停/预览不存为命令；恢复时不读取仍按住的旧鼠标状态补发上一次攻击。随机上下文按稳定事件/效果标识隔离，粒子创建和UI刷新不消耗规则随机数。

## 5. 走位、命中与防御

### 5.1 接触先于随机

现场近战先采用平面几何：弧、线段/胶囊或扇区；直线飞行物沿路径做连续扫掠，避免高速穿过身体和墙体。范围术有地点、边界与生效时刻。画面斩痕、危险线和实际命中区域必须一致；以后若恢复高度或飞行玩法，再定义相应资格和连接。

人真正走出了范围，就不命中；已被真实攻击覆盖，不能再用一个隐藏“闪避率”使其无理由落空。随机留给有不确定意义的伤势差异、器物失控、认知或不精确远战，不能用暴击骰替代现场反应。首版先不做随机暴击、随机命中和装备暴击词条。

身法是受限移动。起步、可避开的作用种类、距离和落点规则明确；是否短暂避开特定攻击由已学本领定义。普通踏步没有通用无敌时间，不能躲开持续火场、毒气、封死的墙和无法到达的落点。若进阶功法提供化虚等特例，必须说明何时、对何物、付何代价。

### 5.2 防御有选择

| 防御 | 优势 | 代价与克制 |
|---|---|---|
| 移动/掩体 | 不消耗专门技能也能避开 | 需要位置和察觉；被包围时选择少 |
| 格挡/招架 | 保持近身阵位，保护后方 | 方向/手段要求，消耗体力/稳定；不能无视背袭和范围火场 |
| 精准招架 | 短时窗换取明显反击机会 | 需本领与判断，失败承担原攻击；普通格挡仍有用 |
| 护持/结界 | 保护自己或同伴，克制指定作用 | 灵力/心神、覆盖范围、持续成本；不是一层万用护盾 |
| 轻装身法 | 位移灵活，便于脱离 | 直接接触时防护较少；反复闪避会耗尽体力 |
| 材料防护 | 对覆盖部位及适用作用提供实际缓冲 | 负重、活动/环境限制、维护；普通衣与专门防具区别明确 |
| 撤退/投降/求援 | 结束不值得承受的交战 | 可能失货、被追、欠情或受约束，不能免费瞬移脱战 |

姿态稳定是动作局部状态：格挡、重击、推撞与立足地形影响它；失稳可打断或短暂暴露。不把姿态再造成人物永久可刷的第四条经验资源。

### 5.3 伤害与伤势

初期只区分能改变应对的几类作用：斩刺、钝击、灼烧、束缚/冲击和专门灵性作用。不是五类都各配一排全民必须堆满的百分比抗性。

原型计算可按以下有界结构起步：

```text
动作作用量 = 此招的基础效力 × 熟练执行系数 × 当前状态系数 × 接触系数
实际健康损失 = 作用量经过适用的格挡、覆盖防护和护持规则处理
失稳/移动/燃烧等后果由各自定义结算，不一律从健康伤害反推
```

系数范围与防护曲线须由少量对局校准。普通剑的锋刃、长度和质量参与相应动作效力与形状；不再额外把鞋帽项链的统一攻击百分比乘进去。多个增幅按来源分组并限制叠加，关键节点改动作行为；不能无上限相乘。

健康减少反映受损，严重受击/特定阈值形成少量伤势类别，影响发力、移动或运转，并需要休息/医护。不逐击模拟几十个器官，不把每次擦伤都升级成长时间不能玩的残疾。健康为零通常倒地；死亡来自致命攻击、持续伤害、失救或明确处决条件。是否下杀手是交战意图与具体行动，不是统一杀光。

死亡的遗体、背包、借用装备、职位、债务、承诺和目击分开处理；医者不会仅因能打就自动懂救治，治疗也不能通过换衣或重新装备触发。

## 6. 资源：短时应对与长期生活

| 状态 | 功能 | 恢复与限制 |
|---|---|---|
| 健康与伤势 | 承受损害和身体可用性 | 止血/治疗/修养；离战不瞬间恢复所有持久伤势 |
| 体力 `stamina` | 发力、冲刺、招架、负重下的短时动作 | 平缓行动和不发力时恢复；短时耗尽可退让，不自动昏睡 |
| 灵力 `qi` | 施术、运器、护持、功法运转 | 由功法/调息/真实消耗品恢复；有些人没有可用灵力也能生活 |
| 精力 `energy` | 长时疲劳、睡眠和持续生活 | 饮食休息与安全安排；影响恢复和可持续工作，不对每次挥剑重复扣同一成本 |
| 姿态稳定 | 当下站稳、招架与承压 | 战斗局部恢复；不作为全身装备凑分门槛 |
| 心神占用 | 同时维持功法/术法/御器的注意负担 | 规则见修行页；限制同时运转，不限制已经学过的知识总数 |

疲劳不能让玩家每打一剑同时损失三条同义体力。普通招式以短时体力计费，长期精力通过整段活动与休息规律结算。极度疲劳或负伤时给明确预警及可行动的退路。

## 7. 招式组合，开放但不无限连控

连招由招式的准备、作用、后摇、位移、失稳和对手回应形成：试探→格挡引诱→重击破势→短追击，是成立的战术；把十个技能轮流按到敌人永远不能动，不是首版目标。

- 默认三段基础攻击各有不同距离/方向/时序；可提前停手，末段不保证一定最优。
- 专门招式有少量明确衔接点，例如踏步后改一次近身斩，招架成功后开放短反击，束缚后便于施术但不保证持续锁死。
- 硬控制连续命中提高短时抗控/脱离保护；轻微打断不无限延长同一后摇。持续束缚允许挣脱、破阵或同伴帮助。首批控制集合只有短硬直、减速/束缚、击退和倒地；浮空无限追打后置。
- 公共冷却不覆盖所有动作；按招式/冷却组/动作阶段约束，避免所有按钮亮着却全被一个隐藏全局CD阻止。
- 暂停期间可以改目标与待执行的一项意图，不能修复装备、缩冷却、免费更换整套功法和恢复资源。

### 7.1 首内容集：十种动作定义

以下是用于原型验证的最小动作库，名称是玩法标签，可因学习路线与媒介有不同演出。不是所有开局自动获赠。

| 动作 | 类型/目的 | 可改变处境的特点 | 生活或非杀伤联系 |
|---|---|---|---|
| 基础击/推离 | 基本身体动作 | 近身短作用；武器版本依持物与训练 | 推开威胁、非致命比试 |
| 踏步 | 基础/学习可改进 | 短位移、需要落点，不穿墙 | 越开障碍，搬运仍受负重 |
| 招架 | 防守架势 | 朝向格挡，精准时点可反击 | 护卫他人；不能代替合法护送约定 |
| 破势 | 重击/钝击 | 前摇较长、打稳定、落空暴露 | 破门需材质/权限与破坏后果 |
| 飞针/短投 | 真实投掷媒介 | 有速度、阻挡和弹药，不自动追踪 | 工具用途不自动等于医术 |
| 引火 | 定点/小范围术 | 地点预警、持续区域，需明确安全范围 | 点火、加工；野外可引发实际火害边界，首版只支持有定义目标 |
| 缚足 | 控制术 | 减速/短束缚，可破离，不无穷叠加 | 捕获、阻止追击，区别于伤害招式 |
| 护持 | 防御/援助 | 朝向或小范围保护，持续占灵力与心神 | 护人作业、掩护搬救 |
| 急救 | 医护行动 | 需要距离、时间与材料，受干扰 | 救命/稳定伤员；不是瞬发无限加血 |
| 御器牵引 | 进阶手段 | 有器物、路径/操控条件、载重与心神 | 搬取小物、隔险作业；不是免费全图取货 |

先验证基础击/推离、踏步、招架、破势四种；再加投射、引火/缚足、护持/急救，最后接御器。首版不同时制作十套武器动作和上百招式。

### 7.2 原型调参起点

这张表只表达手感量级，参数进入未来数据定义后再调。不是从参考游戏复制的数值，也不是Godot当前实现。

| 项 | 建议起点 | 验证问题 |
|---|---|---|
| 一次普通近身动作 | 总约0.45–0.70世界秒 | 看得懂出手，按住不必极限点击；仍能被合理反击 |
| 重击 | 总约0.9–1.3世界秒，主要前摇至少0.35秒 | 有时间识别和闪避，落空有代价 |
| 普通踏步 | 位移约0.25–0.40世界秒 | 不穿墙、不连续无代价躲避；相机不晃到看不清 |
| 短输入缓冲 | 约0.12世界秒 | 不吃正常输入；过期和取消动作不误发 |
| 硬直 | 常见短控制约0.15–0.45世界秒 | 反馈明显，连续控制仍有应对；具体抗控规则单独定义 |
| 法术冷却 | 少量约2–8世界秒 | 除冷却还有站位/资源/读招，不成为等按钮游戏 |
| 基础资源标尺 | 健康/体力/灵力暂按100单位方便测量 | 普通人灵力可为0；不以此推断所有人完全同质 |

打击停顿推荐先做人物表现层的40–60毫秒冲击停帧/残影；规则时间与远方仍正常推进，不利用停帧延长无敌或偷冷却。若原型发现需要真正全局短暂停顿，应单列设计、所有领域一起暂停；不偷偷只停敌人。

## 8. 地形、视野、友伤与高度

首轮新世界采用平面地块，真实位置/格子和纸娃娃绘制偏移分别计算。既有样本中的`elevation`与`altitude`保留以兼容历史；不因此把高低差/飞行算法作为新世界引擎前置。更换高帽、披风、飞剑贴图不增加真实射程或改变命中身体。

未来飞行若恢复规划，低空不是所有地面威胁的免疫，远程和范围作用的高度判定须另定义；飞行需要本领/器物、起落点、负重和消耗。不在未实现可保存地形破坏前开放全屏摧城。

物理飞行物和环境危险默认有真实阻挡及误伤可能，不能穿过队友却只碰敌人。明知友军挡线时默认提示/避免发射，发射后他人走入路径仍可能受伤；同伴AI尝试避开已察觉火线。大范围攻击预览标出已知友军/中立者风险，玩家需先表达危险/敌对意图，但不逐击弹确认框。

近战弧、穿刺、扫击和推离同样区分“允许提出的目标”与“实际身体接触”。默认有物理作用的危险攻击在提交后可碰及友军/中立者，不能因阵营标签自动穿过他们；明显已知的友军挡位在准备阶段触发停手/改位提示，已进入作用阶段不靠隐形过滤删除误伤。非致命推离的具体伤害/失稳按动作定义，同意切磋也仍需约束招式和停止条件。AI与玩家共享此规则，辨友术式才采用明确的过滤特例。

正式身体/衣饰动画需要真八方向，并保持身体左右与逐向遮挡；刀弧、持物朝向和施法线按真实连续瞄准方向表达，不能朝东挥剑却在东北方向无提示命中。当前代码占位不等于完整八方向资源已完成。

若某术法能辨友，是它自己的已学能力/结界条件与代价，不是所有法术免费具有的底层优惠。首期可先用低误伤场景验证，不用误杀路人来强制制造故事。辅助难度如降低友伤必须明示，不能用隐藏改变让玩家无法理解。

AI只对已察觉人物、声音、施法线索和收到命令作反应；不读取主角尚未提交的按键、不隔墙瞬时全知。仇恨不是从全地图读取“谁DPS最高”的强制锁定；保护目标、出口、货物、恐惧与撤退同样进入选择。

## 9. 世界时间与扩展边界

早期原型曾使用10Hz、每tick一个世界分钟；现有实现已改为共同整数毫秒，存在有限动作/伤势样本。具体所有权和已实现范围分别见[ARCHITECTURE](../../docs/ARCHITECTURE.md)与[FEATURES](../../docs/FEATURES.md)。

以下为扩展要求，不要求重做现有共同时间；动作尺度、更新频率和精度仍需在后续工作包验证：

1. 只有一条共同、可排序的整数世界时间轴。战术现场以秒描述，生活/种植/消息以分钟、小时描述，统一换算。
2. 自由现场/战斗默认目标为1真实秒约1世界秒；1/2/4倍是全世界有效推进倍率，察觉威胁后自动回1倍并提示。既有一天144秒不是必须保留的平衡值。
3. 吃住、制作、修炼、旅行提供明确的等待/事务快进。推荐原型先试全局60倍和按下一关键边界推进，实际倍率由P0手感/性能测试选择；不是让玩家真实坐等八小时睡觉。
4. 加速/跳时是玩家请求推进整个世界，目标移动、遇袭、供应和关键消息会在正确边界打断。远方冲突继续算，不因主角睡觉自动全算成和平。
5. 暂停所有规则停止；界面和表现插值可响应。算力不足保留待处理时间，显示降速/进度，不丢掉已宣称推进的事实。
6. 战斗阶段、移动、投射和生活执行必须在同一提交点读写原身体/物资。不能让身体节点自己掉血、分钟模拟又覆盖回来。

生活时长也需共同校准：早期逐格耗时与玩家瞬时移动的假设不是当前实现说明，已有位置与共同时间样本见[FEATURES](../../docs/FEATURES.md)。空间上保留正方格，局部战斗可用格内连续坐标；渲染64像素不直接等于一米或一分钟，物理尺度、道路里程与离场耗时需实际验证。不让切区立即改变同一路程的时间。

自动降速和提示遵守玩家认知：听见/看见危险、已约定渠道收到警报、已经受伤等可触发；未被发现的伏兵或无人告知的远方交战不能通过突然降速泄密。跳时跨过未知危险仍会按事实发生遭遇，到了角色可察觉时才停止并交还操作；算力追赶只说明处理进度，不暴露秘密位置和敌人名称。

后续若确需改变已有时间字段或存档语义，必须设计版本迁移、保留旧fixture并验证双聚落连续性；当前共同时间无需因为本文重写。

## 10. NPC、非战斗者与事件

行为策略按职责和能力组合：守卫阻拦/护人、野兽护巢/逃跑、医者救治、商人保货/求援、修士寻材/护法。不是每个模板都换不同颜色然后冲上来打到死。

先检查目标与所知，再从少量动作中选择，留有反应与决策承诺。NPC与玩家共用动作成本、取消、射程、身体、已学本领和物资。AI不必像玩家按键，但不能免资源或免前摇。

敌对意图分层：切磋、驱离、抓捕、夺物、护送/阻挡、致命冲突。切磋需要同意、限制动作和停止规则；不凭“切磋模式”把已经丢失的灵石/材料复原。原型可用受控非致命动作和明确投降阈值，避免必然制造重伤；正常世界的意外风险仍按已说明规则处理。

无人操作时，人物可完成自己的争端、护送、逃亡和救援。目击者按实际能看见/听见的表面记录学习，传闻延迟传播；完整战斗调试日志不自动成为全宗公知的罪证。制服与旧友关系影响事前判断，正式授权和真伤害仍分别复核。

## 11. 远区、入场与存档

P3现场战斗上线时即有离场策略：**同一个纯规则上下文继续无头细算**，先限制并发数量。P7加入高效粗算，不用“未来会补”让早期版本离场冻结。

唯一权威状态包含参与名单、目标、位置/路线、阶段/时刻、健康伤势、资源、准备本领、持物、持续效果、投射/范围对象、冷却/命中去重和随机上下文。视图与粒子可重建，效果剩余时长不能重置。

精度切换在共同提交点移交执行责任。已提交的受伤、消耗、控制/逃亡结果保留；入场可以改变之后的行动，不能重掷此前战果。围困中的人不能被映射到出口外，已扔出的符也不能退回背包。

远区战斗使用相同本领、装备、伤势、人数/补给和目标语义，比较统计倾向与战略结果，不承诺逐招完全一致。粗算算法不是用双方总战力除一下，也不需要按现场每帧碰撞；可按侦察→接触→交手→撤退/追击的有限阶段，维护真实成本和可干预边界。

死亡/失能在同一阶段释放旧动作与预约、移交物品和责任，岗位可临时代办或明确空缺。旧机构债务不能因签字人死了直接删除；完整政治争议由后续组织规则处理。

## 12. 显示、声音与手感的最小要求

- 战斗HUD只常显健康/伤势、体力、可用灵力、已准备招式和当前动作；姿态/持续运转按需要显示。社会贡献不放进战斗能量条。
- 可预览耗时、范围、作用对象、消耗/材料与主要风险；未知技能只给可观察线索，不能自动显示敌人全部数值和内心。
- 前摇、命中与受击有轮廓/动作/声音，关键控制视觉优先。纸娃娃换华服不能遮住刀刃、施法前摇和队友身份标记。
- 用角色反冲、短痕、有限击退和音色区分效果；镜头震动/闪烁/命中数字可调，颜色不是唯一标识。
- 投射物、命中词条、音效有预算，不为每个后台批算事件播一个特效；远区只摘要与实际可听结果。
- 首版代码几何和分层占位就要能读懂；正式华丽素材在玩法验收后补齐，不用暂缺动画作为命中不清的理由。

## 13. 必须验证的设计场景

本表全为未来标准，未宣称本轮已通过。

| 场景 | 通过的含义 |
|---|---|
| 同一人换三套普通衣服决斗 | 攻击动作效力不凭衣色/价格改变；负重/防护差异来自实际构造 |
| 华服主人与粗衣老修士 | 第一眼身份判断可不同，本领与真实权利独立，接触后可修正 |
| 基础招式对快/慢敌人 | 走位、格挡、停手、追击有不同价值，不只有轮流按亮按钮 |
| 输入恰好早于后摇结束 | 缓冲按窗口生效；取消/过期不误发，暂停不暗中消耗/恢复 |
| 飞行物穿过多个固定步 | 扫掠碰撞不漏墙/人；单次接触不重复扣血 |
| 连续束缚和硬直 | 有可解释的脱离/抗控机制，不能永久失去行动权 |
| 医者护送受袭 | 可护人、救治、撤离或求援，未学习剑术不被迫补攻击装 |
| 借来强法器但操控不足 | 器物真实有用，限制来自公开条件和实际资源，不凭全局装备评分禁用 |
| 卸装/重穿/重配/读档 | 不刷新健康、资源、冷却、认主或消耗品；实例只归一处 |
| 远方正交战、玩家睡觉快进 | 双方继续；关键事件在正确时刻提交/可按设置中断，不静默冻结 |
| 同一场战斗反复进出/存读 | 原人物与阶段接续、既成伤势不重抽、货物不复制 |
| 少量具名/非战斗NPC | 反应依所知和职责，有撤退与救助，不隔墙全知/全员战斗狂 |
| 原型帧率/更新频率变化 | 成本与主要结果按世界时间稳定，视觉帧不成为第二套结算器 |

## 14. 首版范围与开放事项

第一战斗原型仅验证4个基础动作、两种应对风格、一个伙伴和小场景。后续扩到十种动作定义、学习/换装/社会情境与真实供给，再谈20–30人和远区粗算。先证明可读的走位和取舍，不把“系统完整”理解成一次生成上百个伤害技能。

需经原型决定的项目：共同时间单位/固定步长、格内尺度、正常移动与世界分钟的比率、招式时序、伤害/防护曲线、控制保护、身法是否有特定避伤窗口、准备更换时长、友伤辅助选项和HUD密度。方向已明确，数值先给起点，不把未试玩的设计当最终平衡。
