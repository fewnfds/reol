# ACT、弹幕与共同世界

近战武器强调ACT，远程武器强调弹幕；直接操作、鼠标瞄准、连招与技能发生在同一个持续世界。当前框架完成到P5，单位策略与持续任务见[共同决策](unit_decision_framework.md)。下一主题等待试玩反馈。

- [战斗规格](combat_framework/act_and_barrage.md)：当前动作、判定、时序、交付、制作和战斗结算合同。
- [公共行动与作用](action_effect_framework.md)：战斗、工具与生活共享的协议，以及配置/机制/专用脚本的扩展方式。
- [可玩能力](../../docs/status/features.md)、[验证与构建](../../docs/status/baseline.md)。

战斗只是世界中的一种行动方式，生活、修行、创造与交往仍有独立价值。[已确认规则](../rules/README.md)定义产品方向；小队指挥、投降/救援、持久伤势、完整身体/功法差异等仍为长期候选，当前程序没有因此获得这些功能。旧三份战斗提案中的点击操作、通用治疗排序和资源假设已由当前合同替代，历史由Git追溯。
