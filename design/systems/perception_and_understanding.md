# 所见、所知与所在意：人物视角的信息规则

日期：2026-11-03。状态：**总体设计；W3-a温火石有限样本已实现，非全部出口通过**。依据用户最新说明：同一神剑，小道士可能只觉外形不凡；武学大家可能理解深层战斗用途，却不必在普通食物和布衣上看到密集参数。这是人物的阅历、方法、目标和情境差异，不是固定职业面板或物品等级解锁。

本文细化[世界总纲](self_consistent_world.md)与[知物/用器](knowledge_artifacts_and_invention.md)，不建立第二份真实物品、知识或机构账目。当前功能仍以[BASELINE](../../docs/BASELINE.md)为准；[状态与契约目录](../../docs/plans/world_state_contracts.md)负责接入边界。当前`SimArtifactUnderstanding`已只读投影材料/操纵阅历、实际检查与具名说明；请人检查占用原身体/时间，在场才能听到，听到不复制操作法。见[验收](../../docs/qa/20261103_artifact_understanding.md)。U1–U8仍为总体未来标准，不以专用样本全标通过。

## 1. 五个问题分别回答

| 问题 | 决定依据 | 不应混淆 |
|---|---|---|
| 事物实际怎样 | 物的结构、过程、世界条件 | 不因观察者不同而换一套真实属性 |
| 我能接收到什么 | 感官、位置、媒介、遮挡、观察方法、注意条件 | 收到线索不等于知道真名、功能或来历 |
| 我怎样理解 | 已学方法、领域经历、比较物、证言与推断 | 理解可能错误；修为高不等于通晓所有领域 |
| 此刻什么与我有关 | 当前意图、危险、事务、偏好、当下能力 | 不关心不等于不会、不知道或世界不存在 |
| 怎样向玩家表达 | 上述主体可用信息、用途和展开层次 | 简述不能删掉世界状态，展开也不能泄漏未知真值 |

这些是职责，不是五个新属性条。察觉、解释和呈现可由同一个小型流程协作，但持久数据要知道自己属于哪一类。

一种能力可能改变多个阶段：神识能接收某类灵机，剑术经历帮助解释剑势，静心方法能提高观察稳定性；它们不能合成一项万能“鉴定战力”。

## 2. 经历怎样成为可用理解

用少量有来源的领域证据与实践总结表达：学过什么方法，处理过哪些类型的问题，接触过什么器物/材料/流派，在哪些条件下成功或失败。重复日常可以压缩为实践摘要，不永久保存每一次挥剑与吃饭。

既有经历可以装配在开局，不要求玩家亲自重复过人物一生；必须说明与领域有关的来源。NPC也使用同一规则。武学大家可以精于判断招式和气机，厨房学徒可以更了解食物、火候与贮藏；双方都不因总等级自动压过对方专长。

先天感官、已有知识、实际操作熟练和临时状态分开。没看清、看不懂、没认真查和目前不在意，是不同原因。一次剧情事件可以提供伤势、观察、导师、证据、约定或新的目标，从而改变信息与选择；不能只靠“主线进度到第三章”在后台发放无来源的全知能力。

不做无限“经历标签”堆叠：保留影响未来行动的少量方法掌握、适用域、关键经历引用与练习概况。遗忘、失忆或记忆封存若后来加入，也要有作用范围，不一键把全部生活能力清空。

## 3. 同物异观：不是同物异真

下列均为未来呈现样本，语句与细节不作为正式美术/文案定稿。

| 对象与处境 | 可能的基础呈现 | 有依据时才呈现的深入内容 |
|---|---|---|
| 小道士初见一把古剑 | “剑身古朴，映光时似有异样。” | 观察/示范后得到特定线索，未必立刻知道是何剑、如何驱动 |
| 武学大家主动察剑 | 已能识别的剑势、承气方式、与自身方法的相容性 | 特定流派结构、曾见的招式联系、已验证的隐藏战斗用途；未知封印仍未知 |
| 工匠检查同剑 | 接缝、铸痕、材质反应、修补迹象 | 可能识出伪作或结构缺陷，但未必感知深层剑意 |
| 不缺食物的武痴看普通饭食 | “一碗热饭，可充饥。” | 主动问食材、分量或来源时只展开其确知/获告的信息，不出现通用“回复100生命” |
| 药师查看疑似变质饭食 | 与气味/储存经历有关的疑点 | 通过相关方法判断风险和适合的处理，保留不能确定的部分 |
| 武痴身处寒地、受伤或准备远行 | 衣物保暖、食物是否够用等已知信息优先 | 原先次要的日常功能变得相关；人物不会因为“高手不屑俗物”而忽略迫近危险 |

若古剑封得毫无可感知痕迹，小道士也可能把它当普通铁剑；“这是绝世神器”不是默认外观信号。稀有品质色、售价或图鉴编号不能替叙述偷偷泄密。

食物、布甲、疗伤和修行按真实身体/过程规则起作用；在本游戏中不必先有“回多少血”“几点通用防御”，再选择隐藏它们。若某种食物或法衣确有明确治疗/护持功能，照该方法的作用与角色所知说明。

## 4. 关注改变默认重点，不剥夺玩家选择

默认面板先给：对象的可识别类别、眼前可用功能、与当下行动有关的状态，以及已经察觉的重要异常。其余已知信息可以收起，让玩家选择“辨材”“察看气机”“询问来历”“为旅途比较”“查看已知记录”等目的。

主动展开的是人物已有知识、已接收线索与其来源；点击“详细”不是免费全鉴定。真正需要新方法、接触、取样、询问或试验的调查，要作为行动花费相应时间/资源。

人物兴趣用于初始重点与NPC候选行动，不是不可更改的职业过滤器。玩家可以让武痴学做饭，让匠人学剑，也可暂时为了救人去认真研究平时不关心的器物。界面不因初始偏好永远灰掉另一生活方式。

对自己数得清的粮食、约定钱款、交货期限和已确认的载荷应给准确数值。需要描述时用定性表达，有可靠测量时给测量值/范围；不把所有数值藏成猜谜，也不将估计伪装成精确真值。

与风险有关的提示也要遵守所知范围：已看见裂纹、已察觉发热可以警告；不能因为隐藏诅咒将触发，就提前显示它的真名与倒计时。可用的低风险检查方式可以提示，但不能保证任何未知行为绝对安全。

## 5. 同一信息也会被不同人理解

记录感知到的内容与当时解释：看见的刻痕、听到的说法、仪器输出，与“这应当属于某派”的推断分开。错误解释可以长期存在，得到反证后再修订。

重访或学习后可以重读过去确实记下的线索；记忆没保存的细节不能靠后来升级从后台补成高清录像。新方法可能提出“当年纹样也许有另一解释”，进一步确认仍需资料或再观察。

分享只传播实际能表达的内容。武痴说“此剑能引动某种剑势”，听者可记住这个说法与来源，不因此掌握辨认方法或操作能力。工匠展示铸痕，别人可以学着比较；是否看得懂取决于方法与实践。

他人经验可以被信任、怀疑、购买或核验。没有把握不是简单的“低概率正确标签”；系统至少保留来源、获知时间、适用条件与是否经过验证，不用后台真值实时修正角色把握。

## 6. 三个边界：执行、决策与显示

1. **执行查实际条件**：功能能否发生取决于世界与操作，不能因界面简述就让热量、防护或裂损消失。
2. **决策用主体所知**：NPC按已知/误信的性质估计办法；计划器不能读隐藏真值替自己提前筛掉危险和骗局。实际执行失败时，再按可观察结果更新认识。
3. **显示用主体可获得的信息**：正式界面、排序、比较、询价提示与按钮理由要共用信息边界，不能只有说明文本克制，其他地方全知。

道具栏不按未知真实品阶自动排序；商人报价基于自己的认识与库存，而非后台标准价；未鉴定物不预留“3条未发现词条”泄漏功能数量。拒绝原因应描述可知的受阻现象，必要时保留“未能理解原因”，不能列出隐藏封印的破解答案。

开发诊断可检查真实状态、观察链与选择依据；它不成为角色记忆，不作为正常交互验收的捷径。玩家在现实中记住的信息无法完全禁止，角色方法、证据与操作能力仍按状态判断。

## 7. 最小数据与协作契约（待实现）

| 内容 | 责任归属 | 边界 |
|---|---|---|
| 实际性质/过程 | 原对象/身体/作用负责人 | 不按观察者复制多份真值 |
| 可接收信号与观察结果 | 观察行动＋主体记录 | 保存必要来源与条件；不默认记录完整对象快照 |
| 命题、解释、矛盾来源与验证 | 主体知识 | 允许错误/未知和有限把握，机构承认另算 |
| 领域方法/实践摘要 | 主体所学与经历 | 给解释与候选方法使用，不合成总等级 |
| 当前目的、风险与关注重点 | 已有行动/目标状态 | 哪些持久、哪些临时按实际需求定义；不是第二套心理真值 |
| 描述与排序结果 | 只读呈现投影 | 可重建，不写回物品性质、主体知识或机构权限 |

最小查询语义是“谁在何时、用什么方法、针对什么对象、为了什么目的”。这些可作为显式参数或现有上下文，不要求先建立六个独立系统。

信息呈现必须先取得该主体获准使用的线索/认识，再按相关性组织。不得把全真值交给文本模板后只依赖“记得别说秘密”；后续若接生成式表达，也只能从允许呈现的内容构造上下文。

模拟先提交真实变化→确定谁通过什么渠道收到什么→各自形成/修订认识→按当前用途构建说明。修改显示密度不触发新鉴定，不消费新随机，也不改变NPC决策。

## 8. 第一个可验证样本

不先做百种身份文案。选择同一器物、三名观察者、两种检查方法与两个目的：小道士、武学大家、工匠；普通浏览/专业检查；当前使用/备战或远行。

| 编号 | 场景 | 必须成立 |
|---|---|---|
| U1 | 三人看同一封存古剑 | 实物唯一，线索/解释不同；无人凭身份自动知道所有隐藏功能 |
| U2 | 武学大家浏览普通布衣，再准备寒地远行 | 默认简述；相关日常信息可上浮，不改变布衣真实功能 |
| U3 | 不懂药材者点击展开 | 只展开其已知与来源，不自动获得药性真值 |
| U4 | 高手说出一个功能，学徒转述 | 说法与来源传播，鉴别/操控能力不随转述复制 |
| U5 | 学习新方法后重读旧笔记 | 只能解释旧有线索，不能补回从未见过的秘密细节 |
| U6 | 未鉴定宝物出现在排序、比较、报价与失败提示 | 不从品阶色、准确价值、隐藏槽数或拒绝理由泄密 |
| U7 | 故意误认器物后NPC选方法 | 选择受误信影响，真实执行仍按条件结算；不以隐藏真值作弊 |
| U8 | 相同世界/输入，只改面板展开偏好 | 所见重点变化，物品/知识/随机与提交结果不变 |

上述均是未来测试。实现先接已有知识/执行/界面的最小查询，再扩充领域与表达。模板数量、注意阈值、信息密度、练习增长曲线等由开发与试玩调整，不要求用户逐项拍板。
