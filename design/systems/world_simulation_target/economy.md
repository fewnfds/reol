# 大世界持续模拟：目标架构与行为契约：经济、环境与冲突

> 详细设计与候选：具体机制、参数、样本和验收意图须验证；已确认规则见[规则目录](../../rules/README.md)。

## 6. 物质与经济循环

### 6.1 生产、消费与运输形成约束

每个商品定义基本用途、来源、投入、劳力/设施/土地要求、产出时间、保存或损耗方式。第一批只需粮、饭、水、柴、药、矿材、灵石与少量装备；物品多少服从玩家选择需要。

粮食需要生长时间和耕作，水井与采矿有来源容量或补给规则，烹饪消耗投入，建造把材料转为建筑，生活消耗与腐坏形成去向。劳力被征兵或受伤后，生产计划实际减少。修炼可以降低部分生存需求，但必须有明示境界或功法依据，不能所有远区修士自动免消耗。

运输不是库存间无条件相减相加：货物先进入某人或商队的容器，承受路程、负重、补给、风险与费用。可预约未来货量，但预约不等于已经持有。跨区交易必须同时考虑出价、支付能力、运输能力、现货或约定交期。

### 6.2 钱、贡献和人情承担不同功能

- 货币是有发行/矿产/初始来源的可转移资产；工资、税、押金与交易只是转移，不凭空扩大总量。
- 灵石若兼作货币和修炼材料，修炼消耗是实际货币源汇问题；需要开采、外贸或替代结算方式，不把灵石永久当不可耗的万能钱。
- 宗门贡献是机构发行的受限兑付记录，新增贡献意味着新增负担。机构可以设置适用范围、承兑规则与发行预算，但不能把个人刷任务变成无限免费实物。
- 人情、友情、忠诚和信任通常不能自由转让。它们影响具体人愿意承担什么，不统一折算成市场价。

价格先用少量有界规则：卖方库存覆盖、生产/补货成本、买方紧迫程度、已知近期成交价、风险和地方税费。商人只根据自己的库存及获知信息报价，不实时读取全世界供需。初期不用复杂连续竞价，也不靠全局“经济指数”直接增减每个人的钱。

### 6.3 世界边界不是隐藏作弊口

有限世界可以有外域来商、迁入人口、灾害和野生资源再生，但必须是显式来源：从哪个边界或资源池进入、携带什么、何时到达、有何上限。来自外域的粮食/货币计入输入，腐坏/修炼/销毁计入输出。

每类基础实物可检查：

```text
期末在库 + 在途 + 背包 + 已投入可追踪资产
  = 期初总量 + 采集/生产/外域输入 - 消费/毁损/外域输出
```

不同物品的配方转换分别记投入和产出，不把“做饭”视为粮和饭数量相等。无需从创世保留每次一根柴的流水，但测试和开发诊断应能按期间汇总来源、转移和去向。

### 6.4 可失稳，但要能理解和行动

短缺、通胀、饥荒或破产可以发生；稳定性不是保证世界永远富裕。正常种子须有可维持的基本供给，异常种子或战争冲击须产生自救行动：提高报价、求援、换作物、裁减开支、迁居、占路、投降。

不允许用暗中补库存掩盖死循环；如果作为难度辅助提供赈济，必须以有来源的事件进入，且可在设置中辨认。也不强迫世界定期崩溃来制造内容，长期和平与复苏同样成立。

## 7. 城镇、环境和世界生成

城镇由真实设施、土地、道路、人口、工作能力和治理关系组成。建筑蓝图占位不等于建成；需要合法或事实控制的地点、材料、施工、通行和人员。建成后改变实际生产容量、储物、休息或防御，而非只增加“繁荣值”。

首轮房间判定只服务具体需要，如封闭住所、灶房、仓储或修炼室；复杂风水、温度流体、逐块结构承重另行验证是否有决策价值。道路、桥和关口改变行旅图和局部通行，影响补给与经济，破坏后须使旧路线预测失效。

生成顺序采用约束优先：地形与水源 → 可耕作/矿脉/灵脉等资源 → 可达通道 → 可维持人口的聚落 → 组织与依赖 → 人物与未结事务 → 少量初始历史。保证至少一种基本生计及逃离路径；不把“随机”理解为可以生成无粮无路却全员按普通生活开局。

世界地理用有限区域图连接地形坐标，不要求预先实例化每块地面。增加模拟区域不等于每次都新增一张同样大的场景。局部详细地形按种子与持久差量恢复，地理节点与实际出口一致，跨边不能绕过本应存在的关隘。

## 8. 冲突、战争与修仙强者

### 8.1 战争从目标和动员开始

战争目标可以是夺药田、收贡、报复、救人、解除封锁或占领据点。组织评估可用兵力、指挥者、补给、已知敌情、内部反对和退路，才组成部队；不是固定间隔在玩家视野外刷一波无来源袭击者。

部队由实际人员、装备与容器构成；动员后原岗位缺人。粮药、伤员、道路、士气与回撤影响能打多久。占领需要实际控制关键地点并维持执行者；撤离后可能失去控制。投降、赎人、赔偿、割地和停战可以比全灭更合理，败者可留下伤势、俘虏、逃散、债务与仇怨。

### 8.2 现场与远区共用战斗语义

共享参战者、身体/装备、伤害和防护类型、行动成本、地形标签、侦察、撤退与俘虏规则。现场以移动、射程和技能逐步执行；远区按有界交战阶段和风险模型结算，保留阶段耗时、伤亡与资源变化。

两种精度不承诺逐招相同。验收目标是：实力差距、伏击、补给、地形与撤退条件的方向一致，资源和参战身份守恒，已发生伤势不能进场洗掉。用多种种子比较伤亡与持续时间的合理区间，不能只看某一例结果相同。

预测战果只是估计；一旦阶段实际提交则保存结果与随机状态。玩家进场可以影响后续，不能重抽已提交阶段。离场也不能立刻转成有利速决。大型军团可以按小队与后勤群体聚合，但已持久化的主将、旧友、俘虏和重要修士保留个体，展开时总人数、装备和补给不增加。

### 8.3 修仙能力改变世界的代价

强者能飞行、护送、开矿、治伤、威慑或摧毁防御，这些能力要进入共用动作和成本模型。境界压制可以明显，但应有能量、伤势、时间、阵地、责任或政治后果；具体强度由修炼与战斗工作包定参。

飞行不能默认连背包货物和整支商队一起免运费；法器载重、持续消耗与可带人数单独定义。顶级修士不自动巡遍全世界，也不因系统“坏人数量不足”被凭空生成。高阶毁灭技能对建筑和地形的影响，必须先有可保存、可粗算的规则，才开放给 NPC 使用。

## 9. 事件、任务与信息

事件来自几类明确输入：人物行动结果、持续局势、组织计划、自然过程、有限外域变化和编写的场景条件。少量模板把缺粮、失踪、争地、债务、继位等条件组织为机会，不替玩家预定唯一解。

局势维护关联人物/资产、已知解释、时限、升级条件和结束条件。缺粮可以靠贸易、种植、救济、劫掠或减员改变；不要求玩家接了任务才允许 NPC 运粮。局势完成后释放预约、终止过时招募、处理已付押金、通知有关人，不能只从 UI 删除一行字。

任务是玩家已知的承诺、委托或目标视图。发任务者须有提出需求和兑现报酬的依据；委托被他人先完成、雇主死亡或库房被劫后会产生实际变更。UI 说明玩家知道的主要原因，隐藏内部效用和未知秘密。

消息有发生时间、发送时间、到达时间、来源、渠道、接收者与可信程度。口头转述可以遗漏，公函、见证和法器记录有不同核验条件；传播成本按距离、商旅、通信能力和访问权决定。强力传讯法器可以快，但需要实际设施/使用者和代价，不能用它让一切默认全知。

叙事调度选择哪些已发生变化值得提醒，并可按明确规则引入外来条件；不任意改关系、库存或伤亡凑难度。玩家离开时不强制灾变，接近时不临时创造既定大事件。
