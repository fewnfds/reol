# 大世界持续模拟：目标架构与行为契约：人口、历史与规模

> 详细设计与候选：具体机制、参数、样本和验收意图须验证；已确认规则见[规则目录](../../rules/README.md)。

## 10. 人口、历史与不同身份

### 10.1 人物连续，人口有容量

个体寿命、成长、婚育或收徒、招募、迁居、死亡与遗产逐步加入。首版人口增长优先做可追踪的外来招募和迁居，世代家庭待基础生活与死亡规则成立后再接。死亡先停止动作，处理背包/遗体、预约、职务、未结承诺、遗产与消息；不能简单删字典让义务一起消失。

长寿修士与凡人的时间体验不同：凡人换代、弟子出师、职位轮换、土地和机构延续都可发生。长寿不意味着所有社会联系按统一折扣衰减。旧掌门故去后，友情、正式授权、机构债务、法器公账和守门礼数分别处理。

### 10.2 历史压缩保留能改变未来的东西

永久或长久保留重要身份、有效权利和授权、未结债务与承诺、重大伤亡、领土变更、师承/家族、关键证据与来源。重复吃饭和日常搬运可按人物/时期/类型汇总，过期噪声清理。

压缩不能删掉仍被事务引用的证据，也不能把不知情者赋予全知历史。死者可以只留下摘要与必要引用，不要求加载完整生活日志。压缩前后对关键决策的输入含义相同；“系统忘记”与“人物忘记”是不同过程，后者需要明确规则。

### 10.3 身份是同一规则下的不同处境

杂役、农户、商旅、散修、管事、宗主、流亡者和军队统领共用身体、物资、行旅、交互和后果，区别在起点、职责、权利、技能、关系、已知消息与资产。每个正式可选身份必须有至少一条生计、成长、冲突和失势后的去路。

经营权来自雇佣、任职、所有权或他人接受的命令；玩家不能只因打开经营界面就能指挥所有同门。操作可以是本人直接行动、向同伴下令、安排授权岗位，或提交组织计划。NPC 的顺从仍经过职责、能力、承诺和风险约束，拒绝要可理解。

多出身不是一次制作所有职业剧情，也不默认随时附身任意 NPC。以同一世界的身份测试开局证明规则成立；存续世界中角色转换、死亡后继承或新角色进入可作为独立功能，不能与新开档随机重建世界混淆。

2026-11-03用户已将主角跨世玩法定为[有限重生与新生候选](../rebirth_and_new_lives.md)：世界只前进，机会耗尽结束本局，不能免费接管普通新人继续。出生/群落来源、小幅候选前跳和出生后成长分别结算；候选域/档位不因屠杀普通生命而自动归一到极品。当前区域模拟尚无该机制，普通迁居与新开局装配也不能冒充转生。

## 11. 有限规模、诊断和长期验收

### 11.1 先验证再扩大

下表是容量档位候选，用于讨论设计与负载，并非已验证能力、性能承诺或发行规格：

| 测试档 | 模拟与人口目标 |
|---|---|
| S0：小型基准 | 使用两个聚落及有限人物和事务，作为小型正确性场景 |
| S1：一小时切片 | 2–3 聚落、12–30 名持久 NPC |
| S2：系统 Alpha | 4–8 模拟区、60–150 名持久 NPC、本地人物不超过 40 |
| S3：1.0 候选 | 12–24 模拟区、约 12 聚落、3–5 个组织、300–600 名持久 NPC、本地人物不超过 60、现场战斗 20–30 人 |

模拟区、聚落和渲染块不等同。远区部队同时保存实际成员名单和可批算的群组状态；人数与伤亡必须互相校验。每一级还分开记录活跃事务、背景人口、建筑和在途队伍。超预算先限制新开局密度、缩小活跃现场和分散事件，不能把已形成关系的人物删除或换成随机替身。

人口和地图目标由总体计划统一选择并记录参考硬件；先测少量人物下的正确性，再选 1×/2×/4×及长时推进的实际上限。不能用一个静止视野微基准宣称大世界 60 FPS。正式性能目标同时测帧时间、模拟边界处理量、最大追赶延迟、内存、存档大小和读档时间。

限制候选计划、同时在办互动、传播扇出和单帧预算，优先队列/索引只在测量证明需要时引入。人物关系稀疏存储；组织之间只追踪实际往来；消息可聚合相同的低重要性通知；未访问空地没有单位节点。

诊断能回答：哪个过程消耗计算、物资从何而来、谁在占预约、为什么没生产、谁收到什么、某行动因何被选、哪条消息仍在途中。诊断信息不进入正式 NPC 知识或玩家可见真相。

### 11.2 必须通过的场景

| 场景 | 可判定的验收条件 |
|---|---|
| 玩家无操作推进 30 个游戏日 | 基础生产/消费、休息和事务继续；资源/人口变化有来源，等待可恢复或明确结束 |
| 一个地区失去粮源 | 先库存下降，再根据知情与能力补救；没有免费刷新，也不全世界同刻知道 |
| 两人/两商队争最后一份物资 | 仅一次实际取物；其他请求得到等待、改价或失败，不出现负库存 |
| 采集/生产/消费/外域贸易 | 期间源汇平衡可核对，配方投入与产出分别成立 |
| 有钱缺货、有货缺权限、有权缺执行者 | 三种障碍能分别发生，并有不同解决路径 |
| 跨区迁居途中保存及反复进出 | 只有同一个人和背包，职务与责任得到显式处理，不能两地同时工作 |
| 桥毁在商队出发后、消息到达前 | 行程真实受阻，人物在遭遇或获知时改变计划，未提前全知 |
| 城镇施工被断料/施工者受伤 | 已用材料与进度保留；预约清理或交接；不能直接变回未花钱蓝图 |
| 近区/远区分别运行同一供给测试 | 守恒、因果、重要耗时和约定误差达标；不要求每步轨迹相同 |
| 随机交互反复点击、读档和切换 | 同一条件实例不重抽；条件实际变化后才允许新决定 |
| 部队征调农户与返乡 | 劳力、人口、装备和补给同步变化，战争不复制兵也不免费恢复生产 |
| 玩家进出一场未完战斗 | 已发生伤势/消耗保留；无进场洗血、离场重抽、全军传送 |
| 敌强我弱、伏击、断粮、优势地形、可撤退 | 远战与现场的方向合理，多种种子的结果区间可比较 |
| 攻陷与撤出据点 | 实际执行者/仓储/服务/通路改变；撤离后控制可以再次变化 |
| 掌门死亡或被罢免 | 私人帮助、职位、授权、公账与礼数分别延续或争议，不统一清零 |
| 长期历史压缩前后加载 | 有效权利、未结责任和仍引用证据不丢失，个人知识不扩大 |
| 同世界身份测试 | 杂役、散修、商旅和管事各有可执行生计与失败去路，共用成本规则 |
| 多种种子推进 1 年；人口阶段再测 10 年以上 | 无负数/复制/无限增长/永久预约；失稳有可解释因果与自救行为 |
| 暂停、快进及模拟预算耗尽 | 所有领域遵守同一有效世界时间；欠账保留，不静默丢失时间 |
| 任一关键阶段中断存读 | 完整快照恢复并继续；坏档拒绝后原世界完整保留 |

长时测试用小世界/无头执行器加速，年度/世代测试是后续对应工作包的验收，不要求当前 Demo 已能运行百年。每次容量增加都保留双聚落快回归，避免只剩几小时才能执行的整体验证。

## 12. 落地依赖与收敛条件

最先需要补齐的是：可持续资源源汇、人物失败后处理、完整持久化边界与共同时间单位；这些分别支撑经营、战斗、行旅与长期运行。世界调度、社会记忆和账物骨架继续增量扩展，不先重写成 ECS、完整事件溯源或几十个 autoload。

市场依赖生产/消费/运输/货币归属；战争依赖身体/装备/补给/迁移与战斗；世代依赖死亡/遗产/职位/记录传承。缺依赖时用显式有限场景验证接口，不把假库存、临时血量或临时人口接入正式世界充数。

一项新细节只有改变具体人物或玩家的选择，才值得加入。若无法说明谁会因此改做什么、花什么、冒什么风险、留下什么后果，就先不实现。世界的自由来自规则能组合和被干预，而非每个现实细节都有一张表。
