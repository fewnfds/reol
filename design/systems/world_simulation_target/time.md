# 大世界持续模拟：目标架构与行为契约：状态、时间与行动

> 详细设计与候选：具体机制、参数、样本和验收意图须验证；已确认规则见[规则目录](../../rules/README.md)。

## 1. 需要产生的体验

一个农庄先种粮、留种、吃饭，再决定卖多少；一个宗门有灵田、传承、护山能力及对外依赖；一个散修根据消息、盘缠、伤势和人情决定下一站。玩家可以加入其中，也可以改变他们赖以为生的条件。

世界不保证每次返回都有戏剧性大事，但已经发生的事要有结果：粮运到过、有人受伤、旧任退位、道路封锁、账页换了保管者。人物不能因为玩家接近才出生、开始工作或决定结怨。玩家的参与改变过程，玩家的缺席也有成立的过程。

“大世界”首先由距离、依赖、人口与权力网络产生，不用地图平方公里替代玩法密度。先让少数地区形成食物、药材、矿产、功法、护送与政治互赖，再扩展数量。纯空地面积无需逐格模拟。

## 3. 一个世界，多个状态负责人

### 3.1 事实、记录与判断

| 内容 | 由谁持有或保证 | 如何影响行动 |
|---|---|---|
| 身体、位置、伤势、消耗、实物数量 | 对应人物/容器/地形的模拟状态 | 决定行动实际上能否发生 |
| 私人物品的所有权、机构资产归属 | 明确的权利关系与当地认可程序 | 决定拿走是否被认为合法；不等于物理上拿不走 |
| 公账、任职、通行、契约和判决 | 具体机构、职位、账页或法器 | 提供可核验的依据；须由有能力和权限的人执行 |
| 个人所知与预期 | 该人物的知识和记忆 | 决定其认为有什么选项及如何评价风险 |
| 玩家笔记和猜测 | 玩家观察视图 | 帮助玩家推理，不自动创造官方承认 |
| 已提交的结果与未结责任 | 各领域状态，附有限重要事实 | 防重复结算、恢复事务、追踪后果 |

存储可以集中在内存或一个存档里，语义上仍要知道“谁保管、谁能查、谁有权改”。不用为每个长老创建独立数据库。

特别区分实物的**保管、所有权和支取权**。盗贼可以实际持有不属于自己的灵石；库管可以保管宗门物资而无权私卖；长老可以批准支取而手上没有实物。首版交易先覆盖正常转让，犯罪和赃物后续复用此区别。

### 3.2 固定的不变量

- 持久主体的连续性唯一，身体/载体、控制关系与被识别身份分开；现有人形原型仍是一主体一身体。分身/换载体须显式规则与独立状态，不能复制主体、物资或免费执行责任。
- 同一载体/物品的实际位置或在途状态唯一；一个主体可有多个容器，容器与显示列表不产生额外实物。持有载体不自动拥有其中主体的意志或知识。
- 一个行动实例只有一个负责结算的执行器；一个物品实例或可堆叠份额只有一个实际容器。
- 开始时的判断与提交时的实情分开：NPC 可以错误地以为有货，执行时不得凭空变出货。
- 同一笔交付、工资、战利品、建设和付款使用稳定操作标识，重试及读档不能重复生效。
- 消息到达前不改变接收者的知识；世界调度器知道真实路况，不等于商人已经知道。
- 已发生的事实不因入场或重抽骰子被改写；尚未发生的预测可被新行动打断。
- 模拟预算不足时保留未处理时间，降低推进速度或分帧处理；不丢失世界时间或跳过冲突。

## 4. 模拟精度与时间

### 4.1 精度根据互动需要分配

| 层次 | 保存与计算 | 省略什么 |
|---|---|---|
| 玩家附近的现场 | 逐步移动、碰撞、射程、局部地形、可见行动和战斗 | 不省略正在被玩家干预的关键步骤 |
| 远处的持久人物与事务 | 路线/计划、耗时、资源、需求边界、消息、交付、伤势、责任 | 动画、逐格碰撞、每帧寻路与重复评估 |
| 稳定聚落过程 | 明确劳力和设施支撑的生产批次、消耗、库存边界、公共工程 | 状态未变期间的重复工作选择 |
| 尚未细化的背景人口 | 职业/家庭群体、人数、资源负担、死亡/迁入迁出份额 | 无关联背景人物的逐条日程 |
| 地域和跨域网络 | 通道、生态资源、气候、运输、外交、军队与消息 | 未访问空地的场景节点 |

不是“近区真实规则、远区自由编故事”。距离只改变执行细节与允许的误差，不取消成本、人物差异或社会责任。具名、已交往、承担职位、债务、承诺、战斗或家族联系的人物保持个体；不因远离玩家被聚合掉。背景人物第一次细化后获得持久 ID，原群体同步扣减人口与资产，不额外复制一个人。

### 4.2 按最早必要变化推进

沿用现有关键边界算法，逐领域补齐边界类型：

```text
选全局最早必要边界
→ 把有关区域推进到该时刻
→ 原子提交到达、耗尽、完工、伤害、期限或消息
→ 使相关预测失效
→ 各人物按自己所知重新选择
→ 排定下一边界
```

稳定区间截止于最早约束：材料耗尽、作物成熟、员工到休息阈值、目标移动、敌军接近到可察觉范围、道路被毁、天气变更、借期届满或消息抵达。不能先算出月底盈余，再补上月中缺粮。

同刻顺序要在领域规范中固定，例如先确认已经到达的实物，再开放后续交易；互相冲突的预约用持久的公平顺序或轮转序列，不让字典顺序决定永远占便宜的人。同刻顺序本身要保存并可测试。跨区影响先同步被写地区，不能让两个区域各自跑到未来再合并相互矛盾的结果。

### 4.3 生活、战斗和闭关共享时间

战斗、持续作用与长时修行共用世界时间，**不建立会独自流逝的第二个战斗时钟**。各领域须声明期限、相位、打断及粗细推进方式。

暂停停止整个世界的有效行动；1×/2×/4×同样影响移动、生产、需求、战斗和消息。画面插值与按钮响应不承担模拟时间。局部慢放如后期加入，是明确的个体能力规则，不是全世界时间失配。

休息、长途旅行和闭关可推进到下一个与玩家有关的打断点：遇袭、重伤、供应中断、到达、紧急来信、已知期限。玩家可以配置提醒，但不能用“自动休息一百年”跳过身体死亡或实物耗尽。宏观跳时处理周期和重要期限，不逐分钟重放，也不一键随机改全世界关系。

### 4.4 精度切换事务

1. 在共同提交点同步涉及的状态，冻结旧执行责任。
2. 携带当前位置/路线进度、行动阶段、参与者、实物、预约、伤势、随机状态和未结结果。
3. 验证后移交唯一执行责任，再生成或隐藏视图。
4. 保留迟滞范围，避免边界来回走反复重建。

一个没有合格粗算器的战斗可以暂时继续原执行器或限制当前规模，不能卸载时直接判结束。入场可把路线进度映射到合法地点，但不能把原本被围的人放到安全出口。不可达映射须保留阻塞状态并记录诊断，不能偷偷传送解围。

## 5. NPC 与组织如何自己生活

### 5.1 少量需求、目标和有限计划

人物选择由以下信息组成：生存压力与身体、当前职责、未结承诺、偏好与个性、已知机会、风险、资源与关系。先以当事人所知检查选项，再比较少量候选行动；结构合法性和已确知的硬条件可提前过滤，未知真相不得通过候选筛选泄露，实际执行再复核真值。采用短期计划和事件触发重评，不为每人求解无限未来。

目标可以是“今晚吃上饭”“筹齐丹药材料”“完成巡山”“还债”“保持职位”“报复某人”，但只有当前有线索和路径的目标进入候选。连续执行给予适当稳定性，避免每个 tick 换心思；新伤势、危险、期限和被证实的信息能打断。行事失败产生等待、替代、求助、放弃或改变目标，不能永久卡在原任务上。

人格影响倾向，不直接改写事实。多疑者可能要求担保；善意者可能免费帮助；贪利者也会拒绝显然致命的买卖。骰判只用于条件允许后的不确定选择，绑定互动实例和重要条件版本；同样的话重复点十遍不重新抽十次。

### 5.2 组织必须有立足之本

一个组织至少具备成员与招纳方式、职位及办事权限、资产与收入来源、维持成本、内部规则、对外依赖、当前问题和决策者。青岚宗可以靠药圃和护送立足，河湾靠田地和粮食；失去核心来源会造成减薪、缩编、借债、谈判、迁居或争夺，而不是仍按固定面板收入无条件运行。

掌门或会议只能根据收到的信息制定有限计划，再由执事派单、具体人物执行。成员可以因疲惫、私人承诺、派系、贪腐或不信任而改变执行；是否违规、是否被发现、谁来追责分别结算。组织评价、成员私人态度和阵营立场不合成一条全局声望。

宗门关系与国家/阵营关系也分开。两个宗门可以停战却争资源；同一阵营的商人仍可能拒绝亏本交易；敌对组织中的旧友仍可偷偷帮忙。初期只维护发生实际往来的稀疏关系，不做全世界人物两两关系矩阵。
