# 可游玩的修仙社会：完整玩法目标

## 1. 要做成什么体验

玩家进入一个有供给、有利益、有交往和历史的修仙社会。一个人可以依靠劳动活下来，可以学艺、加入宗门、做生意、结伴冒险，也可以承担职位、经营聚落、带队作战。改变身份改变责任与机会，世界继续遵循同一批规则。

完整游戏应能回答五个问题：我靠什么活；我想得到什么；谁愿意或能够帮助我；这会占用谁的资源和时间；我离开之后会怎样。玩家不必拥有城镇，也不必成为掌门才能继续玩。单人游历、带小队和经营据点是同一世界中的选择。

内部当然需要生命、粮食、修为、价格、信任预期等数值。价值在于数值对应具体对象和因果：缺粮来自生产和运输问题，任职来自授权与承认，名声来自传播，修炼来自时间、传承与供给。不能通过一个全局“世界进度”或“派系好感”直接替代全部过程。

### 当前已有的落脚点

代码已提供人物日常、真实库存、请求和承诺、知识来源、机构账目与授权、双聚落共同时间、在途货物、访客服务和联合存读。可复用接口见 `VillageSimulation.submit_action/request_help/report_work/approve_promotion/grant_access`、`SimSocialMemory.evaluate_request`、`SimInstitutionBook`、`RegionalSimulation` 与 `SettlementServices`。

这些仍是有限演示：现有一次性人/鸟/魂开局只有短生活样本；“管事”定义不意味着已有完整经营模式；完整建造、市场、战斗、修炼、人口迁居和政治尚未完成。继任脚本是隔离原型。下文以扩展这些已验证边界为目标，不另造一套并行世界。

## 2. 首发范围：让完整成为可交付的目标

推荐 1.0 是一个**有限、可持续、可重复游玩的地方世界**，先让一座山、一条河谷、几处聚落的规则成立，再扩大版图。首区 512×512 是现有技术起点；后续区域数量依性能测试扩展，不能把一张巨型地图当作玩法完成。

| 维度 | 推荐 1.0 | 后续扩展 |
|---|---|---|
| 可选出身 | 宗门杂役、自由散修、小聚落经营者是早期人形示例；多种生命的入口和体验需随对应身体/生活方案验证 | 掌门高级开局、国家官员、间谍、宗族家主、魔道势力等更多处境 |
| 世界关系 | 至少两个有不同资源基础的修行组织，一个世俗聚落，一个商贸节点；允许合作、竞争、变更首领 | 多国、多文化、跨大陆、复杂联盟与大型派系谱系 |
| 据点 | 一处主要可经营据点；租住、租地、共用设施与独立建造都成立 | 多城分权治理、封地、附庸、复杂土地契约 |
| 修炼 | 炼气→筑基→金丹是人形层级候选；无职业本领网，功法、招式与生活知识可跨域学习组合 | 更高可玩境界、特殊体质、普通生命的转世或夺舍方法、复杂天劫 |
| 主角人生 | 用户确定的有限重生、跨种族新生候选与同一世界接续；出生/成长等依赖待完成 | 更多可玩生命形态、成长与可获得的出生机会 |
| 生产 | 食物、建材、药物、装备、修炼供给五条相互连接的短链 | 大型配方树、精细风水、温度/液体/矿层模拟 |
| 冒险 | 野外遭遇、遗迹或洞府、敌对据点三类内容，能由 NPC 参与并改变状态 | 多层大型地宫、跨区远征、特殊世界规则 |
| 战争 | 小队现场战斗，争夺一条路线或一处资源点的有限战事；可撤退、谈判、赔偿 | 战线、多军团、国家征服、复杂攻城机械 |
| 长期变化 | 人物衰老/死亡、任职变化、迁居、资产交接与旧账处理的基本闭环 | 完整生育/教育/家族谱系、百年历史内容、全阶级政治 |

以上是早期推荐的内容范围，不是已拍板的最终发行规格或必须先全部设计成通用平台的清单。身份和生命形态应复用共同规则，并保留实际处境差异；示例数量不排除非人。首发不得声称“任何社会身份都有同样丰富的专属体验”，须以实际可玩内容与测试确定交付范围。

## 3. 一套世界，三种行动尺度

### 3.1 亲身行动

玩家直接控制自己的移动、交谈、劳动、修炼、交易和战斗。界面接受的是意图，结果经过真实的耗时、路径、资源与执行检查。人物不能一边运粮，一边在另一处施工。

### 3.2 合作与带队

同伴不是玩家额外的身体。加入队伍意味着约定合作范围、报酬、战利品分配、危险与退出条件；共同旅行和交战可以给战术指令，超出约定、明显自杀或触及其核心立场时会提出异议、拒绝或离队。紧急撤退允许快速执行，不让每次挥剑都经过社交骰判。

推荐首发玩家加 3–5 名同伴的现场小队。强者可独行，弱者可依靠向导、护卫、契约与地形，而不是强制每种开局都同样擅长战斗。

### 3.3 经营与治理

玩家有明确权利或任职时，可以设置采购、生产、建设、人员安排与库存策略。命令进入组织的事务队列，由真实负责人安排；玩家能看到缺口、期限和已知原因，不能直接改所有居民的心理和私人资产。

| 关系 | 玩家能做什么 | 执行边界 |
|---|---|---|
| 点头之交、陌生人 | 请求、交易、提供担保 | 对方独立判断，不能直接拖入工作表 |
| 临时雇佣 | 按合同分配工作与结算 | 时间、技能、危险、欠薪、休息与违约条款 |
| 同门与朋友 | 求助、合作、代办 | 公共职责、个人关系、代价和其他承诺分别起作用 |
| 下属/门人 | 在职权范围发布任务 | 实际控制力、规范、待遇、能力与个人选择 |
| 自己的角色 | 直接提交行动意图 | 身体、时间、资源与客观可行性 |

“批准”与“完成”分开。工作排程中断要显示原因；保留上次优先级，避免反复切换。经营界面先做少量领域：粮食、修炼供给、建设、守备、对外事务，不要求玩家操作数十列工作矩阵。

**验收场景**：朋友拒绝离开病人替玩家搬粮，但有合同的雇工愿意在报酬到账后工作；玩家当上管事后可以安排公仓搬运，仍不能取走对方私藏；换掉管事不抹掉已经完成的劳动与欠薪。

## 4. 生计、生产、交换与建造

### 4.1 从普通人开始也能玩

**输入**：身体需求、食宿供给、劳作机会、技能、盘缠、身份、已知地点与关系。

**选择**：干日工换报酬，领组织月例但承担职责，采集自给，学一门手艺，接护送或运输，借宿、租住或结伴。低门槛劳动始终保留若干真实机会，不能全被 NPC 无限制提前占满，也不能无条件生成无限收入。

**后果**：获得真实物资、货币、合同报酬或机构贡献；承担疲劳、伤害、逾期、机会成本。任务板发布来自某个人或机构的需求，发布者有来源明确的预算；玩家没有接，其他人也能承接或让局势恶化。

**失败**：没饭吃先降低体力与工作能力，再发展为伤病或倒地；欠租可能转借宿、搬迁、欠账或驱逐；穷困保留求助、救济、低门槛工作与离开路径。救济有负担与办理者，不能成为无限资源漏洞。首发不把一次操作失误立即变成必死循环。

**验收场景**：散修开局不入宗门，靠运输支付食宿、购买基础材料并获得修炼机会；缺钱时可改走劳作/自给路线；同样的工作也可被 NPC 承接，物资与报酬只支付一次。

### 4.2 生产是供给关系

**输入**：资源点、工具、劳力、季节或天气、配方、设施、库存和运输。

**选择**：生产自用还是出售，保持多少储备，优先粮食还是高价值药材，采购还是自己做，停工休息还是赶工；资源不足时替代材料、转买或延期。

**后果**：收成和产能影响价格、用工、组织计划与人物生活。配方消耗来源明确的原料和时间；产出进入真实容器。种植有生长与采收边界，采集有再生或耗尽规则；加工不允许把中间材料在多个配方里重复占用。

**失败**：断料、欠薪、设施损坏、运路中断都会阻止交付；搬运中断留下现有货物与去向，重新安排或退回需要实际执行。生产低谷触发采购、减产、配给、借粮或迁居选择。

**验收场景**：为扩大药田挤占粮田后，组织必须进口粮食；商路封闭带来涨价和减餐，恢复运输后逐步好转；同一结果在玩家离场时也成立，不通过神秘库存补回。

### 4.3 交易与服务

**输入**：卖方真实库存、买方资金、双方已知价格、运输成本、风险、质量、合同与制度范围。

**选择**：现货交易、预订、雇人运送、联合采购、担保、延期付款；也可以不交易。首发现金与简单合同优先，不先做银行、复杂证券与多币汇率。

**后果**：货币转移、库存转移、履约和欠款记录分别提交。市场价格根据本地供需与库存形成有界调整；商人根据自己的价格信息买卖，消息过时可能亏损。贡献只在发行组织承认的范围兑付，不是通用黄金。

**失败**：不能用钱包数字买走尚未到货的商品；预售要给明确交货承诺与退款/追偿条件；商人破产、库存损失、临时禁售能产生纠纷，但不能每次交易都随机欺诈。

**验收场景**：把粮从有余地区运到短缺地区能够盈利；反复原地买卖不能凭价格更新无限赚取；库存降到安全线后卖方减少出售，造成玩家有钱也未必买到粮。

### 4.4 城镇与洞府建设

**输入**：地形、通行、土地使用关系、建材、蓝图、施工劳力、占地、设施依赖和维护费用。

**选择**：先租用还是自建，扩仓还是扩产，安全选址还是靠近资源，集中生产还是分散储备；道路、出入口、公共设施与私宅布局改变工作距离、攻击路线及邻里关系。

**流程**：选址预览 → 发布蓝图 → 预约并搬入材料 → 分阶段施工 → 完工更新导航和功能 → 日常维护。蓝图可暂停、取消、被损毁；已经交付的材料留在工地容器，按实际残料拆回，不能既退还又继续施工。

**规则边界**：地形或建筑占地不可行属于物理阻挡；无权占用土地属于社会问题，可请求许可、租用、购买，也可违法占用并承担发现、纠纷和拆除风险。首发可以限制开局可建设区域来降低 UI 成本，但不能把“法律禁止”和“物理不能”混作一个世界事实。

**首批设施**：墙门、床位与住宅、仓储、灶房、工坊、农田/药田、练功场、医舍、岗哨与道路。房间先识别是否遮蔽、用途和可用容量；美观、复杂风水与全温度模拟后续扩展。

**失败**：缺料停工、堵路重算、工人离开改派、维护不足降效；拆墙改变路线和防御，停用建筑释放预约但不删除其中库存。离场施工仍消耗同样的材料与工时。

**验收场景**：玩家亲手建一间住所，再雇工扩建仓库；施工一半封路并存读，工人释放不可达预约；取消返还残料一次，继续施工消耗剩余材料；归来看到真实施工进展。

## 5. 修仙成长与世界时间

### 5.1 修炼需要在社会里找到位置

**输入**：身体基础、功法传承、修炼地点、时间、灵气或消耗品、心得与瓶颈。首发保留少量明确变量，不叠加十几种资质、经脉、灵根和道心总分。

**选择**：依靠宗门得到稳定教学与供给并承担义务；做散修购买、交换、探索传承；投入劳作换资源还是压缩生活开销专心修炼；稳妥调养还是冒险突破。

**成长结构（推荐）**：炼气阶段让身体和基础术法可用；筑基形成两条明显不同的修行打法；金丹提供一次行动方式变化，例如御器越障、护持同伴或阵地控制。名称与层级为长期方案默认值，能力边界与倍率仍需验证。原切片的炼气→筑基仍是第一个验证段，不等于 1.0 必须只做这一段。更高境界可作为传承和历史背景；若出现为现场人物，必须有可解释的交涉、避让、撤退或有限对抗方式，不能用永远无敌的障碍强堵玩家。

**后果**：提升生存与战斗手段，改变能承担的工作、距离、危险与社会预期。强者可能获得礼遇，也可能被戒备；实力不直接赋予掌门权限、他人的信任和公共财产。

**失败**：突破失败可以损耗材料、受伤或出现恢复期；应有风险提示、准备方式与挽回路径。决定性突破只在条件改变时重新尝试，不允许无成本重抽。死亡风险只用于明确高风险选择，不把正常修炼变成盲盒。

**验收场景**：相同功法的玩家与 NPC 都要取得传承和供给；修炼中被打断保留合理的已完成进度或明确损耗；连续闭关消耗现实库存，后勤中断会迫使出关而不是继续凭空增长。

### 5.2 练什么要改变操作和规划

首批内容用身体/近身、术法/护持等能力组合验证不同做法，它们不是互斥职业或两条封闭天赋树。详细[修行网络](cultivation_and_learning.md)包含医护、制作、养护、问讯协作和经营，常人基本行动不因没有节点被禁止；学习通过渠道、练习和经历形成，当前准备/运转另有限制。炼丹、炼器以真实配方/设施扩展；阵法先是消耗真实资源的区域规则，不提前做自由电路编辑器。

寿命、伤势、传承和社会变化形成长期取舍。寿命增长应延长可规划时间，而不是让 NPC 每过数日就批量死亡。凡人与修士不同的生命尺度通过定义表达；具体寿命和日历节奏须配合内容试玩再定，不能从小说照抄百年闭关作为常规等待。

### 5.3 同一个时间，不强迫玩家等待

目前代码一天很快，必须在生活、施工、战斗与修炼接入后重新校准。推荐区分“短动作可交互时间”“日常周期”“长期跳过”三个操作尺度，但全部换算到一个世界日历；不能让玩家修炼一月、商人只过一天。

闭关、长途旅行和等待建设可提供推进至下一重要边界的操作：食物告急、敌袭预警、交付期限、伤势变化、职位变动或玩家设定的终止条件。跳过期间世界照常结算；屏幕给出玩家有渠道获知的阶段摘要。玩家并非在全世界发生每个事件时都强制中断。

**验收场景**：离场三天后，运输抵达、工地完成、某位同伴离队的原因都能追踪；长期闭关若遇到已约定的紧急传信会出关，没有收到消息则可能错过机会；暂停和快进不会只让饥饿加速。

## 6. 战斗、危险与失败后的生活

### 6.1 战斗服务于世界目标

**输入**：参与者身体、装备、术法、战斗意图、地形、视野、士气、退路、补给与救援条件。

**选择**：绕过、谈判、偷取、雇护卫、伏击、护送、正面战斗、救援、撤退。双方先有目的：守住药田、抢粮、抓人、夺传承或报复；击败敌人后要决定实际如何完成该目的，不能只减掉敌方“影响力”。

**现场规则**：实时＋暂停，玩家和少量同伴；基本攻击、两种主动技能、可读的施法前摇、射程、阻挡、打断、撤退与救治。首轮新世界按平面地块推进；未来如加入飞行，再单独定义空间资格、消耗和落地限制，不能成为无限避敌。保留既有样本与存档，不追改历史。

**后果**：伤势、装备损耗、物资损失、俘虏、死亡、敌我认知与土地/路线控制变化。杀死一名守仓人不会凭空把整宗资产转到玩家手里。

**失败**：倒地不必立即死亡；同伴可以拖离、医治、投降或交赎金。败方可能损失财物、自由或据点，再从借宿、雇佣、重建、救援中恢复。存档读回保留为普通模式的玩家选项；铁人、强制永久死亡不是首发默认。

**验收场景**：一次运粮遭袭可选择弃货撤退，货物留在袭击者或地面容器；伤员交给医舍产生真实消耗；俘虏获释只转移一次赎金，并释放其旧工作预约；双方共同存读后继续未结束战斗。

### 6.2 不同时模拟大战的每一把剑

首发战争围绕一个明确目标与有限参与者：护卫一条商路、争夺一处矿点、围困一个前哨。募集、征召、补给、行军、威慑、交战与议和连接经济和政治。玩家可作为士兵、雇佣护卫、补给商或负责人参与，不必永远是统帅。

远区战斗可抽象处理部队能力、地形、补给、指挥、侦察和士气；进入现场接续仍存活的人、已消耗的货物和进行中的目标。无需强求远区抽象与逐帧战斗死伤完全相同，但不允许为玩家到场重新刷出一队士兵或恢复伤势。

完整的模拟/抽象契约另见世界方案；这里的玩法验收是：破坏敌方补给有真实效果，战败允许撤退和谈判，占领产生守备与供给负担，而不是地图颜色免费翻转。

## 7. 冒险、传承与动态事务

**输入**：地理资源、遗址状态、通行条件、知情者、传闻、地图、季节窗口、竞争者与现有危险。

**选择**：验证传闻、购买向导、组队、先准备、抢先进入、与他人共享、出售消息或放弃。出发前至少知道大致距离、准备条件、回程风险和消息新旧；保留未知，不做完全盲猜。

**后果**：获得材料、知识、传承、人质/伤员、秘密或新的债务；开采和冒险会改变地点状态。已经被别人取走的宝物不因玩家接任务重新出现；可再生资源则说明周期与条件。

**失败**：到达时已被捷足先登、信息失实、物资不足、封路、同伴退出；提供残留线索、交易、追索或新目标，避免长途往返只得到“任务失败”窗口。重要奖励不能全部依赖固定出生的唯一赢家，保留次级回报与替代路线。

**事务不是等待接取的菜单**：药荒会推动求援、采购、种植、抢夺和配给；失踪引发寻找、隐瞒和继任；遗迹开放会吸引不同队伍。少量模板组织局势，参与者和资源由世界状态绑定，结束条件可由玩家或 NPC 达成。

**验收场景**：玩家忽略的药荒被 NPC 商人解决，价格与求药任务随后变化；遗迹中途存读后，竞争队伍与已搬走的物资不重置；玩家把消息告诉某人后，那个人才有依据准备出发。

## 8. 社会互动、规则与政治

### 8.1 以少量可解释因素做请求判定

现有请求规则可扩展，不需要重新搭一套无限心理系统。每次有意义的提议评估六类信息：当前目标与需要、预计代价与风险、具体交往经验、关系与职责、权力和公开情境、少量个体偏好与当下状态。

提议与回应先根据当事人所知形成；结构非法、权限已明确缺失或公开确知的硬条件可以提前拒绝，不能用未知库存或尚未传到的封路事实提前筛掉选项、泄露真相。对方可能误判自己的能力；执行时再按真实条件复查。强烈倾向直接决定，犹豫区间才用局部骰判；同一处境下的相同提议缓存结果，实质变化或新的压力事件才触发重评。接受不等于必然成功执行。

亲近、守信预期、办事能力、敬重和畏惧可以分别存在，但不是五条都要玩家刷满的进度。保留关键经历与理由摘要：曾救命、两次守约、欠薪未还、师徒义务、与对方的敌人结盟。玩家看到有依据的解释与行为，不免费查看他人全部心理或准确百分比。

**验收场景**：受尊敬的陌生前辈请求冒死护送仍可能被拒；受伤陌生人获得出于职责的救治；新增报酬只能解决物质代价，不能自动消除政治危险；反复点击不会刷到不同结果。

### 8.2 贡献、权利、担保与办事

贡献记录归发行组织，发行和扣减需要合法签署与依据；可兑换权益取决于制度、实际资源与办理者。私人欠情、传闻中的名声、职位权限和物理钥匙分别表达。记录正确也可能遇到暂缺库存或拒不执行，玩家可等待、协商、申诉、找担保或诉诸力量。

首发争议过程尽量短：提出异议 → 交由有权者核验 → 给出履行、延期、补偿或拒绝结果 → 实际执行。证据可来自交付单、目击者、法器记录；重复转述不是多个独立目击。审计、调解与裁定先共用一个最小案件流程，不一次造完整司法体系。

**验收场景**：同一张真实运粮凭据被重复提交只能记账一次；账上有贡献但药库暂空时，玩家可保留债权或换别的补偿；一个私交很好的长老没有掌管药库，也不能凭嘴直接扣公仓给玩家。

### 8.3 组织目标通过人落实

每个组织有资源基础、负责岗位、供给与防卫需求、成员和未结事务。掌门/议事者根据其收到的消息安排目标，经负责者传令，由执行者落实；内部个人可有私利、忠诚、分歧与疏忽。首发只做少量关键岗位和一两个冲突议题，不模拟每名弟子的完整政治派系图。

玩家任职带来预算、印信或特定审批权，同时承担报账、供给、治安与问责；卸任失去职权，私人财产和关系按各自来源继续。经营中的“大方针”要落成资源、任务与授权，不靠一条全宗“忠诚值”自动完成。

### 8.4 继任与人走茶凉

先让职位空缺、实际接掌、授权交接、关键成员承认、旧账办理成为几个可观察的步骤。原型 `SuccessionResolver` 的权重仅可作为候选局部工具，接入前用场景校准；不能让一次公式代替全体成员、各部门及外部人的认知。

新掌门可能继续承认宗门公账，收回依赖旧掌门个人担保的特许，同时仍维持礼遇。旧掌门的朋友也可能通过现有履约、独立担保、实际控制或新合作争取好处。失去利益不是必须剧本，也不是全宗总好感清零。

**验收场景**：旧友掌门去世，玩家仍被礼貌接待但失去私人药园通行；已有合法运粮公账仍可按组织政策办理；一名与玩家有救命之恩的弟子继续私下帮助，另一名掌库者因财政与派系拒绝垫付。更替发生在玩家远行时，消息先后和后果按同一世界时间推进。

## 9. 多出身、迁居与人生路线

开局由已有世界上的一名人物状态装配：位置、身体、资产、技能、关系、知识、身份与未结责任。出身不创造专属宇宙，初始资产与职位必须有历史或授权依据。社会身份、修炼境界、职业技能、组织归属四者分别表达；高境界也可以穷，无官职也可以受敬重。

| 首发体验 | 生计与依赖 | 中期目标 | 危险与转向 |
|---|---|---|---|
| 杂役/普通弟子 | 公共食宿、差事、管事与师门 | 学艺、得到信任、获准进修、晋升或转师 | 欠责、受伤、资源被挤占；可做手艺、外出或离宗 |
| 散修 | 个人技能、旅店、雇佣、交换传承 | 稳定供给、同行伙伴、洞府与突破 | 情报不足、受伤无人救；可投宗、定居或做护卫 |
| 行商/手艺人（游戏内转向，非独立首发出身） | 货源、运输、工具、顾客与本钱 | 稳定路线、工坊、雇工、合约网络 | 价格误判、封路、欠款；可换路线、结盟或转经营 |
| 小聚落经营者（可发展为管事/掌门） | 岗位授权或私产、居民劳力、储备 | 维持供给、建设、培养人才、对外协商 | 欠薪、失去授权、迁出、袭击；可卸任、重建或带队离开 |

迁居需要真实身体与随行资产在途，工作、住房、财产管理、未结债务和信息渠道按规则处理。人物不能同时住在两地并各自生产一份粮。离宗不是清零存档，旧情、债、师承与追责可以延续，但信息仍有传播边界。

“reroll”对应的同世界新人生已由用户在2026-11-03细化：消耗有限重生机会，从若干跨种族新生候选中选择，世界不回滚、可小幅前跳，高难度机会更少，耗尽结束本局；暂不做增加渠道。详见[有限重生与新生候选](rebirth_and_new_lives.md)。这取代此前免费创建普通新人物续玩的建议。

新生命有实际出生来源、身体与社会处境；跨生记忆的保留程度仍是[待验证建议](rebirth_and_new_lives.md)，旧物、公职、债权与旁人认识不自动归还。旧角色身后事、未选候选和其他世界过程继续。早期先以持续角色验证规则，完整续生依赖出生/成长、共同时间与快照；不以退隐切人、任意附身或同局无限开新角色绕过有限预算。

**验收场景**：同一世界种子分别以三种身份进入，已有运输、短缺和组织事务一致；玩家只因资产、所知和职权不同而有不同选项；一个游戏中从雇工变成管事再离职，其欠薪、旧友与私产可追踪。

## 10. 长期目标与失败继续

沙盒不强制所有人以统一主线通关。推荐提供可以追求、放弃、转向并留存结果的生涯目标：修成一条传承、建立可持续据点、经营一条商路、救活或振兴衰落宗门、结束一场地方冲突、完成一次远征。

达成目标形成有依据的里程碑和结局回顾，世界可以继续。结果来自实际状态：据点能供给多少人、谁继承传承、战争如何结束、哪些旧账仍未结，而不是只累计任务完成数。

失败分层处理：单次工作失败改变合同；经济失败导致欠款和重组；政治失败导致失职、驱逐或转向；战败导致伤亡和损失；角色死亡可依有限机会接续新生，也可按模式读档或新开局。首发不要求每种失败都有无限恢复，但重要不可逆选择应有清楚预警与可理解前因。

NPC 同样会改变计划、离开、失败、死亡。长期测试要警惕两种坏结果：所有组织永久稳定无变化；所有组织很快连锁灭绝只留玩家。允许局部灾难，通过迁居、招募、资源再生、外来商旅和新组织形成保留恢复能力；每一项都要有来源和限额，不能后台偷偷复活同名死者。

## 11. 玩家如何理解世界

首发界面围绕行动组织：当前行动与中断原因、背包和装备、已知委托与承诺、地图与消息、人物交往、机构账页、经营事务。重要的机会成本应在确认意图前可见，例如大致耗时、会暂停的工作、使用公仓还是私人物资、需要谁批准。

消息区区分亲见、可信来源与待核验；账面记录与人物私记分开。经营者可查看自己有权收到的报表；在现场看到的材料比旧报表更新，但不会自动更新远方负责人的知识。

玩家可以针对拒绝做有意义的改变：加报酬、改时间、补证据、找担保、减风险、找别人；只有“再试一次”不是可持续交互。系统给出两三个当前可知的主要原因即可，不让玩家阅读几十项隐藏权重。

教程通过一个小局势串联操作：找到住处 → 完成真实差事 → 与人合作 → 使用凭据或报酬 → 获得学习/建造机会 → 经历一次失约或危险 → 选择处理方式。玩家绕开宗门时仍有替代路径。

美术集中制作之前仍必须有清楚的占位图标、选择轮廓、设施用途、命中/受伤反馈与危险预警；“先玩法”不意味着把功能藏在 F3 开发面板里。

## 12. 必须按真实行为验收的场景

下列场景属于目标验收，**本文件没有声称它们已通过**。实施时拆成小工作包，先规则再接表现与存档；同一场景同时覆盖人物、物资、时间、信息与失败后续。

| 场景 | 通过标准 |
|---|---|
| 普通人过日子 | 无修为开局能靠劳动与服务持续生活；资源和报酬来源可查；不是无限领钱 |
| 双人抢末份材料 | 只有一人取得；另一人等待、换料或放弃，取消/受伤正确释放预约 |
| 新建洞府 | 材料、运输、工时、占地、导航和存读一起成立；拆除不复制物资 |
| 建设与修炼竞争 | 同一批劳力/粮食不能同时供无限建设与闭关，调整策略改变实际结果 |
| 尊敬而拒绝 | 同一人礼遇玩家，却因代价/职责拒绝高风险请求；补条件能改变相应理由 |
| 账面有功但缺药 | 合法记录保留，兑付受库存限制，可协商或追责；重复办理不刷奖励 |
| 玩家忽略一件事 | NPC 自主采购、救援或争夺使局势结束；任务记录反映真正结果 |
| 竞争遗迹 | 消息有时效，竞争者真实行动，宝物只归一处；去晚仍有线索或次级选择 |
| 战败撤退 | 伤员、遗失货物、俘虏、救治和后续合同接续；切场景不重置战果 |
| 远行后的归来 | 工地、人物、库存、传闻和未结承诺各自推进；归来不是初始版本 |
| 继任后的旧友 | 私交特许、公账、礼遇和个别人情分别变化；不同部门可给不同回应 |
| 同世界换一种开局 | 世界规则一致，初始权利和信息有来源，至少三类身份有生计和中期目标 |
| 长期不在场 | 世界产生可追踪的变化，无玩家救场也有恢复和新行动；不批量冻结或凭空补库存 |
| 重要边界存读 | 交付/付款/施工/突破/死亡/迁居中途可恢复；既不重抽决定也不重复资产 |

一项玩法成熟的标准不是文档里出现了名词，而是：玩家能选择，NPC 在能力与认知允许时也能选择，执行有真实成本，失败有明确结果，远区与存读接续，玩家能理解自己为什么得到这个结果。
