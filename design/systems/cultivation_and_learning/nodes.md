# 修行与学习：无固定职业的本领网络：本领网络候选

> 详细设计与候选：具体机制、参数、样本和验收意图须验证；已确认规则见[规则目录](../../rules/README.md)。

## 6. 首批40个节点：八域互通

这是**首批内容候选池**，不是首个战斗原型必须全部实现。最小切片先从中挑12个形成可玩通路，后续再扩至40个；“大型”由可扩展网络与组合产生，不能为了图看起来大先堆空节点。

每域五个节点，最后一项优先提供改变策略的关键用法。名称为本项目占位设定，不能据名称推断额外法术。各节点有独立学习来源；下表的组合不代表一项熟练度自动灌注另一个领域。

表中的“新增选择”以已有普通生活能力为底：例如W1新增的是受压时较可靠的定向守势，不是解锁站立；I3新增组合条件的协商模板与判断，不是解锁说出价格；G1新增对多容器、预约和报表的核对方法，不是解锁看自己带了多少粮。专业操作未达要求时，应同时保留安全、简单或求助版本。

| ID | 节点 | 实际新增的选择 | 学习/使用边界 |
|---|---|---|---|
| W1 | 立身 | 可保持合适步距与定向守势，理解失衡风险 | 基础示范/练习，受伤身体仍有限制 |
| W2 | 直刺 | 使用窄线、较明确距离的攻击 | 需要适合工具；不是一切武器都能同样刺击 |
| W3 | 守隙 | 执行防御后辨认可靠的短反击机会 | 依赖可见动作，不读敌人隐藏冷却 |
| W4 | 卸力 | 用方向与时机化解部分冲击 | 有体力与位置代价，不能全方向免伤 |
| W5 | 截势 | 改为抓前摇打断，放弃部分追击能力 | 有准备/恢复承诺，打错时机暴露破绽 |
| A1 | 调息 | 有意识地收束灵气、稳定施术准备 | 不是一秒满灵；疲劳和伤势影响恢复 |
| A2 | 引火 | 从既有火种或灵气维持小规模火候/火术 | 野外用火有环境边界，具体伤害由动作定义 |
| A3 | 御风 | 形成推移/导流的有限作用 | 不等于无需代价永久飞行，重物与固定物受限 |
| A4 | 护持 | 持续保护自己或一个对象的有限范围 | 占心神、耗灵气，受打断/距离约束 |
| A5 | 分念 | 在较低单项强度下维持两项兼容控制 | 改控制分配规则，不能凭空加总容量 |
| S1 | 辨路 | 根据地形和已知线索选择可行路线 | 不揭示未侦察敌人，不穿过实际关隘 |
| S2 | 短步 | 学会一次可靠的小位移/脱离动作 | 共享身法冷却/体力与地形限制 |
| S3 | 稳载 | 搬运时选择稳妥步态与装载方式 | 不无条件扩大背包，不抵消实际重量 |
| S4 | 观势 | 判断可见来袭方向并规划避让 | 不读取视野外目标的准确蓄力状态 |
| S5 | 护行 | 与一位合作者协调移动/撤离 | 限距离与协作范围，不能把不愿同行的人强行拖走 |
| M1 | 辨材 | 对接触过的常用药材做基础区分 | 陌生品种仍需资料或检验 |
| M2 | 处理 | 采用合适清理、保存与基础加工 | 消耗容器/时间，避免采到就永久保鲜 |
| M3 | 煎药 | 按已掌握方剂制作基础药物 | 需要真实原料和设施；会煎药不等于知道所有方剂 |
| M4 | 急救 | 止血、固定与初步照护 | 不是瞬时回满健康；需物品、时间与后续休养 |
| M5 | 辨证 | 结合病案与观察选择诊疗次序 | 可表达不确定，不能精确读取所有隐藏病因 |
| C1 | 识材 | 判断常用材料适用的工序与风险 | 特殊材料需试验或可靠资料 |
| C2 | 木作 | 完成基础木件、箱具和设施部件 | 需要工具、工位和材料，不能远程生成建筑 |
| C3 | 修补 | 判断并修复可修的衣物/器具损坏 | 区分清理、缝补和结构修复；并非全部能恢复如新 |
| C4 | 铸修 | 处理基础金属器具的制造/修理 | 依赖炉具、金属与安全条件 |
| C5 | 因材制器 | 在已知工艺内选择不同材料/结构方案 | 用途取舍，不产生随机万能攻击词条 |
| L1 | 察水土 | 判断可见水源、地势和常用作物适配 | 需实地或可信报告，不免费远程扫描全图 |
| L2 | 耕作 | 正确安排播种、照料与收获 | 生长与资源容量真实推进 |
| L3 | 育苗 | 保存种苗、扩大或替换种植 | 输入/时间/成活条件存在，无限复制稀有灵植不可用 |
| L4 | 野营 | 建立简易休息和基本补给安排 | 取决于场地与器材，危险不能一键消失 |
| L5 | 顺时养护 | 调整作物与生活计划应对已知季节/资源变化 | 改排程与风险，不直接给全村产量百分比 |
| I1 | 问讯 | 组织更明确的问题，区分亲见和转述 | 他人可不回答或说错，不自动获得真实情报 |
| I2 | 礼节 | 识别已接触场合的称谓、服饰与程序 | 只避免有根据的误会，不能换来统一敬重分 |
| I3 | 议价 | 对数量、期限、运输和付款提出组合条件 | 对方按自身处境判断；无钱无货仍无法成交 |
| I4 | 举证 | 整理证据、来源与独立见证的差别 | 不制造证据，不把重复转述变为多人亲见 |
| I5 | 安排履约 | 使用有限担保、分步交付与违约安排 | 需要真实担保人/资产/办理能力，不能强迫别人接受 |
| G1 | 盘库 | 核对可访问容器、预约和实际缺口 | 访问权不足或旧报表会限制信息 |
| G2 | 编排 | 安排自己或获授权团队的工序顺序 | 不凭技能获得指挥权，不能让同一人同时两地工作 |
| G3 | 运筹 | 将库存、载重、行程与期限组成有限运输计划 | 依赖己方所知，不全知避开所有劫匪 |
| G4 | 应变 | 出现缺员/封路后提出替代计划与优先级 | 替代人仍需愿意和有能力，资源不凭空补齐 |
| G5 | 授权交接 | 明确代办范围、信息、资产与汇报条件 | 职位/所有人须有权授权；被撤权后不能继续签署 |

### 6.1 推荐连线举例

W1→W2/W3，W3→W4→W5；A1→A2/A3→A4，A4与已有稳定控制经验可通向A5；M1→M2→M3，M4与病例线索支持M5；C1→C2或C4，C3与C4支持C5；G1→G2→G3，G2/G3的真实偏差经验支持G4/G5。

以上只是清晰的默认学习路线。靠其他可靠师承学会等价基础可以进入中段；关键取舍与真实能力门槛仍保留。图不强制把全部分支练到顶才允许参与日常。

跨域边如A2↔M3（火候）、C3↔M4（固定/器具制作）、L1↔S1（环境观察）、G1↔M2（药材储存）、I5↔G5（合作与代办）显示互助用途。它们不能变成“先把炼丹点满才能砍柴”的人造前置。
