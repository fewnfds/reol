# 修行与学习：无固定职业的本领网络：能力、学习与运转

> 详细设计与候选：具体机制、参数、样本和验收意图须验证；已确认规则见[规则目录](../../rules/README.md)。

## 1. 玩家在选择怎样过一生

玩家可以练剑，也可以先学辨药、经营药圃、教人处理伤口，再学习护送途中够用的身法。宗门弟子、护卫、药师、工匠和管事是人们对其经历、工作与身份的称呼，不是创建角色时不可跨越的技能菜单。

图上的分支表示不同领域如何相互支持。炼丹可以借用火候控制，种药依赖水土观察，护送需要辨路与协调；武艺可以帮助护身，不能代替粮食、证据、信誉或机构任命。玩家不必为了完成非战斗人生而把战斗分支点满。

本系统允许量化，但每项进展必须回答：**从哪里学、练过什么、现在能多做什么、受什么限制。** 不设置一个“总等级”同时发放攻击、社交地位和所有领域的万能点数。

## 2. 什么构成人物的能力

| 层次 | 负责什么 | 不能替代什么 |
|---|---|---|
| 身体和先天倾向 | 体能、感知差异、伤病限制、学习起点；先天影响代价或容易方向 | 不决定终身职业，不用一项资质封死整个人生 |
| 境界与基础修持 | 灵力容纳、调动复杂度、耐受和寿命等能力边界 | 不自动教授全部招式、发官职或让陌生人忠诚 |
| 功法 | 运用身体/灵力的方法、适合的节奏与代价 | 不等于整套职业，也不是换件衣服自动生效的属性包 |
| 学过的本领 | 实际会做的动作、工艺、治疗、判断和组织方法 | 听说名字或拿到秘籍不等于已经会用 |
| 熟练与心得 | 执行稳定、准备步骤、资源控制、衔接和情境理解 | 不凭练剑给种田与查账统一经验，也不无上限加伤害 |
| 当下准备与状态 | 运转中的功法、准备招式、持续术法、体力/灵力、疲劳和伤势 | 已学很多不等于同一时刻能全部开着 |
| 工具、场地和协作 | 刀具锋刃、药炉、工作台、材料、地形、同伴与计划 | 不把普通衣服、首饰和身份服装强制改成战斗属性来源 |

战斗能力从可执行的招式、基础修持、身体、练习、时机和情境产生。衣服可以有实际防护、负担和社会含义；法器可提供某项能力，但只在拥有、会用、已准备并支付代价时成立。首版不显示可跨一切场景比较的“战力总分”。

境界暂沿用长期方案的炼气→筑基→金丹三个可玩层级；它们扩大能够维持和组合的能力范围，不做每境界伤害、血量全部乘十的强制模板。具体量级由战斗样例验证；高境界人物仍有目标、注意力、消耗、伤势、政治责任和不擅长的事。

## 3. 取自大型天赋盘的是什么

[PoE官方被动树说明](https://www.pathofexile.com/passive-skill-tree)介绍了共享网络、不同起点、引导技能簇的显著节点，以及会改变规则并伴随取舍的关键节点。[官方游戏概述](https://www.pathofexile.com/game)把主动技能/辅助宝石与被动树分开。本文只借鉴**网络浏览、跨领域组合、重要节点改变玩法**，不复制其图像、文本或代码，也不把商业游戏的装备经济和角色职业规则当本项目约束。

Reol的区别是：

- 各主体可复用适用于自身的作用与方法定义；出身装配已有经历、资料和认识的人，不锁定图上起点，也不强制共用完整知识图或身体条件。
- 图的连线是可理解的学习路线，不是向宇宙支付一个通用点就获得能力。
- 主动招式、工艺、修持和实用判断可以在同一张知识图中查看；执行规则仍分属对应领域。
- 连接到一片领域只会暴露下一步线索和条件，不能无师无书自动掌握门派秘法。
- 学会后可以长期保有，当前准备与持续运转另算，不靠频繁遗忘本领制造配点限制。
- 少量节点可提高效率，但大多数应开新动作、替代步骤、协作方式或明确取舍，不铺几百个重复的“攻击+5%”过路点。

**常人的基础行动不被图锁住。** 没学问讯、礼节或议价，仍可交谈、按自己所知称呼别人、直接报价与拒绝买卖；没学盘库或编排，仍能数自己可见的背包物品、安排自己的时间。对应节点带来系统化方法、复杂任务处理、可靠识别、信息整理或模板代办，不能变成正常人类行动的许可证。未学立身仍会站立、走动、避让或笨拙推挡；未学急救仍可求救、按常识尝试简单压迫止血，专业诊断、稳定复杂伤势和高风险操作才有真实知识/材料门槛。基础能力差异来自身体和已有生活经历，不要求全体NPC先逐点买回普通生活。

### 3.1 图、前置条件和线索分开

图有三种不同关系，界面用不同线型，不混为一条硬门槛：

| 关系 | 例子 | 是否必须经过 |
|---|---|---|
| 理解前置 | 先能辨识材料，才可靠地区分某药方中可替代的材料 | 该本领的真实能力要求；可由等价经历满足 |
| 学习路线 | 已学守势，师父建议下一步学卸力 | 推荐路径，不排斥别处学到等价基础 |
| 跨域协作 | 引火辅助煎药，盘库辅助药圃经营 | 组合机会；不把不会御火的人全部挡在药师之外 |

条件可写为“具备A或等价基础B，再有资料C与设施D”，不能只能按一个职业序列从头点到尾。等价基础必须明示来源和能力意义，不能为了让某例通过而运行时随意放宽。

### 3.2 玩家看到自己有根据看到的部分

“入门武艺”“常用医护”“基础生产”等公共领域可见大致轮廓；接触过的门派资料、师承或见闻展示相关具体节点。未知秘传显示“有人以此类方法施术”的线索，不直接显示准确名称、配方、战斗弱点或持有者位置。

规划模式可以列出玩家已知路线的未来需要，包括老师、学习费、材料、场所和预计练习；不自动替玩家全世界找真相。搜索“护送”“止血”“远行”等用途能高亮已知相关节点，允许固定两三条近期学习目标。

## 4. 学习是一个能中断、能解释的过程

### 4.1 一项本领的状态

| 状态 | 人物掌握了什么 | 可以做什么 |
|---|---|---|
| 未接触 | 没有足够线索 | 不在个人准确知识清单里 |
| 有线索 | 听过、看过表象或获知学习渠道 | 询问、观察、购买资料或寻找老师 |
| 已理解 | 有可靠说明并理解其要求 | 制定练习计划；高风险实践仍有明确警示 |
| 已入门 | 完成必要示范/练习，具备最低执行能力 | 可以实际尝试，按本领定义承担代价与失败 |
| 已熟悉 | 在有意义的情境完成练习与复盘 | 稳定执行，并逐步解锁该本领的一种用法变化 |
| 已融会 | 达到该节点明确的掌握条件 | 使用关键变式、教授允许传授的部分，或成为跨域前置 |

这是人物状态，不要求每次显示六根进度条。界面重点显示“会不会、缺什么、熟悉到什么程度、下一步可怎么练”。内部进度有界，状态改变必须有依据；首次掌握与往后熟练不能都靠同一个无限累计数处理。

### 4.2 一次学习事务

选择目标→检查本人所知和渠道→与老师/持有人约定或另行取得可用资料→安排练习时段、场所和投入→实际练习→得到反馈→复盘或再请教→提交掌握结果。

参与者并非必须全部存在。基本搬运与安全野营可以实践学习；复杂内功和药方通常需要资料或老师；独自研究可以作为较慢且有明确风险的替代。NPC对资料的判断也基于其所知，拿到假方可能浪费练习或发生后果；模拟不能让未知真假通过“可学”按钮提前泄露。

教学是实际服务：老师有时间、能力和愿意教授的范围，可能要求学费、材料、师门义务或帮工。宗门贡献能换某项课程，是机构和教学者提供的机会；不是扣贡献后立即在人物脑中生成完整能力。

### 4.3 修炼、练习和实战心得

三者分别计入，不能互相无限兑换：

- **基础修炼**改善该功法的调动与境界准备，消耗时间、生活供给、场地或材料。
- **定向练习**形成已知本领的基础执行。木桩、试作、演练可以安全入门和保持手感，但不能单凭同一动作无限掌握陌生战术。
- **情境心得**来自出现了新问题的实践和复盘，例如成功护住伤员、判断一次陌生症状、处理真实交付偏差。结果失败但人物观察并复盘了原因，也可能获得相关理解。

杀死目标不是统一经验来源。自卫、切磋、危险预判、救人、撤退、完成复杂工艺和管理一次缺货，各形成自己领域的依据。重复针对同一无威胁目标、自己制造无意义伤病再治疗、原地空买空卖，不得成为更快的全图成长路线。

反刷机制采用有限的**实践情境类别、近期重复度、难度适配与复盘是否完成**，不保留每次挥剑全量日志。已经掌握的简单劳动仍产出真实物品与收入，只是不会无限提升熟练；不为了防刷剥夺正常谋生。

### 4.4 暂定节奏

首个入门本领应在一次短教学与可控练习中变得可用；第一小时让玩家掌握一种可靠谋生方法、两三种战斗/避险动作和一个能改变做法的节点。高级掌握需要跨多个世界时段的实践，不以无意义等待填时长。

练习耗时定义在共同世界时间中。现场动作按战术尺度执行；长练习、闭关或制作可以选择整体加速到下一个需要处理的边界。不能让玩家练了一个月，而远方商人只过一分钟。具体分钟数、各阶段阈值和学习费用在原型后进入数据定义，本文不硬填一条未经体验验证的经验曲线。

## 5. 学会、准备、运转不是同一件事

### 5.1 长期本领不靠四个快捷键裁剪

人物可以学会很多东西。战斗首版推荐四个准备招式（Q/E/R/F）、一个身法动作（Shift），以及基础动作和架势动作；它们只是当下的快速调用配置。生活手艺从当前场所与事务菜单使用，不占战斗四槽，不因改成治伤配置就忘记种田。

同一个招式放在两个槽里，仍共享自身冷却、消耗和使用状态；不能复制两个技能实体。准备与移除不清除冷却或持续代价。快捷槽上限用于动作清晰与准备选择，不作为人物智力/记忆只能容纳四项的设定。

### 5.2 功法运转与心神容量

推荐初始心神容量为4，仅作为持续控制的离散预算，用来描述“同时顾得过来多少件需要持续分心的事”。它不是另一条每秒消耗的蓝条，不同于短时体力、灵力或长期疲劳。

推荐最多运转一门主功法，另有一门兼修方法；两者都计占用和兼容要求。简单主功法占1、兼修占1、持续护持/御器等占1–2，是待验证的示例。未知高级功法不能靠同名普通槽绕开境界与学习条件；容量成长有上限，不能随境界无限膨胀到全开。

| 现象 | 规则 |
|---|---|
| 知道三门功法 | 保留三门的学习记录，可安全地改准备方案 |
| 主功法与兼修相容 | 按说明组合，占用与消耗都存在 |
| 两法的调息方式冲突 | 不能同时运转；界面在确认前解释冲突，可在安全状态转换 |
| 持续护持再御器超容量 | 必须先结束其中一个持续效果，不能自动抛弃已托管的实物 |
| 长期疲劳或伤势影响控制 | 降低恢复/稳定或当前可用预算，结果预警；持续能力按安全收束流程处理 |
| 短暂进入姿态 | 由战斗动作管理，不因另写“姿态”就绕过持续能力预算 |

技能不因放在准备栏就持续占心神；只在其定义确实需要持续控制时占用。普通持剑、穿衣、煎药知识、守约经验不会持续占用修士心神预算。机械器具的负担由重量/使用条件表达，不把所有东西都硬塞进同一容量。

### 5.3 安全改准备，不用暂停免费切全套

无即时威胁、未在动作承诺阶段、未承担冲突的持续效果时，可以通过短时准备修改招式与功法。暂停允许规划候选，恢复时间后才花实际准备时间提交；正在被追击时不能用暂停界面瞬间改遍所有招式。

更换功法涉及调息、结束旧持续效果、检查携带/在途法器状态，并重新确认角色状态。改完仍保留冷却、伤势、耗材损失与已经发生的结果。紧急收束与落下器物是独立动作，不能让占用容量的法器在切换时凭空消失。

### 5.4 转向与重新学习

不存在点错一次就永久废档的常规节点。已学本领保留，可以把近期学习目标转向其他域；改主修可能需要安顿供给、调息与适应练习，旧经验可提供相关帮助，不全部清零。

少量会长期改变身体/修持方法的关键选择必须提前说明代价、可逆程度与替代方案。首版不采用需要稀有付费式道具才能洗点的通用惩罚。违反师门禁传可能有社会追责，但不能由机构远程抹掉人物已经掌握的知识。
