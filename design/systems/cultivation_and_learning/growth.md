# 修行与学习：无固定职业的本领网络：生活、传承与验收

> 详细设计与候选：具体机制、参数、样本和验收意图须验证；已确认规则见[规则目录](../../rules/README.md)。

## 7. 八种可以形成的生活与行动路线

路线是玩家经历产生的组合，不是职业按钮，不发职业专属装备或独占全部节点。

| 路线示例 | 组合重点 | 可以追求什么 | 需要承受的限制 |
|---|---|---|---|
| 山路护送者 | 直刺/守隙、辨路/护行、运筹 | 护粮、带伤员脱离、结交常走商路的人 | 正面群战与长期施法不擅长；补给和合同重要 |
| 近身御术者 | 卸力/截势、调息/引火、短步 | 控距离、打断与短术衔接 | 占用有限准备，连续贴身施术的资源压力大 |
| 护持与救援者 | 护持、急救、护行、安排履约 | 保护同伴、稳定伤员、组织撤离 | 持续控制占心神，主动追击能力较少 |
| 远行探索者 | 辨路/观势/野营、御风、问讯 | 找路、验证传闻、带回材料与见闻 | 消息可能过时，不能靠图自动知道遗迹答案 |
| 药圃与诊疗者（非战斗完整路线） | 察水土/育苗、辨材/煎药/辨证 | 稳定药源、治疗服务、研究方剂、培养学徒 | 医疗劳动和药材有成本，也需要安全和信任 |
| 工坊修缮者（非战斗完整路线） | 识材/木作/修补/因材制器、盘库 | 建设、修衣修器、定制用途、组织维护 | 依赖材料与订单，不因造武器就自动会战斗 |
| 商旅协调者（非战斗完整路线） | 议价/安排履约、稳载/运筹/应变 | 建立供应和运送服务，雇护卫而非自己练满剑法 | 有失信/欠款/封路风险，保证收益不是无限套利 |
| 聚落照料者（非战斗完整路线） | 耕作/顺时养护、编排/授权交接、礼节 | 安顿居民、生产、培养接班人、维持公共服务 | 有权才能安排他人；缺人缺料仍需协商取舍 |

非战斗路线也有有意义的难题、成长与里程碑：救活一次伤员、维持灾后供给、保住一批种苗、让经营者离开期间据点仍正常运转。它们不是给战斗角色生产装备的附属刷材料职业。

## 8. 传承和社会关系参与成长

秘籍是物品/记录，拥有权、阅读权、传授许可与人物实际掌握分别存在。拿到书可以获得学习依据；书被夺走不应瞬间删除已经理解的基础。秘本中的复杂方剂尚未记熟时，失去资料可能使相关研究暂停；具体保留什么由学习状态表达。

老师决定是否教、教哪一部分以及收费/义务。尊敬、私人情分、机构学籍和可用教学时间分别判断。换掌门可能影响课程准入和资源配给，不能让原弟子已学会的招式全变成灰色；禁传是社会风险与约束，不是远程撤销大脑。

知识可以作为交换内容，但“讲过一次”不保证接收者理解，更不能自动让接收者具有发送者完整记忆、真实认知或全部熟练。抄录会占用时间和材料；记录的出处、完整程度与可信性按信息系统处理。未经许可抄读仍可能在物理上完成并产生知识，是否合法、谁知道、怎样追责另行处理，不能把机构授权误作人物理解文字的物理开关。

## 9. NPC同样学习，但不做无限人生规划器

NPC根据职责、身体、已知机会、供给、承诺和偏好选择少量近期目标。农庄可能请人教基础照护；护卫在失利后改练守势；药师优先解决辨药与供应，不能人人同时追求最高伤害构筑。

每个NPC只保留少量近期学习计划，按开始/结束、资源不足、导师变动、受伤或目标变化重评；不每tick搜索全图最优组合。计划包括资料/老师/练习/复盘的实际阶段，不能离场后每天无成本自动“点一个天赋”。

不同NPC可以使用同一招式的较保守或激进策略，但拥有相同成本、冷却、射程、知识和持续控制约束。远区只批算可稳定推进的学习/工作区间，遇到断粮、受伤、导师离开、材料耗尽、课程截止或冲突时中断并处理。

## 10. 长期职责建议

以下为长期职责建议，不表示每项都需要新增一个类。

| 状态/定义 | 应负责什么 | 不负责什么 |
|---|---|---|
| 本领/功法定义 | 稳定ID、领域、用途、前置/等价条件、使用规则、练习类别、展示和公开程度 | 不写入具体居民熟练度或当前状态 |
| 人物学习状态 | 已知节点、来源、理解/掌握、有限练习摘要与关键选择 | 不替代个人关系、机构授权或库存 |
| 学习事务 | 导师/资料/设施/材料、耗时、进度、中断/恢复和结果 | 不凭计划产生已学能力 |
| 当前准备 | 四招式/身法映射、主/兼修、持续控制占用与待提交变更 | 不复制能力实例、重置冷却或删除已学本领 |
| 规则查询 | 依据人物所知列出学习机会；实际提交复查身体、资源、授权及真值 | 不向未知人物免费传播秘传/真实资源 |
| UI | 用途搜索、领域缩放、条件说明、学习计划、当前准备与中断原因 | 不直接写熟练值、不用按钮完成教学和交易 |

所有学习进展使用稳定人物/节点/事务ID、统一世界时间和确定的阶段提交顺序。临时派生伤害、容量汇总可重算；已经掌握的节点、来源、进度、随机上下文、冷却和持续承诺需要持久化。加载先构造候选并验证节点引用、前置依据与状态一致，再替换存活世界。

将来定义内容进入`data/definitions/`，新开局已有本领和师承在`data/scenarios/`装配；模拟、适配和界面按各自职责协作。旧档新字段不能随意给全体NPC随机补技能，须有显式迁移或仅用于新开局的策略。

## 11. 可判定的验收场景

以下均为未来验收，**本文件未声称通过**。

| 场景 | 通过标准 |
|---|---|
| 换一件衣服 | 人物轮廓/社会线索改变；未学招式、功法熟练与攻击能力不凭空增加 |
| 杂役跨学医护 | 有渠道、费用/劳动和练习即可学习；不因出身无“医师职业”被硬锁 |
| 知道老师却无时间 | 学习有预约/改期/另找渠道；不是点击一项就立刻扣钱学会 |
| 师父教过、秘籍丢失 | 已掌握基础保留，未熟记部分按定义失去研究依据；不是全部归零或免费复制完整秘籍 |
| 反复打木桩/空买空卖 | 可维持相关基础或产生正常产物，但不能无限解锁陌生能力、获得全图通用经验 |
| 败战后复盘 | 对实际观察到的问题获得相关线索/心得；不知道的敌招不自动学会 |
| 纯生产经营人生 | 能完成供给、修缮、照护或贸易的成长通路，无需靠杀敌补经验 |
| 两个槽放同一招 | 指向同一能力状态，冷却/消耗共用，不重复施放 |
| 暂停换准备 | 可以规划，实际变更待安全条件与时间提交；不清冷却、不免费结束持续代价 |
| 心神容量耗尽 | 对新的持续控制给出解释；旧法器、伤员和受护者有明确收束，不凭空消失 |
| 撤销授课资格/换掌门 | 后续机会按政策改变；已学知识不被远程删除，公私义务另算 |
| NPC自行求学 | 使用本人所知和真实资源/导师，离场仍推进；同一人不能同时教学、运粮和练法 |
| 学习一半存读/切区 | 原事务/进度/材料/导师状态继续一次结算；不重领学费、不重复消耗 |
| 实践用量长期增长 | 近期摘要有界，重要来源保留，不为每次挥剑留下永久事件导致无限存档 |
| 新版本删除/替换节点 | 明确迁移、补偿或拒绝未知格式；不静默丢功法/熟练，原档可保留 |

## 12. 早期小网建议与待校准项

早期建议以**来源明确的12节点小网**为示例：立身、直刺、守隙、调息、引火、护持、辨路、短步、辨材、急救、修补、盘库。它同时服务动作原型、非战斗行为和信息边界；跨域学习、当前准备及中断存读成立后再扩展。12/40节点只是可修改的内容示例，不是必须交付的数量。

待原型校准的是：初始心神4与占用量、主/兼修组合、各功法冲突、练习/复盘的节奏、熟练带来的操作宽容、早期资源来源、境界与技法的强度跨度。用户明确的方向是无固定职业、学习形成能力、非战斗人生完整、衣着具有独立价值；本页的容量/节点名/招式数量都是支持该方向的推荐实现，不是必须永久保留的设定。

一项节点若说不清带来了什么新选择、用了什么条件、失败怎样处理，就先不进入正式内容。图可以越来越大，每个进入图中的节点都应该让世界或人物的行动真正多一种可能。
