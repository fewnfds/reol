# 单位决策与持续任务

**P5已实现合同。** 生活、工作与战斗的自主选择共用协调入口，策略模板、个体参数和任务记忆分开。它属于[认识与自主选择领域](../../docs/engineering/architecture/05-framework-domains.md)，通过意图连接[公共行动与作用](action_effect_framework.md)，不统管其他领域事实。

P5尚不是完整的自主生命模型。能力组合、持久目的、个人评价与 NPC 共同生活归[自主生命](beings_and_lifeways/agency.md)。当前青禾宗的可玩范围见[游戏状态](../../docs/status/README.md)。

## 1. 职责与入口

`本人观察与记忆 → 选择目的/任务 → 行动意图 → 原宿主执行 → 可知结果唤醒`

| 入口 | 负责的内容 |
|---|---|
| `scripts/sim/kernel/decisions.gd` | 每单位策略绑定、手动交接、生活/战斗/逃离/跟随模式、持续任务、唤醒与有界诊断 |
| `decision_defs.gd`、`decision_rules.gd` | Resource编译/冻结/签名；从纯值观察与本人可用性选择有序规则 |
| `decision_scripts/range_score.gd` | 显式注册的受信无状态评分范例；不取得World引用 |
| `livelihood.gd` | 原有需要、本人线索与距离的生活候选选择；原宿主执行接近、采集、取放和施工 |
| `combat.gd`、`combat_scan.gd` | 接触与最后所见、威胁发现；动作、取消、缓冲、CD、成本和伤害仍在原宿主 |
| `combat_entities.gd` | 召唤寿命/归属/光环；临时身体跟随/驻守交共同协调，不与交战逐帧争抢 |

人物和随从按实际能力选择。植物、弹体和静物不因能接受作用就获得完整心智；器物已有局部索敌/周期机制继续归原owner。没有将全部生活候选改为数据解释器，也未重做社会、自然或经济规则。

## 2. 状态与交接

共享政策是递归只读编译值；每单位`records`保存政策ID、白名单参数、控制来源、模式、下次思考、任务、规则到期、受击时刻、待处理生活重选标记、反应/重规划/跟随时刻、最近目标与有界执行失败反馈。生活`known`仍归人物；战斗`engagements`仅保存接触/最后所见，没有全知黑板。

`wakeups`与`records.next_ms`配对，保存待处理唤醒。`movement`是跨区间有效的自主移动输入（含停止值），须存读；本地键鼠保持状态不入档。trace/latest是可丢诊断。

| 过程 | 交接合同 |
|---|---|
| 发现威胁 | `remember_contact → notice`只记忆/唤醒，扫描本身不提前终止工作 |
| 自卫/逃离 | 原gate允许时结束旧run、清导航/预约，再切模式；承诺动作等合法边界，强制打断/死亡仍原时刻处理 |
| 手动移动/出招/中断 | 命令成功才`suspend`；松手或到达不自动交回AI；自主工作命令显式`resume` |
| 采集后果 | 中止只清未完成执行/占用，已交付物资、伤害和费用不回滚 |
| 脱离威胁 | 按当时需要与所知重新选任务，续做重验目标和预约，不固定自动回岗 |

政策`fight/flee/ignore`及生命阈值决定威胁应对；逃离转回自卫保留0.1生命比例余量。逃不出去保留威胁，不将攻击者记为不可达而假脱战。失视只按最后所见搜索，到达或5000ms超时放弃；重获视野清旧搜索点。盲区受击来向不提供隐藏射手位置，也不覆盖已有接触。

合作双方仍由Society决定意愿、等待和结束，策略不能替对方接受。自主居民收到单次命令也关联原宿主反馈；显式手动悬挂优先。普通玩法没有NPC控制权切换界面。

## 3. 持续任务与执行

任务ID与原`domain/run_id`分开。单宿主任务引用已有工作/交互/战斗身份，不复制靠近、预约、读条、相位和费用账。World结束原run时直接通知协调器，陈旧身份不匹配就不采用。`World.emit`、日志与PersonEvents不是权威决策输入。

自主候选通过`retry_allowed`检查本人对同一操作/目标的失败反馈；即时准入拒绝和原宿主的异步失败共用`result`，不针对某种设施维护另一套黑名单。每人最多16条，保存操作、目标、原因、发生/到期时刻，以及失败时的个人线索依据。路径或作业位置等结构性失败暂缓5000ms，其他执行失败暂缓1500ms；沿已有结果唤醒重选备选，不逐帧重试。新看到的目标种类、位置、库存版本等相关事实变化或期限到达会解除抑制；单纯刷新`seen_ms`、隐藏库存变化和全图地形版本不解除。

单宿主任务可附原操作/目标与“先接近观察”标记，使前往记忆地点的探索失败仍反馈给原目的；探索到达不算原作业成功。`accepted/started/buffered`不清失败；真正完成或物品交付只清对应操作/目标，受击、取消和被替换不新增目标失败。手动命令可绕过自主候选抑制，实际成功仍解除对应反馈。目标记忆格已可见却实物不存在时，只当场清除该观察者的错误线索，未到场者保留原记忆。

施工协作承诺也遵守同一重试条件：暂时无法开工时保留承诺并有界等待，必要需求仍可进入原生活选择；不因承诺分支反复规划封闭工地，也不擅自转入无关工作。

有限序列保存槽位步骤、索引、当前绑定、等待类型、结果和截止时刻；最多8步、最长6000ms：

- `started`绑定实际激活，`buffered`只等待；转正绑定新激活，过期、失败、换装、清输入及受击作废均关闭等待。
- 自然完成后推进；下一步在原合法取消窗口可请求替换动作，宿主仍决定是否受理，不强制所有连招等到自然结束。
- 冷却、无槽、缺资源/物品退出序列供规则重选；不可执行的高优先级规则跳过，不盯冷却技能罚站。
- 外部中断、换策略和手动接管清后续步骤；离手弹体、区域、状态及已付成本继续原生命周期。

移动、瞄准和出招可以组合。重规划共用原导航约300ms节流，近距退避只检查有限局部方向净空；不是完整人群避让、全图逃生规划或复杂Boss规划器。

## 4. 分层频率与恢复

| 工作 | 当前调度 |
|---|---|
| 生活高层 | 到达/完成/失败、需求跨阈值、恢复控制等唤醒；生活结果500～950ms退避并向上对齐50ms共同网格，活跃宿主不逐帧重选 |
| 战斗局部 | `think_ms`为50～1000ms的50ms倍数，默认50ms；发现约200ms错峰，初次反应另有`reaction_ms` |
| 持续移动/动作/后果 | 原60Hz共同时间及实际动作/到期/接触细分，不因策略降频降低碰撞精度 |
| 跟随/驻守复查 | 300ms；交战暂停跟随，脱离过远先结束接触再回主人/锚点 |

合并较早唤醒；生活结果可将自己的执行结束通知改为实际退避。prepare只扫描待唤醒表，不每帧全遍历休眠单位。`next_boundary`接World共同毫秒，没有逐单位Node、Timer或第二时钟。需求仍每秒采样，饥饿/精力下降跨4000才通知，不承诺瞬时响应全部状态。

恢复先重建原gate，再验证政策签名/参数、字段类型/范围、任务身份、buffer引用、模式和唤醒配对；失败反馈及其线索依据、数量/期限和宿主操作关联同样保存并校验，非法候选整份拒载。读取不重新选择或付费，原prepare重建保存的自主输入；玩家未开始输入按旧规则清除。格式与旧档政策归[compatibility](../../docs/engineering/compatibility.md)。

## 5. 制作与绑定

1. Godot“工具 → Reol 单位策略库”打开`data/definitions/decisions/library.tres`；复制Policy，赋唯一ID并加入库。
2. Inspector设置威胁反应、生命阈值、距离带、反应/判断周期和Rule。条件为`always/near/far/hurt/recent_hit`，动作为`cast/approach/keep_range/sequence/wait`，另配槽位、距离、间隔和序列。最多24条规则；政策`max=0`用默认武器距离，此时`min`须0。有序求值按先后，`weight`供评分求值器使用。
3. 点击原生校验、检查引用；保存后关闭并重新运行游戏。重练不重新编译定义。
4. 在模拟owner冷装配或合法管理边界调用`world.decisions.bind(world, actor, "ranged", {"reaction_ms": 300})`。返回`bound/invalid_policy/invalid_distance_band/action_committed`，不能越过承诺。个体白名单为`flee_health/min/max/reaction_ms/think_ms`。手动悬挂需显式`resume`或自主工作入口交回。
5. F12输入`decisions`查看最近64条选择与当前选中/玩家的模式、任务、拒绝原因；只读脱离Frame，无任意代码执行。

现有7套：居民自卫、基础追击、谨慎撤离、连段压迫、重击间隔、射程控制、射程评分。轻敌/重敌/射手绑定对应策略，技能库仍40动作/24配置。

优先用数据增加行为。规则不足时新增可复用求值器，在`decision_defs.EVALUATORS`显式注册并更新逻辑版本；`range_score`演示接收纯值观察/本人可用性、输出意图的无状态算法。单位可变记忆不能写共享定义。受信GDScript是项目代码合同，不能强制中断恶意无限循环，不是公开沙盒；外部导入应另设计受限纯数据协议。

新增领域沿共同唤醒/任务/宿主反馈接入。图编辑器、通用BT/GOAP/HTN解释器、完整Boss、运行时模型、全生活数据化和新增预警系统均未交付，按真实内容缺口再选题。
