# 众生自行其道：Reol 世界总纲：世界对象与循环

> 详细设计与候选：具体机制、参数、样本和验收意图须验证；已确认规则见[规则目录](../../rules/README.md)。

## 1. 我们要做的不是几条并排的职业线

一个世界中，练剑的人需要药师，药师需要供货，供货依靠道路、劳动和信用；山里的鸟妖可能比任何人都知道断桥的位置，闭关的高手可能依赖一个不会斗法的旧友照料产业。各方有自己的生活，不以是否为主角提供任务判断存在价值。

玩家可以追求力量、安定、亲密、声望、发现、手艺、审美、经营、传承、复仇或隐居，也可以改变想法。系统不要求这些目标最终折算成同一个等级、产值或战力，更不要求“先打完一套战斗内容，才有资格种田、办学或做妖”。

自由来自三件事：**事物有独立用途；用途能与其他规则相接；后果会留下来。** 玩家想到用御火术烘干染布，系统检查热量、衣料、火候和劳动，而不只检查“是否购买裁缝职业”。意外的好办法可以成为当地人的新做法。

不承诺无限动作，也不把写满名词的百科当完整游戏。每项新规则都应产生可亲手尝试的选择，至少接入另一个领域，并有可观察的成功或失败。

## 2. 从文字角色扮演借来开放的看法

先像描述一个可生活的地方那样设计：这里有什么，谁依靠什么活着，谁知道什么，谁害怕失去什么，什么变化会迫使他们行动。不要先填满“力量、智力、敏捷、魅力”和八件装备，再给这些数值找故事。

但描述须分清三种用途：

| 层次 | 例子 | 在游戏中的地位 |
|---|---|---|
| 可执行的世界规则 | 木梁可燃；某种火会消耗燃料并伤及邻物 | 能被行动检查、模拟、保存和复验 |
| 有来源的认识与说法 | 老人说此戒避水；商人宣称它是仙器 | 属于说话者的知识或主张，可以错误 |
| 风味与表达 | 刻纹像失落王朝的云纹；河谷流传一首旧歌 | 营造意义；若成为解谜、权属或能力依据，须补具体关系与规则 |

一段文字可以表达意图、知识和秘密，不能仅凭“此人天下无敌”在后台跳过执行。未来AI可辅助理解自由文字，脚本/动作对象补全提供无AI可玩兜底；有支持的意图进入规则，没有支持的意图明确说明缺少哪种作用，不能编造已经发生的结果。当前游戏不接运行时语言模型，未来接入方式、版本和成本另行设计。

## 3. 世界里有哪些东西

不用一个万能“角色对象”容纳整个宇宙，也不要求每块石头运行一套心理模型。

| 对象 | 最少要回答的问题 | 例子 |
|---|---|---|
| 有意图的主体 | 谁在感知、记忆、选择，维持什么生活 | 凡人、鸟妖、寄魂者、具有意志的器灵 |
| 身体或载体 | 什么在占据空间、受影响、承载能力 | 人身、鸟身、巨兽躯体、封魂戒指 |
| 物与环境 | 有什么材料、结构、位置和变化条件 | 木门、药炉、河流、废墟、灵脉 |
| 行动与过程 | 谁在什么时候，以什么方式改变什么 | 求助、搬运、疗伤、炼制、夺舍尝试 |
| 关系与组织 | 谁与谁有何经历；谁有权要求什么 | 师徒、雇佣、宗门、村落、临时盟约 |
| 记录与信息 | 什么被谁记录，谁能通过什么渠道获知 | 私记、功德簿、假路引、传闻、观察 |

主体、身体、操控者和物主分别表达。戒指是物，戒中老人是主体；持有戒指不等于拥有老人的意志。一个主体可以换载体，一副载体也可能存在争夺控制的问题，但必须有明确的承载、感知与控制规则，不能复制同一主体或物资。

这里“不复制”指同一实例/事务不能被重复记账或提交，不是禁止设定中的造物、分魂、复制和多身。若方法允许这些变化，须明确产生的新实例/主体或控制关联、来源与持续条件；命名、转交和读档不能洗掉其限制。后台ID只用于保持连续，不是NPC可无条件读取的灵魂真名。

不是每一对象都具备上述全部字段。无心智树木有生长过程；树妖才增加记忆、意图和交流。普通蚁群可先作为群落过程，玩家接触并赋予持久关系的具体蚁妖才需要稳定个体记录。

## 4. 共同规则：问“能怎样做”，而不是“属于哪个职业”

### 4.1 能力依处境查询

一次行动检查执行者的感知、移动、操物、表达、理解、承载与维持条件。它们来自身体、已学方法、器物、场所和协作，不是一张全体生命共用且永久不变的属性表。

麻雀有飞行和喙爪，没有人类双手；巨兽有巨大牵引力，但过不了小桥；戒中人能传意，却未必能移动戒指。修士的神识可能发现凡人看不见的印记，凡人工匠却能凭材料与工艺识破修士不熟悉的赝品。

内部使用尺寸、重量、距离、耗时、可用能量、风险等数值。每个数值属于具体作用和对象，按需出现；前台优先说明“翅膀受伤，无法越过山口”“气机不合，强行驱动会灼伤载体”。不强制把一切藏成谜语：自己数得清的粮食、约定价钱、交货期限应准确显示。

### 4.2 意图与执行分开

所有执行入口遵循同一链条：

    产生目的 → 根据所知找办法 → 选择对象与方法 → 检查条件与代价
       → 预约/取得控制 → 花时间执行 → 提交变化 → 有限观察与后续行动

玩家直接选择自己的意图；NPC从已知可用办法中选。让他人办事通常是提出请求、合同、命令或威胁，不是直接接管其意识。已接受职责内的普通动作无需每一步重新掷社交骰；任务变质、风险变化或违背底线时才重新判断。

行动说明至少包含：执行者、实际目标、所用方法、媒介/工具、作用范围、开始和结束条件、资源、可能故障与可观察痕迹。并发冲突由明确的预约、到达和结算顺序处理，不能由界面先刷新谁决定。

一个过程可以有多个参与者与设备，但只有一个权威提交负责人。共同抬木、器灵指导和合作炼制按参与角色及阶段处理；个人行动按实际占用的移动、操物、表达、注意等通道判断冲突，不把“只结算一次”误写成“一个人同时只能存在一个过程”。持续术法有自己的来源与维持条件，首次确有需要时做最小实现。

### 4.3 小量通用作用，加上领域专用规则

先采用能够跨域复用的作用族：移动/施力、转移/容纳、热/冷、湿润/干燥、遮挡/照明/发声、供能/引导/封存、信号/消息、授权/承诺。具体作用仍有明确类型、目标和适用条件。

“可燃”不能意味着所有火都瞬烧所有材料；“会飞”不意味着能带走整座山；“具有幻术”不意味着能改写机构账本。药性、灵性、印契、神识等超自然机制需要自己的作用协议，不能只靠标签联想自动判定一切。

同一种有边界的效果可以服务多种用途：引火可战斗、烧水、烘干，也会暴露位置和损坏载体；驱虫可护药田，也会影响靠虫谋生的鸟妖。先把这些相接点做实，不追求像素级流体或完整化学。

组合规则须声明目标类型、通道/范围、量与单位、持续时间及相互作用。防护、穿透、叠加、抵消和局部例外由对应领域规定，不能靠标签词面或加载顺序决定。先让两个用途共用一种完整作用，再扩大语法。

## 5. 世界的骨架是相互依赖的循环

| 循环 | 过程 | 缺口如何变成玩法 |
|---|---|---|
| 生境与生计 | 水土/季候→植物/动物→采收/捕食→消耗/再生 | 枯水、栖地改变、过度采集、迁徙；觅食、灌溉、协商、搬迁都可介入 |
| 劳动与流通 | 原料→加工→储存→运输→使用/修补/废弃 | 工具、工艺、仓储、道路和劳力互相制约；不只增加产量 |
| 知识与传承 | 察觉→解释→试验→传授/记录→失传/修订 | 误认、保密、语言隔阂、旧书缺页；研究、翻译、拜师、行骗都有空间 |
| 人际与制度 | 相遇→经历→期待/关系→请求/承诺→履约或争议 | 尊敬不等于信任，信任不等于愿意冒险；组织承诺需要有人兑现 |
| 修持与异变 | 获取适合的养分/灵气→练习/调节→能力变化→新需求与风险 | 环境、身体、方法和导师形成不同路径；不是所有生命统一刷杀敌经验 |
| 权力与历史 | 资源/成员/授权→组织行动→利益变化→冲突/继任/新秩序 | 掌门更替、旧账冻结、商路改道、圣地衰落；远方也有原因和后果 |

循环不必永远平稳。世界允许消亡、繁荣、失败的制度、被取代的工艺和暂时无人解决的问题。资源紧张可以驱动故事，但不让全世界无休止地饿到只剩劳动，挤掉社交、研究、创造和闲暇。

### 5.1 修仙世界的自然法则：先有可理解的来源与边界

建议用“物质、生命、五行环境影响与灵气、心智、契约”描述不同作用，不立五个万能资源条：

- 物质有位置、构造和可追踪的转移；实体储物空间若扩展，须明确空间归属、出入口、容量与故障。
- 生命依不同结构维持，凡人吃饭、鸟妖觅食、寄魂者依赖载体稳定；不要求全体吃同一种粮或休息同一张床。
- 五行环境与可花费的灵气分别成立：万物按自身五行构成持续影响周围环境，影响有范围和衰减；修炼者受环境浓度促进，不消耗这份场强。可吸收、输送、储存的灵气由原物品等承载者另持储量，实际抽取才扣该储量，不能把同一余额花两遍。
- 心智有感知、注意与记忆边界。传音、梦境、幻觉分别规定传递/遮蔽的内容与痕迹，不默认全知读心。
- 契约的社会约束与天地强制是两种规则。若设置誓约法术，要有见证机制、可识别的违约条件及作用对象；普通口头承诺不能突然触发宇宙雷罚。

2026-11-05用户确认：所有物品的五行辐射类似催化环境的持续影响，不被外物或修炼吸收消耗，向周围扩散并在远处衰减、消散；每件物品的强度和范围可以不同。可吸收灵气是物品独立的一项状态，物品浸泡在五行辐射环境中可以积攒灵气。容量、积攒规律、吸取后的物品变化和相应玩法后置，先验证大世界框架；不能因现实守恒类比擅自禁止这条仙侠世界法则，也不能提前开放未实现的补气玩法。细则见[环境方案](../../proposals/environment/elements.md#5-五行环境影响与可吸收灵气分开)。

同日追加边界：异类地面物铺开放，同类相容堆只算一份对外强度，数量账保留；五行逐通道max。冷热采用欧氏圆形场，热冷有效等级各取最大后抵消，再相对季节中性温度查表，不平均源摄氏值；等阶冰火对等，冷端温度下限不截断其抗热等级。室外逐格响应，室内按面积平均净等级、一房一温，火冰墙可作来源。原物本体与环境分开，移物后新建立/旧消散；人物/携物新增五行源暂缓。不逐格守恒热量，定向/聚光/反射后置。细则见[环境规范](../../proposals/environment/temperature.md#普通逸散与多来源换热)。

上述已确认部分约束后续实施，其余仍为推荐世界语法，不是全部境界或宗教的最终设定。允许真正的神迹和例外，但例外也须有可复验的作用范围、触发来源或隐藏条件；角色暂时不理解，不代表作者可以事后改口。

2026-11-03用户确认：大多数生命原则上有适合自身的修行路径；少数因当前先天身体/载体条件受限，可通过具体改造或迁载等途径改变。机会仍依方法、资源、经历与代价成立，不保证任何生命都能学会所有方法，也不把人形、同种灵根或固定职业作为全世界前提。具体比例、难度与成长曲线由开发验证。

“物资守恒”在本项目首先是账实一致，不要求所有超自然作用服从现实质量/能量守恒。允许法术产生新物质，但来源、成本或成立条件、持续/消散与实际影响须明确。便宜且可靠的造物若真的存在，应允许改变当地稀缺性和社会组织。

### 5.2 力量不均等，因果仍须一致

一只大妖可以远强于一村凡人；传世重宝可以改变地区格局；专家能轻易做到外行做不到的事。不要为竞技平衡抹平体量、知识和积累。

需要限制的是凭空复制资产、无条件全知、无成本重置失败、离场重掷和规则自相矛盾。非常有效的技巧可以保留：竞争者学习、材料涨价、消息传播、工序改造会自然改变处境。不是每个好办法都要偷偷加惩罚或刷一只更强的敌人。

凡人不必靠“每次攻击至少掉一血”证明有价值。强者也可能有完全成立的绝对防护；要说明防护的媒介和边界。对某个目标确实无能为力是允许的，但世界应仍有其他可生活、协作、迁居和改变条件的路径，不强迫每个角色单挑一切。
