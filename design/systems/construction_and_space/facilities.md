# 建造、空间与共同生活：设施、储藏与工作

> 详细设计与候选：具体机制、参数、样本和验收意图须验证；已确认规则见[规则目录](../../rules/README.md)。

## 家具怎样成为设施

可交互家具需要稳定身份、位置/方向/占地、可接近的操作位置和可提供的动作；定义按需要声明材料、体量、承载、适用对象和连接代价。操作位、座位、物料口可以分别存在，不把来客、值事人和搬运者都压进同一格。外观朝向与实际操作面一致。

能力按需组合：桌面可以放置和书写，座椅支持坐姿，炉具容纳与加热，阵盘引导特定来源的灵气。拥有桌面不代表满足全部锻造、手术或炼器要求；必要条件须能被理解。也不为统一接口，要求每把椅子都有完整人物属性、AI和每帧Node。

不同生命需要不同尺度与动作条件：小妖可用矮台，巨兽需要净空/承重，鸟巢或栖架可替代床，植灵可能需要植根空间，器灵可通过合适器具操作。法术可代替手、火或搬运，仍须真实能力、媒介、成本和意愿，不给所有生命套人类床和固定家具槽位。

花盆、水槽等可提供栽培承载：基质、根系容量、供水和承载位置属于设施条件，原植物保留自身年龄、活性与产物。它不是把植物放进普通储物箱后暂停生长；植入、取出、承载损坏有明确结果，环境读取真实位置和暴露条件。首版花盆的接入范围见[植物接口](../../../docs/engineering/plants-contract.md)，完整室温、自由携盆与嵌套栽培空间按所属框架扩展。

### 常见组合与玩家选择

下表是未来内容目录，不因写入而实现。每次选能服务实际玩法的一小组接通。

| 活动 | 可组合设施/空间 | 人与物的关键条件 | 可玩的差别 |
|---|---|---|---|
| 起居休息 | 床/榻/铺盖、衣柜、屏风、灯、门窗、私人物件 | 身体适配、床位/访客关系、可达与安全 | 借宿/同住、私密/安静、雨冷遮蔽；贵床不保证适合鸟妖或苦修者 |
| 会客聚餐 | 桌席、座位、茶具、灯、庭院、客位 | 实际食物/茶水、接待者、来客认识与礼仪 | 公开/私谈、座次、款待/冷落；桌子不自动生成宴席或忠诚 |
| 厨房餐饮 | 灶/炉、锅、操作案、供水器、食柜、餐桌 | 方法、食材、热源、劳动 | 备食/干粮/饭铺，做与吃分开；不用先建复杂农业 |
| 锻造修补 | 炉、砧、夹具、案台、淬制容器、通风/防火区 | 材料、锻法、工具、火候、身体能力 | 换材、修旧器、委托师傅、承担烟热火险；不靠建筑等级凭空产武器 |
| 炼丹制药 | 丹炉、药案、药柜、研磨器、温养/封存位 | 已知丹法、药性认识、药材/火源、操作阶段 | 选药控火、试验、托人守炉；不先铺全套药材产业 |
| 炼器养器 | 器炉、刻阵案、夹具、材料架、封存匣、阵位 | 工法、材质/器性、灵源/媒介、器灵关系 | 修复改制、分工、借灵地；高阶设备不代替理解与驾驭能力 |
| 读写研究 | 书案、简柜/书架、光源、刻写工具、样本柜 | 可读载体、识读/理解、时间、记录权限 | 借阅、笔记、抄错、鉴伪、讨论；书架不是共享知识光环 |
| 修炼授业 | 蒲团/静室、练功场、靶具、阵器、灵源接点 | 方法、身体、环境适性、师承或自学条件 | 闭关、演练、护法、讲学；静室不自动发经验 |
| 疗养救护 | 榻、诊案、药具、清洁用品、照护空间 | 患者/施治者条件、真实药物与时间 | 陪护/隔离/就近施救，医馆名号不自动治病 |
| 办事档案 | 桌案、值事位、来客位、档案柜、账簿/记功器 | 现任授权、记录有效性、到场人员、库存 | 任职交接、公私记录、排队/代理；柜子不产生官方效力 |
| 展陈祭祀 | 展架、画卷、牌位、碑、供案、庭景 | 物件来历、地方礼俗、参与者与实际仪式 | 招待、纪念、威慑、身份表达，也可能犯忌；不默认全局加功德 |
| 仓储封存 | 货架、箱柜、粮缸、药匣、兵架、宝匣、储物法器 | 容量/相容性、保管访问、环境/封印 | 取用、隐匿、防潮、避火、隔绝器性、托管；详见下节 |

## 储藏：实物、保管与知识分开

物品只有一份权威归处：地面、某容器、某携带者，或明确的在制过程。柜子记录容量/位置和容纳关系，不再复制同名库存。堆叠材料按批次保存数量，唯一法宝、账簿和有独立来历的器物保留身份，不把每粒米都变成实体。

地面掉落按2026-11-05规则：不同物品分散铺放，同类且状态相容才合堆；同类堆的环境逸散只算一件强度，不按数量放大。此处只约束地面堆，不把柜子变成只能存一种物品，也不禁止墙、地表、屋面与区域等兼容空间层共存。人物及其携带物如何整体影响五行仍需设计；细则及邻堆叠场未决边界见[环境方案](../../proposals/environment/elements.md#地面堆叠与来源边界)。

| 容器侧重 | 可提供的条件 | 不应隐含发生的事 |
|---|---|---|
| 衣柜、杂物箱 | 整理、保管、取放、个人使用范围 | 入柜即转所有权 |
| 粮柜、粮缸、地窖 | 按实际密闭/干燥/温度保护食物 | 自动冷藏、永久保鲜、隔空供给 |
| 药柜、材料匣 | 分类、相容隔离、封装、查找 | 普通柜自动识药或消毒 |
| 简柜、档案柜 | 定位知识载体、限定访问 | 入柜全员学会，柜毁全员忘记 |
| 兵架、宝匣、镇物台 | 展示、固定、封存或隔离 | 展出即认主、封存必安全；封印须方法/材料/维持条件 |
| 储物法器 | 在具体法则内改变携带/空间条件 | 无限容量、人人可用、失主即归拾取者；认主/反噬归器物规则 |

物理持有、看守、所有权、使用权、机构职权、钥匙/封印能力分别判断。管理员能接触公物，不等于能私卖；有钥匙不代表合法，有贡献不自动开锁。未来偷取、借用、托管的物理行动与社会后果各自成立，不能用一条“不可交互”代替全部规则。

过滤、优先级、柜名是整理政策，不能移动物品。搬运须知道来源/目标、预约真实容量、沿路到场；改过滤不吞旧物。容器破损或搬走时内容有明确去处；容量不足时留在原处或产生可解释的溢出，不悄悄销毁。套娃容器须拒循环引用，深度与查询预算以后测试定。

知识载体、内容、真实性/官方效力、人物已学知识分开。迁柜只搬书；毁原本可能损失独有信息，却不抹抄本、证人、记忆或既存债权。读账不等于有记账权；个人私簿进入公账柜也不会变成机构承认。法器记录须有登记、访问和同步规则。完整载体搬运/损毁与多副本同步仍待实施。

## 工作是一段共同世界中的过程

统一请求表达“谁希望谁，以什么物/方法，在什么条件下做什么”。无AI时可选动作/对象/条件；未来AI辅助理解/计划，最终仍用相同规则。工位可说明操作，人物可自述本领，接受委托和真正完成分开。

推荐链路：提出/发现机会 → 理解协商 → 查能力/意愿/权利 → 预约资源与操作位 → 取料/移动 → 分阶段操作 → 当场形成结果 → 检查/取走/交付。环节可简化，不能省掉其实际承担的物质/社会条件。

- **竞争**：同一双手、炉膛、桌面操作位、同批料不能同时用于互斥工作。按真实容量处理，不为每个系统再造一份“人物忙碌”真值。
- **在制物**：炉中丹液、半刻器件保存材料、阶段、位置和已投入劳动。接手要有方法与约定；停工不自动退料或交付。
- **阶段**：搬运、升温、锻打、冷却、刻写、检查可有不同条件。有的可无人看守，有的须持续控火；不把一切变成“点一下等倒计时”，也不先模拟全部微观过程。
- **中断/失败**：离位、受袭、缺料、熄火、器具损伤、方法失误分别影响暂停/返工/降质/报废。实际燃料/灵气支出不返还，副产物有去处，随机不能替代能力与条件。
- **替代/创造**：凡火、地火、御火可支持同类步骤，但火性、控制、来源与代价不同。露天修剑、借炉、两人分工应能成立；替代须有因果，不能一句描述绕过世界规则。
- **交付/责任**：材料、工钱、成品、余料各有所有者/受托人。委托锻剑不授权取师傅全部材料；拒办/离岗保留实物与未结责任。

炼丹、官方记账、治伤各有领域规则，共用取放、到场、预约、时间和记录接缝。不每项工作新建一栋功能建筑，也不把全部独特效果塞进万能配方解释器。

## 人、组织与有限认识

NPC和玩家共用到场/取物/操作规则。选择休息、钻研、会客、当差或逃离，依据身体、个人目的、经历、已知地方、承诺与风险。“安排工作”是须传播的请求/命令，不直接改写NPC意志；器灵和守门妖物同样有理解与意愿。

设施可以归宗门、商号、家庭、个人或松散共用。谁值事、谁可用、谁维护、收费与交接来自组织/约定，物件不产生权威。土地、房屋、家具、内装物可以属于不同主体。开放工坊、租炉、客房、隐秘会所由这些关系组合，不先限定为“招人种地”。

人物凭看到、听说、登记、亲用认识场所。匾额、布置、守卫、火光提供线索，可能过时或伪装；不在场不读柜内实时清单。依旧记忆找药柜却发现空了，应能询问/替代/等候，不能暗中补药。

隐私与礼仪不全压成“房间分数”。闯卧房、坐错主位、展示仇敌法宝、翻私簿，影响谁取决于知情、文化、关系和制度。高手未必在意华丽摆件，却可能在意藏经、安静或阵位；同一装饰对不同生活者有不同含义。
