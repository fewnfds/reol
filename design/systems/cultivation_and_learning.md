# 修行与学习：无固定职业的本领网络

成文：2026-11-02。**本领网络、突破与通用创法仍待实现；已有有限学习与探查样本，不代表整套学习系统完成。** 当前行为见[FEATURES](../../docs/FEATURES.md)，证据见[BASELINE](../../docs/BASELINE.md)，授权见[HANDOFF](../../docs/HANDOFF.md)。

本页落实大型网络的组合自由、开放传承、通过选择/学习/实践成长。[世界总纲](self_consistent_world.md)、[众生](beings_and_lifeways.md)与[知物创法](knowledge_artifacts_and_invention.md)优先：图表示有根据知道的路线，可发现/改良/创造/误抄/失传，不是宇宙全部本领的固定清单。

以下人形入门节点、三境界、快捷槽、心神容量和数值只是原型候选，不适用于全体生命。多数生命有适合自身的修行路径，少数须改变先天条件；具体方法仍有适配与代价。五行/风水、环境和社会知识对方法的作用见[最新交互原则](world_interaction_principles.md)，尚无对应新玩法。

## 1. 玩家在选择怎样过一生

玩家可以练剑，也可以先学辨药、经营药圃、教人处理伤口，再学习护送途中够用的身法。宗门弟子、护卫、药师、工匠和管事是人们对其经历、工作与身份的称呼，不是创建角色时不可跨越的技能菜单。

图上的分支表示不同领域如何相互支持。炼丹可以借用火候控制，种药依赖水土观察，护送需要辨路与协调；武艺可以帮助护身，不能代替粮食、证据、信誉或机构任命。玩家不必为了完成非战斗人生而把战斗分支点满。

本系统允许量化，但每项进展必须回答：**从哪里学、练过什么、现在能多做什么、受什么限制。** 不设置一个“总等级”同时发放攻击、社交地位和所有领域的万能点数。

## 2. 什么构成人物的能力

| 层次 | 负责什么 | 不能替代什么 |
|---|---|---|
| 身体和先天倾向 | 体能、感知差异、伤病限制、学习起点；先天影响代价或容易方向 | 不决定终身职业，不用一项资质封死整个人生 |
| 境界与基础修持 | 灵力容纳、调动复杂度、耐受和寿命等能力边界 | 不自动教授全部招式、发官职或让陌生人忠诚 |
| 功法 | 运用身体/灵力的方法、适合的节奏与代价 | 不等于整套职业，也不是换件衣服自动生效的属性包 |
| 学过的本领 | 实际会做的动作、工艺、治疗、判断和组织方法 | 听说名字或拿到秘籍不等于已经会用 |
| 熟练与心得 | 执行稳定、准备步骤、资源控制、衔接和情境理解 | 不凭练剑给种田与查账统一经验，也不无上限加伤害 |
| 当下准备与状态 | 运转中的功法、准备招式、持续术法、体力/灵力、疲劳和伤势 | 已学很多不等于同一时刻能全部开着 |
| 工具、场地和协作 | 刀具锋刃、药炉、工作台、材料、地形、同伴与计划 | 不把普通衣服、首饰和身份服装强制改成战斗属性来源 |

战斗能力从可执行的招式、基础修持、身体、练习、时机和情境产生。衣服可以有实际防护、负担和社会含义；法器可提供某项能力，但只在拥有、会用、已准备并支付代价时成立。首版不显示可跨一切场景比较的“战力总分”。

境界暂沿用长期方案的炼气→筑基→金丹三个可玩层级；它们扩大能够维持和组合的能力范围，不做每境界伤害、血量全部乘十的强制模板。具体量级由战斗样例验证；高境界人物仍有目标、注意力、消耗、伤势、政治责任和不擅长的事。

## 3. 取自大型天赋盘的是什么

[PoE官方被动树说明](https://www.pathofexile.com/passive-skill-tree)介绍了共享网络、不同起点、引导技能簇的显著节点，以及会改变规则并伴随取舍的关键节点。[官方游戏概述](https://www.pathofexile.com/game)把主动技能/辅助宝石与被动树分开。本文只借鉴**网络浏览、跨领域组合、重要节点改变玩法**，不复制其图像、文本或代码，也不把商业游戏的装备经济和角色职业规则当本项目约束。

Reol的区别是：

- 各主体可复用适用于自身的作用与方法定义；出身装配已有经历、资料和认识的人，不锁定图上起点，也不强制共用完整知识图或身体条件。
- 图的连线是可理解的学习路线，不是向宇宙支付一个通用点就获得能力。
- 主动招式、工艺、修持和实用判断可以在同一张知识图中查看；执行规则仍分属对应领域。
- 连接到一片领域只会暴露下一步线索和条件，不能无师无书自动掌握门派秘法。
- 学会后可以长期保有，当前准备与持续运转另算，不靠频繁遗忘本领制造配点限制。
- 少量节点可提高效率，但大多数应开新动作、替代步骤、协作方式或明确取舍，不铺几百个重复的“攻击+5%”过路点。

**常人的基础行动不被图锁住。** 没学问讯、礼节或议价，仍可交谈、按自己所知称呼别人、直接报价与拒绝买卖；没学盘库或编排，仍能数自己可见的背包物品、安排自己的时间。对应节点带来系统化方法、复杂任务处理、可靠识别、信息整理或模板代办，不能变成正常人类行动的许可证。未学立身仍会站立、走动、避让或笨拙推挡；未学急救仍可求救、按常识尝试简单压迫止血，专业诊断、稳定复杂伤势和高风险操作才有真实知识/材料门槛。基础能力差异来自身体和已有生活经历，不要求全体NPC先逐点买回普通生活。

### 3.1 图、前置条件和线索分开

图有三种不同关系，界面用不同线型，不混为一条硬门槛：

| 关系 | 例子 | 是否必须经过 |
|---|---|---|
| 理解前置 | 先能辨识材料，才可靠地区分某药方中可替代的材料 | 该本领的真实能力要求；可由等价经历满足 |
| 学习路线 | 已学守势，师父建议下一步学卸力 | 推荐路径，不排斥别处学到等价基础 |
| 跨域协作 | 引火辅助煎药，盘库辅助药圃经营 | 组合机会；不把不会御火的人全部挡在药师之外 |

条件可写为“具备A或等价基础B，再有资料C与设施D”，不能只能按一个职业序列从头点到尾。等价基础必须明示来源和能力意义，不能为了让某例通过而运行时随意放宽。

### 3.2 玩家看到自己有根据看到的部分

“入门武艺”“常用医护”“基础生产”等公共领域可见大致轮廓；接触过的门派资料、师承或见闻展示相关具体节点。未知秘传显示“有人以此类方法施术”的线索，不直接显示准确名称、配方、战斗弱点或持有者位置。

规划模式可以列出玩家已知路线的未来需要，包括老师、学习费、材料、场所和预计练习；不自动替玩家全世界找真相。搜索“护送”“止血”“远行”等用途能高亮已知相关节点，允许固定两三条近期学习目标。

## 4. 学习是一个能中断、能解释的过程

### 4.1 一项本领的状态

| 状态 | 人物掌握了什么 | 可以做什么 |
|---|---|---|
| 未接触 | 没有足够线索 | 不在个人准确知识清单里 |
| 有线索 | 听过、看过表象或获知学习渠道 | 询问、观察、购买资料或寻找老师 |
| 已理解 | 有可靠说明并理解其要求 | 制定练习计划；高风险实践仍有明确警示 |
| 已入门 | 完成必要示范/练习，具备最低执行能力 | 可以实际尝试，按本领定义承担代价与失败 |
| 已熟悉 | 在有意义的情境完成练习与复盘 | 稳定执行，并逐步解锁该本领的一种用法变化 |
| 已融会 | 达到该节点明确的掌握条件 | 使用关键变式、教授允许传授的部分，或成为跨域前置 |

这是人物状态，不要求每次显示六根进度条。界面重点显示“会不会、缺什么、熟悉到什么程度、下一步可怎么练”。内部进度有界，状态改变必须有依据；首次掌握与往后熟练不能都靠同一个无限累计数处理。

### 4.2 一次学习事务

选择目标→检查本人所知和渠道→与老师/持有人约定或另行取得可用资料→安排练习时段、场所和投入→实际练习→得到反馈→复盘或再请教→提交掌握结果。

参与者并非必须全部存在。基本搬运与安全野营可以实践学习；复杂内功和药方通常需要资料或老师；独自研究可以作为较慢且有明确风险的替代。NPC对资料的判断也基于其所知，拿到假方可能浪费练习或发生后果；模拟不能让未知真假通过“可学”按钮提前泄露。

教学是实际服务：老师有时间、能力和愿意教授的范围，可能要求学费、材料、师门义务或帮工。宗门贡献能换某项课程，是机构和教学者提供的机会；不是扣贡献后立即在人物脑中生成完整能力。

### 4.3 修炼、练习和实战心得

三者分别计入，不能互相无限兑换：

- **基础修炼**改善该功法的调动与境界准备，消耗时间、生活供给、场地或材料。
- **定向练习**形成已知本领的基础执行。木桩、试作、演练可以安全入门和保持手感，但不能单凭同一动作无限掌握陌生战术。
- **情境心得**来自出现了新问题的实践和复盘，例如成功护住伤员、判断一次陌生症状、处理真实交付偏差。结果失败但人物观察并复盘了原因，也可能获得相关理解。

杀死目标不是统一经验来源。自卫、切磋、危险预判、救人、撤退、完成复杂工艺和管理一次缺货，各形成自己领域的依据。重复针对同一无威胁目标、自己制造无意义伤病再治疗、原地空买空卖，不得成为更快的全图成长路线。

反刷机制采用有限的**实践情境类别、近期重复度、难度适配与复盘是否完成**，不保留每次挥剑全量日志。已经掌握的简单劳动仍产出真实物品与收入，只是不会无限提升熟练；不为了防刷剥夺正常谋生。

### 4.4 暂定节奏

首个入门本领应在一次短教学与可控练习中变得可用；第一小时让玩家掌握一种可靠谋生方法、两三种战斗/避险动作和一个能改变做法的节点。高级掌握需要跨多个世界时段的实践，不以无意义等待填时长。

练习耗时定义在共同世界时间中。现场动作按战术尺度执行；长练习、闭关或制作可以选择整体加速到下一个需要处理的边界。不能让玩家练了一个月，而远方商人只过一分钟。具体分钟数、各阶段阈值和学习费用在原型后进入数据定义，本文不硬填一条未经体验验证的经验曲线。

## 5. 学会、准备、运转不是同一件事

### 5.1 长期本领不靠四个快捷键裁剪

人物可以学会很多东西。战斗首版推荐四个准备招式（Q/E/R/F）、一个身法动作（Shift），以及基础动作和架势动作；它们只是当下的快速调用配置。生活手艺从当前场所与事务菜单使用，不占战斗四槽，不因改成治伤配置就忘记种田。

同一个招式放在两个槽里，仍共享自身冷却、消耗和使用状态；不能复制两个技能实体。准备与移除不清除冷却或持续代价。快捷槽上限用于动作清晰与准备选择，不作为人物智力/记忆只能容纳四项的设定。

### 5.2 功法运转与心神容量

推荐初始心神容量为4，仅作为持续控制的离散预算，用来描述“同时顾得过来多少件需要持续分心的事”。它不是另一条每秒消耗的蓝条，不同于短时体力、灵力或长期疲劳。

推荐最多运转一门主功法，另有一门兼修方法；两者都计占用和兼容要求。简单主功法占1、兼修占1、持续护持/御器等占1–2，是待验证的示例。未知高级功法不能靠同名普通槽绕开境界与学习条件；容量成长有上限，不能随境界无限膨胀到全开。

| 现象 | 规则 |
|---|---|
| 知道三门功法 | 保留三门的学习记录，可安全地改准备方案 |
| 主功法与兼修相容 | 按说明组合，占用与消耗都存在 |
| 两法的调息方式冲突 | 不能同时运转；界面在确认前解释冲突，可在安全状态转换 |
| 持续护持再御器超容量 | 必须先结束其中一个持续效果，不能自动抛弃已托管的实物 |
| 长期疲劳或伤势影响控制 | 降低恢复/稳定或当前可用预算，结果预警；持续能力按安全收束流程处理 |
| 短暂进入姿态 | 由战斗动作管理，不因另写“姿态”就绕过持续能力预算 |

技能不因放在准备栏就持续占心神；只在其定义确实需要持续控制时占用。普通持剑、穿衣、煎药知识、守约经验不会持续占用修士心神预算。机械器具的负担由重量/使用条件表达，不把所有东西都硬塞进同一容量。

### 5.3 安全改准备，不用暂停免费切全套

无即时威胁、未在动作承诺阶段、未承担冲突的持续效果时，可以通过短时准备修改招式与功法。暂停允许规划候选，恢复时间后才花实际准备时间提交；正在被追击时不能用暂停界面瞬间改遍所有招式。

更换功法涉及调息、结束旧持续效果、检查携带/在途法器状态，并重新确认角色状态。改完仍保留冷却、伤势、耗材损失与已经发生的结果。紧急收束与落下器物是独立动作，不能让占用容量的法器在切换时凭空消失。

### 5.4 转向与重新学习

不存在点错一次就永久废档的常规节点。已学本领保留，可以把近期学习目标转向其他域；改主修可能需要安顿供给、调息与适应练习，旧经验可提供相关帮助，不全部清零。

少量会长期改变身体/修持方法的关键选择必须提前说明代价、可逆程度与替代方案。首版不采用需要稀有付费式道具才能洗点的通用惩罚。违反师门禁传可能有社会追责，但不能由机构远程抹掉人物已经掌握的知识。

## 6. 首批40个节点：八域互通

这是**首批内容候选池**，不是首个战斗原型必须全部实现。最小切片先从中挑12个形成可玩通路，后续再扩至40个；“大型”由可扩展网络与组合产生，不能为了图看起来大先堆空节点。

每域五个节点，最后一项优先提供改变策略的关键用法。名称为本项目占位设定，不能据名称推断额外法术。各节点有独立学习来源；下表的组合不代表一项熟练度自动灌注另一个领域。

表中的“新增选择”以已有普通生活能力为底：例如W1新增的是受压时较可靠的定向守势，不是解锁站立；I3新增组合条件的协商模板与判断，不是解锁说出价格；G1新增对多容器、预约和报表的核对方法，不是解锁看自己带了多少粮。专业操作未达要求时，应同时保留安全、简单或求助版本。

| ID | 节点 | 实际新增的选择 | 学习/使用边界 |
|---|---|---|---|
| W1 | 立身 | 可保持合适步距与定向守势，理解失衡风险 | 基础示范/练习，受伤身体仍有限制 |
| W2 | 直刺 | 使用窄线、较明确距离的攻击 | 需要适合工具；不是一切武器都能同样刺击 |
| W3 | 守隙 | 执行防御后辨认可靠的短反击机会 | 依赖可见动作，不读敌人隐藏冷却 |
| W4 | 卸力 | 用方向与时机化解部分冲击 | 有体力与位置代价，不能全方向免伤 |
| W5 | 截势 | 改为抓前摇打断，放弃部分追击能力 | 有准备/恢复承诺，打错时机暴露破绽 |
| A1 | 调息 | 有意识地收束灵力、稳定施术准备 | 不是一秒满灵；疲劳和伤势影响恢复 |
| A2 | 引火 | 从既有火种或灵力维持小规模火候/火术 | 野外用火有环境边界，具体伤害由动作定义 |
| A3 | 御风 | 形成推移/导流的有限作用 | 不等于无需代价永久飞行，重物与固定物受限 |
| A4 | 护持 | 持续保护自己或一个对象的有限范围 | 占心神、耗灵力，受打断/距离约束 |
| A5 | 分念 | 在较低单项强度下维持两项兼容控制 | 改控制分配规则，不能凭空加总容量 |
| S1 | 辨路 | 根据地形和已知线索选择可行路线 | 不揭示未侦察敌人，不穿过实际关隘 |
| S2 | 短步 | 学会一次可靠的小位移/脱离动作 | 共享身法冷却/体力与地形限制 |
| S3 | 稳载 | 搬运时选择稳妥步态与装载方式 | 不无条件扩大背包，不抵消实际重量 |
| S4 | 观势 | 判断可见来袭方向并规划避让 | 不读取视野外目标的准确蓄力状态 |
| S5 | 护行 | 与一位合作者协调移动/撤离 | 限距离与协作范围，不能把不愿同行的人强行拖走 |
| M1 | 辨材 | 对接触过的常用药材做基础区分 | 陌生品种仍需资料或检验 |
| M2 | 处理 | 采用合适清理、保存与基础加工 | 消耗容器/时间，避免采到就永久保鲜 |
| M3 | 煎药 | 按已掌握方剂制作基础药物 | 需要真实原料和设施；会煎药不等于知道所有方剂 |
| M4 | 急救 | 止血、固定与初步照护 | 不是瞬时回满健康；需物品、时间与后续休养 |
| M5 | 辨证 | 结合病案与观察选择诊疗次序 | 可表达不确定，不能精确读取所有隐藏病因 |
| C1 | 识材 | 判断常用材料适用的工序与风险 | 特殊材料需试验或可靠资料 |
| C2 | 木作 | 完成基础木件、箱具和设施部件 | 需要工具、工位和材料，不能远程生成建筑 |
| C3 | 修补 | 判断并修复可修的衣物/器具损坏 | 区分清理、缝补和结构修复；并非全部能恢复如新 |
| C4 | 铸修 | 处理基础金属器具的制造/修理 | 依赖炉具、金属与安全条件 |
| C5 | 因材制器 | 在已知工艺内选择不同材料/结构方案 | 用途取舍，不产生随机万能攻击词条 |
| L1 | 察水土 | 判断可见水源、地势和常用作物适配 | 需实地或可信报告，不免费远程扫描全图 |
| L2 | 耕作 | 正确安排播种、照料与收获 | 生长与资源容量真实推进 |
| L3 | 育苗 | 保存种苗、扩大或替换种植 | 输入/时间/成活条件存在，无限复制稀有灵植不可用 |
| L4 | 野营 | 建立简易休息和基本补给安排 | 取决于场地与器材，危险不能一键消失 |
| L5 | 顺时养护 | 调整作物与生活计划应对已知季节/资源变化 | 改排程与风险，不直接给全村产量百分比 |
| I1 | 问讯 | 组织更明确的问题，区分亲见和转述 | 他人可不回答或说错，不自动获得真实情报 |
| I2 | 礼节 | 识别已接触场合的称谓、服饰与程序 | 只避免有根据的误会，不能换来统一敬重分 |
| I3 | 议价 | 对数量、期限、运输和付款提出组合条件 | 对方按自身处境判断；无钱无货仍无法成交 |
| I4 | 举证 | 整理证据、来源与独立见证的差别 | 不制造证据，不把重复转述变为多人亲见 |
| I5 | 安排履约 | 使用有限担保、分步交付与违约安排 | 需要真实担保人/资产/办理能力，不能强迫别人接受 |
| G1 | 盘库 | 核对可访问容器、预约和实际缺口 | 访问权不足或旧报表会限制信息 |
| G2 | 编排 | 安排自己或获授权团队的工序顺序 | 不凭技能获得指挥权，不能让同一人同时两地工作 |
| G3 | 运筹 | 将库存、载重、行程与期限组成有限运输计划 | 依赖己方所知，不全知避开所有劫匪 |
| G4 | 应变 | 出现缺员/封路后提出替代计划与优先级 | 替代人仍需愿意和有能力，资源不凭空补齐 |
| G5 | 授权交接 | 明确代办范围、信息、资产与汇报条件 | 职位/所有人须有权授权；被撤权后不能继续签署 |

### 6.1 推荐连线举例

W1→W2/W3，W3→W4→W5；A1→A2/A3→A4，A4与已有稳定控制经验可通向A5；M1→M2→M3，M4与病例线索支持M5；C1→C2或C4，C3与C4支持C5；G1→G2→G3，G2/G3的真实偏差经验支持G4/G5。

以上只是清晰的默认学习路线。靠其他可靠师承学会等价基础可以进入中段；关键取舍与真实能力门槛仍保留。图不强制把全部分支练到顶才允许参与日常。

跨域边如A2↔M3（火候）、C3↔M4（固定/器具制作）、L1↔S1（环境观察）、G1↔M2（药材储存）、I5↔G5（合作与代办）显示互助用途。它们不能变成“先把炼丹点满才能砍柴”的人造前置。

## 7. 八种可以形成的生活与行动路线

路线是玩家经历产生的组合，不是职业按钮，不发职业专属装备或独占全部节点。

| 路线示例 | 组合重点 | 可以追求什么 | 需要承受的限制 |
|---|---|---|---|
| 山路护送者 | 直刺/守隙、辨路/护行、运筹 | 护粮、带伤员脱离、结交常走商路的人 | 正面群战与长期施法不擅长；补给和合同重要 |
| 近身御术者 | 卸力/截势、调息/引火、短步 | 控距离、打断与短术衔接 | 占用有限准备，连续贴身施术的资源压力大 |
| 护持与救援者 | 护持、急救、护行、安排履约 | 保护同伴、稳定伤员、组织撤离 | 持续控制占心神，主动追击能力较少 |
| 远行探索者 | 辨路/观势/野营、御风、问讯 | 找路、验证传闻、带回材料与见闻 | 消息可能过时，不能靠图自动知道遗迹答案 |
| 药圃与诊疗者（非战斗完整路线） | 察水土/育苗、辨材/煎药/辨证 | 稳定药源、治疗服务、研究方剂、培养学徒 | 医疗劳动和药材有成本，也需要安全和信任 |
| 工坊修缮者（非战斗完整路线） | 识材/木作/修补/因材制器、盘库 | 建设、修衣修器、定制用途、组织维护 | 依赖材料与订单，不因造武器就自动会战斗 |
| 商旅协调者（非战斗完整路线） | 议价/安排履约、稳载/运筹/应变 | 建立供应和运送服务，雇护卫而非自己练满剑法 | 有失信/欠款/封路风险，保证收益不是无限套利 |
| 聚落照料者（非战斗完整路线） | 耕作/顺时养护、编排/授权交接、礼节 | 安顿居民、生产、培养接班人、维持公共服务 | 有权才能安排他人；缺人缺料仍需协商取舍 |

非战斗路线也有有意义的难题、成长与里程碑：救活一次伤员、维持灾后供给、保住一批种苗、让经营者离开期间据点仍正常运转。它们不是给战斗角色生产装备的附属刷材料职业。

## 8. 传承和社会关系参与成长

秘籍是物品/记录，拥有权、阅读权、传授许可与人物实际掌握分别存在。拿到书可以获得学习依据；书被夺走不应瞬间删除已经理解的基础。秘本中的复杂方剂尚未记熟时，失去资料可能使相关研究暂停；具体保留什么由学习状态表达。

老师决定是否教、教哪一部分以及收费/义务。尊敬、私人情分、机构学籍和可用教学时间分别判断。换掌门可能影响课程准入和资源配给，不能让原弟子已学会的招式全变成灰色；禁传是社会风险与约束，不是远程撤销大脑。

知识可以作为交换内容，但“讲过一次”不保证接收者理解，更不能自动让接收者具有发送者完整记忆、真实认知或全部熟练。抄录会占用时间和材料；记录的出处、完整程度与可信性按信息系统处理。未经许可抄读仍可能在物理上完成并产生知识，是否合法、谁知道、怎样追责另行处理，不能把机构授权误作人物理解文字的物理开关。

## 9. NPC同样学习，但不做无限人生规划器

NPC根据职责、身体、已知机会、供给、承诺和偏好选择少量近期目标。农庄可能请人教基础照护；护卫在失利后改练守势；药师优先解决辨药与供应，不能人人同时追求最高伤害构筑。

每个NPC只保留少量近期学习计划，按开始/结束、资源不足、导师变动、受伤或目标变化重评；不每tick搜索全图最优组合。计划包括资料/老师/练习/复盘的实际阶段，不能离场后每天无成本自动“点一个天赋”。

不同NPC可以使用同一招式的较保守或激进策略，但拥有相同成本、冷却、射程、知识和持续控制约束。远区只批算可稳定推进的学习/工作区间，遇到断粮、受伤、导师离开、材料耗尽、课程截止或冲突时中断并处理。

## 10. 当前代码边界与未来职责

现有`PawnState`包含qi、stamina、hunger、energy、mood等字段，境界显示来自定义；已有有限探查、指导、试验、实际学习和本人来源目录，但没有完整修行图、通用学习事务、功法准备或技能熟练系统。现有`VillageSimulation`的有限日常、`SimSocialMemory`与机构记账可协作；现状与证据见[FEATURES](../../docs/FEATURES.md)，不能把有一个qi字段算作已经实现完整修炼。

以下为长期职责建议，可复用或扩展已有模块，不表示每项都需要新增一个类；实际实施与授权见[HANDOFF](../../docs/HANDOFF.md)：

| 状态/定义 | 应负责什么 | 不负责什么 |
|---|---|---|
| 本领/功法定义 | 稳定ID、领域、用途、前置/等价条件、使用规则、练习类别、展示和公开程度 | 不写入具体居民熟练度或当前状态 |
| 人物学习状态 | 已知节点、来源、理解/掌握、有限练习摘要与关键选择 | 不替代个人关系、机构授权或库存 |
| 学习事务 | 导师/资料/设施/材料、耗时、进度、中断/恢复和结果 | 不凭计划产生已学能力 |
| 当前准备 | 四招式/身法映射、主/兼修、持续控制占用与待提交变更 | 不复制能力实例、重置冷却或删除已学本领 |
| 规则查询 | 依据人物所知列出学习机会；实际提交复查身体、资源、授权及真值 | 不向未知人物免费传播秘传/真实资源 |
| UI | 用途搜索、领域缩放、条件说明、学习计划、当前准备与中断原因 | 不直接写熟练值、不用按钮完成教学和交易 |

所有学习进展使用稳定人物/节点/事务ID、统一世界时间和确定的阶段提交顺序。临时派生伤害、容量汇总可重算；已经掌握的节点、来源、进度、随机上下文、冷却和持续承诺需要持久化。加载先构造候选并验证节点引用、前置依据与状态一致，再替换存活世界。

将来定义内容进入`data/definitions/`，新开局已有本领和师承在`data/scenarios/`装配；当前代码继续按sim/runtime/UI依赖方向工作。旧档新字段不能随意给全体NPC随机补技能，须有显式迁移或仅用于新开局的策略。

## 11. 可判定的验收场景

以下均为未来验收，**本文件未声称通过**。

| 场景 | 通过标准 |
|---|---|
| 换一件衣服 | 人物轮廓/社会线索改变；未学招式、功法熟练与攻击能力不凭空增加 |
| 杂役跨学医护 | 有渠道、费用/劳动和练习即可学习；不因出身无“医师职业”被硬锁 |
| 知道老师却无时间 | 学习有预约/改期/另找渠道；不是点击一项就立刻扣钱学会 |
| 师父教过、秘籍丢失 | 已掌握基础保留，未熟记部分按定义失去研究依据；不是全部归零或免费复制完整秘籍 |
| 反复打木桩/空买空卖 | 可维持相关基础或产生正常产物，但不能无限解锁陌生能力、获得全图通用经验 |
| 败战后复盘 | 对实际观察到的问题获得相关线索/心得；不知道的敌招不自动学会 |
| 纯生产经营人生 | 能完成供给、修缮、照护或贸易的成长通路，无需靠杀敌补经验 |
| 两个槽放同一招 | 指向同一能力状态，冷却/消耗共用，不重复施放 |
| 暂停换准备 | 可以规划，实际变更待安全条件与时间提交；不清冷却、不免费结束持续代价 |
| 心神容量耗尽 | 对新的持续控制给出解释；旧法器、伤员和受护者有明确收束，不凭空消失 |
| 撤销授课资格/换掌门 | 后续机会按政策改变；已学知识不被远程删除，公私义务另算 |
| NPC自行求学 | 使用本人所知和真实资源/导师，离场仍推进；同一人不能同时教学、运粮和练法 |
| 学习一半存读/切区 | 原事务/进度/材料/导师状态继续一次结算；不重领学费、不重复消耗 |
| 实践用量长期增长 | 近期摘要有界，重要来源保留，不为每次挥剑留下永久事件导致无限存档 |
| 新版本删除/替换节点 | 明确迁移、补偿或拒绝未知格式；不静默丢功法/熟练，原档可保留 |

## 12. 早期小网建议与待校准项

早期建议以**来源明确的12节点小网**为示例：立身、直刺、守隙、调息、引火、护持、辨路、短步、辨材、急救、修补、盘库。它同时服务动作原型、非战斗行为和信息边界；跨域学习、当前准备及中断存读成立后再扩展。12/40节点不是必须交付数量，也不是当前工作包顺序；已有有限能力样本见FEATURES。

待原型校准的是：初始心神4与占用量、主/兼修组合、各功法冲突、练习/复盘的节奏、熟练带来的操作宽容、早期资源来源、境界与技法的强度跨度。用户明确的方向是无固定职业、学习形成能力、非战斗人生完整、衣着具有独立价值；本页的容量/节点名/招式数量都是支持该方向的推荐实现，不是必须永久保留的设定。

一项节点若说不清带来了什么新选择、用了什么条件、失败怎样处理，就先不进入正式内容。图可以越来越大，每个进入图中的节点都应该让世界或人物的行动真正多一种可能。
