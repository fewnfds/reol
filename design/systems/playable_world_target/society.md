# 可游玩的修仙社会：完整玩法目标：社会与人生路线

> 详细设计与候选：具体机制、参数、样本和验收意图须验证；已确认规则见[规则目录](../../rules/README.md)。

## 8. 社会互动、规则与政治

### 8.1 以少量可解释因素做请求判定

现有请求规则可扩展，不需要重新搭一套无限心理系统。每次有意义的提议评估六类信息：当前目标与需要、预计代价与风险、具体交往经验、关系与职责、权力和公开情境、少量个体偏好与当下状态。

提议与回应先根据当事人所知形成；结构非法、权限已明确缺失或公开确知的硬条件可以提前拒绝，不能用未知库存或尚未传到的封路事实提前筛掉选项、泄露真相。对方可能误判自己的能力；执行时再按真实条件复查。强烈倾向直接决定，犹豫区间才用局部骰判；同一处境下的相同提议缓存结果，实质变化或新的压力事件才触发重评。接受不等于必然成功执行。

亲近、守信预期、办事能力、敬重和畏惧可以分别存在，但不是五条都要玩家刷满的进度。保留关键经历与理由摘要：曾救命、两次守约、欠薪未还、师徒义务、与对方的敌人结盟。玩家看到有依据的解释与行为，不免费查看他人全部心理或准确百分比。

**验收场景**：受尊敬的陌生前辈请求冒死护送仍可能被拒；受伤陌生人获得出于职责的救治；新增报酬只能解决物质代价，不能自动消除政治危险；反复点击不会刷到不同结果。

### 8.2 贡献、权利、担保与办事

贡献记录归发行组织，发行和扣减需要合法签署与依据；可兑换权益取决于制度、实际资源与办理者。私人欠情、传闻中的名声、职位权限和物理钥匙分别表达。记录正确也可能遇到暂缺库存或拒不执行，玩家可等待、协商、申诉、找担保或诉诸力量。

首发争议过程尽量短：提出异议 → 交由有权者核验 → 给出履行、延期、补偿或拒绝结果 → 实际执行。证据可来自交付单、目击者、法器记录；重复转述不是多个独立目击。审计、调解与裁定先共用一个最小案件流程，不一次造完整司法体系。

**验收场景**：同一张真实运粮凭据被重复提交只能记账一次；账上有贡献但药库暂空时，玩家可保留债权或换别的补偿；一个私交很好的长老没有掌管药库，也不能凭嘴直接扣公仓给玩家。

### 8.3 组织目标通过人落实

每个组织有资源基础、负责岗位、供给与防卫需求、成员和未结事务。掌门/议事者根据其收到的消息安排目标，经负责者传令，由执行者落实；内部个人可有私利、忠诚、分歧与疏忽。首发只做少量关键岗位和一两个冲突议题，不模拟每名弟子的完整政治派系图。

玩家任职带来预算、印信或特定审批权，同时承担报账、供给、治安与问责；卸任失去职权，私人财产和关系按各自来源继续。经营中的“大方针”要落成资源、任务与授权，不靠一条全宗“忠诚值”自动完成。

### 8.4 继任与人走茶凉

先让职位空缺、实际接掌、授权交接、关键成员承认、旧账办理成为几个可观察的步骤。原型 `SuccessionResolver` 的权重仅可作为候选局部工具，接入前用场景校准；不能让一次公式代替全体成员、各部门及外部人的认知。

新掌门可能继续承认宗门公账，收回依赖旧掌门个人担保的特许，同时仍维持礼遇。旧掌门的朋友也可能通过现有履约、独立担保、实际控制或新合作争取好处。失去利益不是必须剧本，也不是全宗总好感清零。

**验收场景**：旧友掌门去世，玩家仍被礼貌接待但失去私人药园通行；已有合法运粮公账仍可按组织政策办理；一名与玩家有救命之恩的弟子继续私下帮助，另一名掌库者因财政与派系拒绝垫付。更替发生在玩家远行时，消息先后和后果按同一世界时间推进。

## 9. 多出身、迁居与人生路线

开局由已有世界上的一名人物状态装配：位置、身体、资产、技能、关系、知识、身份与未结责任。出身不创造专属宇宙，初始资产与职位必须有历史或授权依据。社会身份、修炼境界、职业技能、组织归属四者分别表达；高境界也可以穷，无官职也可以受敬重。

| 首发体验 | 生计与依赖 | 中期目标 | 危险与转向 |
|---|---|---|---|
| 杂役/普通弟子 | 公共食宿、差事、管事与师门 | 学艺、得到信任、获准进修、晋升或转师 | 欠责、受伤、资源被挤占；可做手艺、外出或离宗 |
| 散修 | 个人技能、旅店、雇佣、交换传承 | 稳定供给、同行伙伴、洞府与突破 | 情报不足、受伤无人救；可投宗、定居或做护卫 |
| 行商/手艺人（游戏内转向，非独立首发出身） | 货源、运输、工具、顾客与本钱 | 稳定路线、工坊、雇工、合约网络 | 价格误判、封路、欠款；可换路线、结盟或转经营 |
| 小聚落经营者（可发展为管事/掌门） | 岗位授权或私产、居民劳力、储备 | 维持供给、建设、培养人才、对外协商 | 欠薪、失去授权、迁出、袭击；可卸任、重建或带队离开 |

迁居需要真实身体与随行资产在途，工作、住房、财产管理、未结债务和信息渠道按规则处理。人物不能同时住在两地并各自生产一份粮。离宗不是清零存档，旧情、债、师承与追责可以延续，但信息仍有传播边界。

“reroll”对应的同世界新人生已由用户在2026-11-03细化：消耗有限重生机会，从若干跨种族新生候选中选择，世界不回滚、可小幅前跳，高难度机会更少，耗尽结束本局；暂不做增加渠道。详见[有限重生与新生候选](../rebirth_and_new_lives.md)。这取代此前免费创建普通新人物续玩的建议。

新生命有实际出生来源、身体与社会处境；跨生记忆的保留程度仍是[待验证建议](../rebirth_and_new_lives.md)，旧物、公职、债权与旁人认识不自动归还。旧角色身后事、未选候选和其他世界过程继续。早期先以持续角色验证规则，完整续生依赖出生/成长、共同时间与快照；不以退隐切人、任意附身或同局无限开新角色绕过有限预算。

**验收场景**：同一世界种子分别以三种身份进入，已有运输、短缺和组织事务一致；玩家只因资产、所知和职权不同而有不同选项；一个游戏中从雇工变成管事再离职，其欠薪、旧友与私产可追踪。

## 10. 长期目标与失败继续

沙盒不强制所有人以统一主线通关。推荐提供可以追求、放弃、转向并留存结果的生涯目标：修成一条传承、建立可持续据点、经营一条商路、救活或振兴衰落宗门、结束一场地方冲突、完成一次远征。

达成目标形成有依据的里程碑和结局回顾，世界可以继续。结果来自实际状态：据点能供给多少人、谁继承传承、战争如何结束、哪些旧账仍未结，而不是只累计任务完成数。

失败分层处理：单次工作失败改变合同；经济失败导致欠款和重组；政治失败导致失职、驱逐或转向；战败导致伤亡和损失；角色死亡可依有限机会接续新生，也可按模式读档或新开局。首发不要求每种失败都有无限恢复，但重要不可逆选择应有清楚预警与可理解前因。

NPC 同样会改变计划、离开、失败、死亡。长期测试要警惕两种坏结果：所有组织永久稳定无变化；所有组织很快连锁灭绝只留玩家。允许局部灾难，通过迁居、招募、资源再生、外来商旅和新组织形成保留恢复能力；每一项都要有来源和限额，不能后台偷偷复活同名死者。

## 11. 玩家如何理解世界

首发界面围绕行动组织：当前行动与中断原因、背包和装备、已知委托与承诺、地图与消息、人物交往、机构账页、经营事务。重要的机会成本应在确认意图前可见，例如大致耗时、会暂停的工作、使用公仓还是私人物资、需要谁批准。

消息区区分亲见、可信来源与待核验；账面记录与人物私记分开。经营者可查看自己有权收到的报表；在现场看到的材料比旧报表更新，但不会自动更新远方负责人的知识。

玩家可以针对拒绝做有意义的改变：加报酬、改时间、补证据、找担保、减风险、找别人；只有“再试一次”不是可持续交互。系统给出两三个当前可知的主要原因即可，不让玩家阅读几十项隐藏权重。

教程通过一个小局势串联操作：找到住处 → 完成真实差事 → 与人合作 → 使用凭据或报酬 → 获得学习/建造机会 → 经历一次失约或危险 → 选择处理方式。玩家绕开宗门时仍有替代路径。

美术集中制作之前仍必须有清楚的占位图标、选择轮廓、设施用途、命中/受伤反馈与危险预警；“先玩法”不意味着把功能藏在 F3 开发面板里。

## 12. 必须按真实行为验收的场景

下列场景属于目标验收，**本文件没有声称它们已通过**。实施时拆成小工作包，先规则再接表现与存档；同一场景同时覆盖人物、物资、时间、信息与失败后续。

| 场景 | 通过标准 |
|---|---|
| 普通人过日子 | 无修为开局能靠劳动与服务持续生活；资源和报酬来源可查；不是无限领钱 |
| 双人抢末份材料 | 只有一人取得；另一人等待、换料或放弃，取消/受伤正确释放预约 |
| 新建洞府 | 材料、运输、工时、占地、导航和存读一起成立；拆除不复制物资 |
| 建设与修炼竞争 | 同一批劳力/粮食不能同时供无限建设与闭关，调整策略改变实际结果 |
| 尊敬而拒绝 | 同一人礼遇玩家，却因代价/职责拒绝高风险请求；补条件能改变相应理由 |
| 账面有功但缺药 | 合法记录保留，兑付受库存限制，可协商或追责；重复办理不刷奖励 |
| 玩家忽略一件事 | NPC 自主采购、救援或争夺使局势结束；任务记录反映真正结果 |
| 竞争遗迹 | 消息有时效，竞争者真实行动，宝物只归一处；去晚仍有线索或次级选择 |
| 战败撤退 | 伤员、遗失货物、俘虏、救治和后续合同接续；切场景不重置战果 |
| 远行后的归来 | 工地、人物、库存、传闻和未结承诺各自推进；归来不是初始版本 |
| 继任后的旧友 | 私交特许、公账、礼遇和个别人情分别变化；不同部门可给不同回应 |
| 同世界换一种开局 | 世界规则一致，初始权利和信息有来源，至少三类身份有生计和中期目标 |
| 长期不在场 | 世界产生可追踪的变化，无玩家救场也有恢复和新行动；不批量冻结或凭空补库存 |
| 重要边界存读 | 交付/付款/施工/突破/死亡/迁居中途可恢复；既不重抽决定也不重复资产 |

一项玩法成熟的标准不是文档里出现了名词，而是：玩家能选择，NPC 在能力与认知允许时也能选择，执行有真实成本，失败有明确结果，远区与存读接续，玩家能理解自己为什么得到这个结果。
