# 行动战斗：招式、处境与共同世界：走位、资源与招式

> 详细设计与候选：具体机制、参数、样本和验收意图须验证；已确认规则见[规则目录](../../rules/README.md)。

## 5. 走位、命中与防御

### 5.1 接触先于随机

现场近战先采用平面几何：弧、线段/胶囊或扇区；直线飞行物沿路径做连续扫掠，避免高速穿过身体和墙体。范围术有地点、边界与生效时刻。画面斩痕、危险线和实际命中区域必须一致；以后若恢复高度或飞行玩法，再定义相应资格和连接。

人真正走出了范围，就不命中；已被真实攻击覆盖，不能再用一个隐藏“闪避率”使其无理由落空。随机留给有不确定意义的伤势差异、器物失控、认知或不精确远战，不能用暴击骰替代现场反应。首版先不做随机暴击、随机命中和装备暴击词条。

身法是受限移动。起步、可避开的作用种类、距离和落点规则明确；是否短暂避开特定攻击由已学本领定义。普通踏步没有通用无敌时间，不能躲开持续火场、毒气、封死的墙和无法到达的落点。若进阶功法提供化虚等特例，必须说明何时、对何物、付何代价。

### 5.2 防御有选择

| 防御 | 优势 | 代价与克制 |
|---|---|---|
| 移动/掩体 | 不消耗专门技能也能避开 | 需要位置和察觉；被包围时选择少 |
| 格挡/招架 | 保持近身阵位，保护后方 | 方向/手段要求，消耗体力/稳定；不能无视背袭和范围火场 |
| 精准招架 | 短时窗换取明显反击机会 | 需本领与判断，失败承担原攻击；普通格挡仍有用 |
| 护持/结界 | 保护自己或同伴，克制指定作用 | 灵力/心神、覆盖范围、持续成本；不是一层万用护盾 |
| 轻装身法 | 位移灵活，便于脱离 | 直接接触时防护较少；反复闪避会耗尽体力 |
| 材料防护 | 对覆盖部位及适用作用提供实际缓冲 | 负重、活动/环境限制、维护；普通衣与专门防具区别明确 |
| 撤退/投降/求援 | 结束不值得承受的交战 | 可能失货、被追、欠情或受约束，不能免费瞬移脱战 |

姿态稳定是动作局部状态：格挡、重击、推撞与立足地形影响它；失稳可打断或短暂暴露。不把姿态再造成人物永久可刷的第四条经验资源。

### 5.3 伤害与伤势

初期只区分能改变应对的几类作用：斩刺、钝击、灼烧、束缚/冲击和专门灵性作用。不是五类都各配一排全民必须堆满的百分比抗性。

原型计算可按以下有界结构起步：

```text
动作作用量 = 此招的基础效力 × 熟练执行系数 × 当前状态系数 × 接触系数
实际健康损失 = 作用量经过适用的格挡、覆盖防护和护持规则处理
失稳/移动/燃烧等后果由各自定义结算，不一律从健康伤害反推
```

系数范围与防护曲线须由少量对局校准。普通剑的锋刃、长度和质量参与相应动作效力与形状；不再额外把鞋帽项链的统一攻击百分比乘进去。多个增幅按来源分组并限制叠加，关键节点改动作行为；不能无上限相乘。

健康减少反映受损，严重受击/特定阈值形成少量伤势类别，影响发力、移动或运转，并需要休息/医护。不逐击模拟几十个器官，不把每次擦伤都升级成长时间不能玩的残疾。健康为零通常倒地；死亡来自致命攻击、持续伤害、失救或明确处决条件。是否下杀手是交战意图与具体行动，不是统一杀光。

死亡的遗体、背包、借用装备、职位、债务、承诺和目击分开处理；医者不会仅因能打就自动懂救治，治疗也不能通过换衣或重新装备触发。

## 6. 资源：短时应对与长期生活

| 状态 | 功能 | 恢复与限制 |
|---|---|---|
| 健康与伤势 | 承受损害和身体可用性 | 止血/治疗/修养；离战不瞬间恢复所有持久伤势 |
| 体力 `stamina` | 发力、冲刺、招架、负重下的短时动作 | 平缓行动和不发力时恢复；短时耗尽可退让，不自动昏睡 |
| 灵力 `qi` | 施术、运器、护持、功法运转 | 由功法/调息/真实消耗品恢复；有些人没有可用灵力也能生活 |
| 精力 `energy` | 长时疲劳、睡眠和持续生活 | 饮食休息与安全安排；影响恢复和可持续工作，不对每次挥剑重复扣同一成本 |
| 姿态稳定 | 当下站稳、招架与承压 | 战斗局部恢复；不作为全身装备凑分门槛 |
| 心神占用 | 同时维持功法/术法/御器的注意负担 | 规则见修行页；限制同时运转，不限制已经学过的知识总数 |

疲劳不能让玩家每打一剑同时损失三条同义体力。普通招式以短时体力计费，长期精力通过整段活动与休息规律结算。极度疲劳或负伤时给明确预警及可行动的退路。

## 7. 招式组合，开放但不无限连控

连招由招式的准备、作用、后摇、位移、失稳和对手回应形成：试探→格挡引诱→重击破势→短追击，是成立的战术；把十个技能轮流按到敌人永远不能动，不是首版目标。

- 默认三段基础攻击各有不同距离/方向/时序；可提前停手，末段不保证一定最优。
- 专门招式有少量明确衔接点，例如踏步后改一次近身斩，招架成功后开放短反击，束缚后便于施术但不保证持续锁死。
- 硬控制连续命中提高短时抗控/脱离保护；轻微打断不无限延长同一后摇。持续束缚允许挣脱、破阵或同伴帮助。首批控制集合只有短硬直、减速/束缚、击退和倒地；浮空无限追打后置。
- 公共冷却不覆盖所有动作；按招式/冷却组/动作阶段约束，避免所有按钮亮着却全被一个隐藏全局CD阻止。
- 暂停期间可以改目标与待执行的一项意图，不能修复装备、缩冷却、免费更换整套功法和恢复资源。

### 7.1 首内容集：十种动作定义

以下是用于原型验证的最小动作库，名称是玩法标签，可因学习路线与媒介有不同演出。不是所有开局自动获赠。

| 动作 | 类型/目的 | 可改变处境的特点 | 生活或非杀伤联系 |
|---|---|---|---|
| 基础击/推离 | 基本身体动作 | 近身短作用；武器版本依持物与训练 | 推开威胁、非致命比试 |
| 踏步 | 基础/学习可改进 | 短位移、需要落点，不穿墙 | 越开障碍，搬运仍受负重 |
| 招架 | 防守架势 | 朝向格挡，精准时点可反击 | 护卫他人；不能代替合法护送约定 |
| 破势 | 重击/钝击 | 前摇较长、打稳定、落空暴露 | 破门需材质/权限与破坏后果 |
| 飞针/短投 | 真实投掷媒介 | 有速度、阻挡和弹药，不自动追踪 | 工具用途不自动等于医术 |
| 引火 | 定点/小范围术 | 地点预警、持续区域，需明确安全范围 | 点火、加工；野外可引发实际火害边界，首版只支持有定义目标 |
| 缚足 | 控制术 | 减速/短束缚，可破离，不无穷叠加 | 捕获、阻止追击，区别于伤害招式 |
| 护持 | 防御/援助 | 朝向或小范围保护，持续占灵力与心神 | 护人作业、掩护搬救 |
| 急救 | 医护行动 | 需要距离、时间与材料，受干扰 | 救命/稳定伤员；不是瞬发无限加血 |
| 御器牵引 | 进阶手段 | 有器物、路径/操控条件、载重与心神 | 搬取小物、隔险作业；不是免费全图取货 |

先验证基础击/推离、踏步、招架、破势四种；再加投射、引火/缚足、护持/急救，最后接御器。首版不同时制作十套武器动作和上百招式。

### 7.2 原型调参起点

这张表只表达手感量级，参数进入未来数据定义后再调。不是从参考游戏复制的数值，也不是Godot当前实现。

| 项 | 建议起点 | 验证问题 |
|---|---|---|
| 一次普通近身动作 | 总约0.45–0.70世界秒 | 看得懂出手，按住不必极限点击；仍能被合理反击 |
| 重击 | 总约0.9–1.3世界秒，主要前摇至少0.35秒 | 有时间识别和闪避，落空有代价 |
| 普通踏步 | 位移约0.25–0.40世界秒 | 不穿墙、不连续无代价躲避；相机不晃到看不清 |
| 短输入缓冲 | 约0.12世界秒 | 不吃正常输入；过期和取消动作不误发 |
| 硬直 | 常见短控制约0.15–0.45世界秒 | 反馈明显，连续控制仍有应对；具体抗控规则单独定义 |
| 法术冷却 | 少量约2–8世界秒 | 除冷却还有站位/资源/读招，不成为等按钮游戏 |
| 基础资源标尺 | 健康/体力/灵力暂按100单位方便测量 | 普通人灵力可为0；不以此推断所有人完全同质 |

打击停顿推荐先做人物表现层的40–60毫秒冲击停帧/残影；规则时间与远方仍正常推进，不利用停帧延长无敌或偷冷却。若原型发现需要真正全局短暂停顿，应单列设计、所有领域一起暂停；不偷偷只停敌人。
