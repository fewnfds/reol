# 行动战斗：招式、处境与共同世界：行动与指令

> 详细设计与候选：具体机制、参数、样本和验收意图须验证；已确认规则见[规则目录](../../rules/README.md)。

## 1. 战斗在整个游戏里的位置

玩家可以成为擅长打斗的人，也可以以医术、生产、经营、关系和组织能力立足。战斗提供可学习、可协作、可避开的手段；不能把全部人生目标最终都结算成攻击力。

理想体验：看见敌人抬手，判断距离和退路，用一步侧移躲过重击；同伴护住伤员，自己以束缚术截住追兵；也可以事先雇护卫、交易通行或放弃货物。熟悉的招式、对局面的判断和准备形成差别。没有战斗专长的人仍有推开、躲避、求救、弃重物、退让与投降的动作。

四组参考分别取用：Hades的即时移动和动作衔接，DNF的招式关系与连招表达，LoL的技能识别/射程/施放承诺，Warcraft III的小队意图和战场层次。固定视角仍为正交俯视；不改成DNF横向纵深格斗，不加入竞技MOBA经济，也不让玩家每秒指挥全宗门。研究依据与推导边界见[一手参考](../../research/combat_and_character_references.md)。

战斗状态属于原世界中的人物和事务。拔剑不会创建一个暂停城镇生活的独立副本；胜利不会把敌人全宗资产自动转给玩家。

## 2. 实力从哪里来

不存一项统治所有玩法的“战力”，也不规定“功法占60%、装备占20%”的固定份额。下面是能力的不同来源，实际贡献由具体动作决定。

| 来源 | 实际改变什么 | 不能替代什么 |
|---|---|---|
| 身体与健康 | 发力、负重、反应、行动范围、伤后限制 | 好身体不能自动会剑术、辨药或管账 |
| 境界与修炼根基 | 灵气储备/运转、可承载功法、某些新的行动方式 | 高境界不自动获得所有术法、政治权限与他人忠诚 |
| 功法及运转方式 | 恢复方式、护持、引导、擅长与代价 | 一本秘笈放包里不等于已练成 |
| 学会的招式/术法 | 明确的攻防、移动、控制、援助动作 | 穿同一套衣服不能复制对方本领 |
| 熟练与心得 | 执行稳定性、衔接选择、对特定招式的理解 | 杀人数量不能兑换全部学问 |
| 当下准备与处境 | 体力、灵气、伤势、距离、朝向、掩护、侦察、伙伴配合 | 用优势地形不等于永久加了人物属性 |
| 工具、兵器与法器 | 作用媒介、长度/质量/锋刃、防护覆盖、特殊功能 | 普通发簪、鞋、项链不普遍贡献攻击/暴击乘区 |
| 情报与协作 | 能否先察觉、打断、诱敌、分担风险和救援 | 组织尊敬不能让所有成员无条件赴死 |

器物允许很有力量。借来一件护山法器可以暂时改变战局，得到好兵器也能获得明显优势；它有来源、用途、操控条件、维护和损失风险。不为了保证人物属性至上，把宝物做得毫无作用；也不让八件普通服饰叠出来的统一数值取代人的修行。

境界差距需要可感知：高阶可能具备更长作用距离、持续护持、飞行或驱使法器；差距通过动作规则、资源和效果表现。首版不采用“跨境界所有攻击自动无效”的万能免疫。遇到暂不能对抗者，可侦察、逃离、借助守备/阵地、谈判或换目标；普通劳作和经营不要求先击败地区最强者。

## 3. 操作与指令

推荐一套主角直接操作＋可暂停小队指令。以下是候选输入映射，需以原型验证。

| 输入 | 现场默认意图 | 边界 |
|---|---|---|
| WASD | 主角移动 | 受地形、负重、动作承诺和身体状态约束 |
| 鼠标指向 | 朝向/瞄准/地点目标预览 | 瞄准方向与人物脚底位置分开 |
| 左键 | 平时选中；应战状态基础攻击 | 应战状态Alt＋左键仍可选中人物；点击UI不能误攻击 |
| 右键 | 应战状态架势动作，如格挡或蓄势 | 当前准备的一种基本变化，不自动拥有所有武器技巧 |
| Q/E/R/F | 四个准备好的招式/术法 | 是易操作的快捷准备，不是最多只能学四招；生活本领另有情境入口 |
| Shift | 当前身法/闪避动作 | 普通人有有限避让；进阶身法需学习，不默认无限穿人穿墙 |
| Space | 全世界暂停/继续 | 可观察和下令，不发生攻击、移动或资源恢复 |
| V | 改变应战/收势操作状态 | 改控制映射与意图，不创建或结束世界冲突 |
| G | 当地情境交互 | 行医、取物、交谈等依合法目标和条件执行 |
| Tab/小队栏 | 选择队友并发布有限指令 | 权限与合作约定仍成立，不变成随意操纵陌生人 |
| I / K | 物品穿戴 / 修行图 | 默认查看不暂停；可使用Space先暂停。受威胁时不能无耗时换装/重配 |

选中陌生人不立即攻击；主动对中立者用武需要先明确敌对意图，再正常操作，不逐次弹窗。被袭、护卫责任或已知敌对目标可直接应对。故意敌对、误伤、目击与合法自卫是世界判断的问题，不用按钮替玩家宣告“全世界都认可此战合法”。

普通攻击可以三段衔接，但不要求敲长串方向键。按住连击与逐次输入可在辅助设置中选择；短输入缓冲帮助正常衔接，不能排队十秒的自动连招。方向、技能取消与移动辅助可调，不能在隐藏规则中自动替玩家躲掉危险。

小队首批命令：跟随、守位、攻击指定目标、保护指定人物、撤到标记点、停止追击。战斗前可约定自主用药/施法/撤退条件。成员优先保命、遵守约定和完成命令；明显超约定风险可以提出异议。不是每次普通攻击都先做社会骰判，指令接受也不保证路径或资源足够。

V只改操作映射，不免费拔剑、收鞘、卸下药箱或腾出双手。第一次出招若需拔取武器，必须完成相应收放动作；恢复搬运/救治也要满足持物与手部占用，不能切个模式让工具自动回仓。

## 4. 一个动作怎样发生

每个动作实例有稳定ID、执行者、目标/方向、开始时刻、阶段、成本、命中记录和结束原因。流程为：

```text
提出意图 → 检查已知可选条件 → 执行时复核真值/取得执行权
  → 准备/前摇 → 作用阶段 → 收势/后摇 → 完成
                ↘ 被打断/取消/目标失效 → 明确清理与后果
```

### 4.1 阶段与承诺

- **准备**：确认可用身体、手段、灵气/体力、目标政策、距离/地点和导航。错误输入不扣费，不能用隐藏对象状态给出泄密错误。
- **前摇**：有可见动作，部分招式允许小幅转向，随后锁定朝向。敌人不能最后一帧瞬间180度追踪玩家。
- **作用**：产生接触、飞行物、范围或持续效果。每个命中对象/作用脉冲最多结算一次。
- **后摇**：暴露机会成本。可取消的阶段和可取消到的动作是显式定义，不是所有招式都可免费闪避取消。
- **结束**：完成、打断、失败或死亡。清理执行权与预约，已经发出的箭/术法按自身生命周期继续，不因施法者收手而自动消失。

每种动作需要定义：手持条件、目标类型、距离/形状、移动/转向允许、阶段时间、提交成本时点、取消窗口、打断等级、控制效果、友伤政策、声音/可见线索、冷却组以及离场执行方式。定义进入未来数据文件，不写入动画方法名作为规则。

### 4.2 成本与取消

体力通常在发力开始时支付；持续格挡/引导按有效持续时间付费；灵气在成术或各脉冲的明示时点消耗。高成本术式可以先付小量准备成本，再付成术成本。

取消不会退还已经付出的发力/准备消耗。尚未提交的阶段不扣后续成本。投掷物在实际发出时离开原容器，符纸在指定施放阶段实际消耗；失败清理不能既退符纸又保留飞行效果。冷却从明示提交时点开始，被打断不默认为完全免冷却。

人物的移动、操物、表达、注意等通道按实际能力和占用裁决：冲突的占用不能被两个执行器重复使用，但不冲突的活动可并行。例如运粮与挥剑若争用同一只手或互斥动作就需中断或调整，已经搬着的货物和可续用进度仍保留；停止追击后回原职责也需要实际移动和条件复核。

### 4.3 同刻顺序与输入持久化

首版采用固定阶段语义：到期/到达和消息先提交，持续效果使用`[开始,结束)`的有效区间；随后接纳命令/阶段成本、推进本阶段移动、按同一阶段快照收集接触效果，再汇总施加健康/资源/控制变化，最后处理倒地/死亡/中断清理和观察。具体固定步实现由原型试验决定，不能由字典遍历顺序决定谁永远抢先。

同阶段已经成立的互相命中可同时结算；已发射飞行物不因施法者同刻倒地被回滚。普通治疗与伤害按该阶段汇总后再判倒地，明确致命/不可逆事件有自己的可见优先规则。精准格挡、无敌或护持只在有效区间内参与这一阶段，不能靠显示帧的先后获得额外生效时间。

已经受理的待执行意图与短缓冲保存为世界命令：序号、目标/方向、最早执行时刻、到期时刻和取消标记。存读后至多执行一次，不能重新延长缓冲。未提交的鼠标悬停/预览不存为命令；恢复时不读取仍按住的旧鼠标状态补发上一次攻击。随机上下文按稳定事件/效果标识隔离，粒子创建和UI刷新不消耗规则随机数。
