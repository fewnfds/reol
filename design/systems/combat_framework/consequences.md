# 行动战斗：招式、处境与共同世界：世界、远区与验收

> 详细设计与候选：具体机制、参数、样本和验收意图须验证；已确认规则见[规则目录](../../rules/README.md)。

## 8. 地形、视野、友伤与高度

首轮新世界采用平面地块，真实位置/格子和纸娃娃绘制偏移分别计算。既有样本中的`elevation`与`altitude`保留以兼容历史；不因此把高低差/飞行算法作为新世界引擎前置。更换高帽、披风、飞剑贴图不增加真实射程或改变命中身体。

未来飞行若恢复规划，低空不是所有地面威胁的免疫，远程和范围作用的高度判定须另定义；飞行需要本领/器物、起落点、负重和消耗。不在未实现可保存地形破坏前开放全屏摧城。

物理飞行物和环境危险默认有真实阻挡及误伤可能，不能穿过队友却只碰敌人。明知友军挡线时默认提示/避免发射，发射后他人走入路径仍可能受伤；同伴AI尝试避开已察觉火线。大范围攻击预览标出已知友军/中立者风险，玩家需先表达危险/敌对意图，但不逐击弹确认框。

近战弧、穿刺、扫击和推离同样区分“允许提出的目标”与“实际身体接触”。默认有物理作用的危险攻击在提交后可碰及友军/中立者，不能因阵营标签自动穿过他们；明显已知的友军挡位在准备阶段触发停手/改位提示，已进入作用阶段不靠隐形过滤删除误伤。非致命推离的具体伤害/失稳按动作定义，同意切磋也仍需约束招式和停止条件。AI与玩家共享此规则，辨友术式才采用明确的过滤特例。

正式身体/衣饰动画需要真八方向，并保持身体左右与逐向遮挡；刀弧、持物朝向和施法线按真实连续瞄准方向表达，不能朝东挥剑却在东北方向无提示命中。

若某术法能辨友，是它自己的已学能力/结界条件与代价，不是所有法术免费具有的底层优惠。首期可先用低误伤场景验证，不用误杀路人来强制制造故事。辅助难度如降低友伤必须明示，不能用隐藏改变让玩家无法理解。

AI只对已察觉人物、声音、施法线索和收到命令作反应；不读取主角尚未提交的按键、不隔墙瞬时全知。仇恨不是从全地图读取“谁DPS最高”的强制锁定；保护目标、出口、货物、恐惧与撤退同样进入选择。

## 9. 世界时间与扩展边界

身体、行动、消息与长期过程使用共同世界时间，并在明确的提交边界交换结果。

以下为扩展要求，不要求重做现有共同时间；动作尺度、更新频率和精度仍需在后续工作包验证：

1. 只有一条共同、可排序的整数世界时间轴。战术现场以秒描述，生活/种植/消息以分钟、小时描述，统一换算。
2. 自由现场/战斗默认目标为1真实秒约1世界秒；1/2/4倍是全世界有效推进倍率，察觉威胁后自动回1倍并提示。既有一天144秒不是必须保留的平衡值。
3. 吃住、制作、修炼、旅行提供明确的等待/事务快进。推荐原型先试全局60倍和按下一关键边界推进，实际倍率由手感与性能测试选择；不是让玩家真实坐等八小时睡觉。
4. 加速/跳时是玩家请求推进整个世界，目标移动、遇袭、供应和关键消息会在正确边界打断。远方冲突继续算，不因主角睡觉自动全算成和平。
5. 暂停所有规则停止；界面和表现插值可响应。算力不足保留待处理时间，显示降速/进度，不丢掉已宣称推进的事实。
6. 战斗阶段、移动、投射和生活执行必须在同一提交点读写原身体/物资。不能让身体节点自己掉血、分钟模拟又覆盖回来。

生活时长也需共同校准。空间上保留正方格，局部战斗可用格内连续坐标；渲染64像素不直接等于一米或一分钟，物理尺度、道路里程与离场耗时需实际验证。不让切区立即改变同一路程的时间。

自动降速和提示遵守玩家认知：听见/看见危险、已约定渠道收到警报、已经受伤等可触发；未被发现的伏兵或无人告知的远方交战不能通过突然降速泄密。跳时跨过未知危险仍会按事实发生遭遇，到了角色可察觉时才停止并交还操作；算力追赶只说明处理进度，不暴露秘密位置和敌人名称。

若改变时间字段或存档语义，应对声明支持的存档进行候选校验与连续性验证。

## 10. NPC、非战斗者与事件

行为策略按职责和能力组合：守卫阻拦/护人、野兽护巢/逃跑、医者救治、商人保货/求援、修士寻材/护法。不是每个模板都换不同颜色然后冲上来打到死。

先检查目标与所知，再从少量动作中选择，留有反应与决策承诺。NPC与玩家共用动作成本、取消、射程、身体、已学本领和物资。AI不必像玩家按键，但不能免资源或免前摇。

敌对意图分层：切磋、驱离、抓捕、夺物、护送/阻挡、致命冲突。切磋需要同意、限制动作和停止规则；不凭“切磋模式”把已经丢失的灵石/材料复原。原型可用受控非致命动作和明确投降阈值，避免必然制造重伤；正常世界的意外风险仍按已说明规则处理。

无人操作时，人物可完成自己的争端、护送、逃亡和救援。目击者按实际能看见/听见的表面记录学习，传闻延迟传播；完整战斗调试日志不自动成为全宗公知的罪证。制服与旧友关系影响事前判断，正式授权和真伤害仍分别复核。

## 11. 远区、入场与存档

现场战斗需要离场策略：可以先让**同一个纯规则上下文继续无头细算**并限制并发，之后按约定误差加入粗算；不能因离场静默冻结。

唯一权威状态包含参与名单、目标、位置/路线、阶段/时刻、健康伤势、资源、准备本领、持物、持续效果、投射/范围对象、冷却/命中去重和随机上下文。视图与粒子可重建，效果剩余时长不能重置。

精度切换在共同提交点移交执行责任。已提交的受伤、消耗、控制/逃亡结果保留；入场可以改变之后的行动，不能重掷此前战果。围困中的人不能被映射到出口外，已扔出的符也不能退回背包。

远区战斗使用相同本领、装备、伤势、人数/补给和目标语义，比较统计倾向与战略结果，不承诺逐招完全一致。粗算算法不是用双方总战力除一下，也不需要按现场每帧碰撞；可按侦察→接触→交手→撤退/追击的有限阶段，维护真实成本和可干预边界。

死亡/失能在同一阶段释放旧动作与预约、移交物品和责任，岗位可临时代办或明确空缺。旧机构债务不能因签字人死了直接删除；完整政治争议由后续组织规则处理。

## 12. 显示、声音与手感的最小要求

- 战斗HUD只常显健康/伤势、体力、可用灵气、已准备招式和当前动作；姿态/持续运转按需要显示。社会贡献不放进战斗能量条。
- 可预览耗时、范围、作用对象、消耗/材料与主要风险；未知技能只给可观察线索，不能自动显示敌人全部数值和内心。
- 前摇、命中与受击有轮廓/动作/声音，关键控制视觉优先。纸娃娃换华服不能遮住刀刃、施法前摇和队友身份标记。
- 用角色反冲、短痕、有限击退和音色区分效果；镜头震动/闪烁/命中数字可调，颜色不是唯一标识。
- 投射物、命中词条、音效有预算，不为每个后台批算事件播一个特效；远区只摘要与实际可听结果。
- 首版代码几何和分层占位就要能读懂；正式华丽素材在玩法验收后补齐，不用暂缺动画作为命中不清的理由。

## 13. 必须验证的设计场景

本表全为未来标准，未宣称本轮已通过。

| 场景 | 通过的含义 |
|---|---|
| 同一人换三套普通衣服决斗 | 攻击动作效力不凭衣色/价格改变；负重/防护差异来自实际构造 |
| 华服主人与粗衣老修士 | 第一眼身份判断可不同，本领与真实权利独立，接触后可修正 |
| 基础招式对快/慢敌人 | 走位、格挡、停手、追击有不同价值，不只有轮流按亮按钮 |
| 输入恰好早于后摇结束 | 缓冲按窗口生效；取消/过期不误发，暂停不暗中消耗/恢复 |
| 飞行物穿过多个固定步 | 扫掠碰撞不漏墙/人；单次接触不重复扣血 |
| 连续束缚和硬直 | 有可解释的脱离/抗控机制，不能永久失去行动权 |
| 医者护送受袭 | 可护人、救治、撤离或求援，未学习剑术不被迫补攻击装 |
| 借来强法器但操控不足 | 器物真实有用，限制来自公开条件和实际资源，不凭全局装备评分禁用 |
| 卸装/重穿/重配/读档 | 不刷新健康、资源、冷却、认主或消耗品；实例只归一处 |
| 远方正交战、玩家睡觉快进 | 双方继续；关键事件在正确时刻提交/可按设置中断，不静默冻结 |
| 同一场战斗反复进出/存读 | 原人物与阶段接续、既成伤势不重抽、货物不复制 |
| 少量具名/非战斗NPC | 反应依所知和职责，有撤退与救助，不隔墙全知/全员战斗狂 |
| 原型帧率/更新频率变化 | 成本与主要结果按世界时间稳定，视觉帧不成为第二套结算器 |

## 14. 首版范围与开放事项

第一战斗原型仅验证4个基础动作、两种应对风格、一个伙伴和小场景。后续扩到十种动作定义、学习/换装/社会情境与真实供给，再谈20–30人和远区粗算。先证明可读的走位和取舍，不把“系统完整”理解成一次生成上百个伤害技能。

需经原型决定的项目：共同时间单位/固定步长、格内尺度、正常移动与世界分钟的比率、招式时序、伤害/防护曲线、控制保护、身法是否有特定避伤窗口、准备更换时长、友伤辅助选项和HUD密度。方向已明确，数值先给起点，不把未试玩的设计当最终平衡。
