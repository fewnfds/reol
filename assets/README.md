## 重建和代码入口

```powershell
python tools/build_art.py
python tools/godot.py import
```

生成器仅依赖Pillow 10–13（实际本机13），从已入库源图和`tools/pixel_fixtures.py`离线重建三张运行atlas、catalog和两张联系表；不会请求模型、改存档或装配世界。生成稿不是精确网格：地物/植物按每行实际白色留白分列，植物另用实测不等高行边界；先切出完整轮廓，再去白底/量化并裁透明边。打包保留边缘与接触影空间，不能用放大atlas槽位恢复已经被预裁丢失的树冠。运行清单现有246个地物/物品/特效条目，含四向家具；人物仍为八向。

### 坐标、占地与接地点

地图和图片均使用+X向右、+Y向下。所有世界精灵落在占地底边中点：单格为`(x+0.5,y+1)`，多格为整个占地矩形的底边中点。catalog的anchor是素材内对应的接地像素，不能把整张树图的几何中心当作树根；透明留白不决定脚点。树冠允许跨格，接触影限制在根部附近。

`Art.footprint_foot`定位静物，`Art.body_foot/body_position`在连续身体位置与显示脚点间互相转换。人物显示脚点比逻辑身体中心向下半格，整个移动过程只作固定偏移，不在换格时取整；点击落点作逆转换，使脚点仍能到达鼠标位置。镜头/拾取/选中圈、路线、弹道和结果特效使用同一显示对应。地形、碰撞、环境采样和存档坐标仍是原世界坐标，不为贴图改动迁移事实。

墙/门/屋顶/沿轴家具的素材原本以占地中心绘制，离线打包将素材内pivot同步移到占地南缘；这使统一底部锚点后仍保持原铺设范围。地板继续覆盖完整方格，墙的可见覆盖和阻挡都为完整一格，不引入半格墙。长床等两格高素材允许pivot位于图块下沿，不能用只容纳0..63的参数截断成0。

家具为轴对齐顶视图，基准方向朝上，四向绕占地中心转动；没有把等轴测斜图旋转90度冒充四向。床用头端、箱用开口、椅用面对方向区分。多格图块按catalog的原始footprint适配实际占地，避免把单格斜图拉成长床。自然树木无需为朝向复制四份。

- `scripts/presentation/art.gd`：图集/图标读取与八向解释；`frame.gd.Visual`是共同显示代码，Runner从真实行动发布，不让模拟依赖美术脚本。
- `objects_canvas.gd`：按观察描述符准备完整静态精灵、底边中点和邻接墙/门变体，采用catalog锚点/footprint；与人物共用显示脚点深度排序。只在描述符变化时重建，屋顶遮雨掩码一并更新。
- `population.gd`及shader：人物与静态物合为同一MultiMesh。由原始局部顶点构造图片像素，不依赖QuadMesh的UV上下约定，不给Control重复套翻转。GPU插值、动作、图集/接触影与整物记忆明暗共用批次。
- `terrain_canvas.gd`、`atmosphere.gd`与shader：地面图集、原有迷雾纹理、Godot CanvasModulate、单屏天气和有界太阳短影。没有每格/每人灯、粒子节点或新结算引擎。
- `action_effects.gd`：可靠结果的有界显示；`art_gallery.gd`：F8按需预览，关闭不更新预览帧。
- 运行纹理使用nearest、无mipmap、lossless。导出包含catalog，排除源稿、联系表、第三方原切片和已退役的旧人形技术样本；源码保留来源可重建。

## 临时包的明确局限

动作由同一八向底姿派生，是剪纸/工具叠加动画，不是专业逐帧完整动作。模型的SW误画为SE，已用镜像修正；目前不作为解剖左右或非对称装备挂点标准。休息/进食等是状态示意，不保证手口或床面精确接触；攻击相位不是精确的命中帧。

影子是与根部相接的解析椭圆加小幅太阳方向偏移，不再压缩一整棵树的轮廓到几像素后出现断层；不做物理长影/动态灯。树摆使用绕接地点的线性切变，根部固定。前后排序按新姿态采用时近似，屋顶最后画。生物预备仅单姿，完整八向动作/尸体在启用相应玩法时再补。音效、音乐、全套技能与最终UI皮肤不属于本次交付范围。

旧[humanoid_sample](characters/humanoid_sample/README.md)只保留原创源资产与重建工具供追溯，已不被当前场景读取；旧提示词不形成后续开发任务。
