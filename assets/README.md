## 重建和代码入口

```powershell
python tools/build_art.py
python tools/godot.py import
```

生成器仅依赖Pillow 10–13（实际本机13），从已入库源图和`tools/pixel_fixtures.py`离线重建三张运行atlas、catalog和两张联系表；不会请求模型、改存档或装配世界。生成稿不是精确网格：地物/植物按每行实际白色留白分列，植物另用实测不等高行边界；先切出完整轮廓，再去白底/量化并裁透明边。打包保留边缘与接触影空间，不能用放大atlas槽位恢复已经被预裁丢失的树冠。运行清单现有288个地物/物品/特效条目，含四向家具及16种施工连接模块；人物仍为八向。

### 坐标、占地与接地点

地图和图片均使用+X向右、+Y向下。静态精灵落在占地底边中点：单格为`(x+0.5,y+1)`，多格为整个占地矩形的底边中点。移动身体的脚点直接落在连续逻辑位置，不按所在格的底边偏移。catalog的anchor是素材内对应的接地像素，不能把整张树图的几何中心当作树根；透明留白不决定脚点。树冠允许跨格，接触影限制在根部附近。

`Art.footprint_foot`定位静物，`Art.body_foot`直接采用身体的地面接触中心，`BODY_FOOT_OFFSET`为零。人物头身贴图向脚点上方延伸，不增加地面占格；碰撞、瞄准、拾取、选中圈、镜头、弹道和结果特效使用同一位置，不再让显示脚点比碰撞中心向下错开半格。静物与人物按各自脚点共同排序，人物站在家具南侧时可遮住家具，站在树冠等前景后方则可被遮挡。原存档坐标仍直接使用，不迁移世界事实。

地面物品堆和未开工蓝图先绘制，人物与实体景物在共同层内按脚点排序，成品屋顶最后绘制。墙逻辑占地仍为完整一格，素材在其上方向上延伸20px，表现顶面与前立面；人物头身不会因此碰墙。固定视向不是等轴测菱格，也不要求真实透视侧面。

家具先将二维平面设计绕中心旋转，再绘制向上的高度与正面细节，不能旋转完成的斜图。当前素材沿原32px逻辑格制作；长床1×2、桌/灶台2×1按真实占地准备，四向不会将视觉高度随占格方向拉长。人物仍用原八方向素材，天然树木无需四向复制。

`catalog.parts`允许同一对象引用多张64px切片，每片声明`key`、相对完整占地底边中点的像素`offset`及独立排序`depth`。偏移/深度随源footprint到实际占地的缩放同步变化，不新增实体或碰撞。长家具按地面行切分，纵向门分后/前部；较大素材先整张创作再切片。单片源anchor通常为`(32,56)`，人物保持`(24,42)`；每片使用自己的锚点与可选`contact_shadow`（连续家具仅接地部件投影），不截断大图pivot或将立面挤进地面占格。源条目/部件可声明`occluder`，高墙/门/树/屏风才在主角附近局部淡化，矮家具与作物不淡化；这只改透明度，来源描述仍来自原观察/记忆。

- `scripts/presentation/art.gd`：图集/图标读取与八向解释；`frame.gd.Visual`是共同显示代码，Runner从真实行动发布，不让模拟依赖美术脚本。
- `objects_canvas.gd`：按观察与临时外围描述符准备静态部件、底边中点和邻接墙/门变体，采用catalog锚点/footprint；与人物共用显示脚点深度排序。只在描述符变化时重建，屋顶遮雨掩码一并更新。
- `population.gd`及shader：人物与静态部件合为同一MultiMesh。由原始局部顶点构造图片像素，不依赖QuadMesh的UV上下约定，不给Control重复套翻转。GPU插值、动作、图集/接触影共用批次；墙门/矮物复用地面柔边纹理，树冠与屋顶保留整物记忆明暗。
- `terrain_canvas.gd`、`atmosphere.gd`与shader：地面图集、原有迷雾纹理、Godot CanvasModulate、单屏天气和有界太阳短影。没有每格/每人灯、粒子节点或新结算引擎。
- `action_effects.gd`：可靠结果的有界显示；`art_gallery.gd`：F8按需预览，关闭不更新预览帧。
- `view_rig.gd`让世界直接由原生Camera2D绘制，并统一坐标转换，见[显示架构](../docs/engineering/architecture.md#纯二维显示)。
- 运行纹理使用nearest、无mipmap、lossless。导出包含catalog，排除源稿、联系表、第三方原切片和已退役的旧人形技术样本；源码保留来源可重建。

## 临时包的明确局限

动作由同一八向底姿派生，是剪纸/工具叠加动画，不是专业逐帧完整动作。模型的SW误画为SE，已用镜像修正；目前不作为解剖左右或非对称装备挂点标准。休息/进食等是状态示意，不保证手口或床面精确接触；攻击相位不是精确的命中帧。

影子是与根部相接的解析椭圆加小幅太阳方向偏移，不再压缩一整棵树的轮廓到几像素后出现断层；不做物理长影/动态灯。树摆使用绕接地点的线性切变，根部固定。前后排序按新姿态采用时近似，屋顶最后画；新素材是统一视向的像素测试稿，尚未制作完整逐方向正面细节。整屏远近形变因像素边缘产生台阶而撤除，素材维持固定斜俯视，不生成隐藏侧面。生物预备仅单姿，完整八向动作/尸体在启用相应玩法时再补。音效、音乐、全套技能与最终UI皮肤不属于本次交付范围。

退役人形技术样本、旧清单与专用生成器已删除，可从[整理前版本](https://github.com/fewnfds/reol/tree/bd1971c/assets/characters/humanoid_sample)追溯。当前图集、源素材、来源记录和`tools/build_art.py`继续保留；旧提示词不形成后续开发任务。
