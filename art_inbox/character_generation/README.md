# 外部角色图像接收区

目前用户已决定先使用代码生成像素示意，正式外部美术后置；本目录仅作为未来候选的接收约定，当前无需继续生成或交付。

提示词与逐批顺序见[制作任务包](../../docs/archive/art/character_generation/README.md)。本目录是候选接收区，不属于Godot运行资源；`.gdignore`避免自动导入未经核对的大图。

每个编号提示词只生成一张八方向表，按文件开头说明上传前置图。将第一批原始PNG按建议图片文件名放这里，附生成模型/版本、提示词、seed（若工具提供）、是否做过编辑和输出使用条款或授权信息。保留原PNG，不转JPEG，不将网格展示图冒充逐层源图。超过50MB的单文件先说明。

我们在核对镜头、左右、透明、脚点和叠合后，再处理并迁入assets；不要覆盖现有humanoid_sample。文件名只用作交付管理，不要让模型把文字画进图里。
