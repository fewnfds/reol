# 文档与项目记忆

## 怎样进入上下文

| 来源 | 载入方式 |
|---|---|
| 当前对话、宿主指令 | 宿主注入 |
| AGENTS.md | 宿主按目录发现载入 |
| 技能名称/描述 | 宿主提供目录，任务匹配时读取正文 |
| HANDOFF、工程、设计、计划等文件 | 按需主动读取；链接不会递归载入 |

本机配置、凭据与顾问程序不属于公共项目记忆。具体宿主载入行为以实际注入为准。

## 怎样维护

正文归属见[文档地图](README.md)。同一结论维护一处，其余页面用链接定位。

- 规则直接写当前内容；“某日补充”“本轮决定”和修订过程由Git或原始日志追溯。测量日期、来源版本等证据元数据保留在对应记录中。
- 持久内容只保存会影响后续判断的事实、理由和未决问题。先按概念或代码标识找原页；新文件应有独立用途和可发现入口。一次性建议不自动成为全局约束。
- HANDOFF只保存实际停点、未完事项的下一动作、必要代码/证据路径和受保护工作；完成后移除待办。实现事实回原领域页，排错和顾问原文留本机。
- 随改动维护受影响页面，删除失效或重复说明。候选与历史注明性质；内容冲突时核对用户决定、代码和测量，不按日期或重复次数定真伪。

组织方式的来源见[文件组织研究](../design/research/project_structure_references.md)。
