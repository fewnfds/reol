# 已验游戏功能与操作

核对：2026-11-05。本文列出稳定基线已接通的行为、入口和样本边界，不记录授权或下一工作包。最新验证的具体SHA在[BASELINE](BASELINE.md)，待完整回归的世界输入/装配改动和隔离争环WIP不算下文已验功能。

读档首屏呈现修复已由其对应CI通过，见[QA](qa/20261104_world_view_continuity.md)；原高度/飞行样本仍存在，但新世界引擎先做平面，高差扩展后置。通用世界编辑、完整五行场/风水、自由组织和出生转生并未因设计文档而实现。

**实施中：平面地表草稿、运行编辑与持久化。** 开局装配可接受草/水/岩的稀疏格修改，普通存读恢复同一底图和修改；通行、附近水环境潜力、地表与植被覆盖、静止视线随原地图更新。已有定向与真实停开/画面证据，完整回归待对应SHA。显式运行`python tools/godot.py run -- --world-editor`后F8进入暂停开发工具，左键以1/3/5格宽画笔修改，保护人物/大型占地/设施/完整在途路线与活任务接触；独立编辑档可保存/读取，退出仍暂停。普通运行不提供免费改地；玩家改造动作、多格设施/种植区仍待实现，地表水和岩石不自动生成可提取水量或矿藏。

**实施中：结构与视野。** 原N施工簿仍用真实木料和工时；建成木墙按四邻连接，木门开关保持门框。真实墙/关门会遮住背后的当前视野，开门后静止人物也会更新视野，旧探索记忆保留；桌柜阻路不等于挡住视线。只读工具可查原工程/值事房部件的覆盖格、地面/屋面层与物理事实。当前仍限原单工地及单格工程，通用多格家具、区域创作和完整在途重规划未接；验证范围见BASELINE。

**实施中：在途清场。** 新墙/关门会等待当前正通过的原路段，包括对角通行需要的旁格，不取消行走者或抹掉已做工时/搬到的材料；人通过后可重试。兽身使用同一首段保护，低床/屋面保持可通行。固定运粮还不会随动态结构绕路，本阶段先禁止把新增阻挡建成在其道路上；自由封路/通用重规划另接，纸面蓝图仍不挡路。

**实施中：固定冷热器物。** 新局灶房放有默认关闭的赤纹石与青纹石。走近点击器物，亲自“循纹探查”后可花一分钟及1灵气启用；附近的人能花一分钟关闭。火石耗自身有限储量放热，寒石把周围热量吸入自身有限容量；同格对冲仍各付真实成本，关闭不重置周围温度。启用中先关闭再搬动，耗尽/吸满不会自动关闭或补充。玩家只见外观、亲历用法与定性开关状态，普通界面不显示隐藏能量。当前仅固定地点，移动辐射、可搬箱、充补能与热场自动回收待后包；本包完整回归状态见BASELINE。

**实施中：自然日照。** 普通天色、左上环境行和右键可见地块观察改读同一自然光规则；太阳高度与昼长来自共同时间、季节和整张地方地图的宏观纬度/经度，晴雨影响天光。纸面屋面不遮光，实际有支撑的屋面才压低该格自然光，拆除/塌落后恢复露天天光，进入房间不会让整张地图变暗。当前默认北纬30°；其他纬度/极昼夜由定义与定向场景验证，尚无普通世界创作表单。此包不改变NPC视力、植物生长、Fog、太阳供热或局部灯；画面与完整回归证据见BASELINE，不把自然光查询当完整环境光系统。

**实施中：固定火石局部光。** 新局火石在原学习、启用动作完成后，按实际释热流照亮近旁，距离衰减、已建墙/关闭门与岩石遮挡；开门/拆除即时改变透光。关闭或用尽即变暗，余热仍在，光不多扣一份储量。可见地面观察和左上环境行给定性暖光，画面只对当前视野内的格投影；灵魂不会获得肉身视力。多源叠加，当前规则每笔最多441受光格、128活跃放热引用、总相对局部光上限40000（尺度10000）。旧内容包没有lighting配置就不发新光，不改写旧档。定向、普通夜间画面及完全停开后同未来已验，最终SHA完整CI仍待验；不含移动灯、夜明珠、容器遮光、光照改变NPC/植物或光热能量分账。证据见BASELINE。

**实施中：新局地理气温。** 普通新局按明确的地理草稿生成实际年/日气温曲线：纬度决定基温和季节幅度，南北反季，海陆调节影响温差和季节滞后，经度平移日温相位。同一曲线作用到热场、人体和植物，仍由原天气补晴雨温差。默认整张地图北纬30°，两地区只有海陆性/局地偏移不同；入树前可独立传地理或完整内容包，当前无创作表单。档内保存曲线及digest，加载不按当前草稿重编，既有旧曲线继续生效。定向、冷热原生画面和完全停开同未来已验，最终SHA完整CI待验；这不是完整气象或雨雪/生物群系生成，具体近似精度见执行页。

## 3. 地图、时间和离场连续性

**已实现基础。** 首区512×512格、64×64区块；地形高度、可达性、加载、昼夜表现、战争迷雾与探索记忆。玩家相机可平移/缩放，固定正交俯视。

身体有连续位置；手动移动和自动路线共用世界毫秒与实际速度。人身闪身有起势、位移、收势，扣原体力、检查地形，不授予无敌。路线仍连接格路节点，部分绘制仍会显得跳格；不能称为已完成顺滑战斗优化。

山门与河湾共用时间。离开后当地日常、运输、消息与未完成事务继续；远区按必要变化批算，归来接续当前状态。封路会影响在途运粮，恢复后续行；消息需要实际传播时间。界面的“中断/恢复运粮道路”是**开发验证工具**，不是角色拥有的技能。

U3-a另装配一处野外断碑台，不是第三聚落。人物在野外仍保留原数据所有者，显示/点击按真实位置和当前视野；离开所属聚落不会消失，旧探索标记也不提供远处人物或物件现状。地点亲见目前按固定两秒观察时点与显式到场处理，寻物沿原身体/路线执行；这仍有持续采样成本，不是完整事件化远区或海量多年规模验收。

**历法/冷热是有限首步。** 同一世界毫秒派生360日简历与四季，原08:00开局保持；地图明确气候范围和昼夜/季节温度曲线影响室外背景，降雨按原晴雨规则降温。实际穿着/湿润决定御寒与暑热负担，走原精力；不新增万能生存条。每分钟采样只改未来，移动/换衣后最多到下次采样才调整消耗，体感可先变化。NPC按原需求/承诺后穿外层御寒挡雨、晴热脱外层。无受管植物等逐分过程的温和远区仍可批算；当前两药丛每分钟同步，风雪、完整天气/生态和多年规模未完成。见[E1 QA](qa/20261103_calendar_temperature.md)。

**屋舍/余热是有限首步。** 实际温石释热及固定冷热器物影响同一局地热场，屋面减少散失，墙和关门减少导通；开门、拆墙或塌顶先结旧布局，再改变未来流动，不清空或复制既有余热。冷热可缓解或加剧身体负担，普通界面不展示后台能量账。环境先按旧负担同步原身体，再固定分钟热样本供未来消耗；未来NPC预判纯投影，不推进世界。连续移动辐射、不同材料容量与完整室内空气模拟尚未做。当前近场为源中心5×5、最多512个激活格，格与来源历史保留、不回收，达到容量会拒绝新源；全格均不足0.1°C的守恒残余不强迫中性远区逐分钟同步。原温石证据见[E2 QA](qa/20261103_local_heat.md)，固定冷热器物见BASELINE。

范围：验证限于当前双聚落和有限居民，不是数百万平方公里模拟、通用迁居/多区生成、战争或规模性能验收。证据：[双聚落连续性](WORLD-CONTINUITY-IMPLEMENTATION.md)、[共同时间与生活](qa/20261103_continuous_life.md)。主要代码：[regional_simulation.gd](../scripts/sim/regional_simulation.gd)、[local_motion.gd](../scripts/sim/local_motion.gd)、[route_travel.gd](../scripts/sim/route_travel.gd)。

## 4. 自主生活、实物与生计

**已实现基础，内容有限。** NPC根据饥饿、精力、职责与所知安排取食、休息、搬运、制作和部分补料。物品从真实容器取出、随身携带、再交付；预约限制竞争，中断不能复制或抹掉实物。

人身在“生活与办事”里可以亲自送柴、挑水、运粮到灶房、下厨，完成后到功德堂交工。实际劳动形成凭据，有权登记者核验后记贡献；贡献可兑换现有饭食，再吃随身饭。零钱时也有劳动换饭路径。

“采集”页可拾柴、采野稗、汲泉、采野药，并明确选择“自留采集”或原公差送库。两种用途共用同一有限自然来源、预约和完整劳动；自留产物留在原行囊、不记公差，已有同物也不能代替本次劳动。公差仍先采入本人、再实际携回设施，交付后才形成凭据。开关只影响下一次意图；NPC可依据本人库存认识为原职责补料，也能使用相同自留动作。

**野药生态是有限样本。** 两地原野药改用适温、有限土水与真实降雨生长，停用其旧固定两小时增长；原成熟库存、预约与采集仍共用。干时停长，寒冷/过热时休眠，水暖恢复后接续；浇水不能绕过温窗。本人原私水预约、路线和两分钟工时完成后才扣一份，入土或溢流有同笔来源，公差水不能侵占。采到鲜药仍可用于原救护或私料焙药。药丛仅在原可见且近旁条件下画出有限阶段/定性描述，查询不推进生长。首包每分钟同步两个受管地区，显示卸载不停止过程，但不是海量植物/多年性能优化；无种子、植株死亡、完整农业或植物人生。当前“药圃”是原地点和野药来源的单格锚点样本，该格受原施工保护，不能直接盖温室；尚无可框选种植区或通用多格植物/建筑。这不规定未来药田或温室的形状。见[本包QA](qa/20261103_herb_ecology.md)及[长期空间合同](../design/systems/construction_and_space.md)。

**私料加工是有限样本。** “制作”页可把自己采得的柴粮水煮成饭、柴药草焙成干药。原行囊先预约，实际到灶房/药圃才整批投料点火；燃柴不退，停工保留在制物与工时，选原批续做只付剩余劳动。做成后成品仍在现场，另行实际取回才进原行囊；可在别处安排返回取货，不能远程领取。生产占原身体并消耗原精力，公差/受托物不会转成私人收益，不发公差贡献。饭接原随身吃饭，干药接原有限买卖；两种配方/共用场所，没有工位排队/品质腐败/负重/代工或NPC私人商业规划。证据：[私料加工](qa/20261103_personal_production.md)，规则：[personal_production.gd](../scripts/sim/personal_production.gd)。

**受托公物是有限样本。** 公差搬运/采集、做饭领料与跨聚落运粮，都认真实领用的一批；同类私物不被自动拿去交差。停工保留实物和责任，普通消费、投喂与买卖只用可处分部分；续做认原批次，不重复领料。也可点击交回，让本人走到原供给点清点归还，满库失败则继续保管，不发额外功德。买到/自留/获准取食取药的物品继续正常可用；施工料沿原项目链。

范围：低库存自主三日、自留接实际买卖与受托/归还已有证据；尚无完整产权/侵占/追偿/执法、农田/留种、完整产业、通用雇佣/全局经济或饥荒伤亡。旧已取消且出处不完整的混合物仍未分类，不把旧历史全面追认为私物或公物。证据：[生活基础](qa/20261103_world_foundation.md)、[有限自然来源](qa/20261103_renewable_livelihood.md)、[自留采集](qa/20261103_personal_foraging.md)、[受托公物](qa/20261103_entrusted_goods.md)。代码：[action_executor.gd](../scripts/sim/action_executor.gd)、[inventory_ledger.gd](../scripts/sim/inventory_ledger.gd)、[land_resources.gd](../scripts/sim/land_resources.gd)、[entrusted_goods.gd](../scripts/sim/entrusted_goods.gd)。

### 公源借用、验还与具名看护

**已验收的有限样本。** 普通人身实际取原温石、亲学循纹手法，走到值事房向现任管事用C“询问公源借用安排”，再申请“引息归身一次”或“温养原石一次”。原办理完成才签一次具名借用；实际去地火隙引息，源量不足、物件被占或身体条件不合仍不能做成。许可有最迟开工期限，失败/取消不消费一次成功，无许可仍能物理取用。

用后实际“放回灶房”，回管事面前用C“声称已归还，请人核验”。他同意后自己沿原路赴灶旁亲见原公器，再回桌登记，玩家可以继续活动。登记证明原公器当时已复位可用，保留“申请人声称归还”，不证明是谁亲放；别人代还也可履行归位义务。面板不会报告远处核验坐标或自动得知结果，须当面再次询问。

看护只涉及山门这处公源、同一块温石和石头一人：新局显式安排两小时，石头先顾原需求、已承担的事和个人生计，有空才用原身体走到灶旁查看。只有本人实际看见引息、双方能够当面通信而又未采信借用依据时，才提出警告，初始宽限九十秒。玩家可停引息、C向他说明本人记得的签注，或继续；警告不提前取消引息。宽限到期仍可见、原源过程仍在、委托/身体/手段都允许，才可能转成原有限驱离。当前扮演主体实际收到警告时会停快进、恢复一倍并暂停，原人身在鸟/魂开局下自行遇事不会误暂停玩家。

签注仍在固定公簿上；C说明传递的是本人已有、带来源的签发记忆，看护可以采信，也可能误信已用过但自己不知的旧依据。没有远程翻整账或全门派同步知情。无人看见、隔墙、不同高度或看护离岗时，无许可的取用仍能物理完成；胜负不转移公源/温石归属，不发奖励或补满状态。没有通用巡逻、领地执法、搜身没收、完整产权/借赠追偿或任意合同。旧档只迁入空看护状态，不补人、物或过去的警告。证据：[借用/验还QA](qa/20261104_source_loan.md)、[看护规格](plans/source_care.md)与BASELINE。

范围：一处公有工地、木墙/门/床/屋面及有限围合/床位安排；晴雨仍是循环气候原型。已有历法/温度与有限余热，完整生态/室内空气、门锁、私人地产、租房、施工工资、攻击破坏和完整经营未做。NPC床位注意是近邻与通路判断，非长期房间记忆；现有野药受雨影响，但种植作物及其降雨反馈、雨对鸟类和战斗的后果尚未实现。证据：[施工](qa/20261103_construction.md)、[围合/床铺](qa/20261103_rooms_and_rest.md)、[屋面/晴雨](qa/20261103_roofs_and_weather.md)、[屋舍余热](qa/20261103_local_heat.md)，规则：[construction.gd](../scripts/sim/construction.gd)、[resting.gd](../scripts/sim/resting.gd)、[weather.gd](../scripts/sim/weather.gd)、[local_heat.gd](../scripts/sim/local_heat.gd)，参数在data/definitions。
