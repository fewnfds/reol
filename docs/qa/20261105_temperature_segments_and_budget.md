# 温度目标分段与边界查询成本（F2a-2）

日期：2026-11-05。隔离规则包，承接[实际温度状态](20261105_actual_temperature_state.md)，不等于普通Main替换、完整时间调度或房温完成。

## 已实现

- [`SimEnvironmentTemperatureSegments`](../../scripts/sim/environment_temperature_segments.gd) 将已验证气候/天气、位置、共同时间、冷热等级、seed与显式期限编译为一个常量目标段；不修改输入、不积分、不推进时钟。
- 结束于当地气候整数温度变化、天气相位、全局潮汐格点、调用者已知期限中的最早边界。额外气候/天气边界继续使用原全局格点的tide采样，不因查询或分片重新采样。冷热等阶时跳过无效tide边界。
- 温度状态的下一边界改为可重建计数索引；只在提交/恢复时维护，查询O(1)，没有每格Timer、新持久字段或第二时钟。失败/pending不改响应或索引，恢复完整候选后一起发布。

当前编译器每次仍防护所查询的区域/曲线/天气结构；目标段的下一次提交由调用者负责。尚未提供分块动态温度调度、真实原物变更候选、Main人体/植物历史或房间。源变更不能先改实物再异步等GPU；它需要旧/新覆盖区的完整候选与无yield联合提交，GPU缓存现有自动发布接口不能直接当该事务使用。

## 默认1000ms持值与连续潮汐的理论差异

这是候选时间粒度，不是已接入普通世界的默认配置。固定周期600000ms、98%–100%三角倍率，1000ms内与连续倍率之差保守取68ppm。净等级千分整数G经四舍五入后的差值可界为 `D=ceil(G×68/1000000)+1`。在中性20°C、实际有效等级范围 `[round(0.98G),G]` 中取相邻表段的最大斜率，再加两端温度舍入合计0.001°C，有下列保守目标温差界：

| 净等级 | 热目标误差上界°C | 冷目标误差上界°C |
|---:|---:|---:|
| 1 | 0.041 | 0.041 |
| 3 | 0.161 | 0.041 |
| 5 | 0.801 | 0.081 |
| 8 | 2.668 | 0.088 |
| 10 | 5.001 | 0.025 |
| 100 | 20.001 | 0.001（此范围实际已恒为绝对零） |
| 1000000（支持上界） | 170002.501 | 0.001（实际恒值） |

高阶热源的摄氏误差会放大；68ppm不等于0.1°C精度。不同中性温度会改变冷侧斜率，其他周期/格点/表须重算。主局接入前必须决定哪些过程读取这种离散规则、哪些需要更细粒度/预计算周期，不能据此承诺连续模型下的阈值触发时刻一致。

同初值、同正tau、所有真实变更边界对齐且目标差始终≤ε时，一阶趋近的误差是目标差的非负衰减加权平均，权重和≤1，因此任意时长的实际温差≤ε；有初始误差时≤max(初始误差,ε)。这仅是数学界，浮点误差、脉冲、不同tau、未对齐事件和每段额外舍入需另计。无需在运行时计算该证明中的积分。
