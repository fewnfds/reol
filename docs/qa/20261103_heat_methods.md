# 温火石第二用途与 NPC 自主摸索验收

2026-11-03，工作包见[范围](../plans/artifact_heat_methods.md)。仍为有限生活样本，非通用热力学或完整自主发明。

同一块温火石既能替柴做饭，也能在药圃烘药；共用有限储能、本人灵气和原库存事务。烘药消耗两份原草药，留下两份干药，不直接增加钱或功绩。缺料、预约冲突、容量不足或热量不够均不半扣材料；中断不退已投入灵气、不发产物。

NPC 在已有做饭需要而本人以为缺柴时，才考虑附近见到的石头，依次端详、付自己的灵气探查、学会、催火。观察与学习不会传给玩家；后台储能不参与提前预测，实际试出余热不足才留下 depleted 经历并考虑注灵。吃饭、休息和正在执行的劳动不会被强行抢占。完成后亲眼查看现场，避免只凭过时记忆重复做饭。

自动测试覆盖两用途竞争、中断、原子失败、本人认识、错误库存信息、余热不足后的选择、粗细推进和 JSON 接续；运行/断言数字仅在 BASELINE 维护。

实际游戏验证：

- 器物面板“去药圃备料”通过真实路线抵达，5285000ms 开始烘药，灵气15→13；5405000ms 中途保存，再240000ms完成，草药12→10、干药0→2、储能4→3。
- 完全停止、重开游戏后读中途档，继续240000ms得到相同全联合状态散列 **1099446088**。日志 `logs/heat-drying-start.json`、`heat-drying-future.json`、`heat-drying-restart.json`。
- 新开局没有改 NPC 状态：阿禾50ms端详、60050ms开始探查、300050ms学会并开始做饭、480050ms留下实物饭；灵气15→12、储能6→4、厨房饭8→14、米6→4、水4→3。玩家依旧不懂方法。
- 在127000ms探查中保存，继续473000ms到600000ms。完全停开游戏，读同一档再推进同样时长，全联合散列均为 **2629224224**；日志 `logs/heat-npc-opening.json`、`heat-npc-investigation.json`、`heat-npc-future.json`、`heat-npc-restart.json`。
- 修复分数分钟完成时左侧仍显示办理中的问题；实机再次读烘药中途档，在5645000ms完成点已显示“眼下没有在办理的差事”。截图 `logs/heat-drying-panel-fixed-20261103.png` 与 `logs/heat-panel-completed.json`。
