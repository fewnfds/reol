# 分块温度锚点与私有候选（F2a-3）

日期：2026-11-05。隔离温度域优化，承接[前版成本](20261105_temperature_segments_and_budget.md)；没有替换普通Main，也没有宣称整个世界容量通过。

## 代码与语义

同一个 `SimEnvironmentTemperatureState` 改用16×16块：present字节、start/until整数毫秒、initial/target/slope双精度、tau整数。prepare只复制受影响块，完成校验后把候选根和边界计数封存在owner；公开计划只含原只读行和身份凭证。commit核owner/revision、原凭证、owner私存行身份与时刻后安装候选，不再逐格重复三遍恢复与预检。失败/预算不足不改活状态或现有有效计划，恢复使旧计划失效。可变proof字段不能换掉owner私存候选。

实际查询直接读packed锚点，复用Response原有相同运算顺序；默认积分分支未改语义。写档仍是原v1行顺序、字段和全精度JSON，未把packed缓存写成新格式。snapshot仍扫描分配块槽并排序/物化全部行，restore仍严格逐行校验后构建隔离候选。

**尚无可中断的大批准备。** 现有budget仍是完整批次格数，超量返回pending而不保cursor；prepare复制块键/边界键并遍历变更，必要时排序。commit虽安装根引用，旧根/块释放仍有规模成本。下一步需真正有界的候选准备及输入，不能每秒全图物化字典目标、快照或全格读取；这些成本没有因GPU场快而消失。
