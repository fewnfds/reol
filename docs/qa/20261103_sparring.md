# 同门对练实机验收

2026-11-03。实现范围见[样本工作包](../plans/sparring_sample.md)，当前总状态见BASELINE。

SimSparring在原RegionalSimulation共同毫秒轴上结算；复用原actor身体与体力。一个全局练习样本可约两名同一区域居民，山门玩家可从K面板邀请所选同门。精力/饥饿/体力不足会拒绝，搬运或制作不能强拉过来；轻松巡视可由本人同意后中断。双方原自主状态保存，收手后恢复；没有对练刷经验或全局关系奖励。

首招试掌：300ms起势、100ms接触、350ms收势，投入5体力；110px/左右60度扇区，命中造成14点短时体力负担和200ms打断。同刻接触先收集再汇总。可见扇区对应规则，地形/高差不满足则不能击中；普通闪身没有无敌，但确实走出范围可避开。参数都在data/definitions/sparring.json，仅为样本可调值。

NPC有限接近→起势→收势。实机发现NPC停在低一级地面却反复出掌，修正为先检查接触条件、不满足就进一步走近；增加反例回归。受击不能意外缩短原恢复/决策等待。对练占身体生活执行权；玩家空闲时可行走/闪身，出掌/受击阶段不能叠另一主动作。自动旅行/访客事务/器物/等候不能双占。

K面板在约练成功后自动收起，底部保留简洁自己的阶段/体力/按键提示，避免遮住双方。按J出掌、K再开面板可收手。读档重置旧界面提示，不泄露被放弃时间线的消息。

实际运行：K打开并点击约练石头；J第一掌离高地太远打空，NPC继续走到接触允许的位置，实际击中玩家。第二次J在8950ms开始，体力81→76；9100ms起势中保存。原进程再150ms使石头135→121；再750ms到10000ms，双方体力76/116，全联合状态散列105590987。完全停止并重新运行后读同一档、再900ms，散列相同。原样固定为tests/fixtures/session_v7.json；记录logs/sparring-current-start.json、sparring-current-future.json、sparring-current-restart.json。

实际规避：从同一真实档推进到9850ms（NPC起势中），D+Shift启动向右闪身，玩家体力76→68。再400ms身体[16416,16416]→[16536,16416]，NPC命中数仍1、当前掌hit=false，玩家仍68，没有额外损伤。记录logs/sparring-evade.json。K面板点击收手后到10550ms，NPC自主true、玩家自主false、原背包6钱保留、短动作已自然结束；logs/sparring-stop.json。
