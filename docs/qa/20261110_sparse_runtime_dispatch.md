# 共同运行与人物执行：显式同步及稀疏调度

本包承接[运行架构调查](20261110_performance_architecture_audit.md)，归[唯一基础计划](../plans/foundation-priorities.md)的共同运行与原身体执行。工作分支`codex/sparse-runtime-dispatch`基于da90e3b，旧生产与main839ff88一致。当前验证、审查及CI终态以[BASELINE](../status/baseline.md)为准。

## 实现边界

- `VillageSimulation.actors`/`actor_state()`只读取原记录；规则需要当前身体时显式`synchronize_actor()`，完整捕获、连续输入切换和画面发布用`synchronize_actors()`。现有生产调用和QA工具同步迁移，序列化的`actors`键保持原样。
- `projected_actor_position()`与`SimRouteTravel.projected_point()`纯求已受理路段的坐标；实体、容器及空间通知读取不再递归积分身体。没有新身体、时钟或存档格式。
- 原生结算/自主筛选复用原`SimParticipationIndex`的到期及失效集合。同刻维持原ID顺序；同步回调使较后ID失效时合并进剩余候选，较早ID留到下一边界。未声明依赖通知的独立Callable保守全体执行。
- `SimSettlementKernel`接owner本地工作条件；空闲过程跳过业务回调，阶段/依赖不重排。进入过的分片过程即使条件改变仍续完清理；预算耗尽保留原工作。装配器直接绑定可用owner，恢复后重编译。
- 只对可以证明空闲的领域使用条件；连续需求、来源、环境响应及远区仍推进。物品生命周期承担环境事务清理，保持执行。

这不是全领域到期化。当前仍有完整世界边界、活动域内部轮询、全部身体在公共发布时同步，以及重复布局/全员可见性筛选；后续空间导航、呈现与联合规模仍在原计划中。

## 固定负载前后对照

## 原生持续负载与停开

Windows/D3D12 Forward+、同一开发机/引擎，`python tools/stress_demo.py --residents 50/150 --seconds 20 --quit-after-capture`逐次执行。真实原行动持续巡行，包装器均退出0，world_errors为空；截图已实际查看。下表新旧样本按相同入口但不同现实运行时段取得，负载随实际流速演进，不是固定终点配对。

| 人数 | 前包流速 / 帧P95 | 本包流速 / 帧P95 | 实际移动 / 平均行走人数 / 改道 |
|---|---|---|---|
| 100 | 0.96252× / 16.633ms | 0.96740× / 17.325ms | 99 / 98.744 / 745 |
| 300 | 0.40766× / 26.376ms | 0.42509× / 27.680ms | 299 / 297.241 / 705 |

20秒样本没有证明稳定60FPS/300人1×；帧P95也没有改善。原生记录器包含诊断包装费用，没有GPU时间或发布版测量，开发机约32GB/5060Ti不替代16GB/RTX3060整机目标。证据`crowd-100-20261110-211940.{json,png}`、`crowd-300-20261110-212011.{json,png}`及同名日志，revision字段为基提交da90e3b且dirty=true。

为定位剩余瓶颈，临时包装本包原方法，300人同固定负载含插桩工作段27945.149ms，整个未来hash仍相同，finally逐字节恢复。含子调用：寻路5825.070ms、人物投影2916.344ms、截止点候选2166.619ms、连续需求1779.276ms、home视图1834.007ms、环境步骤1492.494ms。相互嵌套，不相加；插桩较无插桩约多22.4%。空领域调用削减不足以完成规模出口，空间导航和联合呈现仍沿原计划处理；不因领域文件数量认定环境是主因。证据`dispatch_scopes.py`、`dispatch-profile-300.{json,log}`，未新增永久测试。

`logs/dispatch_clock_capture.gd`复用已入库`clock_world_capture.gd`，只更换独立证据路径；两个原生进程先write再read，途中保留跨聚落受理路线。1234ms停开检查点hash为`25a0fefc4f1f7f44c677f811c9613a8033642058ba9ef858a75afeb7e69b3a71`，4451ms整个未来hash为`282a01e393d258f5921250397513544d62754264b44bceb391a511af894b859c`，两进程一致，均退出0。日志`dispatch-clock-{write,read}-20261110-2124*.log`，截图覆盖1280×900和1600×900；没有覆盖普通玩家档。
