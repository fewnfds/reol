## 同一会话：创建到离返再到完全停开

`object_lifecycle_restart.gd` 的 write/read 为两个独立Godot进程，走普通Main和 `save_game/load_game`：

1. 由定义生成一件原实物，实际移入玩家容器再放回原格；从原账本拆出3份木料。
2. 同一世界在60000ms抵河湾，120000ms回山门；三个节点的原实物ID、地面位置和3份木料不变。保存河湾快照供读进程另行构造候选检查，远处没有重建成新世界。
3. 回家后开始4000ms搬运，121000ms保存仍在预约中的2份木料，写进程完全退出。
4. 新进程加载，在124000ms完成；材料总量92、交付2/地面余1，释放原预约，重试不重复结算，整个世界的未来摘要与不停机续算一致。
