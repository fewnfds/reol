## 性能：静态几何索引

主机 i5-13600KF / 20 逻辑核，Windows 11，Godot 4.7.2 官方开发程序 headless。每个规模独立进程，30 秒/1 GiB 外部守卫顺序运行；每格一个合成引用、共 1000 次确定种子单格查询，单次最多 1024 工作单位，实测最大 258。还验证 17×17 跨桶查询及全图小预算明确失败，无部分结果。

| 密度 / 引用数 | 构建 ms | 单格查询 p95 / p99 ms | 进程峰值工作集 MiB |
|---|---:|---:|---:|
| 64² / 4096 | 18.930 | 0.034 / 0.038 | 95.1 |
| 128² / 16384 | 75.031 | 0.034 / 0.035 | 98.6 |
| 256² / 65536 | 302.790 | 0.041 / 0.053 | 118.6 |
| 512² / 262144 | 1243.969 | 0.037 / 0.046 | 195.9 |

构建包含逐条校验、引用编码和 seal。它是离线静态捕获成本，512² 的约 1.24 秒不能放在每帧执行。引用和精确格链接使用紧凑数组/分桶，静态没有 tick；快照更新需重新捕获，实时增量更新留生命周期包。

这些是 **合成几何索引**，不是 262144 个已持久化、可交互、可成长对象，不能当作普通世界容量、渲染 FPS、NPC 模拟、环境场或 GPU 加速证据。1024²/2048²未测且超本索引对象上限，不能据地图坐标上限推导支持。
