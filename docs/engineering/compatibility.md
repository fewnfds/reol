# 存档支持现状

当前仅支持`reol-world-11`开发布局：保存独立瞄准方向、AI接触、动作相位/连段/分组冷却、命中去重、受击保护、在飞弹/追踪相位/穿透记录、区域预警与周期、持续状态、独立器物的身份/耐久/归属/部署，以及战斗规则内容签名。毫秒时间不要求50的整倍数。原物资/穿戴、身体耐受/冷热伤害余数、个人事件与生活路径保留；派生热列不入档。F5/F9默认使用新的`user://act-p4-quicksave.reol`，保留P3的`act-p3-quicksave.reol`，保留P2的`act-p2-quicksave.reol`、P1的`act-quicksave.reol`及旧`quicksave.reol`和备份，不自动加载；关闭重开后可主动读取。本版需新开局，不维护旧开发格式迁移链。

`World.state_owners()`是实际领域入口，各owner的`STATE_FIELDS`显式选择原状态，`persistence.gd`通用遍历，不序列化任意引擎对象。身体页另按热列导出；缓存、Frame、Thread、Callable和锁不入档。新能力只在实际owner扩展状态与语义校验，不需要为每个功能重写文件I/O。

保存从完整模拟边界取得脱离值，独立冷I/O线程写二进制或重建候选。覆盖实物/材料、路径/通用行动/预约、植物/宿主/来源、AI接触/动作相位/CD/在飞物、个人线索/承诺/成长、探索/静态记忆、地区、历法/天气与随机状态。校验域类型、数组长度、库存/引用和过程，重建空间/场/导航缓存后才由owner替换会话；失败保留原世界，成功提升epoch。恢复不通过推进世界来重建缓存，不偷刷离场静态记忆；本机按住输入和直接速度不入档，恢复后不自动走动/射击，已承诺动作与飞行物继续执行。

耐受与小数伤害余数要求有限值及合法范围；个人事件只保存事实环和序号，恢复时校验预算、时间/载荷并重建人物索引及视图。读档使人物列表回到存档时状态，UI不保留后一段未来。界面缩放属于本机`interface.cfg`，不随世界档回退。

P2使用format9，保存单槽待执行意图、独立击退/控制预算、敌人原定收招与一次惩戒资格、弹体已掠过身份与AI思考相位；练习模式也随世界保存。候选验证仍保留动作/命中等完整状态，Runner采用会话时清玩家未启动的下一招缓冲，恢复当前已开始动作、CD和在飞物；NPC缓冲不受本机输入边界影响。战斗音量/震动/闪光属于本机`feedback.cfg`，不随世界读档回退。键鼠偏好属于独立`controls.cfg`，不进世界档；配置缺失/非法仅在内存使用默认并提示，保存改键失败不替换当前绑定。没有组合键/手柄偏好的格式保证。

P3在format10延续这些状态，新增`effects`、`areas`、`implements`领域；移速修正从持续状态重建，不重复保存。战斗逻辑定义或配置绑定与存档签名不匹配时拒绝整个候选，保留当前世界/原文件；标题、描述、颜色不参与该签名。保存定义后必须关闭并重新启动游戏才能采用新内容，重练按钮不重新装载定义；没有运行时热改或历史规则版本链。器物绑定记录是其唯一耐久来源，去回程/回收不另生成库存件。

库存和穿戴统一验证规范物品键，穿戴必须匹配实际槽位；实物审计包含已穿物。恢复先校验源记录，再重建所有身体的派生属性，最后校验现血上限；不以默认裸身上限截掉合法装备血量，非法槽位/未知品质/越界基础值拒绝整个候选。重用身体槽位重新计算新身份属性，不继承上一个人物的装备缓存。

写入先到`.tmp`，保留上份`.bak`后替换；主文件缺失时可尝试备份，主文件存在但无效则明确失败，不悄悄切换历史。Windows替换不是断电持久性承诺，错误通过回执返回。四次覆盖同一路径与全新进程续接已做短验证，证据归BASELINE；没有旧档兼容、任意恶意文件沙箱或跨Godot版本二进制兼容保证。

P4 format11增加领域run/运动代次与可重建占用、独立弹体载荷及伙伴等待；保存资源池/再生余量、状态层数与隔离归属、盾层/方向格挡、反应次数/ICD、共享因果预算/访问集、待请求、脚本宿主状态、召唤/光环成员及器物多槽部署。候选校验所属运行、模式/预约关系与载荷后重建绑定，不保存本地按键。P3签名与布局不兼容，不自动迁移或覆盖旧档。

注册脚本`owned_marks.gd`以显式`LOGIC_VERSION`参与定义签名，状态有独立schema version；修改算法须同步提升逻辑版本。导出不读取.gd源码来生成签名。可选追踪、空间索引、UI键位、派生属性/人口能力列不入世界档。
