# 存档支持现状

功能恢复第1段提供新的`reol-world-1`格式，仅支持现行开发布局；不读取旧运行框架的世界档，不维护历史迁移链。F5/F9默认使用`user://quicksave.reol`，不自动加载；重启后可主动读取。

保存从模拟owner完整边界取得脱离值，独立冷I/O线程进行二进制写入、或校验并重建候选世界。成功读取后owner替换会话，失败保留原世界。格式标识之外还校验域类型、数组长度、库存、引用和当前过程；未来新领域在自己的状态列表扩展，不向存档写入引擎对象或显示Frame。

写入先到`.tmp`，保留上份`.bak`后替换；主文件缺失时可尝试备份，主文件存在但无效则明确失败，不悄悄切换历史。Windows替换不是断电持久性承诺，错误通过回执返回。没有删除或改写用户旧档、凭据及原始素材，历史开发档不构成新格式兼容要求。
