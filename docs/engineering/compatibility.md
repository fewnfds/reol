# 存档支持现状

## 当前格式

源码仅支持`reol-world-29`开发布局和相同战斗/决策/主体/操作/成长/社会定义签名。F5/F9默认使用`user://sect-quicksave-v29.reol`；旧阶段存档和备份不自动加载或覆盖。现有独立P5包仍用format14及自己的默认文件；没有旧开发格式迁移链，也不维护第二套旧世界。

战斗签名由`action_defs.gd`生成，包含逻辑定义、配置、运行合同版本与受信脚本显式版本；决策另由`decision_defs.gd`生成，含Policy/规则、运行合同与求值器逻辑版本。标题、描述与颜色不参与战斗签名。编辑定义后须关闭并重开游戏采用；重练不重新编译定义。修改受信脚本算法须同步提升对应`LOGIC_VERSION`，状态另有schema版本。

主体定义由`being_defs.gd`从显式Resource库编译/递归冻结，签名不含标题。形态、临时出生归属和个体能力覆盖是原状态；有效能力和身体页代谢/环境开关是派生值。恢复校验进行中操作、劳动与接触伙伴是否仍有对应能力；常驻身体统计按出生归属计数，与是否需要进食、是否人形无关。

操作定义另有`operation_signature`，由`operation_defs.gd`签名可信宿主/handler、本人要求、目标规则、持续时长/独占、费用及作用，不含标题/图标/菜单别名。进行中动作只存操作ID与原run，不存Resource；拒载未知操作或错误宿主，不因目标在途变化拒载合法过程，到场/提交仍按当前状态复核。静止主体的完整操作/自主支持仍待后续。

T04将方法分为理解与实践的规范子记录，加入素质/持续体况和`growth_signature`，源码现format17/新默认文件，保留旧16档。已解锁能力从掌握进展派生，与显式场景授予取并集；恢复不写第二份精通标志或重放成长。教师ID/资料来源是历史，允许对象已消失；暂时失能不抹记忆，持续体况源记录保留而按能力决定有效性。

## 原状态与恢复边界

`World.state_owners()`列出实际领域，各owner用`STATE_FIELDS`选择原状态，身体页用显式热列合同。`persistence.gd`通用遍历这些值，不保存任意对象；缓存、Frame、Thread、Callable、锁、纹理和输入偏好不入档。

当前另覆盖P5政策绑定、独立参数/任务、规则到期、唤醒配对与持续自主输入；恢复重建gate后验证任务/run、buffer、模式、字段与目录签名。本轮另保存有界的执行失败反馈及其个人观察依据；受理不冒充完成。trace/latest诊断不入档。

施工阶段保存`construction_started`与剩余工时；恢复验证蓝图阶段类型、旋转后完整占地和已开工实体的通行阻挡。已观察半成品的阶段也随个人静态记忆保存，离开视野不会自动更新。允许作业格从定义与占地派生，不另存一套位置真值。

当前覆盖实物/穿戴、身体与冷热耐受/伤害余量、行动/预约/run身份、路径、AI接触、ACT相位/连段/缓冲/CD/去重/受击保护、弹体载荷/追踪相位、区域与状态节拍/来源生命周期/模板槽/标签压制/平面触发原因、池/回复余量、盾/格挡、有界反应与脚本宿主、召唤/光环/器物、个人事件、认识/探索/静态记忆、地区与环境随机状态。已交付攻击保留来源阵营和近远两项攻击快照，来源移除或身体槽复用不改后代归因。

保存从完整模拟边界取得脱离值，冷I/O线程负责文件或独立候选；只有模拟owner能采用候选。恢复先验证类型、范围、引用、库存、过程、规则签名和载荷，再重建派生属性/空间/导航/占用等缓存。制作资源与在飞载荷使用相同作用参数校验，非法候选整份拒载，不修改当前世界或原文件。

恢复不推进世界、不重新付费或产出，不刷新离场记忆。先重建装备/状态属性，再校验现血，不用裸身上限截掉合法装备血量。来源销毁后的只读攻击归因可以保留，要求活宿主的引用必须仍然有效。

成功读取提升会话epoch，恢复已承诺动作/飞行物/CD和NPC待执行意图，清除玩家尚未开始的本地输入与下一招缓冲。键鼠、界面比例和战斗反馈分别属于本机`controls.cfg`、`interface.cfg`、`feedback.cfg`，不随世界存档回退。

## 文件交付

先写`.tmp`并刷新，再保留上份`.bak`后替换。主文件缺失时可尝试备份；存在但无效时明确失败，不静默切换历史。Windows替换不是断电持久性保证，也不承诺任意恶意文件沙盒或跨Godot版本二进制兼容。

当前构建与实际恢复验证见[BASELINE](../status/baseline.md)。来源贡献、控制聚合、决策失败反馈与设施登记使用format14布局，旧format13及更早开发档不迁移或覆盖；旧包及备份保留。战斗40/24内容目录保留，决策拥有独立签名。
