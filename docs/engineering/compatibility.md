# 当前模型与存档支持

开发期只维护最新运行模型及其当前存档格式，包括领域内部格式。旧格式不迁移、不保留兼容分支或版本样本；历史需要时从Git追溯。实际版本统一登记在[BASELINE](../status/baseline.md#代码与采用版本)，代码依据是`SessionSaveSchema`、`RegionalSimulation`与各领域schema。

根格式不符统一返回`unsupported_version`并提示新开局；领域格式不符也拒绝独立候选。认识账本只接受当前版本。拒绝加载不会部分改变活会话；不会把旧档缺失的规则、物资或经历从当前开局模板补造出来。

当前保存仍复用[通用管线](architecture/04-persistence.md)：完整边界捕获，独立候选验证成功才替换，派生索引与设备工作重建。来源的待采用位置样本属于后续计算输入，需要保存；呈现队列、执行游标和GPU句柄不保存。

仓库旧fixture已删除，不再维护各版本存档收藏。保存槽覆盖当前文件；写入期间的`.tmp`和最多一份`.bak`用于写入失败恢复，不是不断累积的历史版本。当前有效档的失败恢复继续保护，过时开发存档可清理，不需要为其设计转换器。格式变化只更新本页、原schema与实际受影响入口，不展开迁移矩阵。
