# 植物与栽培承载合同

> 实现参考：描述代码接口及消费者假设，可随重构更新；稳定边界见constraints，范围按当前用户任务。

`SimPlants` 持植物唯一身体，`SimPlantRules` 持纯定义/区间规则，植物行动与候选校验分别在 `plants/plant_actions.gd`、`plants/plant_snapshot.gd`。实现归植被与自然生命框架；共同事件、空间和存读服务全局，见[领域](architecture/05-framework-domains.md)、[事件](event-contract.md)和[存读](architecture/04-persistence.md)。

## 原状态与数据

- `data/definitions/plants.json` 组合基质、冷暖、生长季、光、水、寿命、阶段、残根、产物、几何及来源 profile。定义不被实例改写；开局样本另在 `data/scenarios/plants.json`。
- 每株有 ID、出生/初始年龄、当前结构、损伤、累计生长、产物计数、原位置/支撑引用。普通草木不建立 NPC/主体/背包/Node。
- 地面允许小型植物共格；木本占地和花盆根容量分别校验。空间投影只索引原身体，多株不会合成虚构的一个实例。
- `SimConstruction.cultivation` 持花盆基质、水和植物 ID；植物在花盆内只持 support，无第二份家具坐标。当前单株根容量；基质为定义声明，浇水消耗原库存。
- 水/石地块的 `growth_factor_at == 0` 不作为植物普遍禁令。植根、生存、适宜生长、自然分布分别判断；有实际水面的地方能支持水生物种。

## 时间、生命与环境

按共同时间到期/变更执行；稳定采样默认每游戏分钟一次，不在 `_process` 逐株运算。预算不足保留当前 due 集和结算游标；休眠仍保留年龄、寿命与环境唤醒，不冻结远区。

成熟、开花、结果与休眠/损伤/死亡分开。年生按自身寿命结束，多年生可休眠恢复；可再生物种砍后留根，重新生长保留 ID。残根长出阻挡前复核实际身体/在途占用，避免把人封入树干。

生长使用上一采样条件结算旧区间，再读取实际冷暖、历法、自然光/屋面与自身水；水是有限储量，生境湿润潜力不等于免费物品。雨补水、休眠期间仍蒸发、干旱/极端温度损伤属于当前简化模型；死亡清掉未完成的产物进度。条件分辨率为一个采样周期，不宣称逐毫秒生态精度。

植物 source 引用全局 `EnvironmentSourceDefinitions` profile，复用已有五行/冷热通道与半径规则，火属性与发热独立。来源启停/移位/移除在旧区间结清后更新环境索引，保留环境原处残留。冠层参与本格自然光衰减；完整相邻树冠、根系/营养/流体网和物种间竞争不在本阶段。

## 行动、产物与支撑变化

玩家/NPC 共用 `SimActionContract` 的占用、接近、预约、持续复核、中断、释放和完成发布。采摘转移原产物，伐取/采走原株结算对应身体产物，清残株另立动作；一次请求回执和原库存 operation 防止重付。失去目标、权限/控制或路径条件时取消，已受损/已耗时间不会倒流。

效果提交前先结清目标的旧区间，再复核行动条件。伤损、承载变化或觉醒使作业不合法时，在同一完整边界结束前取消并释放；存档不留下恢复时才被发现的不合法活动作业。

首版活株移栽限相邻、可达、基质与容量合适的地面/花盆，保留年龄、伤势和 ID。任意距离携带活株归完整行动/搬运阶段，不用瞬移冒充搬运。花盆损毁留下原地受损植株并释放支撑关系，不复制植物或重发开局库存。

旧野药/野稗源在开局明确交接给植物；保留原 `resource:` 容器、已有库存/提取账，旧增长器停用。泉水和林缘落枝等非植株资源继续归原 owner。已实例化位置的地表装饰被抑制，砍除后不会露出同一棵背景树。

## 灵智、观察与恢复

显式事件成立后，`SimEmbodiment` 把主体与通信能力关联到原植物。固定树精能回应并允许采果/拒绝伤根；未觉醒的植物不自动升级为 NPC。仅记录觉醒后的真实交谈，不凭开发查询制造角色知识。

Main 右键观察可见处，提供采摘、砍伐、清残、浇水、邻格移栽与尝试商量；面板只投影可见外观，不公开五行数值、隐藏药性或未经互动得知的灵智。全知对象查询与这些玩家投影严格区分。

原采集页的私水照料经`start_home_work`转接同一植物作业，耗时来自会话植物定义；进度/中断/回执沿共同动作，不复活旧资源生态。已登记资源地点可从远处动身，任意独株仍需当前观察；显示近况先过原可见距离与迷雾校验。

存读使用统一 registry。身体、花盆关系、产物/预约/回执、进行中动作、灵智和事件全部进入独立候选；空间、due、支撑和来源索引恢复重建。旧 owner 的地图/结构通知连接在原地恢复时解绑，避免旧身体继续响应新世界变化。
