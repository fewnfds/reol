# 顶层领域职责

本页唯一维护产品的逻辑职责，不是全部已实现功能清单。领域不等于某个class、Autoload、Node、线程或数据库；当前实现与写入者只查[运行架构](../architecture.md)，当前实际能力只查[FEATURES](../../status/features.md)。可以用少量直接代码承载多个领域，不按表格行数预建框架。生命成长与社会组织的职责已补清，运行机制仍待实施；源码缺口和理由见[共享框架审查](foundation-audit.md)。

## 逻辑领域

| 领域 | 负责的事实与过程 | 提供的接缝 |
|---|---|---|
| 世界地块与空间 | 地形/材质、坐标与真实占地；从原对象派生分块候选、净空、接触和可见几何 | 带适用范围/版本的局部查询与变化范围；视图瓦片不作权威碰撞 |
| 实体、物品与容器 | 唯一身份、定义/实例、各域能力的载体装配、原物/数量、包含与实际保管；受控生命周期 | 稳定引用、按实际能力查询、合法转移和变化；权属/授权关联社会事实，原物不因跨格、视图或任务复制 |
| 建筑与组合空间 | 结构/家具、施工/拆改、材料过程、门/屋面、操作位、设施及推导围合 | 真实拓扑/材质/开口与设施条件；房间不是另一份建筑/库存 |
| 植被与自然生命 | 原株/其他生命的专属状态、物候/生境/响应、残株与产物、条件能力 | 实际占地、来源/受体与领域作用；不要求每株完整心智/背包/Node |
| 环境 | 历法/气候/天气、温度/五行/照度的各自规则、必要响应与可定位来源 | 带时刻/空间/输入依据的查询及受体条件；不复制原物或生命后果 |
| 生命状态与能力成长 | 按需装配的个体素质、维持/资源、身体条件、掌握/修持与成长后果；各类事实分别有明确写入者 | 向行动/评价提供实际条件和已掌握手段，变化时重建有关派生值；不复制原HP/资源或Nature物候，不把成长和伤病强压成同一种状态算法 |
| 单位行动与交互 | 消费实际能力，处理移动/路线/避让、受理/接近/预约/耗时/中断、共同参与与通信执行 | 玩家/NPC共用意图/过程/失败和实际结果接缝；施工、产物、伤势、学习等后果归实际领域，过程按真实载体保存 |
| 认识与自主选择 | 来源明确的观察/记忆/传播、理解/评价、持久目的、当前意向/有限方法，对需要与职责的本人选择 | 基于本人认识向P5交付当前步骤、采用反馈与重选；全知索引、实际掌握和客观社会记录不能写成个人信念的同一真值 |
| 社会联系与组织 | 已成立联系及认可范围、组织/成员、职务/任职/职责范围、事项/份额、住所/服务安排、权属/授权、实际办理依据与有限消息 | 有权受理/变更/履责和可送达的内容；与个人认识/感情、当下动作run、物理保管/数量分别交接，不代替个体自主或现场工位预约 |

建筑和植物共同改变空间，环境与生命双向作用，行动与认识从首次可作用时参与。建设依赖与出口只看[主计划](../../plans/foundation-priorities.md)，具体计算/数据/并行合同只看[计算接入](../execution-batches.md)。

跨生活、工作与战斗的[单位决策与持续任务](../../../design/systems/unit_decision_framework.md)是认识与自主选择领域已实现的P5协调能力；它通过共同意图连接原行动宿主，不新增一个统管所有领域事实的决策领域。

同一逻辑域内部也可有不同状态owner。身体当前资源、持续身体条件与能力掌握不因同列“生命状态与能力成长”就成为一个大记录或共用一套变化公式；学习的实际掌握与本人以为会了分别成立。植物物候继续由自然领域负责，只有真实需要的个体能力才装配共同成长/自主记录。

## 贯穿领域的边界

唯一事实、共同因果、认识与恢复完整性只由[constraints](../constraints.md)及[已确认规则](../../../design/rules/README.md)定义；这里仅解释各域交接，不复制另一组全局要求。批计算/输入段的当前细节分别在对应工程接口页，目标做法属于候选规格。

## 跨域变化应怎样归属

墙门变化：建筑提交真实结构；空间更新局部几何/连接；行动使受影响路线失效并在执行时复核；环境更新对应传播/房间；认识只向实际观察者提供可知结果。动态重规划是行动内部能力，不能独立充当顶层计划。

植物变化：自然生命提交原株/产物；原资源owner处理物资，空间更新占地，环境更新真实来源/受体，行动重评实际目标，认识按观察传播。无能力的对象不产生该域持续工作。

教学与任职：共同参与过程提交实际投入，成长owner采用学习进展，社会owner按具体约定处理职责份额，认识更新当事人实际得到的信息与评价。成立师徒关系不赠送本领，动作完成不自动结清全部义务；任职变更不凭空搬运钥匙、物资或让所有成员即时获知。

跨区和跨线程：按实际读写依赖选择任务/屏障，计算结果由相应owner采用；不能仅因同处一块就认定全部相互独立，也不能把一人跨格变成所有域全量运行。

## 新能力接入需回答

事实归谁、输入适用哪个逻辑时段、什么触发/到期、变化影响哪些消费者、失败/取消有什么后果、资源怎样唯一提交、哪些内容保存/恢复、玩家何时如何知晓，以及实际工作量怎样随规模增长。

这些是设计/评审问题，不要求先建立一组空基类或注册平台。不同能力只有出现真实公共责任才提取机制，不能为样例逐个新增顶层系统。

频率、重要性、计算序列及CPU/GPU选择统一从[计算接入](../execution-batches.md)选用现有接缝；领域文档只补自己的状态与响应语义。
