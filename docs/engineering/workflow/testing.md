# 当前验证方式

验证服务本次行为和真实性能，不按次数评价进展。旧CI、分片聚合和旧全玩法回归已退役，不恢复其门禁。

`python tools/godot.py test`只执行当前内核的短反例：资源守恒/串并行结果、治疗与致死顺序、死亡一次、取消释放预约、门/破墙/导航更新、自主运行不等画面、旧快照不被覆盖、暂停和回执消费。默认15秒进程上限，正常几秒。当前不测试已删除玩法。

新脚本/资源按需import；呈现改动要实际观察，性能改动用同负载release短窗口。`python tools/check_structure.py --audit-code`辅助查当前链接/资源/入口，动态依赖仍需判断。工具进程改动有`python tests/tool_smoke.py`，无需每次运行。

命令只在[usage](../tooling/usage.md)维护。性能结果只在BASELINE登记负载、近似、失败与未测范围；短smoke不证明全部玩法和长期容量。运行期间做独立工作，只剩等待就等待同一进程，不反复查询无变化。
