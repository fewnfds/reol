# 当前验证方式

验证服务本次行为与真实性能，不按次数评价进展。旧CI、分片聚合与全玩法长回归已退役，不恢复门禁。

`python tools/godot.py test`执行`kernel_smoke.gd`及它调用的小型`feature_smoke.gd`、`sight_smoke.gd`。前者用512人/120步核对串并行资源结果，并短验存读/中断、材料施工、多格索引、宿主/来源、环境与身体；后者共用一个6人世界验证墙挡箭/射手死后箭继续、互杀/共用冷却、交易/承诺/修行、地表和静态记忆离场冻结/读档/重返刷新、已探索区隐藏人物，以及旅行时原地事务继续。视野小反例另验动态视距/失明、长半径/边界、多格可见、物理阻挡、失联/隐藏销毁/槽位复用、盲区反击、和平警戒、驻守换目标和不可达追击暂缓/失败位置记忆与重新发现。默认15秒进程上限，正常约7秒；容量另用release窗口，不把smoke扩成负载矩阵。

新脚本/资源按需import；呈现改动实际观察，性能改动用同构建同负载release短窗。`python tools/check_structure.py --audit-code`辅助查当前链接/资源/入口，动态依赖仍需判断。`python tests/tool_smoke.py`只在Python进程/超时工具改动时使用。

命令语法只在[usage](../tooling/usage.md)，结果/局限只在BASELINE。自动交互探针要标明范围，不冒充完整手动游玩；真实窗口不互相重叠争用设备。运行期间做独立工作，只剩等待就等同一进程，不反复查询无变化。
