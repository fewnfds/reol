# 决策适用性索引

此页负责“旧决策现在怎样适用”，不是按时间追加的当前状态日志。完整88条原始ADR与推导原样保存在[决策原文](archive/documentation_consolidation_20261104/docs/DECISIONS.md)；具体算法/边界查对应领域，运行事实查ARCHITECTURE/BASELINE。

最新用户指令优先。版本跟最新稳定、平面优先、无LLM也可玩、机构记录/个人认识分层、真八方向、有限转生等由[GAME-BRIEF](GAME-BRIEF.md)及相关领域维护。Goal和下一任务只由[HANDOFF](HANDOFF.md)维护，原ADR里的“本轮只设计/active/下一包”是历史时态，不产生新授权。

## 权威入口

- 概念与体验：[GAME-BRIEF](GAME-BRIEF.md)、[design索引](../design/README.md)。
- 代码所有者与接口：[ARCHITECTURE](ARCHITECTURE.md)；完成/证据：[FEATURES](FEATURES.md)、[BASELINE](BASELINE.md)。
- 新实施依赖：[ROADMAP](ROADMAP.md)、[world_engine_execution](plans/world_engine_execution.md)。
- 文档维护：[DOCUMENTATION](DOCUMENTATION.md)。新增决策应写独有理由、状态、影响和负责领域，不抄当前进度或重复全部不变量。
