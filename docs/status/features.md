# 当前可玩能力

2026-11-13：UI体验反馈、中文人物事件与冷热耐受已接入，普通试玩已移除隐形压力场源。任意角度连续移动、地块分层、临时像素包、柔和视野和地形小地图保留；正式Main与Windows Demo使用同一后端。正式包与实测只看[BASELINE](baseline.md)，命令只看[usage](../engineering/tooling/usage.md)。以下是当前可体验范围，不等于旧版全部内容逐项迁回。

## 世界、实物与生活

- 512×512连通有限地图，开局50个围合房间；门始终可穿行并保持围合。墙/家具影响导航与感知，人物允许互相穿行，不会为玩家瞬移让位。
- 土/砂/水基底、不可选的装饰草地、可作用植物和人工地板分别存在。自然植物不生在已有房间/地板或错误水土中；玩家后来围起已有植物不会自动清除。低草可直接铺地板，灌木/树/残桩需先清场；蓝图取消保留草，拆地板露土，不移除同格家具/盆栽。当前自然撒布只在开局/地区装配，没有持续野生扩散。
- 默认24人普通开局；千人使用同一身体、库存和行动后端。NPC依据个人观察副本、饥饿、精力选择探索、采集、交付、休息、吃饭、烹饪和已知施工；不会查询远方最新库存再冒充本人认识。
- 单位按任意角度连续路线移动，右击保留格内小数落点；S原地停止，换令从当前位置转向，不回格心。追击、攻移与日常操作位共用导航；身体大小约束过门/绕墙，飞行可越墙，途中建墙使受影响路线失效。P可显示选中可见单位的剩余路线，对象详情显示连续坐标；八向只是显示朝向。仍无群体避让/编队。
- 人物、静态物、植物均有单调身份；静态对象不占移动身体页。分类库存、容器、材料投入、原子取放/交换、丢弃与拆除返还是真实数量。死亡保留携带物，尚无尸体搜刮的正常操作入口。
- 真实材料蓝图、多格家具、箱、床、炉灶、桌椅、门墙与屋顶层；共用接近、预约、耗时、取消、停工续工和失败反馈。下单需本人携足材料并投入蓝图，尚无跨仓自动备料链。箱子可并行取放，独占作业设施持有预约。
- 玩家附近材料堆(178,186)、测试箱(176,186)、床(176,182)、炉灶(174,185)。箱内有粮水，炉灶有饭；烹饪消耗粮水、进食消耗真饭、休息恢复精力。屋顶目前仅可放置层，没有完整遮雨/照度后果。

## 自然、感知与人物能力

- 冷热/五行来源、房间温度、身体接收、独立百分比潮汐；新增历法、季节、昼夜照度和天气，实际影响身体与植物。五行在稳定输入下保持不变；空地没有热历史，人物和房间有温度惯性。
- 普通开局不再装入随机冷热/五行压力源，也没有无实体的地区演示冷热源；地区背景、天气和真实植物排放仍有效。混合压力开局才显式启用随机源。身体先以耐受抵消冷热伤害，耗尽后才扣HP，安全时缓慢恢复；不抵挡战斗伤害。暴露指标、恢复条件与数值只查[运行与精度](../engineering/simulation-pacing.md#冷热暴露与耐受)。
- 六种植物示例：一年生草、多年生草药、古树、荷花、沙生刺和赤焰草。土/砂/水生境、温度/季节/光照/水分、生长成熟、产物、砍伐树桩、再生和枯萎可观察；花盆与植株保有独立身份和宿主关系。养护、采收、砍伐、拔除走共同行动，产物仅提交一次。植物按慢周期打散采样，短暂经过的环境影响可能漏采，精度见[运行与精度](../engineering/simulation-pacing.md)。
- 古树可在条件与机缘下原身份成精并可请教，不靠换成另一种怪物复制身份。赤焰草显式具备热源与火行源；五行属性不自动意味着发热。古树灵气是独立可消耗储量，环境五行不被当作灵气消耗。
- 每个身体有自己的视距，对象详情显示真实格数；生活观察、战斗感知与玩家迷雾共用距离/环境损耗。墙、家具和成熟大树降低范围，损耗预先平滑；屏幕柔边按人物同一显示轨迹的连续位置绘制，不再跨整数格移动圆心。未探索区遮住，已探索但离开视野的地形、地板、建筑、家具和植物显示最后所见的暗色缓存；整树不因冠部跨格被地面迷雾裁掉，重返才刷新。视野外人物、选中圈及飞行物隐藏。读档恢复旧记忆，不偷刷离场真相。NPC只对局部候选查询，不各建全图；逻辑观察/记忆仍有原周期，屏幕连续柔边是有界显示近似，细节只查运行与精度。尚无队伍共享视野、隐身、声音、复杂注意力或完整社会认识。
- A攻击移动、H驻守、追击、近战/弓箭、扫掠投射物、墙体拦截与同一边界互杀；战斗打断作业并释放预约，自主人物结束后可恢复生活。和平自主NPC能发现附近新威胁；看不见目标后追最后所见，到达或超时放弃，不读取隐藏目标的新位置。盲区受击只能沿实际来向搜索；守卫避开射不到的目标，不可达追击记住失败位置，相关条件改变再自动尝试。投射物发射后不依赖射手存活。飞行可越墙，大体型使用净空导航，身体不容纳的原地变形会拒绝；目前仍共用人形显示，不是完整鸟身/器官/立体战斗。
- 旅居修士#2在(177,187)附近，可交谈传播一条有来源和时间的旧线索、真实交换、请教与请求施工协作；承诺之后还需本人实际执行。方法、书籍、修行进度、能力与灵气分开：用药换书→读书或请教→古树旁修行三次→解锁消耗资源的回春。没有完整对话树、组织、市场或NPC长期修仙规划。

## 临时视觉

人物八向动作、死亡倒地、植物阶段、建筑家具/物品、昼夜/接触影和天气已有实际呈现。墙完整覆盖一格并自动连接直线/转角/分叉；家具为轴对齐四向，建造预览中R或旋转按钮选择N/E/S/W，多格占地随朝向旋转。世界精灵统一以占地底部中央接地，完整树冠允许跨格，影子与根部相接；连续移动、拾取与鼠标落点同步转换。雨向下落，寒风白絮向右下飘、热浪上升。F8浏览图鉴；覆盖、许可、坐标对应和局限只看[素材入口](../../assets/README.md)。动物等预备图不等于已有相应玩法，当前使用矩形面板/现有图标的临时UI，保留真实数值。

## 地区与会话接续

- 谷地、寒林和旱砂地位于同一地图，有实际背景温度与生境差异。旅行沿真实路径前进，不传送、不复制随身物；远处人物、施工和植物一直在同一时钟内推进。尚无无限地图、区块装卸或远区LOD。
- F5异步保存、F9读取当前开发格式：保留实际领域状态、物资、路径/过程、蓝图投入/剩余工时、植物/来源/宿主、战斗订单/在飞物、个人线索/承诺/成长、耐受/伤害余数与个人事件、探索/静态记忆、天气与随机状态。冷I/O线程准备并校验独立候选，失败保留活世界，采用成功提升会话epoch；旧档保留，本版需新开局。格式边界只看[存档现状](../engineering/compatibility.md)。
- FPS、实际倍率、运行/暂停状态、玩家本人的HP/行动状态、鼠标坐标、温度、五行与潮汐常驻显示；暂停按钮切为继续图标，死亡另有顶部HP0/骷髅状态，受理用箭头、完成用勾、拒绝用叉短暂显示。对象详情按类型展示HP、需求、库存、视距、植物阶段和生长原值，原始完整行动/统计仍可F12查看。F12调试面板能查看错误/调用栈、模拟线程与指令队列状态并导出诊断，详见[运行与测量](../engineering/tooling/usage.md)。显示与模拟独立，画面不补造未完成的世界时间。

## 操作与建议试玩路线

默认命令作用于金色标记玩家#1，左选NPC是观察。青蓝圈表示当前选中者，选中自己会出现双圈。原NPC红/橙等七色圈是移动场源调试标记，并非敌我或护盾，现默认隐藏，可在DEV切换“场源标记”。

主角命令台贴屏幕底部，左下为当前对象动作，分类抽屉收纳营造、种植、背包、人物、地区和DEV；没有新增备注、副标题或说明段落。默认UI大小是此前的一半，作为新的100%基准；设置输入50%～200%并确认，按新基准缩放，偏好单独保存在本机，不缩放世界相机。未定人物属性用锁定按钮占位，背包只提供现有物资与数量操作，没有装备穿戴系统。

| 操作 | 行为 |
|---|---|
| 左键 | 选择观察；同格人物/家具/地板可重复轮选；不移动主角 |
| 右键 | 空地连续移动；可见敌人追击；家具、植物、中立人物打开对象菜单，菜单内可指定移动 |
| M后左击 / A后左击 / S / H | 显式移动 / 地面攻移或追击人物 / 原地停止 / 驻守；都有主角台按钮 |
| J / E / 剑弓按钮 | 自主工作 / 用药 / 切换近战或弓箭；回春依实际解锁状态启用 |
| 方向键 / 中键拖动 / 滚轮 / F | 平移 / 拖镜头 / 缩放 / 切换跟随玩家 |
| B / 营造图标 / R | 打开营造抽屉 / 进入占地和材料预览 / 旋转四向；旋转也有按钮。左键单次放置并发起施工，右键或Esc取消工具；没有隐含队列 |
| 对象施工、协作、拆除 / Delete | 继续已有蓝图、指定人物协作、接近拆除；Delete进入拆除目标工具。蓝图创建成功但未能开工时仍选中已扣料的蓝图，供续工/拆除 |
| R / Q / D / I | 拿取 / 放入 / 丢下 / 背包物资窗口；可选物品与数量，提供1、半数、全部及输入，上限考虑已知库存/容量 |
| 对象休息、进食、烹饪 | 床休息、容器食物进食、炉灶单次烹饪；原料沿现有规则消耗，不是生产订单 |
| 种植抽屉 / 植株菜单 | 预览生境并逐处播种；按阶段提供照料/采收/续播/砍伐/拔除；花盆复用同一操作 |
| 人物/古树菜单与人物抽屉 | 交谈、示例交换、请教、读书、修行、回春；协作先点蓝图再指定请求对象，未增工作优先级表 |
| 人物抽屉“事件” | 主角或当前可见选中人物的中文记录，按提交顺序向下列出；连续冷热损耗合并时间段。主角保留256条，NPC每人最多64条且共用2048条环，满后淘汰旧记录；随存档回退，不披露隐藏袭击者身份 |
| 地区抽屉 | 前往谷地、寒林、旱地；真实走路而非传送 |
| 小地图 | 熟悉瓦片颜色、建筑/植被剪影与彩色单位点；滚轮或±缩放，跟随图标切换地图中心跟随；左击/拖动镜头，默认右击移动#1。未探索遮住，静物显示记忆，动态单位只显示当前可见 |
| 空格 / 1、2、4、8 / 顶部倍率按钮 / Esc | 暂停 / 对应请求倍率 / 选择1×、2×、4×、8×、16× / 逐层退出窗口、工具、抽屉和选择，最后打开暂停菜单；菜单关闭恢复进入前状态。请求倍率不保证实速，超过容量时HUD仍显示实际倍率 |
| F5 / F9 / 菜单 | 异步保存、读取；切换会话关闭旧工具和窗口，失败保留原会话 |
| F8 / F12 / DEV | 素材图鉴 / 日志诊断 / 天气、身体、场源等开发演示；开发开关不再混入普通对象命令 |

地块探针固定在右上角，以20Hz采样当前可见鼠标格，显示坐标、温度、背景/热/冷分量、基底/覆盖/地板/房间与五行；查询在途时保留上一份完整信息，收到结果后按采样格一起更新坐标/数值，不先清空；鼠标移到UI时保留最后有效值，不拦点击。HUD保留FPS、请求/实速、耐受与潮汐百分比，其他HUD/小地图仍按10Hz更新，探针刷新不增加世界结算频率。普通详情在离场时降级为静物记忆，不显示隐藏库存或人物。数量窗口及模态界面阻止世界热键与持续相机轮询；快捷键和按钮共用命令入口。

可先取放材料与施工，再观察盆栽和赤焰草；找修士交换/学习后到(175,180)古树修行，最后去寒林、保存、关闭重开再读取。近战按钮要求目标在接触范围，追击/攻击移动会自己接近；金色之外人物也会按实际规则反击。人物控制权、多选/编队/Shift队列仍未实现。

更完整家具配方、自动建材物流、器官伤势、群体避让、复杂技能、组织关系、独特器物、出生招募与开放世界分块尚未恢复。当前功能是六段代表性闭环，不是完整成品；目标低配整机和长局尚未验证。
