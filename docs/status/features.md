# 当前可玩能力

2026-11-12基础运行框架重建后，正式Main和Windows Demo使用同一个新内核。这里列实际切片，不把Git中的旧实现或保留的JSON当成已迁回能力。运行/导出命令见[usage](../engineering/tooling/usage.md)，性能证据见[BASELINE](baseline.md)。

## 目前能体验

- 512×512有限平面地图；50个5×5围合房间，800墙/门格和450地板格，共1250结构格。门始终可穿行并保持围合。
- 默认1000个有原状态的单位。999名NPC持续执行原生网格寻路→预约资源点→500ms采集→真实携带→仓库入库→休息的容量切片；资源有限，不凭空补充，枯竭后不再空跑。该程序是基准工作循环，尚不是恢复后的认识/需求驱动AI。
- 墙实际挡路；玩家可建墙/门、拆除；受影响在途路线重算。原地可互相穿行，NPC不会为玩家瞬移让位。
- 96静态+32携带的冷热/五行源、房间温度和人物体温/需求，秒级采样；五种分钟级独立百分比潮汐。极端温度会扣血，死亡保留携带材料。当前没有空地残余热历史。
- 暂停与真实1×/2×/4×，显示与模拟分别运行；界面显示FPS、实际流速、坐标、温度、五行、HP、需求、携带数量及命令结果。
- 同一命令入口处理移动、停止、恢复工作、近身攻击和喝药；死亡与资源后果由模拟端结算。已有八方向人形图集、GPU显示插值和相机跟随。

## 当前操作

默认发令对象是金色标记的玩家#1。左键观察NPC不会接管它。

| 操作 | 行为 |
|---|---|
| 左键单位/地块 | 选择观察，地块数值跟随鼠标刷新；可检查墙/门/资源格 |
| 右键空地 | 玩家寻路前往，回执和到达/不可达结果可见 |
| 方向键 / 滚轮 | 平移镜头 / 缩放；F切换跟随玩家 |
| 空格 / 1、2、4 | 暂停 / 对应倍率；也可用HUD按钮 |
| S / J | 玩家停止 / 恢复采集搬运工作，优先处理已有货物 |
| A / E | 攻击选中且在2格内的单位 / 喝一份药恢复HP；有冷却/数量和存活校验 |
| B / G / Delete | 在选中格即刻建墙 / 建可穿行门 / 拆除。当前是开发施工工具，不扣材料或模拟建造工期 |
| T | 切换选中格的静态环境源；来源以彩色点表示 |
