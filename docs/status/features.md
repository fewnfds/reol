# 游戏功能与操作入口

核对：2026-11-10。当前是可操作的有限世界原型。main已整合通用SL、事件/植物、环境组合、完整行动及试玩/缓行/连续呈现和压力Demo；当前主线SHA839ff88完整CI通过，准确状态见[基线](baseline.md)与[接续](handoff.md)。根56/区域47，只接受当前格式。满密度动态规模、16GB整机及独立发布尚未验收。

技术是否进入Git main、开发分支与隔离服务的区别统一查[技术落地总表](technical-status.md)。本页只维护操作与玩法范围，不另存一套技术施工清单。

当前普通世界提供过载缓行：共同时间限制新请求、按计算成本调整流速，普通HUD显示缓行并保留所选倍率，F3提供欠算和成本。未结清时画面保持最近完整时刻，停止等命令即时显示是否受理；结算失败会暂停并显示原因，已有合法存档可重新加载。完整时刻同步捕获画面，渲染只回放已提交投影。主线缓行修复合并重复捕获、分段续算环境到期响应，并修正短片段误降速；准确验证状态见[BASELINE](baseline.md)。以上是共同运行合同，不新增玩法；性能边界按具体负载声明。

主线提供人物和镜头的显示过渡：完整发布的坐标在渲染帧间连续显示，原身体仍按共同时间结算。独立人口压力Demo沿真实规则持续巡行；入口和限制见[工具说明](../engineering/tooling/usage.md)。人物按自身到期/读取积分，库存观察按实际变化更新；独立入口仍用原规则。性能缺口以持续移动样本为准；准确性能与验证见[压力QA](../qa/20261110_presentation_crowd.md)。

状态用语：**已接入/有限样本**指实际入口和特定路径已有证据，不代表通用完整功能；**专用工具**需显式启动且不等于玩家能力；**隔离原型**未接普通游戏；**待验**缺对应范围或最终 SHA 的验收。每个领域页面保留原始范围与对应 QA，版本证据以基线为准。45–60 分钟完整切片、正式美术和独立发布均未验收。

“生活与办事”的“搬运”页可选本人行囊、已知聚落容器及眼前获准储藏箱；人物实际到场取货、携带、交付。公物中断后可续送或交回，不能消费；普通移动与工作受阻会尝试绕路，不可达则中断。工作与交锋共用原身体/共同时间，战斗仍为有限木剑、气弹、护障及闪身，没有致死/掉落/群战。原物及行动接口见[合同](../engineering/object-lifecycle-contract.md)，不提供任意NPC指挥、普遍负重或嵌套容器。

普通世界的[环境合同](../engineering/world-environment-contract.md)已扩展为材质传播、房间混合温度及可定位库存/携物/容器来源，沿共同时间保留残留。相同材料同堆数量不放大源强；人物体质整体源、任意嵌套和完整五行修行尚未接入，当前主线整合CI通过。历史[来源QA](../qa/20261105_environment_source_bindings.md)、[缓存QA](../qa/20261105_environment_ground_cache.md)和[响应QA](../qa/20261105_environment_response.md)是各自版本的局部证据，不能代替当前整包验收。

普通来源变更与目标刷新目前同步运行于CPU。独立的CPU/GPU/auto计算服务和旧版本性能数据见[计算QA](../qa/20261105_environment_ground_compute.md)与[优化QA](../qa/20261106_environment_optimization.md)；普通游戏尚无GPU开关，也未完成端到端大规模性能验收。
