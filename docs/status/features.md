# 当前可玩能力

当前源码为P5共同单位决策与近远组合试玩版，统一双击根目录[启动.cmd](../../启动.cmd)：选1进入源码战斗练习，选2进入源码普通世界，选3进入已导出的当前成品。旧A攻击移动、S停止、H警戒、点击追击与剑弓模式开关已移除。导出包是生成时快照；构建与实测查[BASELINE](baseline.md)，运行命令查[usage](../engineering/tooling/usage.md)。

P1直接操控已接入：Esc→设置→键位设置可改键鼠，按上下文提示冲突并确认合法两键交换，独立保存偏好、支持恢复默认；HUD/按钮提示同步。主角脚边浅色尖标表示当前瞄准、橙色短弧表示当前招式锁向、青色短标表示实际后退/侧移方向。ACT测试开局左前方有L墙与单格门，供贴墙、穿门和转向试玩。

P2单剑切片已接入：三连具有分段推步/移动恢复，命中与挥空有不同取消时间，终结须承担收招；轻敌可短打断，重敌起手稳固、收招可被终结/重斩打出失衡。闪步前90ms避可闪近战/普通箭，箭穿过继续飞；重击有短火花/轻震、稳固有金弧与不同接触音。练习场顶部可选“轻敌／重敌／混战·重练”，死亡也能重开；重练会新开整个练习世界，不覆盖存档。Esc→设置可调战斗音量、震动和闪光，正式动画/混音仍待制作。

当前默认血刃＋混战；建议先选轻敌试招，再切混战。顶栏下拉选择配置，切换会新开整个练习世界。技能、交付、效果包、状态、成本、池、反应与实体使用Godot原生Resource；Inspector可校验和跳转引用，具体步骤见[制作合同](../../design/systems/combat_framework/act_and_barrage.md#102-制作者新增技能的实际流程)。

P5已接入共同单位决策：轻敌会闪步接三连，重敌以承诺重击与收招间隔制造攻防窗口，射手会保持距离并在技能冷却时用普攻。居民按自身政策自卫/逃离，结束威胁后按当时需要重选生活；日常事件/到期唤醒，战斗默认50ms判断，运动/命中保持原精度。策略为7套原生Policy，个体参数/任务独立，支持有限多步组合与受信评分脚本。制作/绑定见[单位决策](../../design/systems/unit_decision_framework.md#5-制作与绑定)，普通游戏不展示编程界面。

## 世界、实物与生活

- 512×512连通有限地图，开局50个围合房间；门始终可穿行并保持围合。墙/家具影响导航与感知，人物允许互相穿行，不会为玩家瞬移让位。
- 土/砂/水基底、不可选的装饰草地、可作用植物和人工地板分别存在。自然植物不生在已有房间/地板或错误水土中；玩家后来围起已有植物不会自动清除。低草可直接铺地板，灌木/树/残桩需先清场；蓝图取消保留草，拆地板露土，不移除同格家具/盆栽。当前自然撒布只在开局/地区装配，没有持续野生扩散。
- 默认24人普通开局；千人使用同一身体、库存和行动后端。NPC依据个人观察副本、饥饿、精力选择探索、采集、交付、休息、吃饭、烹饪和已知施工；不会查询远方最新库存再冒充本人认识。
- 玩家WASD直接连续移动，斜向归一化，鼠标瞄准独立于移动；直接扫掠并贴墙滑动。NPC接敌、旅行与生活操作位仍沿任意角度连续路线移动；身体大小约束过门/绕墙，飞行可越墙，途中建墙使受影响路线失效。P可显示选中可见单位的剩余路线，对象详情显示连续坐标；八向只是显示朝向。仍无群体避让/编队。
- 人物、静态物、植物均有单调身份；静态对象不占移动身体页。分类库存、容器、材料投入、原子取放/交换、丢弃与拆除返还是真实数量。死亡保留携带物，尚无尸体搜刮的正常操作入口。
- 人物面板有武器、衣甲、鞋履、饰物及核心战斗/移动数值，另有修行和中文事件页。背包可独立或并排打开，图标格显示件数、Q品质并提供数值比较；装备/卸下、药物/读书、数量丢弃和容器转移使用真实物资。换装改变实际近远程伤害、防御、生命上限或移速，不仅更换文字；完整八方向外观换装、耐久/词缀、自动换装和拼图容量尚未实现。当前样例物品与数值由[items定义](../../data/definitions/items.json)提供，品质只用于这些装备；材料仍按原数量堆。
- 真实材料蓝图、多格家具、箱、床、炉灶、桌椅、门墙与屋顶层；共用接近、预约、耗时、取消、停工续工和失败反馈。下单需本人携足材料并投入蓝图，尚无跨仓自动备料链。箱子可并行取放，独占作业设施持有预约。
- 地面作业位置已统一：不阻挡的植物在本格操作，实体建筑/家具在完整占地外围正交相邻格操作，盆栽继承花盆的空间要求；灶台烹饪只有一个指定工位，随占地四向旋转。预览和交互选中时用金色格框标出指定工位，工位堵塞时不会从其他侧面隔空操作。位置配置与扩展见[空间与施工](../../design/systems/construction_and_space/places.md#定义与扩展)，没有新增锻造玩法。
- 蓝图待开工时为半透明轮廓；实际开工后用按完整占地拼接的实体半成品表示。成品有碰撞的工地在完整占地内仍有存活地面身体时等待腾空，不消耗施工工时；开工后阻挡通行，中断保留半成品和剩余劳动，完工再启用成品用途及围合。单格和旋转后的多格施工共用同一过程，没有逐百分比施工动画。
- 玩家附近材料堆(178,186)、测试箱(176,186)、床(176,182)、炉灶(174,185)。箱内有粮水，炉灶有饭；烹饪消耗粮水、进食消耗真饭、休息恢复精力。屋顶目前仅可放置层，没有完整遮雨/照度后果。

## 自然、感知与人物能力

- 冷热/五行来源、房间温度、身体接收、独立百分比潮汐；新增历法、季节、昼夜照度和天气，实际影响身体与植物。五行在稳定输入下保持不变；空地没有热历史，人物和房间有温度惯性；[沿途环境响应的目标](../../design/rules/environment.md)尚未完整实现，不能当作旧规则已被自动取消。
- 普通开局不再装入随机冷热/五行压力源，也没有无实体的地区演示冷热源；地区背景、天气和真实植物排放仍有效。混合压力开局才显式启用随机源。身体先以耐受抵消冷热伤害，耗尽后才扣HP，安全时缓慢恢复；不抵挡战斗伤害。暴露指标、恢复条件与数值只查[运行与精度](../engineering/simulation-pacing.md#冷热暴露与耐受)。
- 六种植物示例：一年生草、多年生草药、古树、荷花、沙生刺和赤焰草。土/砂/水生境、温度/季节/光照/水分、生长成熟、产物、砍伐树桩、再生和枯萎可观察；花盆与植株保有独立身份和宿主关系。养护、采收、砍伐、拔除走共同行动，产物仅提交一次。植物按慢周期打散采样，短暂经过的环境影响可能漏采，精度见[运行与精度](../engineering/simulation-pacing.md)。
- 古树可在条件与机缘下原身份成精并可请教，不靠换成另一种怪物复制身份。赤焰草显式具备热源与火行源；五行属性不自动意味着发热。古树灵气是独立可消耗储量，环境五行不被当作灵气消耗。
- 每个身体有自己的视距，对象详情显示真实格数；生活观察、战斗感知与玩家迷雾共用距离/环境损耗。墙、家具和成熟大树降低范围，损耗预先平滑；屏幕柔边按人物同一显示轨迹的连续位置绘制，不再跨整数格移动圆心。未探索区遮住，已探索但离开视野的地形、地板、建筑、家具和植物显示最后所见的暗色缓存；整树不因冠部跨格被地面迷雾裁掉，重返才刷新。视野外人物、选中圈及飞行物隐藏。读档恢复旧记忆，不偷刷离场真相。NPC只对局部候选查询，不各建全图；逻辑观察/记忆仍有原周期，屏幕连续柔边是有界显示近似，细节只查运行与精度。尚无队伍共享视野、隐身、声音、复杂注意力或完整社会认识。
- 剑的点按三连、120ms短缓冲与下一段重新锁向；弓按住左键连射。右键按真实武器执行重斩/五箭扇射，均有世界时间CD；空格有方向输入时沿移动方向闪步，无输入时向瞄准反方向后撤，共CD700ms、前90ms避伤；不可免疫环境/持续伤害。出招有前摇/有效/收招，按招式分别规定续刀/技能/闪步窗口，轻斩实际命中后可提前闪步，第三刀不能普攻跳收招。近战扇区、同次攻击去重、移动折线扫掠、弹体体积擦墙和同毫秒互杀已接入；同一发射组对同一身体有短保护，硬直有累计上限。战斗打断作业并释放预约，自主人物结束后可恢复生活。和平自主NPC能发现附近新威胁；看不见目标后追最后所见，到达或超时放弃，不读取隐藏目标的新位置。盲区受击只能沿实际来向搜索；NPC不可达接敌记住失败位置，相关条件改变再自动尝试。投射物发射后不依赖射手存活。飞行可越墙，大体型使用净空导航，身体不容纳的原地变形会拒绝；目前仍共用人形显示，不是完整鸟身/器官/立体战斗。
- 旅居修士#2在(177,187)附近，可交谈传播一条有来源和时间的旧线索、真实交换、请教与请求施工协作；承诺之后还需本人实际执行。方法、书籍、修行进度、能力与灵气分开：用药换书→读书或请教→古树旁修行三次→解锁消耗资源的回春。没有完整对话树、组织、市场或NPC长期修仙规划。

## 临时视觉

人物八向动作、死亡倒地、植物阶段、建筑家具/物品、昼夜/接触影和天气已有实际呈现。固定斜俯视的纯二维测试素材用顶面与前立面表现高度，墙仍占完整一格并自动连接；门和长家具可分部排序，主角被前景遮住的局部淡化以便辨认。家具建造预览中R或旋转按钮选择N/E/S/W，占地同步旋转。采用固定斜俯视，世界与界面由Godot原生二维绘制，不做整屏透视形变。连续移动、技能落点、拾取与迷雾使用同一坐标换算。F8浏览图鉴；素材来源、制作与局限归[素材入口](../../assets/README.md)，显示实现归[架构](../engineering/architecture.md#纯二维显示)。动物等预备图不等于已有相应玩法，当前仍是测试美术与临时UI。

## 地区与会话接续

- 谷地、寒林和旱砂地位于同一地图，有实际背景温度与生境差异。旅行沿真实路径前进，不传送、不复制随身物；远处人物、施工和植物一直在同一时钟内推进。尚无无限地图、区块装卸或远区LOD。
- F5异步保存、F9读取当前开发格式：保留实际领域状态、物资、路径/过程、蓝图投入/剩余工时、植物/来源/宿主、AI接触、动作相位/连段/冷却/短意图/命中去重/受击状态/在飞物及掠过身份、个人线索/承诺/成长、耐受/伤害余数与个人事件、探索/静态记忆、天气与随机状态。冷I/O线程准备并校验独立候选，失败保留活世界，采用成功提升会话epoch；旧档保留，本版需新开局。格式边界只看[存档现状](../engineering/compatibility.md)。
- FPS、实际倍率、运行/暂停状态、玩家本人的HP/行动状态、鼠标坐标、温度、五行与潮汐常驻显示；暂停按钮切为继续图标，死亡另有顶部HP0/骷髅状态，受理用箭头、完成用勾、拒绝用叉短暂显示。对象详情按类型展示HP、需求、库存、视距、植物阶段和生长原值，原始完整行动/统计仍可F12查看。F12调试面板能查看错误/调用栈、模拟线程与指令队列状态并导出诊断，详见[运行与测量](../engineering/tooling/usage.md)。显示与模拟独立，画面不补造未完成的世界时间。

## 操作与建议试玩路线

默认命令作用于金色标记玩家#1，左选NPC是观察。青蓝圈表示当前选中者，选中自己会出现双圈。原NPC红/橙等七色圈是移动场源调试标记，并非敌我或护盾，现默认隐藏，可在DEV切换“场源标记”。

主角命令台贴屏幕底部，左下为当前对象动作，分类入口收纳营造、种植、背包、人物、地区和DEV；没有新增备注、副标题或说明段落。默认UI大小是此前的一半，作为新的100%基准；设置输入50%～200%并确认，按新基准缩放，偏好单独保存在本机，不缩放世界相机。人物与背包各自开关；箱子使用人物/容器同网格，宽屏双栏、窄屏分页。查看可见NPC复用人物/背包组件，标明#id且禁止操作；离场后不继续展示其隐藏库存。

| 操作 | 行为 |
|---|---|
| WASD / 鼠标 | 连续移动 / 独立瞄准；静止转身、朝前瞄准并后退或侧移 |
| 左键 / 右键 / 空格 | 当前范例主攻击（剑点按；弓/火/冰/毒可按住） / 当前武器技 / 方向闪步或中立后撤 |
| E / C | 配置声明的主动槽二／三；未配置时不出招，冷却/资源不足给出拒绝反馈 |
| Tab | 切换ACT与交互／营造；切换清除持续输入。交互中左键选择、右键对象菜单或取消工具，空地不移动 |
| F / R / Q | 附近可见对象交互 / 用药 / 已学回春；交互和背包仍使用真实物品与实际接近 |
| 1 / 2 / 武器按钮 | 装备背包中的真剑／真弓；动作承诺中或最近受伤时拒绝换装，不是无成本切射击模式 |

地块探针固定在右上角，以20Hz采样当前可见鼠标格，显示坐标、温度、背景/热/冷分量、基底/覆盖/地板/房间与五行；查询在途时保留上一份完整信息，收到结果后按采样格一起更新坐标/数值，不先清空；鼠标移到UI时保留最后有效值，不拦点击。HUD保留FPS、请求/实速、耐受与潮汐百分比，其他HUD/小地图仍按10Hz更新，探针刷新不增加世界结算频率。普通详情在离场时降级为静物记忆，不显示隐藏库存或人物。背包、模态界面、暂停、失焦和读档清除持续输入及玩家尚未开始的下一招缓冲；关闭后需要新的按下，已开始动作/CD/在飞物保留。数量输入不触发世界热键，快捷键和按钮共用命令入口。

可先取放材料与施工，再观察盆栽和赤焰草；找修士交换/学习后到(175,180)古树修行，最后去寒林、保存、关闭重开再读取。战斗不自动追人，必须自行移动和瞄准；金色之外人物也使用同一动作规则反击。ACT练习默认血刃＋混战，可用顶栏切范例及单轻敌/单重敌；L墙和单格门保留，其他人物继续生活。普通世界的剑弓仍由实际装备赋予；练习范例的技能由下拉框绑定，1/2仅更换真装备。普通玩法的NPC控制权切换、多选/编队/Shift队列仍未实现；底层已支持手动悬挂与显式恢复自主策略。

更完整家具配方、自动建材物流、器官伤势、群体避让、组织关系、出生招募与开放世界分块尚未恢复。战斗已有有界分裂/传播/结果反应、多种状态、蓝/怒/盾/格挡/吸血、瞬移、临时身体/图腾光环和多件自主器物。复杂伤害类别/抗性/暴击词缀、完整器物经济与成熟成长构筑仍待后续；没有任意用户触发脚本或流程图解释器。现有人形整身WALK、合成音与程序几何特效仍占位；正式动作、主观听感／手感平衡、敌人成套花型尚未收敛。本包无攻击者权威停顿，不追加100／500弹性能验收。键鼠改键不含组合键、双槽绑定或手柄；目标低配整机和长局尚未验证。
