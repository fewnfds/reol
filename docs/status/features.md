# 当前可玩能力

2026-11-12基础运行框架重建后，正式Main和Windows Demo使用同一个新内核。功能恢复第1、2段已完成集成；当前源码能力如下，正式包版本与测量只看BASELINE。运行/导出命令见[usage](../engineering/tooling/usage.md)。

## 目前能体验

- 512×512有限平面地图；50个5×5围合房间，800墙/门格和450地板格，共1250结构格。门始终可穿行并保持围合。
- 默认24人普通开局，千人及以上通过参数配置，使用同一库存/行动后端。NPC依据局部观察的个人库存线索、饥饿和精力选择采集、交付、休息、吃饭、烹饪或已知蓝图；观察5秒级，到达/动作结果就地刷新。没有线索时探索，不读取远方即时库存；当前半径观察尚无墙体感知衰减。
- 真实材料蓝图、多格床/家具、箱/工作台、屋顶层与地面层，工期、中断保留剩余工作、续工、拆除返还均共用接近/预约/计时合同。下单需本人携足材料并投入蓝图，尚无跨仓自动备料链；屋顶目前是可放置层，不承诺完整遮雨/照度模型。
- 开局床位(176,182)、炉灶(174,185)，炉灶有30份饭，箱内有粮水。取粮水后能烹饪成饭，再吃掉真饭恢复饥饿；床恢复真实精力。设施独占操作预约，箱子取放允许多人同时耗时，完成时原子转移。
- 人物、材料堆、箱子、墙门和家具有稳定身份；人物身份与可复用身体行分开，支持运行时生成/移除的内核接口。箱子和背包保有实际分类数量，材料转移、中断、死亡和身体回收不复制或蒸发实物。静态对象不进入50ms身体移动批。
- 玩家能接近材料/箱子、耗时取放或丢下；选中对象查看真实库存。普通开局材料堆在(178,186)、测试箱在(176,186)，玩家在附近。
- F5异步保存、F9异步读取当前格式；保留世界时间、在途路径/取放/施工和设施过程、蓝图投入/剩余工时、多格索引、个人线索、实际库存、环境状态和随机状态。候选读取失败不替换活世界，成功后重置显示历史并拒绝旧会话命令。磁盘I/O和候选重建不运行于显示线程。
- 墙实际挡路；玩家可建墙/门、拆除；受影响在途路线重算。原地可互相穿行，NPC不会为玩家瞬移让位。
- 96静态+32携带的冷热/五行源、房间温度和人物体温/需求，秒级采样；五种分钟级独立百分比潮汐。极端温度会扣血，死亡保留携带材料。当前没有空地残余热历史。
- 暂停与真实1×/2×/4×，显示与模拟分别运行；界面显示FPS、实际流速、坐标、温度、五行、HP、需求、携带数量及命令结果。
- 同一命令入口处理移动、停止、恢复工作、近身攻击和喝药；死亡与资源后果由模拟端结算。已有八方向人形图集、GPU显示插值和相机跟随。

## 当前操作

默认发令对象是金色标记的玩家#1。左键观察NPC不会接管它。

| 操作 | 行为 |
|---|---|
| 左键单位/地块 | 选择观察，地块数值跟随鼠标刷新；可检查墙/门/资源格 |
| 右键空地 | 玩家寻路前往，回执和到达/不可达结果可见 |
| 方向键 / 滚轮 | 平移镜头 / 缩放；F切换跟随玩家 |
| 空格 / 1、2、4 | 暂停 / 对应倍率；也可用HUD按钮 |
| S / J | 玩家停止 / 恢复采集搬运工作，优先处理已有货物 |
| A / E | 攻击选中且在2格内的单位 / 喝一份药恢复HP；有冷却/数量和存活校验 |
| R / Q / D | 接近选中物体拿取 / 放入选中物体 / 在脚下丢下；每次最多10份，物品类别由HUD下拉框选择 |
| F5 / F9 | 保存 / 读取当前开发格式，结果由可靠回执显示；正常操作也有对应按钮 |
| N / B / G / Delete | 按下拉定义施工 / 施工墙 / 施工可穿行门 / 接近并拆除选中物；真实材料和工期 |
| HUD续工、休息、进食、烹饪 | 对选中设施发令；物品下拉含grain/water/meal等类别 |
| T | 切换选中格的静态环境源；来源以彩色点表示 |

## 已退役、未迁回

以下目前不可玩：开放世界分块接续/世界生成、战争迷雾/墙体感知衰减、更完整家具/配方、植物生命周期、社会组织/对话/服务、修行/独特器物体系、鸟身飞行/大体型、复杂AI、自动索敌/攻击移动/驻守、飞行物/复杂碰撞与战斗技能。身体增删已有内核接口，尚无正常游戏中的出生/招募入口。

保留产品规则和原始素材/定义供之后选择迁移；不自动恢复上述列表，也不将旧类作为新架构前置。开发机短窗容量不代表这些玩法全部接回后仍保持相同性能，目标低配整机与长局仍未验证。
