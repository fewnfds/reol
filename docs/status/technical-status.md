# 重构起点：现有Demo与目标缺口

核对：2026-11-10。此页描述现存代码能力，不冻结原class/存储/同步方式。目标架构与问题登记在[唯一主计划](../plans/foundation-priorities.md)，采用版本和准确证据见[BASELINE](baseline.md)。

## 七个领域的现有素材

| 领域 | 现有Demo可复用能力 | 本次重构关注 |
|---|---|---|
| 世界地块与空间 | 平面地图、区块呈现、地形覆写、原身体/物品/结构占地及净空查询 | 分块/分层数据、局部拓扑和批查询，降低重复几何与全局失效 |
| 实体、物品与容器 | 身体/独特物/数量库存、身份与控制、容器、预约/搬运及有限跨账本事务 | 按能力组织热数据，完整生命周期；统一引用不要求统一重量 |
| 建筑与组合空间 | 多格/朝向、材料/工地、家具操作位、储藏/有限生产、围合与损毁 | 静态/动态空间、局部依赖和设施争用，保持真实物资与过程 |
| 植被与自然生命 | 原株/产物/物候、花盆、残株、最小灵智及少量鸟兽样本 | 自然过程批算、受体/来源输入段和能力参与，完整生态未实现 |
| 环境 | 共享背景、材质传播、房间混合、携物/容器来源与植物照明 | 重选计算粒度，CPU/GPU同规则批接口；当前普通场仍CPU同步 |
| 单位行动与交互 | 玩家/NPC原身体、寻路/绕行、行动投影/停止、原库存搬运和有限交锋 | 批导航、局部避让、活动执行和因果提交；完整战斗未实现 |
| 认识与自主选择 | 有限观察、私人认识、社会记录、职责/需求与少量自主目的 | 局部候选、信息/阈值唤醒、执行与决定分离；通用策略未实现 |

## 横向能力与明确缺口

现有共同时间、事件、存读、参与索引及过载流速提供可参考的因果接缝。原实现的存在不要求保留相同调度器、索引或数据格式；类名定位见[工程索引](../engineering/README.md)。

普通模拟仍主要同步执行在一个线程。已有GPU基础目标服务未装配当前普通Main；Godot自身渲染/资源线程不算游戏规则已多核。300人1×/60FPS、目标PC、长局增长及独立导出尚未验收。

现有未提交导航/地形缓存和局部视图补丁不构成当前实施队列，按新结构取舍。所有已接/有限样本/隔离后端都必须在普通世界的完整链路、规模与停开证据下重新确认。
