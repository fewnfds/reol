# 当前状态

这里只放会随开发变化的信息，不定义世界法则。

- [handoff](handoff.md)：当前任务、停止点、未提交工作及恢复条件。
- [features](features.md)：实际操作入口与范围；区分专用样本、隔离候选和未完成系统。
- [technical-status](technical-status.md)：按七个顶层框架登记实际接入、缺口与公共合同，并区分Git main/开发分支/普通Main。
- [baseline](baseline.md)：采用版本、提交与证据索引；不是历史流水账。
- [branches](branches.md)：分支审计快照及用途，不替代实时 Git。

领域职责在[顶层框架](../engineering/architecture/05-framework-domains.md)，建设依赖与出口在[基础建设计划](../plans/foundation-priorities.md)，稳定约束在[工程](../engineering/README.md)，具体结果在[QA](../qa/README.md)。
