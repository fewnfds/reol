# 施工、居住与存读

## 11. 建筑与组合空间

按N打开营造面板，走近柴粮库后划定工地；可登记多处不重叠工地并切换查看，选择用途区域和建筑/家具定义、朝向，在空地落蓝图。当前普通开局默认工地7×5、原home公料及获准施工者；底层支持有界不同尺寸工地，同能力的新定义复用原机制。

可建木墙、石墙、门、窗、屋面、屏风、不同尺寸床、桌椅、储藏箱和灶台。多格物件各格指向同一实体；朝向影响真实占地和操作位置。蓝图不挡路，材料从原库预约，由身体实际取料、搬运和动工后才完工。中断保留已取材料、实际落点与工时；撤蓝图不传回仓库。拆除留下有限余料，实际搬回后才归库。

墙门窗参与围合，门开合影响实际通行和视线，窗可挡路而透光，屏风不自动形成房间。屋面在上层独立施工，不占下方床/家具的位置；附近原支撑按有限跨度承托，拆掉最后支撑会使有关屋面塌回有限余料。围合、屋面、用途分别成立，区域名字不产生资源。

选中座椅后使用实际座位；书案座椅须面向真实桌面。人物先预约位置、走到场，再坐下，时间到或主动停手释放。选储藏箱和物品/数量可放入、取出，使用原随身库存，到场耗时后才转移；当前容量按数量合计，默认24份，取消和不足不复制/吞掉物品。非空或忙碌设施不能直接拆除。

选灶台可用原私料生产规则加工一批，材料、燃料、工时、成品与收取仍由原生产系统处理；原固定厨房等入口继续可用。通用工位条件已经接通，不表示炼丹、炼器、锻造等具体工艺全部实现。

床铺按rest能力接原床位安排和持续恢复；路上预约，到床后才恢复原身体精力，精神充足、肚饿或主动中断会结束。当前低矮床可跨越，多格床只有一个床位。晴雨、露天床受潮、有顶遮雨及晾干继续沿共同时间运行，离场/快进不另用一套生活时钟。

建筑拥有独立耐久和防护，权威伤害入口可结算损毁；残骸停止原功能，保留身份和原内容物，取空后才能清理，余料只发行一次。依赖它的座位或生产会中断。玩家/NPC通用攻击建筑、修理、武器塔和完整战斗尚未接入；接口不冒充可操作战斗玩法。

当前室外场仍不按墙门顶隔热或形成房温；灯火、燃料、完整室内空气、植物/盆栽、井水和墓葬等专属过程按所属领域后续实现。原home之外的施工政策、跨账本容纳、独特器物/嵌套储藏、锁与私人地产、施工工资和在制批次换台尚未覆盖。实际代码合同见[建筑合同](../../engineering/construction-contract.md)，验收范围见[BASELINE](../baseline.md)。

## 12. 保存、恢复与呈现

**已实现基础。** 联合快照包括当前身份、共同时间、探索、原身体/库存/机构记录、在途货物与各已接领域。先构造独立候选并完整检查，再替换活世界；文件写入有备份/原子替换。当前普通根格式为53；根52使用旧建筑模型，根1–51缺少新场所需的历史，当前入口明确拒绝，不自动迁入，也不改原档或活会话。环境与原物的联合候选通过校验后才替换活世界；main与稀疏分支各自已有对应存读回归，具体范围见[BASELINE](../baseline.md)。

已统一部分UI、人物/设施/地形风格和拥挤点击布局，魂体使用独立感知视图；人物当前采用代码生成像素占位。历史fixtures和进行中源档保留为只读证据，不表示当前入口能迁入旧根格式；兼容边界见[兼容政策](../../engineering/compatibility.md)，最新回归结果见BASELINE。当前小世界有1280×720运行截图与同机呈现对照；不等于正式美术、全部比例布局、目标人口性能或独立发布包通过。
