# 现有Demo：建筑与存读

普通Main提供定义/实例/能力组合的多格建筑及家具、朝向/材料、多个工地、操作位、储藏/有限生产、休息及耐久损毁。墙门、屋面、围合和用途分别表达，真实结构变化影响通行、视线和环境；门可自由穿行，经过时不改变房间状态，锁门暂不实现。材料、原物、库存与过程各有唯一状态。

N营造入口组织蓝图和施工/拆改；设施使用需要原身体可达、资格/资源和实际工时。箱体按容量/过滤/操作位接受已支持数量搬运，公物保管责任不因中断消失。完整工艺、任意嵌套、普遍负重、私人地产/锁和维修经营尚未实现。边界见[建筑合同](../../engineering/construction-contract.md)。

F5/保存按钮请求安全保存：按预算结清已受理区间，在完整提交点捕获过程，不必等整段旅行结束；成功/失败有回执。F9/读取按钮构造并校验独立候选，成功才替换活会话。坏候选不部分改身体、钱货、时间或环境。

原身份、共同时间、探索、原身体/库存/记录、在途货物及已接领域一同保存。完全停开接续和支持格式的准确证据见[BASELINE](../baseline.md)与[兼容政策](../../engineering/compatibility.md)。开发期只支持当前格式。

当前仍是占位视听与有限世界；新架构可替换存储/装配实现，继续保护过程、唯一事实及失败原子性，不要求永久保留旧schema或中央恢复链。
