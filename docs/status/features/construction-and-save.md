# 施工、居住与存读

> 状态依据 2026-11-05 的既有代码与有限验证；原文中的“已验收”仅指具体样本。最新完整回归和未提交工作见[基线](../baseline.md)。

## 11. 工地、门墙与场景改变

**有限样本。** 人身N打开施工簿，先到柴粮库附近划定一处获准的宗门工地，选格画蓝图。工人需实际预约库木、走去取出、搬到工地旁、完成劳动；蓝图不挡路，建成木墙和关闭木门才阻挡地面通行，门打开可走。飞鸟可从上方飞过，不能落入实体占地。

本人可亲自施工；石头有明确日常施工职责，看见附近工单、身体空闲且不急于吃睡时，会根据自己的库存认识接手。玩家离开后过程继续，实机验证过玩家在河湾、石头在山门建成木门。不是所有NPC都会无偿听命。

WASD或停手会中断，材料落在真实位置、已做工时保留；续工先取回那批料。撤蓝图不把料传回仓库。拆除耗时，只留下部分余料，另行实际搬回才归库；完工/关门时有人或余料占地会等待清场。进行中与完成结构一同保存，旧世界不补造工地。

同一施工簿还能造木床。墙/门围合后，选内部格显示面积、平整程度和敞开门口；蓝图和家具不当墙，拆侧墙会变开放。围合与覆盖分开，没有实际屋面的格明确显示**未覆顶**，围合不自动防雨或保温。

选择木屋面可在床上方独立画上层蓝图。原材料/搬运/劳动完成，附近同高度实际墙/门提供有限跨度支撑后才遮雨；屋面不挡地面，蓝图不算覆盖，不能靠屋面无限接力支撑。拆屋面保留下方床；拆最后支撑会塌回有限余料，仍需搬回仓库。

当前两聚落有共同时间驱动、各自偏移的有限晴雨循环。可见露天床会受潮、休息恢复变慢，盖顶后仍须逐渐晾干；同雨下有顶床不继续淋湿。泉源有限收雨，实际汲取/搬运才进入水缸和灶房。界面显示所在地晴雨和有上限的雨线，残识不免费获得人类天气视图；离场后同一规则继续。

选中建好的床，在下方安排本院共用或具名同门使用，再“到床上休息”。路上已预约，真正到床后原身体精力持续恢复；精神充足、肚饿或主动停下会结束。自然醒来实际走离床格再释放，同床不能两人使用，忙碌床不能拆/改分配。低矮木床可跨越；关门或封路仍可能阻止走到床，需先处理通路。疲劳NPC会考虑附近获准可达的床，没有合适床仍可回原杂役院；实机玩家在河湾时老周独自睡醒并去报工。

E2已让真实门墙/屋面影响有限余热的导通与散失；围合本身不会免费升温，也不自动成为均温房间。源与原料、旧段热流、同刻结构改变有各自来源，完工/拆改不重置既有热量。

范围：一处公有工地、木墙/门/床/屋面及有限围合/床位安排；晴雨仍是循环气候原型。已有历法/温度与有限余热，完整生态/室内空气、门锁、私人地产、租房、施工工资、攻击破坏和完整经营未做。NPC床位注意是近邻与通路判断，非长期房间记忆；现有野药受雨影响，但种植作物及其降雨反馈、雨对鸟类和战斗的后果尚未实现。证据：[施工](../../qa/20261103_construction.md)、[围合/床铺](../../qa/20261103_rooms_and_rest.md)、[屋面/晴雨](../../qa/20261103_roofs_and_weather.md)、[屋舍余热](../../qa/20261103_local_heat.md)，规则：[construction.gd](../../../scripts/sim/construction.gd)、[resting.gd](../../../scripts/sim/resting.gd)、[weather.gd](../../../scripts/sim/weather.gd)、[local_heat.gd](../../../scripts/sim/local_heat.gd)，参数在data/definitions。

## 12. 保存、恢复与呈现

**已实现基础。** 联合快照包括当前身份、共同时间、探索、原身体/库存/机构记录、在途货物与各已接领域。先构造独立候选并完整检查，再替换活世界；文件写入有备份/原子替换。真实历史档保留作迁移与进行中重启回归，旧档没有的事实不补造。

已统一部分UI、人物/设施/地形风格和拥挤点击布局，魂体使用独立感知视图；人物当前采用代码生成像素占位。真实历史fixtures和新增灵源进行中源档保持只读，当前兼容格式与最新回归结果见BASELINE。当前小世界有1280×720运行截图与同机呈现对照；不等于正式美术、全部比例布局、目标人口性能或独立发布包通过。
