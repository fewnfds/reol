# 现有Demo：建议试玩与缺口

当前运行旧Demo而非新架构；启动/键位见[操作](controls.md)，版本及存档支持见[BASELINE](../baseline.md)。

1. 搬运：生活/办事面板选择库房到灶房的柴，观察到场取货、携带和交付；WASD/停止中断后核对随身货物/受托责任。
2. 建造：N登记工地、布置墙门/家具蓝图并实际施工；使用门、床、储藏等，观察真实材料、工时、空间和环境反馈。
3. 植物：右键看见的原株，采产物/伐取/移栽或浇水，中断后核对原株、产物、占地及工时。
4. 有限交锋：先实际取剑、向近处人物学习，再走位、发招、护障、闪身和退让；当前不致死。
5. 连续性：在搬运/施工/行旅中保存，关闭进程后读取，核对原过程、钱货、身份、时间与环境接续。

也有温石试用/损伤/照护、实际学习/记录、信息差、野外寻物、有限非人身体等组合样本。它们不证明完整长流程、正式内容或陌生玩家能自然理解。

明确缺口：完整战斗/经济/组织政治/生态/风水/修行/转生、任意策略/交互、普遍负重与嵌套、多区生成/迁居、正式视听及独立发布。当前性能也未达到300人1×/60FPS。

本次重构的具体问题/情况只在[主计划](../../plans/foundation-priorities.md)，不把上述玩法缺口变成另一份开发队列，也不按旧样本编号逐个补系统。
