## 13. 当前可以连着体验的几条链

### 第一次试玩建议

当前行动分支可从普通Main试玩，未提供独立安装包。运行`python tools/godot.py run`，新局选“山门杂役”，空格继续/暂停，WASD行走。旧根55及更早存档明确拒绝；本轮体验请新开局，旧文件保留。

1. **取货与交付。** 左侧“生活与办事”→“搬运”，起点选山门柴粮库、终点选山门灶房，柴2份；表单内滚动找到提交按钮。观察本人走过去取货、随身受托量增加，再实际送达。WASD或停止按钮可中断；按相同起终点/物品/数量重新提交会续送原批，也可在“差事与凭据”交回。
2. **盖房与家具。** N营造，先走近柴粮库登记工地，再落墙/门/家具蓝图并施工。材料与工时真实支付；自留采集的私人材料可存箱，或在搬运页刷新眼前箱体后选择端点；公物仍只交登记公共地点或随身保管。未完成的框架/工地不是瞬间成屋，门开关影响真实通行。
3. **有限交锋。** 走近并选中石头或陈守拙，U请求示范，双方实际练习一分钟后才学会手段；忙碌、距离和状态不符会拒绝。住处木剑须实际取用。U明确驱离敌意后，WASD走位、Q木剑、E气弹、R护障、Shift闪身、X退让，空格可暂停观察。交锋会消耗原体力/灵气并留下挫伤；当前不致死。
4. **验证持续世界。** 搬运或施工途中F5，退出游戏进程，再运行并读取近况；原动作、货物、成本及环境接续。遇到问题可描述操作顺序、画面反馈和是否读档，便于按原owner复现。

这条路线用于收集实际操作与手感反馈；完整伤亡战斗、自由NPC指挥、质量/体积负重及任意嵌套容器不在当前试玩范围。

### 其他已接体验

温石误用→持续不适→自留采真实鲜药→当面交流发现医者→实际诊断/投入处理→离场生活中逐步恢复，保存/完整重启接续同一身体。

| 体验 | 已接通的过程 | 到哪里为止 |
|---|---|---|
| 劳作谋生 | 采集/搬运/做饭→实际交付→登记贡献→兑换饭→吃饭 | 非完整市场/职业生涯 |
| 出门办事 | 山门↔河湾→运粮/吃住→凭据报工→通行/取药 | 非多区贸易与战争 |
| 野外机缘 | C本人来源问路或实际发现→L原路行旅→先到取同一铜环，或在小满自主取走后见到空台；实际见到持环者可商量固定报价，持环并完成两次研究后可短距引取松置木剑 | 一处遗迹/一位自主寻物者；引物为木剑白名单，私人交割已验收，明确争夺后果未做 |
| 认识与试用 | 自己观察/请人辨识→投入探查→温石做饭/烘药/有限释热→误用损伤 | 非通用工法创造 |
| 有限引息与生活 | 实际到灶旁/学习原手法→以原石引息归身或存石→原温养/做饭/焙药/释热→离场后源继续按有限供给变化 | 一处火属性灵源，两种转化；非完整修行或五行玩法 |
| 人际信息差 | 口头资格→不同采信→临时取药→私人核验→出示新依据 | 非完整骗术/司法 |
| 非人生活 | 雀身觅食歇翅衔药；残识传意协商携戒感知 | 非完整种族流程或出生转生 |
| 动作处境 | 约练→走位/出掌/闪身→疲惫/收手→恢复日常 | 非正式伤亡战斗 |
| 有限交锋 | 实际取剑与当面学习→表明敌意→木剑/气弹/护障与走位→挫伤、退让和休养；NPC按本人目击判断 | 非自动领地守护、致死/战争或完整搜索AI；本轮感知最终验收见BASELINE |
| 施工与居住 | 工地→真实材料/劳动→门墙/床/屋面→雨湿/遮雨/休息→拆改与余料回库；离场继续 | 非完整室内/生态或建筑经营 |
| 应对冷暖 | 实际穿衣或原温石限时释热→原精力承受未来负担→热源结束后环境影响逐渐趋向新目标 | 非完整气候、移动辐射或生态 |

这些是组合深度仍有限的原型，不是已完成的独立长流程。陌生玩家是否觉得有趣、能否自然理解目标与信息边界，尚需专门试玩。
