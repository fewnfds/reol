# 现有Demo：认识、器物与学习

个人见闻、听说、自述、理解、实际掌握与正式机构记录分别保存。交谈可以获得过时或错误的信息；亲自查看只纠正本人，开发全知不能直接进入NPC知识。私人情谊不等于贡献或永久授权。

少量独特器物保留原身份、保管位置、储量、损伤及学习经历。温石可投入探查、试用、温养、有限释热、做饭/烘药；误用可能损伤原身体或石芯，读档不修复已发生后果。地火隙提供有限引息，真实供给/容量/在途预约与完成时核对共同决定收益。

温养手记允许命名/调整有限步骤、实际试验、版本采用和当面传授；实物记录可制作、阅读、抄写和交接，读到说明不等于掌握。引物环提供少量真实用法研究/短距引物；不是任意物性或通用创法。

衣着是实际取放/穿脱的独特物，保暖、雨湿与晾干影响身体；单纯携带不等于穿着。八向外观当前为代码生成占位，预览剑/玉佩不取得装备或能力，正式全体型/全动作素材未完成。

这些接口提供有限学习、器物和认识样本。完整修行、突破、大型本领网络、通用鉴定/炼器/创造及衣饰社会后果尚未实现。操作见[控制](controls.md)，新架构范围见[主计划](../../plans/foundation-priorities.md)，旧证据见[QA](../../archive/qa/README.md)。
