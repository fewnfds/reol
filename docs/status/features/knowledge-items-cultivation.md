## 6. 个人认识、关系与口头资格

**有限样本。** 事件是否发生、某人是否知道、某人相信什么、机构是否承认分别保存。关系有方向，私人情谊不自动变成贡献、永久通行或所有人的态度。

“交谈”页可以询问/转告灶房近况。NPC按自己的亲见、听说、来源和时间形成库存预期；说法可以过时或错误，亲自查看只纠正本人。页面不直接显示后台仓库总数。

同页可声称已有取药登记、出示真实签注、请有权者核验、出示私人回执。普通同门可能承担一次临时放行；管事要求核簿。信了你并不改变正式贡献/永久通行；取药仍需原身体、路线、库存和完整劳动。核验不自动广播，向别人出示回执才提供新依据。同条件重复声称不重掷、不续期、不补回已用额度。

实际验收中同一句无正式记录支持的声称，被阿禾拒绝、被石头暂信；这不是每次开局必定如此的剧情承诺。当前NPC可调用同一接口，但没有自主策划欺骗。

范围：尚无通用信念推理、完整《骗经》、身份伪装、司法与政治。机构记功簿已有固定值事房的记录载体引用，尚无可携带/毁坏的通用物理账本。证据：[资格与核验](../../qa/20261103_social_admission.md)。代码：[social_memory.gd](../../../scripts/sim/social_memory.gd)、[stock_information.gd](../../../scripts/sim/stock_information.gd)、[institution_book.gd](../../../scripts/sim/institution_book.gd)、[social_admission.gd](../../../scripts/sim/social_admission.gd)。

## 7. 温火石：认识、使用、生活用途与损坏

**有限样本。** 新开局灶房有唯一温火石。可走近、端详、取放、投入灵气探查、催火和温养。不同人的材料阅历与操纵阅历产生不同认识；可请附近空闲同门实际花时间检查，在场听到具名说明不等于学会操作。

有限储能可替柴做饭，或把原草药烘成干药；两种用途仍消耗真实原料与时间。阿禾有按自己认识摸索替代燃料的有限行为。错误催动可能反噬，过量注灵可真实损伤石芯、流失储能并损耗原身体；取消不退已投入资源，读档不修复石头。

I页的“释热暖身”只在本人持有且懂原方法时显示，实际还要健康允许、石芯可用和原储量足够。花原一分钟、无需追加灵气，完成才耗去一份储热，在完成位置留下有限暖流；取消不扣储热、不提前产热，与做饭/烘药竞争同一储量和原身体。普通NPC也可按寒冷需要使用本人持有且懂用的温石，既有需求、健康、衣着与承诺优先；同刻暖流已足则回原日常，不凭空取石。已释出的热留在空间，石内剩余储热仍随持有人移动。见[释热QA](../../qa/20261103_local_heat.md)。

**地火隙引息是有限修行/生活样本。** 山门灶旁有一处真实火属性灵源。本人须在近旁、身体健康允许且能支配行动，借本人持有或灶旁公共的完整温石，沿亲自学过的循纹手法引息；听别人介绍不算学会。一个面板选择“本人”恢复原灵气，或选“温石”存入原器物，再用同一个“引息”按钮开始。两分钟过程只预约原来源、身体和温石，完成时重新核对并共同提交；手动开始保留原连续位置，不把人吸回格心。停止或条件失效没有提前收益，同一石头不能同时被别人操作或指导。

两条路线争用有限源息；深层供给逐次释放、满后散失，深层耗尽后不会无限恢复。目标只接收自己尚能容纳的部分，其余转化损失；满目标不能开始。原身体得到的灵气仍支付原温养/教学等成本，原温石得到的储热仍用于做饭、焙药或释热。普通休息不会因此恢复灵气；已懂方法的近旁NPC只在原需求、职责与承诺之外考虑归身，不会自动知道或走向远处灵源。

只有近旁当前可见才显示定性源况和可用温石；远处、遮挡或重开界面只保本人已经见过或有原过程记录的位置线索，不公布源数/深层储备，也不按后台余量替玩家禁用按钮。当前只有这一处固定引息火属性灵源；室外五行环境场的底层已接，完整五行修行、突破、阵法、源产权争夺和通用寻源规划尚未完成。实现与真实档/原生画面证据见[规格](../../archive/specifications/finite_spirit_source.md)、[E4 QA](../../qa/20261103_finite_spirit_source.md)。

范围：没有通用鉴定、完整热力学、炼器/创法、修复、干药医疗或完整市场。原物与学习状态以当前存档为准。证据：[生活器物](../../qa/20261103_world_foundation.md)、[做饭/烘药](../../qa/20261103_heat_methods.md)、[不同理解与裂损](../../qa/20261103_artifact_understanding.md)。代码：[artifacts.gd](../../../scripts/sim/artifacts.gd)、[artifact_understanding.gd](../../../scripts/sim/artifact_understanding.gd)。

**温养手记是有限创造/学习样本。** 学会原引流基础后，M可调整流量与持续时间、命名草案并实际试验；改名不复制本领，修改步骤保留独立版本。草案不授予掌握，原身体花灵气/时间，容量不足会逸散，急灌可能撑开原裂隙。储下的热继续用于原做饭/烘药/有限释热，不能凭命名直接获得材料或贡献。

已练过的具体版本可向近处空闲同门提出传授；对方会按原社会规则答应或拒绝。双方实际在场，教师付指导成本，学员亲手投入与练习；任何一方中断都不授予未完成的学习。旧版不自动升级，旁人不会免费学会。阿禾在原职责缺柴、亲历枯竭时可用自己学过的版本补热，玩家离场仍运行。证据：[试验与传授](../../qa/20261103_heat_method_crafting.md)，规则：[heat_methods.gd](../../../scripts/sim/heat_methods.gd)。

**实物木牍是有限传播样本。** M实物记录页可花原行囊中可处分的木料刻写已知版本，或精确抄写已读步骤；耗时且占原身体，中断不退已耗材料。木牍只有一个位置，随持有人走，也可放到眼前设施、收起或向眼前同门商量交接。对方可拒绝，人在远处不能遥交；实际交接后他也不会立即读懂。

读完才获得这一版的步骤；持有不授知识、阅读不授掌握，不具引流基础仍不能独立操作。之后照步骤投入原灵气/时间并做出可验证结果，才形成本人实践；后来修订不更新旧木牍。NPC能在原需求和日常之外阅读收到的木牍，并在实际缺热且具备基础时尝试；未接触的第三人不会自动获得。实机已从山门正常携至河湾、交给阿禾，再离场，由她自行阅读；玩家远处只记得已交接，不能透视她读后的结论。范围只有温石步骤的精确记录，未实现识字/语言、误抄/伪作、损毁、任意工法、自动著书/科研或物理机构账本。证据：[实物记录](../../qa/20261103_method_records.md)，规则：[method_records.gd](../../../scripts/sim/method_records.gd)。

**已验收的U2-a有限样本。** U页“查看本人的学习与实践”原有七项来源目录；U3-b1加入引物环后当前有八项，仍只引用本人原招式、器物、版本与木牍事实，目录不额外授予本领。实际学会原护障后，可付原气力练习一分钟，完成才获得护障动作内45%速度缓步。取消、阻路或受击不授技、不退款，NPC同规则；其余发招、闪身与反应锁不放宽。完整能力组合、功法网络和突破仍待实现。U2-a普通主局、真实练习/护障中途档及停开见[QA](../../qa/20261104_capability_network.md)，U3-b1最终证据见BASELINE。

### 实物衣着与生活用途

**有限样本。** 人身V整理衣物，新局原常服为唯一实例；山门住处存靛青衣/蓑衣，老周随身有蓑衣。取放须靠近且本人有权，穿脱耗时，占原身体；同位先脱再换，未完成/取消不移物。常服/外层各一位，原人物与纸娃娃按真正穿着绘制，衣物没有战斗属性表。

下雨会湿润露天常服；实际屋面和已经穿好的蓑衣遮雨，只带在包中无效。湿透增加原精力消耗，脱下不立即干；NPC在原需求/凭据/承诺之外可遇雨整理随身蓑衣。近旁只看表层线索，外层遮住内层细节，衣色/剪裁不授任职或通行，不读别人包。

范围：三种衣物/两穿法、本人合法取放、分钟气候/局地热采样；已有共享八向像素占位，见下节。尚无完整服饰生产/交易/借赠/盗窃、审美/礼仪反应、清洗/损坏/负重；各领域状态以当前存档为准。证据：[实物衣着](../../qa/20261103_clothing_foundation.md)，规则：[clothing.gd](../../../scripts/sim/clothing.gd)，入口：[clothing_runtime.gd](../../../scripts/runtime/clothing_runtime.gd)。

### 真八方向外观技术样本

玩家、两地NPC与V预览共用八方向、动作相位、附着点和逐帧层序；实际常服/蓑衣来自原穿法。左手剑/右腰玉佩按解剖侧独立投影，不整身镜像；V勾选仍只是技术演示，不产生装备。九张透明图集由原[生成器](../../../tools/build_humanoid_assets.py)生成像素占位，来源/合同见[资源说明](../../../assets/characters/humanoid_sample/README.md)。正式复杂资源后置，[外部提示词](../../art/character_generation/README.md)仅为未来资料，当前不需要用户交齐图片。

只有待机、行走与短生活展示；正式奔跑、倒地、受击/起身和战斗全动作、步幅锁脚仍未做。48视图人物CPU约1ms目标尚未达到，不把限帧结果当完整世界性能达标。技术合同与此前真实行旅中重启证据见[A1 QA](../../qa/20261103_eight_direction_sample.md)；最新像素呈现/完整检查以BASELINE为准。
