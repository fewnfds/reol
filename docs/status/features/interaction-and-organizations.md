# 现有Demo：交互与有限事务

C及生活/办事面板提供有限事项；表达、理解、意愿、权限、距离、资源、实际耗时和结果分别检查，玩家/NPC使用原领域入口。完整自由谈判、任意文字指令/能力推理、玩家策略编程和自主政治尚未实现。

| 事项 | 当前支持的有限链路 |
|---|---|
| 公共工作/贡献/现金 | 实际劳动和交付形成依据，现任有权者办理登记、兑换或验收，公库支付真实钱货 |
| 受托搬运 | 本人行囊、已知聚落容器及眼前获准箱体间取货/携带/交付；中断保留货物和保管责任 |
| 常备买卖/私人加工 | 原库存双边交割、本人原批次投入与取回；不是完整市场或所有配方 |
| 信息与放行 | 当面说法、具名来源、临时采信、正式核验与私人回执；认识不自动广播，也不直接改公账 |
| 来源借用/看护 | 当面签注、委托、警告与实际回应；口头声称和可核验依据分开 |
| 野外见闻/器物交割 | 本人线索/到场、实际寻物与少量固定报价/用法研究；不是通用探索或私物交易 |
| 能力介绍/求助 | 接收者按自身处境自述，真实诊断/照护和学习使用原身体、药物、时间与资源 |

地点、人物、配方和物品清单都是当前内容样本，不是新架构必须逐项复刻的任务。具体操作见[控制](controls.md)，现有原物/行动接缝见[合同](../../engineering/object-lifecycle-contract.md)，原场景证据按[QA](../../qa/README.md)日期读取。
