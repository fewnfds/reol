# 开局与操作入口

> 状态依据 2026-11-05 的既有代码与有限验证；原文中的“已验收”仅指具体样本。最新完整回归和未提交工作见[基线](../baseline.md)。

## 2. 如何进入和操作

用 Godot 4.7.2 打开项目运行主场景，或执行 `python tools/godot.py run`。新开局在暂停状态选择**山门杂役、山间雀妖、戒中残识**之一；也可接续已有存档。选定后不能在同一人生中免费换身份。

2026-11-07补充：`python tools/godot.py run -- --world-editor` 启动现有开发编辑，F8可选地形、实物放置或实物移除；实物列表来自当前physical定义，开发放置不扣材料。退出编辑后，点击可见实物，普通物品面板可耗时取起、放在脚边，WASD/停止可取消；同高、触及、遮挡及多格占用受原规则约束。普通保存可接续进行中的操作；该入口不等于材料通用背包、NPC搬运指挥或任意物品造物。

| 范围 | 当前入口/操作 |
|---|---|
| 世界时间 | 空格暂停/继续；HUD选择1/2/4倍；T等候十五世界分钟，到时暂停；空格可中断，手动走动取消等候 |
| 本领与交锋 | U选近处人物请教或明确驱离敌意；住处木剑须通过I页或实际点击取用。Q/E/R发招、X停手；正在起势/收势或硬直时不能闪身，空档可走位。可见危险不允许快进等待，远处未知冲突不泄露 |
| 日期与冷暖 | 左上天气行显示同一时间的日期/时令、本地风雨和人身体感；V实际穿脱改变御寒，湿衣保暖下降；只携带衣物不提供穿着保暖，原身体精力承担采样后的冷热负担 |
| 有限温石释热 | I器物页，实际取石并循纹探查后“释热暖身”；完成才耗原储热，完成处形成短时热源，停止后环境影响逐渐趋向新的环境目标；当前门墙和屋面不阻隔冷热场。暖天可能过热；已释出的影响不会随持有人瞬移。旧版证据见[QA](../../qa/20261103_local_heat.md)，当前验收状态见BASELINE |
| 有限灵源引息 | 实际走到山门灶旁，点击看见的地火隙，或从I器物页“灶旁地火隙 · 引息”进入；选择原温石、目标“本人/温石”，再点一次“引息”。须亲自学会原循纹手法，持续两分钟，完成才恢复原灵气或储热；停止不提前获益，远处只有本人已知位置 |
| 公源借用/看护 | C向现任管事询问借用、签一次用途与验还；向近旁石头询问看护或说明本人签注记忆，也可明确作无可核来源的口头声称。本人实际收到警告会暂停供选择；可停止原引息、说明或继续。撤回仅原委托者与看护本人能当面办理，普通玩家无权直接撤岗 |
| 山川草木 | 右键可见地块查看地表、土质、草木与原有限自然来源的定性线索；已探索但不在视野的地面不提供实时情形，残识沿原灵机感知 |
| 值事房 | 新局在两地可见真实墙门和桌柜；原报工/贡献兑换/通行公账办理依现任权限、在岗人物和固定机构记功簿。人外出时可以等其真实归岗，失败不提前扣贡献或交货 |
| 人身 | WASD走动，Shift闪身；点击人物查看/选择，面板办理生活、劳作、交谈和采集 |
| 人身专项 | I或点击温火石看器物；O或点击旧戒看寄魂者；K约练面板、J试掌；B观察/投喂雀妖或求衔药 |
| 人身统一请求 | C打开/收起，选择眼前接收者、事项、对象与口头/手势表达；辨材/探查/石隙取药、本地买卖、劳动分工/当面撤回、承接现金差事/验收；可向近旁停稳的山兽比划递出随身饭食 |
| 身体不适/救护 | 温石真实反噬后C显示本人体感；向近旁懂行者请看不适，再用本人鲜药请求处理；双方实际耗时，随后逐步休养，取消不退已投入药 |
| 当面介绍/回想 | C选择“交流：询问能帮什么”、公开话题；听对方按处境自述，进度区域可滚动，重开C/读档可回想本人听到的旧话 |
| 野外问路/见闻 | 人身C向实际当面的人“打听野外去处”；L“野外见闻”只列本人已知地点，可行旅、到场查看或查看眼前器物。也可自行走近发现；U3-a已验收 |
| 引物环用法 | I器物页实际取环并完成外形研究，再由本人持环循纹研究用法；学会后选择眼前符合条件的松置木剑引到本人手边。U页只读显示本人的实际学习来源；本包已验收 |
| 私人旧环交割 | C向眼前持灰纹环者商量固定4钱/5秒交割；对方同意后实际占用双方身体，完成才同时转移钱与原环，可停手撤销。本机与对应完整CI已验 |
| 人身试验/记录/传授 | M或器物页“温养手记”，命名流量/时长草案、亲手试验/当面传授；实物记录页花原木料刻牍、阅读/抄写、取放/自愿交接，照已读步骤仍须基础和实际练习 |
| 人身施工/居住 | N施工簿：靠近柴粮库划定宗门工地，选格画木墙/门/床/上层屋面蓝图并实际施工；开关门/拆改/回库，安排床位/亲自休息。屋面与地面可同格分层选择。B仍观察雀妖 |
| 人身衣着 | V衣着页：走回住处取放本人的备用常服/蓑衣，实际穿脱、表层观察与纸娃娃；穿好蓑衣/实际屋面挡雨，湿衣渐干并影响原精力 |
| 八向外观技术样本 | 代码生成像素占位；实际人物/NPC八向待机、行走与有限生活展示；V可转向/切预览动作，勾选左手剑/右腰玉佩仅演示，不取得装备；非正式全部动作 |
| 人身行旅 | “行旅与见闻”选择前往河湾/返回山门，L页前往本人已知的断碑台；“保存近况/读取近况”保存整个会话 |
| 人身受托物资 | “差事与凭据”里的“交回受托物资”：每次实际交回下一批；也可续做原公差。随身总量与受托量同时显示 |
| 人身私人加工 | “制作”页用私料煮饭/焙药；选择本人批次续做或实际取回；干药用原C常备买卖出售 |
| 野药照料 | “采集”页先自留汲泉，再“浇灌野药”；本人携自己的水到场劳动，完成才耗水入土，取消无生态收益、不记公差贡献。近旁可观察药丛线索，远处不显示实时土水 |
| 人身现金差事 | C向眼前有付款权的管事承接送柴/挑水；“工钱”页续做/放弃；交付后C请现任验收，实际到功德堂领钱 |
| 玩家雀身 | WASD振翅，F落地，E啄食，R歇翅，Q衔药，G放入共享药圃；面板可停止行动；F5/F9存读 |
| 玩家残识 | E感受灵机，C换一道近处气息，Q传意求携戒，R休眠，F重新凝神；面板撤回请求；F5/F9存读 |
| 镜头/诊断 | 镜头平移、缩放和中键拖动；F3诊断；残识使用专用有限灵机视图 |

不同身体有不同入口。人身的工作、行囊、机构办理不能直接给雀身或残识使用。路线中断保留已经取得的实物，不自动退回起点。
