# 植物与自然生命

工作分支 `codex/environment-composition` 承接的有限操作范围；准确验收及主线状态见[HANDOFF](../handoff.md)/[BASELINE](../baseline.md)。工程行为见[植物合同](../../engineering/plants-contract.md)，建设仍归唯一主计划。

普通人身右键观察当前可见地面。真实植物显示外观与可见生长阶段；面板可以采摘产物、伐取地上部、采走原株、清残株、浇水、中断，或把同一植株移栽至邻格空花盆。先靠近、预约、经过工时后才提交；继续时间才能完成，WASD/停止可中断。

花盆在正常营造定义列表建造，使用原工料和施工过程；提供自身基质、水与单株根容量。首版活株移栽限相邻可达位置，未提供远距离抱盆/背包活株运输。花盆损毁会留下受损的原植株。

原采集页的“用私水浇药”也使用同一植物作业，原行囊必须有水；到场、完成工时才浇入，停止释放未耗的水，不授公差贡献。工时按本会话植物定义，面板显示真实进度与完成结果。

开局野药/野稗由真实植物继续生长，仍使用原资源账；另有赤叶草和古树代表样本。水生、旱生、年生、多年生通过同一数据/接口表达，尚未生成整个地图的可采植株群落；背景装饰不是免费可采物。

古树在显式情境事件后可以回应，玩家可尝试商量采果；面板不提前报告灵智、药性或五行数值。植灵仍是原地身体，没有行走、化形、战斗、宗派或完整树身人生。遗传、授粉、繁殖网、病虫害、根系流体及食物网继续后置。

环境组合沿原生境输入加入同一实际房温及自然/人工总照明，箱体和真实墙门按通道影响暴露；当前整包在验，准确证据见BASELINE。没有读到有效温度/光照时返回不可用，不把失败当作零照度或室外气候。
