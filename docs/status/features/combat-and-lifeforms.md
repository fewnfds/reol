# 现有Demo：有限交锋与非人生命

人身有少量实际学习、约练、木剑/气弹/护障和闪身；动作包含成本、起势/执行/收势、受阻/中断及身体后果。工作与交锋争用同一原身体/控制条件，已发射效果不会因后续停手被抹去。

当前交锋可造成疲惫和挫伤、退让与休养，尚非完整致死/掉落、群战或战争系统。NPC依据有限本人目击/记忆作判断，不拥有全图即时敌情；原知识与隐藏对象不从诊断面板泄露。

雀妖/玩家雀身有有限觅食、休息、衔药和飞行样本；戒中残识拥有独立意志及有限感知/传意，不能免费操控持有人；大体型动物实际占多格，移动/互动按扫掠与真实接触检查。植物已有最小原地灵智，见[植物](plants.md)。

这些身体/身份只是同一世界的有限样本，完整种族流程、出生、生态、寄魂战斗和有限转生尚未完成。旧高度/飞行代码不等于当前平面新局已交付高差。按[操作](controls.md)体验，准确验证见[BASELINE](../baseline.md)。
