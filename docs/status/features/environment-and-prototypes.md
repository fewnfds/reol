# 环境、地表与计算原型

> 核对 2026-11-07 收尾工作树。普通世界已接新的室外环境场，本包整体验证及规模性能验收尚待核对；旧QA只证明其当时版本与范围。状态见[基线](../baseline.md)和[接续](../handoff.md)。

## 游戏功能与操作

本文记录当前接线、入口和样本边界；旧版本的画面、测试与CI不能自动证明本次环境接入。当前代码与存档合同见[普通世界环境](../../engineering/world-environment-contract.md)，最终验证状态见[BASELINE](../baseline.md)。

读档首屏呈现修复已由其对应CI通过，见[QA](../../qa/20261104_world_view_continuity.md)；原高度/飞行样本仍存在，但新世界引擎先做平面，高差扩展后置。通用世界编辑、完整五行玩法/风水、自由组织和出生转生并未因设计文档而实现。

**实施中：共同时间与预算续算。** 普通时钟只显示原世界实际完成的时间，预算不足保留未完成请求和帧债，后续继续处理；自动行程不提前移动到未完成的未来，WASD先接管再移动。待处理时保存明确拒绝并保留原档；正常在途存读与完全停开同未来已定向验证，最终SHA完整回归待验，见[证据](../../qa/20261105_clock_world_commit.md)。当前室外环境场按同一共同时间推进。

**实施中：平面地表草稿、运行编辑与持久化。** 开局装配可接受草/水/岩的稀疏格修改，普通存读恢复同一底图和修改；通行、附近水环境潜力、地表与植被覆盖、静止视线随原地图更新。已有定向与真实停开/画面证据，完整回归待对应SHA。显式运行`python tools/godot.py run -- --world-editor`后F8进入暂停开发工具，左键以1/3/5格宽画笔修改，保护人物/大型占地/设施/完整在途路线与活任务接触；独立编辑档可保存/读取，退出仍暂停。普通运行不提供免费改地；玩家改造动作、多格设施/种植区仍待实现，地表水和岩石不自动生成可提取水量或矿藏。

**实施中：结构与视野。** 原N施工簿仍用真实木料和工时；建成木墙按四邻连接，木门开关保持门框。真实墙/关门会遮住背后的当前视野，开门后静止人物也会更新视野，旧探索记忆保留；桌柜阻路不等于挡住视线。只读工具可查原工程/值事房部件的覆盖格、地面/屋面层与物理事实。当前仍限原单工地及单格工程，通用多格家具、区域创作和完整在途重规划未接；验证范围见BASELINE。

**实施中：在途清场。** 新墙/关门会等待当前正通过的原路段，包括对角通行需要的旁格，不取消行走者或抹掉已做工时/搬到的材料；人通过后可重试。兽身使用同一首段保护，低床/屋面保持可通行。固定运粮还不会随动态结构绕路，本阶段先禁止把新增阻挡建成在其道路上；自由封路/通用重规划另接，纸面蓝图仍不挡路。

**实施中：固定冷热器物。** 新局灶房放有默认关闭的赤纹石与青纹石。走近点击器物，亲自“循纹探查”后可花一分钟及1灵气启用；附近的人能花一分钟关闭。火石消耗自身有限储量，寒石占用自身有限容量；启用且有余量时分别提供热场或冷场，双方影响按冷热等级抵消，场模型不作逐格热量守恒。关闭或耗尽/吸满后，既有冷热影响逐渐趋向新的环境目标；启用中须先关闭再搬动，设备不会自动关闭或补充。玩家只见外观、亲历用法与定性开关状态，普通界面不显示隐藏储量。人物随身物整体辐射、可搬箱及充补能尚未完成；本包完整回归状态见BASELINE。

**实施中：自然日照。** 普通天色、左上环境行和右键可见地块观察改读同一自然光规则；太阳高度与昼长来自共同时间、季节和整张地方地图的宏观纬度/经度，晴雨影响天光。纸面屋面不遮光，实际有支撑的屋面才压低该格自然光，拆除/塌落后恢复露天天光，进入房间不会让整张地图变暗。当前默认北纬30°；其他纬度/极昼夜由定义与定向场景验证，尚无普通世界创作表单。此包不改变NPC视力、植物生长、Fog、太阳供热或局部灯；画面与完整回归证据见BASELINE，不把自然光查询当完整环境光系统。

**实施中：固定火石局部光。** 新局火石在原学习、启用动作完成后，处于可定位且有储量的启用状态时照亮近旁，距离衰减、已建墙/关闭门与岩石遮挡；开门/拆除即时改变透光。关闭或用尽即变暗，余热仍在，光不多扣一份储量。可见地面观察和左上环境行给定性暖光，画面只对当前视野内的格投影；灵魂不会获得肉身视力。多源叠加，当前规则每笔最多441受光格、128个共享来源引用、总相对局部光上限40000（尺度10000）。旧版本的定向、普通夜间画面及完全停开证据不能替代当前包验收；固定火石本身尚无移动照明，容器遮光、光照改变NPC/植物与光热能量分账也未完成。证据见BASELINE。

**实施中：新局地理气温。** 普通新局按明确的地理草稿生成实际年/日气温曲线：纬度决定基温和季节幅度，南北反季，海陆调节影响温差和季节滞后，经度平移日温相位。同一曲线作用到热场、人体和植物，仍由原天气补晴雨温差。默认整张地图北纬30°，两地区只有海陆性/局地偏移不同；入树前可独立传地理或完整内容包，当前无创作表单。当前存档保存曲线及digest，加载不按当前草稿重编；普通入口当前不自动迁入根1–51旧档。已有定向、冷热原生画面和完全停开证据属于旧版本，当前包完整回归待验；这不是完整气象或雨雪/生物群系生成，具体近似精度见执行页。

**实施中：随身固有微光。** 普通新局山门住处有微光珠子、河湾住处有微光薄片，点击可端详、取放、熟悉和辨材；取物要花真实时间，未完成时仍在原处，完成后同一件原物随人移动，放回后恢复原处照明。原墙门/岩石遮光、多源叠加和当前视野裁剪复用；没有另发光量余额或热量，不增加NPC视野/植物用途。固有微光可与武器或引物工具能力组合；固定火石的光取决于启用、可定位与自身储量。固有微光和随身物冷热/五行辐射是不同机制，后者尚未实现。共享上限128个来源引用/441受光格，旧承载位置或欠算明确不可判定；远区未同步、鸟嘴/箱体透光与移动冷热仍待接。旧版本的定向、普通夜间取放/行走及完全停开证据不能代替当前包验收。

## 1. 状态怎么读

**普通世界：室外场与实际响应。** 地面独特实物、同类材料堆及代码支持的固定位置非人物器物，按内容定义成为来源；同堆数量不乘大源强。每源按圆形欧氏距离衰减，五行各通道取最大；冷热各取最大后按等级抵消，形成相对本地气候的温度目标。受影响格的温度与五行状态随共同时间逐渐趋近目标，源移动、移除或关闭后旧处保留残余并逐渐趋向新的环境目标。普通世界使用共享接收端潮汐；这不是总能量守恒模拟，也不授予玩家知晓隐藏来源的权限。详见[环境合同](../../engineering/world-environment-contract.md)。

**已接范围与缺口。** 人体暴露和当前有限草木采样读取同一环境温度；五行可查询，但完整修行与生态消费尚未接通。人物及随身物整体发源、容器遮掩、鸟兽植物与墙材普遍发源均未实现。墙门屋面可参与原有围合、挡光等规则，但不阻隔冷热/五行场；没有一房一温或开门换气。温石暖身动作完成处形成限时热源，其停止后影响不会瞬间清零。当前普通根存档为52，1–51暂不自动迁入；环境候选须连同原物及时间通过校验后才能替换活世界。

**独立计算与历史证据。** 早期[来源查询](../../qa/20261105_environment_source_bindings.md)、[源场](../../qa/20261105_source_field_foundation.md)、[实际温度](../../qa/20261105_actual_temperature_state.md)、[气候目标段](../../qa/20261105_temperature_segments_and_budget.md)、[分片准备](../../qa/20261105_bounded_temperature_preparation.md)与[联合候选](../../qa/20261105_source_temperature_transition.md)记录各自版本的局部实验，不能代替当前普通世界验收。独立CPU/GPU/auto服务有旧版对照数据，见[计算证据](../../qa/20261105_field_compute_acceleration.md)；普通世界来源变更与目标刷新当前是同步CPU路径，没有玩家GPU开关，动态密集规模和端到端性能仍需实测。
