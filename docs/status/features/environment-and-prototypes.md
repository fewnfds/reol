# 现有Demo：环境与计算后端

普通Main已接以下有限能力；准确代码与验证范围见[BASELINE](../baseline.md)，接口见[环境合同](../../engineering/world-environment-contract.md)。

- 平面地形/材质、地理气候和有限晴雨，共同时间驱动季节/昼夜与背景。
- 原物/材料、已支持器物、植物及可定位库存/携物按能力提供来源，实际响应保留建立/消散过程。
- 材质透过、真实墙门/开口与覆顶房间组合传播和房间温度；同处不会简单重复叠加室内外两份实际温度。
- 自然/人工光、屋面和遮挡提供相应照度，植物读取实际环境条件；人体暴露按当前有限采样规则影响原身体。
- 来源、响应、房间关系及原物过程接联合存读。模型是奇幻场和有限混合近似，不是严格热守恒/空气流体。

普通环境内部来源候选已使用常驻GPU worker，冷块、同步命令与设备失败走CPU。旧独立基础目标验收服务已删除，原[实卡记录](../../archive/qa/20261105_environment_ground_compute.md)只供追溯；当前范围和结果见[BASELINE](../baseline.md)。

完整风水玩法、五行修行/材料后果、人物体质整体源、任意嵌套、完整天气/生态及目标PC密集动态规模尚未验收。后续CPU/GPU调整参考[候选规格](../../specs/world-engine/execution.md)，不能沿旧独立服务倍数宣称全游戏收益。
