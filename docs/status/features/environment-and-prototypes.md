# 环境、地表与计算原型

核对：2026-11-09。main保留既有基础；`codex/environment-composition`扩展传播、房温、容纳及受体，当前整包在验。代码/分支范围查[技术总表](../technical-status.md)，准确版本与证据查[BASELINE](../baseline.md)。不把尚缺内容称为“整个系统待验”，也不把基础通过称为完整生态。

## 已接入的环境与空间基础

| 能力 | 实际行为 | 当前边界 |
|---|---|---|
| 平面地表与编辑 | 新局从地理/地图草稿装配512²草/水/岩和稀疏修改；通行、地表/植被覆盖、附近水条件与视线读取原地图，保存恢复同一修改 | 高度/飞行旧样本保留；当前新局是平面；水地表不自动生成可提取水库存 |
| 开发改造 | 显式`--world-editor`，F8暂停画地、放置/移除受管实物，支持独立草稿；保护身体/多格占地/设施/已承诺路线与任务接触 | 非玩家免费改地/造物；没有通用区域或完整创作编辑器。键位见[操作](controls.md) |
| 结构、视野与清场 | 真实木墙四邻连接、木门开关保留门框；建成墙/关门挡视野，静止观察者也刷新；新障碍等待当前路段/对角旁格清场，兽身复用扫掠保护 | 工程内容/多格家具有限；固定运粮原路保护，不是动态全局重规划 |
| 地理与天气背景 | 新局纬度决定基温/季幅，南北反季、海陆调节和经度日温相位；同一曲线驱动环境/人体/野药，有限晴雨叠加本地修正 | 默认地图宏观北纬30°，两地区有限差别；没有完整雨雪/风/空气或逐格气候带生成/创作表单 |
| 自然日照 | 同一时间、季节和宏观经纬度得到太阳高度/昼长/天色，晴雨调整；实际支撑屋面压低本格自然光，蓝图不遮光 | 植物已读取本格自然光及冠层衰减；尚未普遍驱动NPC视力或太阳供热 |
| 室外冷热与五行 | 原实物/材料堆及已支持固定位置器物按定义发源，圆形欧氏衰减；五行逐通道max，冷热各max后按同一有向等级抵消；实际响应逐渐建立/消散 | 同类堆数量不乘强度；不是逐边热传导/守恒。当前共享接收端潮汐，不是每物独立计时器 |
| 有限冷热设备 | 灶房两类设备按原探查/耗时开关启用，热侧消耗自身储量、冷侧受自身容量限制；关闭/耗尽后残留继续趋近新目标 | 启用中不能直接搬走；无充补能/可搬热箱；普通携物已在环境分支接跨格时刻，人物体质整体源未接 |
| 局部光与随身微光 | 固定热设备依启用/可定位/剩余量发光，固有微光物可实际取放并跟随持有人；距离、墙门/岩石遮挡、多源和当前视野裁剪 | 当前128共享来源/441受光格；不开第二热/光余额，环境分支接箱体分通道遮光和植物实际生长照明；普遍视力后果未接 |
| 身体、植物与保存 | 人体暴露与当前野药采样读唯一实际温度；场锚点/背景/残留和进行中原物过程进入联合快照 | 五行可查询但完整修行/材料变化未消费；保存有未结算事务时拒绝，不伪造完成点 |

主要入口：[地图](../../../scripts/sim/world_map_data.gd)、[环境域](../../../scripts/sim/world_environment_fields.gd)、[地理内容](../../../scripts/data/geographic_content.gd)、[结构查询](../../../scripts/sim/structure_query.gd)、[局部光](../../../scripts/sim/local_light.gd)。规则边界见[环境合同](../../engineering/world-environment-contract.md)与[时间/空间](../../engineering/architecture/03-time-space-presentation.md)。

## 仍未实现与隔离计算

- 环境分支用材质透过率、实际覆顶房间均温及开口响应补室内外组合；是简化模型，未实现空气质量、流体与严格热守恒。
- 携物/原植物/建成建筑/可定位库存按已有能力发源；鸟兽本体、人物体质整体源、嵌套容器、完整风水、五行修行/材料后果和完整生态仍未接。
- [CPU/GPU基础场服务](../../engineering/environment-ground-cache-contract.md)有独立实测，普通世界来源变更与响应仍同步CPU，无玩家GPU开关；不能用隔离倍数证明整款游戏加速。
- 主线准确代码有普通画面和完全停开证据；本轮稀疏分支有自身回归/存读与短测。旧版密集静态测试不等于当前满密度动态世界或16GB整机验收。

历史局部实验仍见[QA索引](../../qa/README.md)，本文不再复制各包“实施中/待验/下一步”的旧状态。
