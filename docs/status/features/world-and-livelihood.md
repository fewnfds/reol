# 现有Demo：世界与生活

本页描述重构前普通Demo的可玩范围，准确版本见[BASELINE](../baseline.md)，不是新架构的实现约束。

平面首区512×512格，按显示区块加载地形；身体持连续位置，格路用于通行/占地，人物与镜头在完整坐标间连续呈现。战争迷雾与探索记忆区分当前可见和曾经到过，固定正交俯视。旧高度样本不等于新局有多层世界。

山门与河湾共用世界时间，提供实际行旅、运输、消息和日常工作。离场居民与在途事务继续，地图显示卸载不销毁原身体。有限野外地点通过本人线索或实际到场发现，不提供远处实时对象清单。

人物按需求/职责选择吃饭、休息、采集、搬运及有限生产；预约、路线、劳动、交付、贡献/现金与随身保管分别成立。私人加工保留原批次，公物不能通过中断或存箱变成私产。

历法、晴雨、自然光、实际温度及穿着湿润参与有限生活。植物已有独立原株、物候/残株、产物和花盆，见[植物](plants.md)；房温、材质传播和携物来源见[环境](environment-and-prototypes.md)。

目前是双聚落和少量野外内容，尚无通用迁居、战争、完整市场/经济或多年大规模验收。规模和新运行目标统一在[重构计划](../../plans/foundation-priorities.md)。
