# 世界连续性与生活

> 2026-11-07按代码复核有限功能范围；Git main/开发分支区别见[技术总表](../technical-status.md)，准确版本和验证见[基线](../baseline.md)。

开发分支的“搬运”页复用原库存和服务过程，支持不同聚落账本、本人行囊和眼前获准箱体。每次最多24份、到场取放各1秒；箱体另核原容量/过滤/操作位。公物只交登记公共地点或随身继续保管，不能送入普通箱体洗掉责任；私人材料仍可存取箱子。工作和战斗可中断同一过程；受阻尝试绕行。地面堆/独特器物仍用原入口，没有任意嵌套或普遍重量/体积模型。准确版本与证据见BASELINE。

## 3. 地图、时间和离场连续性

**已实现基础。** 首区512×512格、64×64显示区块；当前默认新局使用平面生成器，有可达性、加载、昼夜表现、战争迷雾与探索记忆。旧高度/飞行样本仍在代码中，不能把它算作已完成的新局高差系统。玩家相机可平移/缩放，固定正交俯视。

身体有连续位置；手动移动和自动路线共用世界毫秒与实际速度。人身闪身有起势、位移、收势，扣原体力、检查地形，不授予无敌。路线仍连接格路节点，部分绘制仍会显得跳格；不能称为已完成顺滑战斗优化。

山门与河湾共用时间。离开后当地日常、运输、消息与未完成事务继续；远区按必要变化批算，归来接续当前状态。封路会影响在途运粮，恢复后续行；消息需要实际传播时间。界面的“中断/恢复运粮道路”是**开发验证工具**，不是角色拥有的技能。

U3-a另装配一处野外断碑台，不是第三聚落。人物在野外仍保留原数据所有者，显示/点击按真实位置和当前视野；离开所属聚落不会消失，旧探索标记也不提供远处人物或物件现状。地点亲见目前按固定两秒观察时点与显式到场处理，寻物沿原身体/路线执行；这仍有持续采样成本，不是完整事件化远区或海量多年规模验收。

**历法/冷热是有限首步。** 同一世界毫秒派生360日简历与四季，原08:00开局保持；地图明确气候范围和昼夜/季节温度曲线影响室外背景，降雨按原晴雨规则降温。实际穿着/湿润决定御寒与暑热负担，走原精力；不新增万能生存条。每分钟采样只改未来，移动/换衣后最多到下次采样才调整消耗，体感可先变化。NPC按原需求/承诺后穿外层御寒挡雨、晴热脱外层。无受管植物等逐分过程的温和远区仍可批算；当前两药丛每分钟同步，风雪、完整天气/生态和多年规模未完成。见[E1 QA](../../qa/20261103_calendar_temperature.md)。

**室外冷热是有限首步。** 温石完成暖身后在原地形成短时热源，固定冷热器物和按定义接入的地面物品也可影响室外场；来源停止、移除或移动后，旧处环境影响逐渐趋向新的环境目标。人体和当前有限草木采样读取同一实际环境温度，普通界面不展示隐藏来源。这里采用按距离衰减、冷热等级抵消的奇幻场，不模拟逐边传热和热量守恒；墙、门、屋面尚不隔绝冷热/五行场，也没有一房一温。人物随身物整体辐射和完整室内空气待做。旧版温石样本见[E2 QA](../../qa/20261103_local_heat.md)，新场接线与验证状态见[环境合同](../../engineering/world-environment-contract.md)和BASELINE。

范围：验证限于当前双聚落和有限居民，不是数百万平方公里模拟、通用迁居/多区生成、战争或规模性能验收。证据：[双聚落连续性](../../archive/report-entries/world-continuity-implementation.md)、[共同时间与生活](../../qa/20261103_continuous_life.md)。主要代码：[regional_simulation.gd](../../../scripts/sim/regional_simulation.gd)、[local_motion.gd](../../../scripts/sim/local_motion.gd)、[route_travel.gd](../../../scripts/sim/route_travel.gd)。

## 4. 自主生活、实物与生计

**已实现基础，内容有限。** NPC根据饥饿、精力、职责与所知安排取食、休息、搬运、制作和部分补料。物品从真实容器取出、随身携带、再交付；预约限制竞争，中断不能复制或抹掉实物。

人身在“生活与办事”里可以亲自送柴、挑水、运粮到灶房、下厨，完成后到功德堂交工。实际劳动形成凭据，有权登记者核验后记贡献；贡献可兑换现有饭食，再吃随身饭。零钱时也有劳动换饭路径。

“采集”页可拾柴、采野稗、汲泉、采野药，并明确选择“自留采集”或原公差送库。两种用途共用同一有限自然来源、预约和完整劳动；自留产物留在原行囊、不记公差，已有同物也不能代替本次劳动。公差仍先采入本人、再实际携回设施，交付后才形成凭据。开关只影响下一次意图；NPC可依据本人库存认识为原职责补料，也能使用相同自留动作。

**野药生态是有限样本。** 两地原野药改用适温、有限土水与真实降雨生长，停用其旧固定两小时增长；原成熟库存、预约与采集仍共用。干时停长，寒冷/过热时休眠，水暖恢复后接续；浇水不能绕过温窗。本人原私水预约、路线和两分钟工时完成后才扣一份，入土或溢流有同笔来源，公差水不能侵占。采到鲜药仍可用于原救护或私料焙药。药丛仅在原可见且近旁条件下画出有限阶段/定性描述，查询不推进生长。首包每分钟同步两个受管地区，显示卸载不停止过程，但不是海量植物/多年性能优化；无种子、植株死亡、完整农业或植物人生。当前“药圃”是原地点和野药来源的单格锚点样本，该格受原施工保护，不能直接盖温室；尚无可框选种植区或通用多格植物/建筑。这不规定未来药田或温室的形状。见[本包QA](../../qa/20261103_herb_ecology.md)及[长期空间合同](../../../design/systems/construction_and_space.md)。

**私料加工是有限样本。** “制作”页可把自己采得的柴粮水煮成饭、柴药草焙成干药。原行囊先预约，实际到灶房/药圃才整批投料点火；燃柴不退，停工保留在制物与工时，选原批续做只付剩余劳动。做成后成品仍在现场，另行实际取回才进原行囊；可在别处安排返回取货，不能远程领取。生产占原身体并消耗原精力，公差/受托物不会转成私人收益，不发公差贡献。饭接原随身吃饭，干药接原有限买卖；两种配方/共用场所，没有工位排队/品质腐败/负重/代工或NPC私人商业规划。证据：[私料加工](../../qa/20261103_personal_production.md)，规则：[personal_production.gd](../../../scripts/sim/personal_production.gd)。

**受托公物是有限样本。** 公差搬运/采集、做饭领料与跨聚落运粮，都认真实领用的一批；同类私物不被自动拿去交差。停工保留实物和责任，普通消费、投喂与买卖只用可处分部分；续做认原批次，不重复领料。也可点击交回，让本人走到原供给点清点归还，满库失败则继续保管，不发额外贡献。买到/自留/获准取食取药的物品继续正常可用；施工料沿原项目链。

范围：低库存自主三日、自留接实际买卖与受托/归还已有证据；尚无完整产权/侵占/追偿/执法、农田/留种、完整产业、通用雇佣/全局经济或饥荒伤亡。旧已取消且出处不完整的混合物仍未分类，不把旧历史全面追认为私物或公物。证据：[生活基础](../../qa/20261103_world_foundation.md)、[有限自然来源](../../qa/20261103_renewable_livelihood.md)、[自留采集](../../qa/20261103_personal_foraging.md)、[受托公物](../../qa/20261103_entrusted_goods.md)。代码：[action_executor.gd](../../../scripts/sim/action_executor.gd)、[inventory_ledger.gd](../../../scripts/sim/inventory_ledger.gd)、[land_resources.gd](../../../scripts/sim/land_resources.gd)、[entrusted_goods.gd](../../../scripts/sim/entrusted_goods.gd)。
