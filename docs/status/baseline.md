**混合活动中的稳定60FPS尚未实现**。最终门版本相对基线时钟工作约少11.4%，但已按用户决定取消3次周期性开关门，并让原门操作员加入巡行；这是模型与负载变化，不将其全部归因于分频。最终样本world_errors为空；仍有发布/视野、真实建造拓扑及未分片原子操作的尖峰。没有为重复量帧时恢复长回归，候选只在[主计划](../plans/foundation-priorities.md)。

当前实际运行：原生人物和共享shader呈现；身体数学可用CPU批执行；普通环境来源候选使用常驻GPU worker，冷块、同步命令或设备失败由同规则CPU路径继续。是否值得调整设备由端到端测量决定。

最终会话累计（**含装配，非仅45秒窗口**）760条携源跨格通知合并261条，采用499条，强制提前采用0；GPU采用499次、失败0。200ms候选的GPU采用次数反而从基线418增至659，且环境阶段累计1807.788ms；400ms候选降低到约500次/1453ms后保留。GPU计数还受同步/异步路径比例影响，不能把它当总场重建次数或吞吐率。

## 共享空间读取的首批实施

基于`9e5b997`实施，已移除普通人物/服务对runtime Node导航的依赖；几何页、路径缓存和来源变化回到模拟层，地图/建筑/植物/大身体仍是原事实owner。投射物现在每边界只准备一次身体输入，按候选量选择同算法串行/线程池，接触与伤害仍按原顺序采用。没有移动整个模拟到后台，也没有把普通路线请求异步化。

同机300人45秒混合release（4身体worker、auto GPU、kernel/render/navigation计时全开）：`logs/crowd-release-mixed-300-20261111-145832.json`，包SHA256 `4dcb3c5953df7257bc51f9f827818c38adbad720a772e82d1dc03a0d5726f875`。实际流速0.992210×、P99 18.704ms、最大29.528ms，世界错误为空；16次搬运、1次生产、22枚飞行物、平均282.79人移动。相同诊断模式的前轮P99 19.085ms；单窗口的微小差异不作为稳定提速结论，稳定60FPS仍未达成。

采样后只整理了寻路便利入口与私有上下文之间重复的端点检查，算法/返回结果不变；最终源码通过相关短检查，未为这次小整理重跑45秒。报告所指发布包以以上digest为准。

本轮原生/服务导航3915次，累计53.584ms（含缓存）；运行中新建几何页0、局部更新168格。空间查询93批/94段，共捕获27900身体行，准备152.567ms、查询4.688ms；**并行批0**，因为同刻飞行物很少，未达4096候选对阈值。身体数学并行仍只有极少批次，不能据此宣称主要负载已经多核化。下一实际成本仍包括身体输入准备及主线程发布。

同输入debug/headless有界探针`logs/multicore-read-probe.json`：普通开局23769格范围、120个读取页，冷补页160.700ms，七次暖捕获中位159微秒；七个私有AStar冷建471.187ms，复用后同一批路线串行8.825ms、4worker 5.097ms，结果一致。暖捕获只分享已有页引用，**不代表首次装配变成159微秒**；不可与上轮整图539ms直接当作同范围端到端倍数。

同探针的300身体×64线段纯候选：串行1.951ms、4worker 0.927ms、8worker 0.843ms，结果一致；不含身体捕获、遮挡和伤害提交，也不是release FPS。首版在每对候选反复访问共享脚本对象，4worker反比串行慢；任务内一次解析packed列后才采用上述实现。另一个不装配Main的短粒度探针在300×16时串行297微秒/4worker153微秒，300×8保持串行；验证当前阈值方向，未据此固定未来所有任务粒度。日志`logs/spatial-grain-probe-20261111-150133-343220100.log`。

相关短检查通过：共享旧页与失效、地形局部更新、私有寻路、候选过滤/等距串并行一致；普通世界中原始通行/掩体对照、真实阻挡植物死亡及一次完整会话捕获/恢复/采用也通过，未写玩家档。集成日志`logs/geometry-integration-20261111-145801-407604700.log`。没有恢复旧CI或长回归，线程实际CPU/等待分解与完整显示发布仍待实现。

## 多核主线的首轮核查

基于`22c3aa7`，只补诊断计数和可选路径跟踪，未改变普通模拟规则、线程配置或频率。2026-11-11的300人45秒混合release仍采用4个身体worker及auto GPU，报告`logs/crowd-release-mixed-300-20261111-142010.json`（kernel/render/navigation计时均开）。世界流速0.989934×、P99 19.085ms、最大29.750ms，无世界错误；这次增加了诊断开销，不作为相对上一包的提速结论。

关键发现是**运行窗口内**身体并行只有home的1批/66行、river为0批；worker经过时间累计61微秒、准备709微秒、采用1176微秒。包含装配的旧累计则是home3批/river2批，不能拿它代表45秒持续并行。新增`actor_execution_capture`在相同世界内给出差值，原累计明确标注`session_including_setup`。Time计时是经过时间，不是线程实际CPU时间。

同一窗口原生/服务路径提供者3915次调用，累计93.227ms，单次最大1.488ms，只有28组不同起终点。数据包含路径缓存命中，不覆盖战斗空间直接搜索；不能据此宣称所有导航总成本低，也不能把这93ms当成当前全部卡顿。主要已计时领域累计为native1.979s、环境1.420s、服务1.034s、交锋0.592s；整个时钟12.572s，其中runtime区间7.479s，存在显著区间之外的发布/观察成本。范围相包含，不能把这些数字全部相加。

另做有界、未进普通运行的CPU重放探针：从上述真实请求取28组不同坐标，在**另建且暂停的普通开局几何**上冻结23769格，使用原AStar搜索、同一格子/斜角/预算规则及每个执行槽私有上下文。先暖一次、轮换执行顺序，每档7个短样本；所有路径与同一冻结时刻的主线程原查询完全一致。报告`logs/multicore-navigation-probe.json`，日志`logs/multicore-navigation-probe-20261111-142656-756983000.log`。

| 同一批查询的执行档 | 暖批次中位耗时 | 范围 |
|---|---|---|
| 相同快照/私有搜索，串行 | 8.943ms | GDScript debug、headless，只测CPU批次，非release帧时 |
| 2个worker | 6.854ms | 真实线程池任务 |
| 4个worker | 5.710ms | 相对相同算法串行约1.57×，不是整游戏提升 |
| 8个worker | 7.156ms | 多开线程反而退化；7个执行槽不等于8核同时满载 |

一次性准备快照539.261ms，建立7份冷AStar上下文402.298ms；原实时世界回调搜索43.700ms另列，不能把其与4worker之比全部归为并行。这条未经增量输入/持久上下文改造的路径**不接入普通运行**，否则准备成本远大于节省。首版探针因28项只分1个chunk未实际并行，修正为7个独立槽后才采用上述结果；未将无效数据当证据。

这次已完成方案、诊断接缝及可行性探针，尚未完成主要计算多核化或模拟线程迁移；当前阶段从[主计划](../plans/foundation-priorities.md)继续。CPU总占用率3%的用户观察没有与本报告同步采样；实际线程CPU/等待分解仍待做，不据此声称硬件已满载。

诊断收尾用一个约7.5秒的临时headless检查核对原生/服务查询结果、结束时恢复回调、运行窗口差值及换世界后拒绝跨世界相减；通过，日志`logs/multicore-recorder-check-20261111-143215-753854900.log`。文档/路径结构检查0错误；未恢复旧CI或长回归。

## 采样精度范围

固定探针使用原衰减与解析响应函数：直线12格、每格267ms、起步偏移137ms、半径4格、tau30000ms、随后停留到10000ms，沿线每25ms观察。100ms采样最大归一化偏差0.002316，对低等级满幅20℃目标约0.04632℃；400ms采样的五行通道1000最大偏差8.624，最大调度延迟396ms。日志`logs/multirate-error-probe-20261111-132906-126821300.log`。

这不是长期、房间重混合、多源竞争或极端速度的误差上限；低等级热源单次延迟100ms的响应比例约0.333%，强冷热来源因此保留精确过格，不用小百分比掩盖大绝对温差。植物仍沿内容的分钟条件采样，只改变各株相位，未宣称大批植物已测得固定提速。机器繁忙不改这些逻辑周期，必要时仍沿共同过载政策缓行。
