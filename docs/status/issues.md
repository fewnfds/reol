# 审查问题与处理状态

当前验证范围见[基线](baseline.md)。旧报告及原始复现条件可从[历史资料](../archive/README.md)定位。

## 系统组合成本

| 对应项 | 当前证据 | 后续遇到相关负载时可以看什么 |
|---|---|---|
| C01 调度 | 个人到期、优先级队列和普通观察准入已经索引化。三千人长窗结束时有 2,910 项观察等候，最老 62 个游戏秒 | 分开测到期准入、候选枚举、视线与记忆落地。可观察完成量与最老等待，避免只把积压搬到规划域 |
| C02～C04 投影与站位 | 本人任命、服务和常用站位已局部化。规划复用自己线索的只读版本。其他消费者仍可有重复投影 | 新的高频消费者按主体、影响范围与实际复用率独立看成本 |
| C05 失效范围 | 部分自然属性与静物布局仍共用失效。密战中身体桶和局部时序的建立有可见成本 | 对照语义稳定的读者、局部版本维护和按活动区域构建的总成本 |
| C06 战斗候选和采用 | 按身体槽与阵营桶减少了近战几何工作，三千人密集夹具仍约 0.33×，受真实活动边界与裁决占用 | 同地可比紧凑数据、局部时段和窄原生内核。多地可比较区域分工及跨区依赖 |

观察和规划的完成量、采样年龄及渲染实测见[性能收尾对照](baseline.md#性能收尾对照)。三千人长期自治、同地满速战斗与更大规模仍缺证据。历史 512 人帧率正常、历史 4,600 人开发场与当前自治负载各有不同活动量。
