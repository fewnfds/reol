# 环境与组合空间规格：范围

本目录维护环境框架与建筑/空间/行动交接的详细规格，未实现部分保留为候选。领域职责查[顶层框架](../../../engineering/architecture/05-framework-domains.md)，建设依赖与出口查[基础建设计划](../../../plans/foundation-priorities.md)。

实际授权和停点只看[HANDOFF](../../../status/handoff.md)，能力与缺口只查[技术总表](../../../status/technical-status.md)，受检版本查[BASELINE](../../../status/baseline.md)。设计按平面地块实现，旧档支持按[有限兼容政策](../../../engineering/compatibility.md)声明，不永久保留旧实现。

实体、物品、运动和工具的公共接入沿[世界装配与创作规格](../program.md)。内部算法和验证服务于所属框架；旧W0–W5和A编号只供Git及历史记录定位，不再形成独立施工顺序。

高度维度的[后续研究](../../../../design/proposals/elevation.md)暂缓，不要求本轮实现坡道、崖壁、射线高度、海拔或多层；本轮围绕平面地表、结构连接及二维环境传播。

已确认概念以[环境规则](../../../../design/rules/environment.md)为准。具体曲线、气象、房间近似与风水利用方式仍按领域设计收敛；五行环境影响与可吸收灵气储量分别处理。

沿用[自洽世界](../../../../design/systems/self_consistent_world.md)、[世界交互原则](../../../../design/systems/world_interaction_principles.md)；原领域设计见[天地环境](../../../../design/proposals/environment.md)和[建造与空间](../../../../design/systems/construction_and_space.md)。[教程、源码与工具取舍](../../../../design/research/world_engine_references.md)给出依据。原有顺序只作历史参考；超凡者为主要玩法、农业只补循环的长期方向保留。
