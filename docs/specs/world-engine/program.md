# 内容、装配与创作工具合同

候选合同；施工与出口归[重构主计划](../../plans/foundation-priorities.md)，实际接入归[当前快照](../../status/technical-status.md)。本页不增加编辑器开发队列。

## 定义、开局与实例

定义保存可复用的物种、材质、能力、配方和规则；开局保存初始位置、数量、关系与状态；实例保存真实变化和过程。游戏概念ID与显示名分开，多个实例共享定义，运行中不改原模板。数据路径及当前引用核查见[data](../../../data/README.md)。

共同引用和能力接口不要求各类对象共享同样字段、继承树或Node。物品数量和独特实例保持各自语义；原物、包含、保管与处分权限分别成立。世界空间/容器索引只保存可重建投影。

会话绑定实际使用的内容、开局/地图生成描述及版本。编辑同ID定义不能静默重解释活世界；候选使用完整一致的规则输入。新架构可以重做文件拆分和装配代码，原格式不是永久兼容约束。

## 独立装配与恢复

1. 外来内容/存档完整校验，构造独立候选；不从活世界补齐缺失身体、物品或历史。
2. 校验身份、地形/几何、占地、容纳、数量和跨域引用，失败不发布半个对象或部分世界。
3. 新局只发行开局事实；恢复不再发行初始钱货、人物、任职或知识。
4. 从原状态重建空间、来源及任务派生索引，核对逻辑时刻/输入段/在途占用，成功后才发布。
5. 保留不可重建变化及必要过程，不用seed替代持续世界状态；兼容按[当前政策](../../engineering/compatibility.md)明确接受或拒绝。

## 创作工具与观察

定义编辑、地图/放置、开局、过程观察和诊断共用内容及规则接口，按框架需要交付最小可操作入口。工具提交草稿或受控命令，不能维护第二份世界/物资状态。预览与正式会话隔离，未知药性、隐私与远区事实不能由普通玩家工具泄露。

批量创作需提供错误位置、原因及必要回滚/取消语义；参数编辑和新增引擎规则分别处理。图形编辑器、插件或通用脚本平台仅在真实需求成立时选择，当前不以先造编辑器作为执行重构前置。

## 数据验证

格式、值域、引用和跨域合法性由相应owner/装配器验证；数据清单与静态文件引用只能证明结构完整。内容改变按影响验证，旧运行测试可重建fixture，但不能通过补造旧世界事实让坏候选通过。
