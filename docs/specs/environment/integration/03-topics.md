# 房温与拓扑接缝候选

本页为[基础建设计划](../../../plans/foundation-priorities.md)中环境框架提供详细候选，不安排独立F2c分包。下述聚合、公式和近似须在实际支持范围验证；当前运行只按[普通环境合同](../../../engineering/world-environment-contract.md)，不据候选宣称已有房温。

## 所有权与组合条件

- 围合与覆顶必须按真实结构推导：当前 `SimConstruction` 的有限工地区域和 `SimWorkplaces` 固定开局房只是起点，不假定已有任意大地图完整房间。新增有界几何查询支持四邻围合、门独立开关和屋顶覆盖；空间归属可重建，但实际房温/锚点属于唯一环境域。功能室依然由人、实物与过程组成，不能由房名自动生成能力。
- 封闭且符合覆顶条件的房间只有一个实际温度。每个房内地块分别取当前冷热源最大值并得净等级，再按实际地面面积平均净等级；普通家具占据的格仍在分母中，火/冰墙作为原结构来源参与，随后房间只乘一次其固定锚点潮汐、查表成目标。门开关使用有限漏热预设，初版不建逐墙热流网络；“开门”与“拆除分隔墙合房”是不同事实。五行场仍可逐格，不强制全房同值。
- 变更前将受影响室外格/旧房按旧目标结到同一事件时刻，完整预检新结构、连带塌顶、物料/空间与全部新空间映射；分房继承旧实际温度，合房以覆盖面积加权平均**旧实际温度**，开敞转室外以旧室温作为相关格的起值，之后才开始趋向新目标。合房瞬时均匀是明确近似；共享墙引用一个原实物，不能双发材料/掉落。失败不扣新增成本或更改任何结构/温度，预算不足保积压；重排房间编号不能错绑持久状态，恢复时须用空间归属及结构独立校验。
- 新房间状态与结构引用通过独立候选联合校验，格式和支持输入遵循[兼容政策](../../../engineering/compatibility.md)，不因本候选恢复旧Q或另建旧档迁入链。实际仍存在的旧引用按真实调用和退役范围核对，历史数据与fixture不改写。
- 验证开门/拆墙分合、来源覆盖跨房、普通建造/观察、进行中材料成本和停开后的同未来；负载与聚合误差按[全项目性能基线](../../../engineering/architecture.md)及本次支持范围实测。采用的模型回写现行工程合同，结果归FEATURES/BASELINE，不沿用原方案的固定地图数字担保容量。

## 使用方式

建筑/空间先提供真实结构、围合和屋面变化，环境按主计划接入房温与响应；旧F2a/F2b不再承担当前施工顺序。具体实现、测试和性能验证归所属框架出口，当前授权及停点只在HANDOFF登记。
