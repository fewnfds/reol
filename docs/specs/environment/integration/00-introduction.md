# 环境接入参考：范围与来源

本目录最初于2026-11-05形成F2a/F2b/F2c候选。原来源、响应、普通接管与退役分包只作为历史定位；当前运行/存读以[普通环境合同](../../../engineering/world-environment-contract.md)和[兼容政策](../../../engineering/compatibility.md)为准。后续施工只按[基础建设与改造计划](../../../plans/foundation-priorities.md)，实际范围和证据见[技术总表](../../../status/technical-status.md)与[基线](../../../status/baseline.md)。

## 资料的适用范围

[温度所有者方案](01-topics.md)与[普通接管方案](02-topics.md)保留当时技术接缝。它们关于待切换Main、旧Q或旧格式导入的表述不描述当前实现，也不产生新任务。普通世界统一接管的结果见[收尾QA](../../../qa/20261107_world_engine_finish.md)。

[房温与拓扑候选](03-topics.md)用于后续环境框架：围合、屋面和原结构由建筑/空间提供，实际环境状态归环境owner，身体/植物消费同源条件。公式、阈值及近似尚须按实际接入验证，不因写入规格而成为已确认玩法。
