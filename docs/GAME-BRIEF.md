# 游戏概念与用户已定边界

本文只维护概念，不管理当前授权、开发停点或实现完成度。授权见[HANDOFF](HANDOFF.md)，功能见[FEATURES](FEATURES.md)，验证见[BASELINE](BASELINE.md)，实施依赖见[ROADMAP](ROADMAP.md)。

## 1. 一句话

在一个持续运转的修仙世界里，主要扮演一名角色，自行选择生活、修行、创造、交往、冒险或组织他人的方式。凡人、修士与非人生命都有自己的处境；玩家在场或离开，世界都接着发生变化。

Reol 来自 reroll，用户取意于 Dota Allstars 的 `/reroll`（重选英雄）。世界感与“这样也行？”的发现来自相接的规则、有限认识与持续后果。

## 2. 已拍板：世界怎样成立

| 概念 | 当前方向 | 规则入口 |
|---|---|---|
| 自由沙盒 | 战斗者、创造者、经营者和角色扮演者可走不同道路，也可中途改变；不统一折算成战力/进度条 | [世界总纲](../design/systems/self_consistent_world.md) |
| 开发重心 | 玩家主要成长为修士、妖魔、侠客或领袖等超凡者；凡人生产支撑世界循环，优先做能力、冒险与局势而非复杂农场 | [超凡者优先](plans/transcendent_focus.md) |
| 玩家是世界的一员 | NPC有自己的生活、认识、算计与个性；组织有目的、资源基础和内部分歧 | [总体框架](../design/systems/living_world_framework.md) |
| 玩家缺席时继续 | 近区细算、远区算法推演，人物/货物/事务与时间不断；归来接续，不能冷重启 | [世界连续性](../design/systems/world_continuity.md) |
| 社会事实有归属 | 贡献归机构记录；欠情归个人经历；名声由见闻传播；礼遇、信任、实利与卖命分别成立 | [社会交互评审](../design/systems/social_interaction_review.md)、[总体框架](../design/systems/living_world_framework.md) |
| 机构与人分开 | 职位、任职者、财产、签发与兑现能力分开；换人可能改变旧承诺的承认与价值 | [社会系统提案](../design/systems/social_system.md)；具体继任算法/权重仍是原型 |
| 有限认识 | 真相、可感知信号、领域理解、当前关注与界面表达分开；高手不全知，外行也有独到经验 | [人物视角](../design/systems/perception_and_understanding.md) |
| 世界先于固定面板 | 身体、方法、器物、经历、环境和协作决定可行动条件；内部可数值化，不强制所有生命共用属性表 | [众生](../design/systems/beings_and_lifeways.md) |
| 衣着与物品 | 衣着有审美、身份、生活和社交价值；非人人战士；宝物不等于拿到就懂、穿上就能用 | [衣着与物品](../design/systems/appearance_and_possessions.md)、[知物与用器](../design/systems/knowledge_artifacts_and_invention.md) |
| 学习与修行 | 无固定职业锁定；选择、师承、知识与实践形成能力；大型网络表达联系，允许改良/创法 | [修行与学习](../design/systems/cultivation_and_learning.md) |
| 修行机会 | 多数生命原则上有适合自身的路径；少数需改变先天条件，不保证所有生命能学一切 | [众生](../design/systems/beings_and_lifeways.md) |
| 地方差异 | 术法依资源、知识与权力普及，并真实改变当地生产、贸易与权力结构 | [世界总纲](../design/systems/self_consistent_world.md) |
| 自洽先于平衡 | 允许强弱悬殊、稀有能力和主角例外；能力有真实成立条件，不靠临时改规则纠正聪明玩法 | [世界总纲](../design/systems/self_consistent_world.md) |

“百年闭关”用来说明时间与社会变化，不是必须实现的剧情；《骗经》、神剑、戒中老人、麻雀与古兽用于检验不同知识、身体与生活处境，不是逐项已完成的内容清单。AIRP是开放设计视角，描述和生成文本须落到可执行规则才能改变世界。

## 3. 已拍板：玩家怎样行动与续生

- **单角色人生为主**：可以协作、雇佣、经营和下达命令；不默认直接操控所有成员。开局身份范围逐步扩展，杂役是原切片起点。
- **实时、可暂停**：战斗借Hades的衔接、DNF的招式表达、LoL的可读性与Warcraft III的小队层次；这些是参考方向，完整动作/技能列表不是固定答案。高阶局部慢放保留为后期设想。
- **日常与主动快进并存**：可跨年，重要消息/危险能打断；时间比例、阈值与性能预算由开发测试。
- **普通死亡通常魂散**：保魂/寄魂等需具体方法和条件，不能全世界人人无限轮回。
- **主角有限转生**：世界不回滚，可小幅前跳；从跨种族新生候选中选择接续，高难度次数更少，耗尽结束本局，暂不设计增加渠道。重选/自选/稀有度操作的具体消费方案待做；不得通过屠杀候选人口保证极品或无限洗牌。退隐接续不能形成绕过有限次数的免费旁路，具体事务随原型处理。

出生、成长、有限候选和防利用的详细设计见[有限转生](../design/systems/rebirth_and_new_lives.md)。现有三种一次性开局不等于已经实现死亡/退隐接续。

## 4. 最新收集：环境与交互扩展

详细记录见[世界与交互原则](../design/systems/world_interaction_principles.md)，包含用户方向、澄清与开发建议。

| 方向 | 已明确的体验 | 仍由设计/原型决定 |
|---|---|---|
| 环境与生态 | 天气、温度、植物与非人生活相互影响；植物既是材料来源也是世界生命 | 模拟精度、生态细节、更新预算 |
| 五行与风水 | 万物非消耗影响、同位同类取最强；冷热也用源场和渐进响应，不追求逐格热量守恒；可吸收灵气由原物品另持储量 | 源场算法/生克/布局与规模性能；积攒容量、速率与变化后置 |
| 建筑与破坏 | 模块化墙/门窗/家具/房间，场景对象和地块可改变 | 完整建筑蓝图是否有用、结构/损毁模型 |
| 灵活组织 | 玩家可构建联盟、隐秘结社、山寨、宗门等，不固定为种地招人的基地模板 | 第一组治理动作、成员权责与编辑界面 |
| 自动策略 | 玩家编排本人/下属策略；命令执行受实际通信、认识和社会规则影响 | 策略语法、模板、可视编辑与调试方式 |
| 通用交互 | 提出事项后，对方依自身状况理解、回应与行动；交流可发现能力 | 通用意图格式、先合并哪些专用入口 |
| AI与兜底 | 自由文字主要面向未来AI，动作/对象/条件补全面向脚本；无AI也可玩 | 模型、接入、生成边界与运行成本 |
| 世界对象 | 活物、植物、物品均可寻址和作用；内部能力按对象实际需要组合 | 具体接口，不预建全量ECS |
| 顺滑运动 | 即时移动/战斗应顺滑，格子主要承担空间与放置边界；性能优先 | 连续/离散混合方案及规模实测 |

树开局是启发性例子。优先有微弱意识和可选择的生活；被动终老由玩家选择，不随机强迫，也不默认树都要化人。

2026-11-03补充：基础环境采用同一时间上的历法/气候/局地温湿，五行亲和与真实灵机分别建模，风水由真实山水/建筑/源流产生，不设全局吉凶条，见[具体方案](plans/world_environment.md)。人物要求真八方向、解剖左右不变的持物/挂件、逐方向/动作遮挡与共享相位，见[外观方案](plans/eight_direction_appearance.md)。用户方向已确定，具体历法/采样/帧数/预算由开发测试调参；各子集是否实现只看FEATURES与BASELINE，不按本愿景段落判断完成度。

2026-11-05已确认：物品可以浸泡在五行辐射环境中积攒可吸收灵气；环境浓度不因修炼或积攒被扣减。先完成大世界的来源、场、空间与性能框架，再定容量、积攒规律和物品变化。具体合同见[五行环境与灵气](plans/world_environment.md#5-五行环境影响与可吸收灵气分开)；此前将环境五相浓度当可消耗库存的建议不再采用。此概念尚未实现。

## 5. 技术与制作边界

Godot **跟进最新稳定版（当前安装/验证为4.7.2）** / GDScript；这是用户2026-11-04的版本策略澄清，不是本轮已升级引擎。每次采用版本与验证记录看BASELINE，工具兼容/升级路径看[套件选型](AI-TOOLKIT-REVIEW.md)。先Windows；2D固定正交俯视、正方形格，相机平移/缩放，不旋转。当前世界引擎先平面地块，高差/坡道/多层后置，原样本不追改，旧实现按[有限兼容政策](COMPATIBILITY.md)退役。首区512×512格、64×64区块是当前基座；不等于完整世界的永久面积上限。当前格子像素尺度和国风占位色盘是开发实现，正式素材尺寸/风格待测。

单机模拟网游般的群像生活；不做真实MMO服务器、账号或联机。规则与脚本/效用AI保证基础可玩，未来AI可参与理解、对话与计划；实际行动仍由共同世界规则执行。未授权安装运行时模型或新依赖。

先让玩法与世界循环成立，再做正式美术音频。可借鉴并依法使用可商用资源，也可代码制作；候选资源不自动成为依赖，见[资源与工具研究](plans/resource_tooling_scout.md)。

## 6. 参考坐标

| 参考 | 主要借鉴 |
|---|---|
| RimWorld、Dwarf Fortress | 自主生活、相互作用、历史和失败叙事 |
| Kenshi、修真小说、模拟网游 | 玩家只是众生之一，多种身份与力量尺度 |
| 饥荒、缺氧、异星工场 | 环境约束、循环、可组合过程和自动化反馈 |
| 修仙模拟器、鬼谷八荒、太吾、觅长生 | 修行、师承、时间、人际与地方文化 |
| Warcraft III、战争游戏、Warhammer | 空间和单位可读性、组织行动、局势与冲突 |
| Hades、DNF、LoL、PoE | 动作承诺、招式/技能表达与开放能力组合 |

参考是提取可验证机制，不是把这些游戏总内容相加或换皮。来源与取舍见[研究索引](../design/README.md)。

## 7. 制作分工与侧重点

用户决定游戏概念和全局方向；开发自主处理常规架构、算法、参数、平衡与测试。优先让世界引擎可运行、可编辑、可测量，再装配内容；超凡者战斗/法器/学习功法/冒险/组织仍是玩法重心，凡人生产维持基础循环。

当前使用代码生成像素示意图，不等待外部美术；正式画风未定。真八方向、解剖左右不变和不对称挂件合同保留。完整45–60分钟切片仍是内容出口，不把原型或通用引擎通过当作完整游戏。

历史选择理由查询[DECISIONS](DECISIONS.md)，被后来用户决定取代的固定阵营声望、全角色人形战斗面板和四向镜像不再约束当前设计。
