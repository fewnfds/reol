# E2：屋舍与有限余热

2026-11-03。有限首包已接线并验证，证据见[QA](../qa/20261103_local_heat.md)。承接[环境方案](world_environment.md)的E2，当前构建与最终检查以[BASELINE](../BASELINE.md)为准；不是完整热力学或大世界规模验收。

温火石的原持有人理解导热方法后，可用原身体花一分钟将一份原储热释在实际所在格。完成才扣原charge并留下唯一来源凭据；取消不扣储热、不提前放热。与煮饭、烘药使用同一器物、同一储量、同一身体占用。受伤不能继续引流，不能通过菜单获得别人的器物。

`SimLocalHeat`只拥有相对室外背景的正余热，不复制天气、人物精力或温石储量，也不冒充完整绝对热力学。整数能量属于稳定空间格，房间编号不拥有热量。源格为中心的5×5有限近场、最多512格；外边界视为室外浴，屋面改变散失，墙和关门减小导通，开门增大导通。首包墙/关门同系数、空地/开门同系数。预算不足拒绝新源，不移除旧热量。参数由数据定义，后续依据实际玩法调整。

全局十秒格点冻结整数通量。普通额外查询/时间切分不重采通量；真正放热或结构改变先结旧段，再采新导通。边只计算一次，内部同额收支；始终满足`各格现存量之和 + 已散失 = 总投入`。拆墙、开门、塌顶只改变未来，不因重建房间或卸载显示区块复制/清空热量。无流稳定段不持续唤醒远区。

区域共同时间先结余热旧段，再处理同刻器物和施工。环境先按旧缓存同步原人物精力，再采该分钟的热场及实际位置/穿衣，存为未来消耗依据。局地余热可能改善寒冷，也可能造成过热，不能被“室外舒适”快路吞掉。NPC预判仅只读投影当前冻结段，超段明确未知，不推进热场未来；正式动手重新检查实际条件。原initiative实际选中后才留同刻临时交接票，失效回原职责，不抢其他身体动作。NPC先处理原需求、健康、衣着与已有职责，再考虑本人持有的有限温石，不凭空生成热源。

当前激活格和来源历史永久保留、不回收；512格满后拒绝新源。首包无连续移动源/负余热/不同材料容量，不能将该实现限制当世界法则或无限规模承诺。

根32/区域28新增局地余热；环境v2每条历史样本增加`heat_tenths`。旧v31在原保存时刻启用空余热，原环境采样只补零热分量，不重采过去，不改天气/衣物/身体/雨水。新档恢复独立候选，核对热量守恒、冻结通量、实际几何、来源动作及历史环境采样后才替换活世界。真实旧fixtures只读。
