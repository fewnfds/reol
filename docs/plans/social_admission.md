# W5-a：口头资格、个人采信与实际放行

2026-11-03。有限链样本已实现并验收，见[实际证据](../qa/20261103_social_admission.md)。前置已有个人库存说法、机构正式通行、真实取药、共同身体/毫秒与联合存档。用户要求本包收尾后暂停Goal，转入进度通报与理念讨论；不自动开启下一包。

目标：玩家声称“我已领到当地药圃通行登记”，普通同门可能暂时相信并允取一枝药；有权核簿的管事要求另行核验。相信、现场放行、正式资格和真实物品分开。相同入口也供NPC使用，认出问题只改变实际知情者的记忆。

范围：只检验一条有明确内容的口头资格链，不造完整伪装/衣着/幻术、任意谎言解析、万能信誉分或全局通缉。首样本仅人类原生同聚落；登记簿沿原机构域，由有权管事当面花时间检查。普通同门提供的是自己承担的一次临时放行，不能签正式凭据。

规则：

- 交谈四个方法：口头声称、出示本人实际通行凭据、请有权者核验、出示本人真实核验回执。前两种信号不自动揭示真假；只有实证模式可读取出示的证据。
- 使用原身体与通信/执行权；花费共同时间，期间不能另做劳作/器物/服务/对练。对方不被接管，完成时已离开则没听清；取消不倒退世界。原NPC可自己用同一API发话。
- 普通接收者按已有有向信任/性情和事项风险，复用原社会骰与条件缓存；不把声称是否真实偷偷塞进评分。相同内容、方法和已知依据连点不重掷、不延长放行期限；时刻/饥饿变化不算新证据。有权者对口头说法要求核验，不能远程神谕识谎。
- 临时放行只准一次原取药动作、有效十五分钟，实物仍须原人前往原药圃劳动取得；没货/被撤销/已使用会失败。取消取药不耗尚未交付的额度，但不延长有效期。一次放行不变成正式贡献或永久通行。
- 当面核验读取当地机构登记，保存签注/缺档依据与核验者。说法被本地账证反驳，只让本次双方知道；另一同门不会自动改变态度。实际出示回执才让该人知道、收回自己的相关临时放行；已到手的药不倒扣/复制。

文件：新增`SimSocialAdmission`与schema、定义JSON；区域时间/动作互斥与持久化接缝，原服务取药增加明确的一次临时依据，原交谈页/运行适配。真身体/库存/机构/人际关系继续归原域，不在新域复制。既有场景不手改。

存档：根14/区域11/临时放行1，真实v13显式迁空新域；原样v1–v13及overload_v10不改。新域保存进行中交谈、原请求引用/结果、私人核验回执与临时放行使用记录；候选交叉核对社会事件、正式凭据、服务实际取药事务和身体占用后整体提交。

验收：同一句口头说法面对普通同门/管事产生可解释差异；假说法不改正式账目与库存，实际许可后才按原过程取到真实药；重复不重掷/续期/再生额度；核验不全知传播，真实回执能改变第二名接收者判断；NPC可发起同类说法；打断/失控/离场/旧档/完整JSON与新进程一致；坏同意、假核验、双用额度或双占身体候选原子拒绝。完整check与1280×720实机截图、进行中完整重启齐全才验收。
