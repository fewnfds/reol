# W7-a 多格形体与边缘接触

2026-11-03；有限首包已交付，证据见[QA](../qa/20261103_large_bodies.md)，最新构建以BASELINE为准。

目标：把已有3×3古兽定义接到真实身体、通行和联合存档中。玩家从身体边缘接近并递食；离场后山兽继续走动/休憩，不能借远区省略挤过窄路。

## 本包规则

- `SimBodyGeometry`为无状态的矩形占地/净空/逐格移动/有界寻路。身体中心对应奇数格占地；每个覆盖格都须为可走地形且与身体其余部分高差不超过一层。斜行两侧均须有净空，不能切角。
- 首样本仅3×3方形；四向转身不改变方形覆盖，不声称已有任意角度旋转或长条身体的转弯扫掠。几何单位格与已有连续世界坐标之间保持明确转换。
- `SimLargeBodies`拥有唯一兽身位置、地盘中的两个休憩点、当前一步/待行路径、重试和最近进食时刻。不是Village人形的复制品，也不新建兽背包/灵气/全局社会属性。
- 开局从附近真实地形寻找可容纳的地盘，避开原设施、人物和已知来源。主体/载体按原Embodiment登记。旧档迁空，不在读档时凭空生兽。
- 路线按完整占地寻找；每步开始前检查真实墙、人与在途目的格。一步行进中占用起止覆盖的并集，人类通行、落鸟和新施工不能穿入该扫掠区。已有路被挡时等待/重算，开放后续行；不推走NPC、不穿墙或传送。
- 原时钟驱动连续位移与休憩；远区同样结算。原有限食物可经C统一请求“递食”在身体边缘给出，只接受手势；不能听懂鉴定要求。递食是一次接触提交，直接消耗原行囊可处分饭食，保留原操作凭据；走动/饱足时拒绝，不增加好感条或瞬间驯服。
- 可见文字只说外形和当前可见动作，不显示远区实时状态或私有地盘目标。兽身不是新增可选开局。

## 实施接缝

新增定义/开局、纯几何、尺度域/候选校验、Node2D视图；复用原C请求门面、库存consume、Embodiment、RegionalSimulation边界和联合候选替换。建筑域的占用查询扩展为包含兽身；不改第三方addons或手工场景资源。

根schema 23→24、区域20→21，尺度域1；v23只迁空尺度域并保留所有旧状态。真正旧fixture不改写。现代候选校验形体/引用、共同时间、进行中插值、路径相邻、地盘范围、原食物凭据、身体互斥及真实地形，再替换世界。

## 验收

1. 同一窄路人类可行、3×3不可行；宽路可走，堵墙会改道或等待，斜角/地图边缘/崖面不得穿过。

3. 真实主场景能见山兽连续运动，原人物不能进入扫掠占地；施工不能在其脚下完成墙体。
4. 粗细推进、离场、原进行中存读和完整进程重启获得同一联合未来；坏候选原子拒绝、v23显式迁空。
