# 完整游戏验收矩阵

方案日期：2026-11-02。本文是**长期目标验收矩阵**，未在此整项勾选通过；有限实现与证据见[FEATURES](../FEATURES.md)/[BASELINE](../BASELINE.md)。超凡者优先，F/P编号为验收领域；当前先平面世界引擎、Goal已暂停，见[执行记录](world_engine_execution.md)。容量与推荐范围沿[长期方案](full_game_program.md)。

测试目的不是证明“有这个类/按钮”，而是证明玩家、NPC、物资、时间、认知、制度和失败后续能够一起成立。现有测试可作为回归基础，但不能把已有双聚落成功外推成整个矩阵已通过。

人物/战斗细化另见[组合验收CC1–CC14](combat_character_design.md)，约束是无固定职业、衣着的独立社交/生活用途与实战本领来自学习。部分动作/穿戴已有限接入，不等于组合标准全数完成；用户授权和暂停状态以[HANDOFF](../HANDOFF.md)为准。

[世界先行W-A至W-L](world_first_sandbox.md)补充并提前检验多种生命、跨用途作用、有限认知、条件用器、欺骗/核验、独立寄魂、方法创造与远近连续。旧人类出身/形体/学习节点不作为所有生命的验收模板。允许力量不均，先验因果一致与完整生活；若干有限样本已有交付，完整共同局面与各包出口仍需分别验收。

## 证据格式与通用要求

本次增加超凡者体验门槛：首小时尽早接触超凡能力；至少三种实际不同的能力组合可解决问题（不要求全战斗型）；至少两种路线处理同一冒险/争端；一次学习改变真实可行动条件；一次个人选择改变他人/组织局势；无玩家介入的对手或组织也行动。普通生产是可选筹备与世界来源，不以反复农务凑时长。事件化远区另验中途介入、旧计划失效、资源唯一归属、消息延迟及存读不重掷，详见U方案；以上均未提前标通过。

每条测试记录：构建/内容版本、种子、初始fixture、推进方式、玩家或NPC操作、期望与实际、命令/日志/截图路径。不可把开发工具直接修改库存、权限、胜负当正常玩法验收；确定推进世界时间可用于可重复测试，实际UI通路另验。

自动化分三种：纯规则及不变量；runtime/快照/导航整合；有代表性的长局/性能脚本。人工验证检查正常操作、可读反馈、选择与失败恢复。每个包只增加能证明行为的必要测试，不为低影响排版复制实现细节。

所有涉及持续事务的场景增加共用变体：中断/取消、相关人物死亡或失权、最后一份资源竞争、离场、执行一半存读、重复命令、无效引用。按真实领域选择适用项；不机械制造所有组合。

## F1：普通人可以生活

对应P1。不依赖无限初始赠送或隐藏补库存。

| ID | 给定与操作 | 必须观察到的结果 |
|---|---|---|
| F1.1 | 初始盘缠有限，连续数日靠合法劳动和交易吃住 | 工资来自雇主预算；投入与产出有来源；形成下一周期供给 |
| F1.2 | 粮食/水/柴中一种短缺，玩家选择求助、生产或迁往别处 | 有提前预警、实际损耗及至少一条可行动恢复路径；NPC也应对 |
| F1.3 | 两人同时抢最后一份食物或材料，一人随后取消 | 最多一人持有/消耗；预约不遗留、不复制；另一人合理改选 |
| F1.4 | 商人钱或货耗尽，重复出售；雇主无钱发薪 | 拒收、换物或债务按明示规则；不是无限金币/悬赏机器 |
| F1.5 | 正常条件推进多周期，再移除一个关键工人/工具 | 产能随真实约束变化；其余人可重排、雇人或缩产 |

## F8：完整玩法Alpha

对应P8。以下是发布候选所需门槛，不是要求所有随机世界永远和平富裕。

- 从三种出身各完成一次完整通路，可在生活、经营、冒险之间转向；三可玩境界与长线目标均有实际内容。
- 选至少10个固定代表种子，覆盖平稳、贫瘠、封路、资源不均、战争后恢复；每种先验30日，再选代表跑365日。数量是初始测试预算，发现新问题再增，不重复跑无价值样本。
- 检查实物/货币源汇、人口收支、不可达工作、悬挂预约、未结事务、记忆/历史大小。预先定义各场景“允许失稳的局部结果”和“系统性失败”，不能出结果后随意改通过线。
- 使用临界fixture和F7.8长跳时覆盖世代，不用365日全员未老的结果证明寿命机制成功。
- 用正常操作开展5–10实际小时完整历程校准；测试有趣的选择密度与重复劳动，不用快进空白硬凑内容。
- 已知重要失败均能说明主要原因与下一步。玩家可查其合法可知的记事、账页和渠道；不开放全知调试数据替代说明。
- 作者自测后至少3轮陌生人任务试玩；记录完成目标、迷路/卡点、是否读懂拒绝和是否被迫读档。外部试玩尚无人参与时如实保留待办。

## F9：正式视听与资源交付

对应P9，进入批量生产前先锁一张可玩的样板。

- 白天/夜晚/迷雾/拥挤/战斗下，玩家、同伴、敌人、设施、危险、前摇与伤势可辨；颜色不是唯一的信息渠道。
- 1280×720、1920×1080及一个宽屏比例下，缩放/长中文文本不挡关键操作，支持可读字体与基本操作提示。
- 资源族比例、锚点、动画帧和地形拼接一致；替换贴图不改碰撞、命中和可走性。
- 快进、远区批算、读档不会连播历史音效；总音量/音乐/效果独立，静音不丢规则提示。
- 清单逐文件/部件关联原来源、确切版本或哈希、许可、修改和署名；发布包实际包含必要文字。免费、开源、可下载都不是许可验收的替代。
- 导出后检查缺图、缺字体、透明边、循环音、内存/包体，不能只看编辑器预览。

## 未通过时如何收敛

先定位为规则错误、状态交接错误、信息解释不足、内容不足或纯性能问题，再建立最小复现。不得用补库存、重置人物、删历史、扩大初始赠送掩盖原因。可以在保留因果的前提下缩小人口/地图、减少配方和同时事件、简化房间细节、降低远区重复评估频率。

每阶段给出“通过/未通过/未验证”的证据清单。路线、设计和Goal完成状态必须对应实际交付；此矩阵是验收标准而非当前完成功能表，不在此提前登记未来F出口通过。实际工作包证据由BASELINE及对应QA维护。
