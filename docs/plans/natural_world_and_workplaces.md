# 自然地块与可组成的办事场所

日期：2026-11-03。状态：有限基础已实现，最终行为与验证以[BASELINE](../BASELINE.md)和本包QA为准。用户要求自然世界更丰富，并以房间、区域、家具和人物提供服务，取代一个功能一个成品建筑的测试场表达。仍遵守[超凡者优先](transcendent_focus.md)，不借此继续扩展复杂农务。

用户随后要求把起居、装饰、各类工作台、知识/食物/法宝储藏及人与设施交互扩成长期规则，并授权后续按玩法需要主动补设定，详见[建造与空间](../../design/systems/construction_and_space.md)。本页只记录已实现的自然/固定场所首包，不将长期设施目录算作完成项。完整Goal已再次恢复active，下一玩法包见[U1-a](transcendent_conflict.md)。

## 办事场所的规则

“功德堂”首先是组织中的职责和日常活动；它可以在一间有桌案、档案柜、记功法器的房间内发生，也可因破坏、搬迁和人员离岗改变可用性。墙围出房间，家具提供具体用途，人以当前职位和授权办事，记录载体支持查验和记账，实际库存支持兑付。摆桌案不产生职位、贡献和可兑物资；空房有匾额也不能自行发任务。

正式公账仍归原 `SimInstitutionBook` 的机构/职位账目。实体账簿、档案柜、法器是承载、访问和核验这些记录的物理条件；长老的私记仍只能提供个人记忆或证据，不能因此取得公账效力。首包不实现偷账、烧账、伪造、司法或完整记录同步。

## 现有实现核对

| 接缝 | 实际行为 | 本轮应改变的部分 |
|---|---|---|
| `SimConstruction` / `SimEnclosedSpace` | 已有真实墙、门、屋面、床和派生围合；目前限单个宗门工地 | 可复用围合算法，不能把现有单工地冒充全部聚落建筑 |
| `VillageSimulation.places` | 每个用途是一个带名称的目标格，同时对应库存容器 | 保留稳定ID和事务锚点，组合独立空间、家具和使用站位 |
| `FacilityVisuals` | 多数用途统一画为完整房子图标 | 改为可读的地面区域、墙段、开口和家具；围墙必须接通行，不能只有画面 |
| `SettlementServices.issuer` | 找到附近仍活着且有权限的人即可 | 对需要公账的事务追加工作场所/可用记录的检查 |
| `VillageSimulation.report_work` | 原生日常的另一条记功路径 | 与来访服务共用接待/记录条件，防止绕过 |
| 陈守拙日常 | 原职责是巡查，不是常驻办公 | 无吃住或其他紧急动作时实际回办公站位；不能传送到桌前或冻结在岗 |

现有施工定义严格限四种 `wood_*` 构件；施工快照严格限单 `sect_yard`。通用聚落建筑不能直接塞进此格式而忽略材料、来源、原工作和历史兼容。`SimMethodRecords` 是已学习方法的实物记录，不能为了复用名称把官方贡献账伪装成一本温养功法。

## 有限实施建议

先把值事房作为可运行样本：房间/开口、桌案、档案柜或固定记功载体、接待站位与原机构职位共同支持原报工和兑付。其他场所表达为灶台与用餐区、货架与储物区、床铺与住区、自然药地和水源，逐步接同一规则，不增加一批孤立功能按钮。

纯规则评估只读原状态，返回场所、当前权限人、可用家具/记录与失败原因；它不另存余额、库存、人物位置或一份接待锁。人物在岗使用真实位置和原活动，进入场所需原寻路。公账事务在提交前再次核对任职、接待条件、记录与库存；失败不记功、不扣贡献、不转移物资。机构换任使用原职位持有人，旧记录不会因换任重建。

当面谈买卖、提出请求和口头约定不必全部强制发生在桌前；正式公账核验、实物交割等分别检查各自真实条件。不要通过全局削弱 `has_permission` 把外出的长老变成没有职位的人。

## 保存与边界

围合、房间用途汇总、可接待性、界面说明和渲染可以由保存的构件/区域/人物/记录位置派生，不需另存这些查询结果。固定开局布局可以作为场景初始条件，但一旦可搬迁、拆除、损坏、携带记录，变化必须有持久状态和显式校验，不能每次加载按当前定义重新生成。

旧档保留原位置、在途事务和原账目。若首包采用新的场所状态，需明确迁移启用政策；不回填“过去早已建好”的办公屋，不以新场景覆盖历史配置。修改真实碰撞后需验证旧路径和站位，不能让人物凭空困在新墙内。所有历史fixture只读。

## 场所验收

- 相同家具放在没有授权人的房间里不能发放机构贡献；私账不具公账效力。
- 有权人不在、记录不可用、所需库存不足时，分别给出可解释结果，钱货与余额不提前变化。
- 离岗办吃住等日常后实际返回；接待期间不同时执行另一项占用身体的动作。
- 后续改建包：拆墙/屋面与移除必要家具按各自条件改变场所；本包固定开局值事房不提供拆迁入口。原玩家施工门墙、床铺与屋面仍可按原规则改建。
- 进行中保存/恢复与近远推进使用同一人物、同一账本和同一库存，不补新奖励、不重建记录。
- 新局实际可见屋内家具与人员活动；通路和服务通过原玩家入口可用，保留旧玩法回归。

## 本轮实际自然基础

`WorldMapData`继续唯一提供原水/草/岩通行与高度。在其上用同一seed和坐标派生以下数据，`NaturalEnvironment`的4096格缓存只保存可重建查询，不是另一份存档事实。独立读档候选有独立地图与缓存。

| 层次 | 当前实现 | 范围与边界 |
|---|---|---|
| 地表 | 山泽水面、山岩、含矿岩脊、溪岸湿土、湿地、山林腐殖土、砂砾薄土、肥沃草甸、山间草地 | 不改原静态碰撞/高度；含矿外观不等于可开采矿脉 |
| 物理潜力 | 湿润潜力、肥力、矿质、冠层潜力、曝露、近水及植物适生度 | 湿润潜力不是原土水库存；实际降雨、温度、药源土水仍由原域拥有 |
| 五行 | 金木水火土向量、主导亲和、相生相克查询，地表与植物具有不同物性 | 这是仙侠世界的虚构规则，不冒称自然科学；亲和不是灵力存量，不免费恢复灵气、不变成全局五色声望条 |
| 植被 | 松、竹、灌丛、蕨、野药、山花、长草、蒿草、芦苇、水生叶、岩衣、石苔的稳定覆盖与原创像素外观 | 本包覆盖物没有独立砍伐/生长/死亡；原有限林料/野药/泉水依旧只能通过真实来源劳动取得 |
| 动物 | 原两只雀妖与山兽保留；新局两地各加一只普通山雀；根据生境、巢距和可落脚空间选择原食物点 | 普通鸟不懂请药手势，但可吃食/歇翅/投喂；共享原食源，不新增免费食物；鹿兔狐鱼等只是栖地定义，尚未生成活体 |
| 观察 | 右键观察眼前地块、地表/土质/植被与原自然来源；房内显示铺地/家具/遮雨 | 不公开实时远处信息、数值五行或未知灵药身份；魂身沿原专用感知，不获得物理地面检查 |

原灵源仍由`SimSpiritSources`保存有限储量、深层供给、预约和支出。当前只接原火行地火隙；地块火亲和不能代替这个来源。原药源按原温窗/土水/雨水生长，本包不回填新的生长倍率，以免改写旧档历史。

地图继续用`TileMapLayer`，增加地表与透明植被图集，不为每棵草建Node。运行流式每帧最多处理256格；跳转焦点或换图会清理未完成区块。正式美术后置。

## 本轮实际场所与兼容

新主场景在两聚落分别找同高度、可到达、无原人物/地点重叠的真实5×5或5×4地块，按构件布局保存值事房。它含墙段、开放门口、木地面、屋面、桌案、档案柜和一个引用原机构的固定记功簿。画面采用切开屋顶的视图；实际墙与桌柜接通行，屋面接原遮雨，墙/屋面查询也接回原有限余热。值事房地块不允许被原工地登记重叠覆盖。

这是固定开局房间的构件样本，**尚不是玩家可任意指定、装修、迁址的通用房间系统**。现有施工域仍有自己的实际建造/拆改，不把这套固定开局布局偷偷塞进其材料账。灶台、货架、床铺与药丛外观取代成品房子图标，但除值事房外，其他用途仍沿原单点库存/行为；不声称已做所有真实厨房/仓库/宿舍。

职位、贡献和交割仍归原机构账本与库存；场所只增加办理条件。记功簿的稳定ID和机构引用保存在原`places.records.workspace`中，不能改成私人机构的簿册冒充公账。它目前不是可携带/损坏/盗取的通用物品；个人账本、私记、柜中多份记录与法器同步仍待后续。

在岗人使用原身体/位置与真实归岗visit，吃住和明确劳动约定优先；原生报工与来访登记/兑付/授权共用场所判断。当前来访人与值事人仍共用`records.cell`接待目标，不是完整座椅、排队或多柜台。

新局显式启用`workplaces_version=1`与`workspace_return`，布局原样入现有地点存档。旧档不补造房屋/载体/鸟群，继续原柜台规则；加载后再次保存和候选验证仍可接续。兼容比较只显式分离可选场所配置，原资源定义和其他配置仍严格比较。现代布局损坏、错机构、额外家具/位置篡改等在独立候选中拒绝，失败不改活世界。根schema34/区域30保持，所有历史fixture只读。

## 接下来如何扩展，而不倒回种田主线

1. 将地块亲和用于实际功法、阵位、法器准备与秘境风险；真实五行源汇先有物/时间/方法，再发生转化，禁止从亲和值直接发能量。
2. 关键灵木/灵药/矿脉升级为可辨认、有限、可受损的原生对象；稀疏覆盖仍批量表示。不先做完整农务、牧场或繁殖工业。
3. 玩家建造桌柜/记录器、指定房间区域、迁移原载体和安排任职后，才获得新办事地点；无职位/档案时仍不能记官方贡献。
4. 房屋受损、载体遗失、人员外出分开影响服务；记录损坏不等于抹去所有债权，争议回到证据、见证和机构继任规则。
5. 动物/妖类扩展捕食、领域、迁徙和势力事件，与超凡探索、修炼和冒险接通；不以补齐每种现实生物作为战斗/功法前置。

参考研究见[来源核查](../../design/research/natural_world_workplace_sources.md)。完整回归、实际运行和边界以本包QA/BASELINE为准，不从表格数量推断完整生态或风水已经完成。
