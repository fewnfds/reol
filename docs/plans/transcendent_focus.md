# 超凡者主线与事件化远区：实施优先级

日期：2026-11-03。用户明确纠偏：先让修仙、妖魔、侠客与领袖的体验成立；凡人生产提供自洽世界的循环，不继续做复杂农务。用户随后恢复完整游戏Goal为active。本文调整顺序，不删既有玩法、不改变单机/有限认知/共同规则/有限转生等决定，也不把目标写成完成项。

## 1. 复杂度投入在哪里

| 范围 | 当前要求 | 何时继续深化 |
|---|---|---|
| 农业、采矿、狩猎、吃住 | 维持有限来源、补给、材料、工时和代价；缺料有恢复途径即可 | 超凡者冒险/炼制/组织行动需要具体约束时 |
| 天气、温度、房屋、生态 | 保留已有因果；暂停浅沟/导流、精细农务、复杂湿热和更多生活按钮的扩展 | 能直接改变战术、秘境、灵地、阵法或资源争夺时 |
| 战斗与装备 | 高优先；读动作、位移、距离、打断、技能组合、武器/法器行为与受伤后续 | 从下一轮正式玩法包开始逐步增加 |
| 学习、武学与修行 | 高优先；师承/领悟/试验/传承、功法运转、准备与代价、突破和不同成长路线 | 与战斗、非战斗术法、冒险和组织权利同时连接 |
| 冒险、任务、组织 | 高优先；真实目标、地点、敌手、机缘、承诺和战果，允许战斗/交涉/潜入/协作等选择 | 不等待完整市场、农业、五行或全城镇经营 |
| 大世界自循环 | 从首个正式冲突包起接入远区事件，不等所有近景系统完成后补 | 先具名关键人物/小队/势力，随后按规模扩展 |

凡人、创造者和非战斗修士仍可玩；“超凡者优先”不是强制固定战斗职业。修士可因知识、法器、组织、技艺或武力获得超常的行动范围与影响力。装备继续具有外观、礼仪、身份和生活价值；武器/法器也应拥有值得理解和使用的独特机制，不能把所有衣物换算成攻击力。

## 2. 本轮公共接缝修复包

修复目的：后续战斗、施法、学习、装备操作和多人合作能复用共同基础，不再次复制身体占用和存读接线。

| 工作 | 实施范围 | 验收 |
|---|---|---|
| 行动占用 | 从原领域状态只读投影，统一固定域清单与命名用途；允许排除自己，保留主体控制权/原生日常/对练阶段的差异 | 互斥、可并行的原动作、未知人/空域、读档候选不读活世界；不造第二份锁/过程 |
| 调度/装配 | 固定域目录收拢机械存储与边界查询，执行按有名阶段保持原先同刻顺序 | 原时间边界、先旧后新、细算/稀疏推进与未来一致 |
| 候选绑定 | 领域公开`bind_world`，全校验成功后接回会话；不从父域直接改私有owner | 坏档不影响活状态；有效候选重绑定后继续完成原活动 |
| 快照工具 | JSON值规范从runtime抽到纯persistence工具，公开必要上下文，保留旧调用包装 | 小数坐标、最大整数、StringName键值、旧档与进行中保存语义保持 |

不为该等价整理升级schema、重写真实历史fixture、改变旧结算顺序或全量替换迁移链。存档中兼容的双份home和长期历史增长是另有格式/规模验收的后续工程项，不在本轮伪称全部解决。

## 3. 接下来的玩法顺序

P/F编号继续作为旧领域和验收索引，不再表示“先做完P1农业、再做完P2建造才轮到修仙”的排队顺序。

| 新顺序 | 交付内容 | 玩家必须获得的体验 |
|---|---|---|
| U0 公共接缝 | 本轮修复和完整回归、实际运行 | 既有世界继续有效，后续动作接入成本下降 |
| U1 超凡冲突核心 | 现有连续移动/闪身/时间上加可用武器、至少两种不同作用的术法、敌对行动、瞄准/范围/接触/打断、消耗和伤势/撤退 | 用距离、时机与能力处理一场真实危险；NPC同规则，暂停可下令，不靠刷重复日常获得资格 |
| U2 功法与器物构筑 | 共用学习网、少量规则变化节点、师承/秘本/练习、武器/法器条件功能、非战斗术法；有限修炼与突破 | 同一问题可用至少三种实际不同的能力组合；发现“原来这也能用”，不先铺千节点空图 |
| U3 冒险与任务 | 两三个相接地点、探索/妖患/遗迹或争夺、一位自主对手；委托源自实际人物目标和世界问题 | 战斗、交涉、借力或绕行至少两路有效，任务接受不刷新唯一宝物，NPC可以抢先解决 |
| U4 组织行动与权力 | 结伴、远行分工、授权/拒绝、战术意图与通信、少量职位/继任旧账 | 从独行到借助他人扩大影响；关系、面子、承诺和实际权利产生不同效果 |
| U5 首小时与大世界验证 | 上述每包均接事件化远区；此处扩大地区/时间/负载，整合45–60分钟切片与独立包 | 玩家离开时人物继续学习/旅行/争斗，回来能理解变化；有可恢复的失败与持久成长 |

U1–U4是相互交叉的交付顺序，不能把“完整战斗做完”变成学习、组织或非人玩法必须等待数月的前置。每包完成一个能玩的组合，并保留近远/存读的同一事实。

首小时围绕修士与地方局势：遇到真实妖患/遗迹/争端→了解人物和门路→取得或学会新能力→准备/行动/承担代价→改变自己与当地。普通劳动是备选筹备途径；不以数十次挑水、种田、吃饭和等待凑时长。起始杂役身份保留，尽早接触超凡世界，不要求所有角色先完成凡人产业链。

## 4. 远区可以事件化，不能只随机播报

这是拟采用的技术方案，尚未实现为新的远区总引擎。当前两聚落执行器继续有效；不直接以随机文本替换已有生活事实。

采用“持续状态＋按需安排的事件＋稳定过程批算”：共同时间推进到下一个有意义的边界，而非逐格模拟远方所有人。

| 过程 | 留存状态 | 事件边界与实际变化 |
|---|---|---|
| 旅行/追踪 | 人物或小队、起终点/路线、出发时刻、速度/补给、目的 | 出发→到达路段/危险点→发现或遭遇→到达；封路、受伤、改目的可重排 |
| 修炼/学习/疗伤 | 原功法/资格/场所、实际资源、开始与剩余工作、风险上下文 | 资源耗尽、传讯/危险打断、阶段完成；已投入时间和消耗不会重置 |
| 冲突 | 双方实际成员/能力/装备/伤势、接战处境、意图/撤退线、已消耗资源 | 按交战片段结算压制、伤损、脱离或求援；非一次比较总战力决定死亡 |
| 势力活动 | 目标、发起者/授权、实际人手/资产、所知局势与计划 | 募集、出行、交涉、争夺、任免和后续反应；无资源不能无中生有派军 |
| 地方供给/生态 | 库存与源汇、劳力分配、稳定条件/上次结算 | 无交互区间可累计求解；短缺/工人离开/环境变更生成下一个边界 |
| 消息 | 当事人、见证/记录、发送者、路线/媒介 | 事实发生与收到消息分开；远区事件不全世界瞬间公开 |

事件建议字段：稳定ID、类型、因果ID、发起者/对象、发生地、到期时刻、确定排序号、计划generation、必要引用及随机上下文。一个计划更新使旧generation无效；事件执行前复核当前人/物/授权，不让旧排程复活已死亡的人或重复拿走物品。事件队列本身要存读，并有每帧处理预算和欠算状态。

随机事件只提出候选机会/压力；要形成真实遭遇，必须取得实际参与者、场所和资源。个人生死、唯一法器去向、权力交替及已发生效果持久保存；重复进入/离开不重抽。普通群体可有总量表示，但具名超凡者、承诺和唯一物不能被群体池吞没。

进入近景前先推进到共同提交时刻，再把原位置/队形/意图/伤势/消耗交给近景执行；离开也在一致点转交。允许远区省略挥剑每一帧，不能因切换抹伤、补蓝、复制掉落或让同一场战斗两边同时跑。玩家在中途到达应加入尚未结算的局面，不能先预定全部死亡再展示假战斗。

首次验收：离开前交战/修炼在途→远区推进→途中存读→中途接近介入→再次离开→事件只结一次；封路/死亡/撤职使原排程合理失效；两派争同一唯一物不能同时成功；消息只在到达后改变已知。近远数值抽象须用代表性的双方/地形/撤退案例比较，不能承诺逐帧完全相同，也不能只依观察与否制造明显优势。
