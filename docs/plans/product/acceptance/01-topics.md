## 证据格式与通用要求

本次增加超凡者体验门槛：首小时尽早接触超凡能力；至少三种实际不同的能力组合可解决问题（不要求全战斗型）；至少两种路线处理同一冒险/争端；一次学习改变真实可行动条件；一次个人选择改变他人/组织局势；无玩家介入的对手或组织也行动。普通生产是可选筹备与世界来源，不以反复农务凑时长。事件化远区另验中途介入、旧计划失效、资源唯一归属、消息延迟及存读不重掷，详见U方案；以上均未提前标通过。

每条测试记录：构建/内容版本、种子、初始fixture、推进方式、玩家或NPC操作、期望与实际、命令/日志/截图路径。不可把开发工具直接修改库存、权限、胜负当正常玩法验收；确定推进世界时间可用于可重复测试，实际UI通路另验。

自动化分三种：纯规则及不变量；runtime/快照/导航整合；有代表性的长局/性能脚本。人工验证检查正常操作、可读反馈、选择与失败恢复。每个包只增加能证明行为的必要测试，不为低影响排版复制实现细节。

所有涉及持续事务的场景增加共用变体：中断/取消、相关人物死亡或失权、最后一份资源竞争、离场、执行一半存读、重复命令、无效引用。按真实领域选择适用项；不机械制造所有组合。

## F0：可靠的当前世界

对应P0。出口要求现有玩法没有退化，新持久状态具有明确的取样和恢复边界。

| ID | 给定与操作 | 必须观察到的结果 | 证据 |
|---|---|---|---|
| F0.1 | 当前新档完成取粮→搬运→报工→兑换→通行→取药→往返；中间保存重启 | 原人物/货物/账目/知识与未结服务继续；没有重复记功付款 | 现有回归＋正常UI操作 |
| F0.2 | 在一致时刻保存；另一地区有稳定批算/消息/在途货 | 快照各领域同一提交点；恢复后语义状态与继续运行一致 | 快照整合测试 |
| F0.3 | 探索、修改当前支持的世界状态后保存；损坏文件、缺引用或版本过新再读 | 支持的状态准确恢复；坏档拒绝且原世界不变；可找到备份 | 正常/异常读档测试 |
| F0.4 | 用一份真实旧fixture升级到当前格式，再保存读回 | 有效字段与因果保留；不能迁移时说明原因，不静默丢失 | 迁移fixture与报告 |
| F0.5 | 时间试验包含细分战斗动作、分钟消息、暂停与1/2/4倍 | 只有一条世界时间；同刻顺序稳定；取消/读档不重抽结果 | 隔离试验结论与测试 |
| F0.6 | 同机同场景测独立运行的静止、移动、拥挤和远行 | 记录主线程/模拟/渲染分布及原始条件；不把宿主后台FPS当达标 | 可复现基准和日志 |

## F1：普通人可以生活

对应P1。不依赖无限初始赠送或隐藏补库存。

| ID | 给定与操作 | 必须观察到的结果 |
|---|---|---|
| F1.1 | 初始盘缠有限，连续数日靠合法劳动和交易吃住 | 工资来自雇主预算；投入与产出有来源；形成下一周期供给 |
| F1.2 | 粮食/水/柴中一种短缺，玩家选择求助、生产或迁往别处 | 有提前预警、实际损耗及至少一条可行动恢复路径；NPC也应对 |
| F1.3 | 两人同时抢最后一份食物或材料，一人随后取消 | 最多一人持有/消耗；预约不遗留、不复制；另一人合理改选 |
| F1.4 | 商人钱或货耗尽，重复出售；雇主无钱发薪 | 拒收、换物或债务按明示规则；不是无限金币/悬赏机器 |
| F1.5 | 正常条件推进多周期，再移除一个关键工人/工具 | 产能随真实约束变化；其余人可重排、雇人或缩产 |

## F2：建造与经营确实改变世界

对应P2。自动测试关注资源/路径/责任，实际操作关注建设流程、信息与权限。

[P2-a门墙首包](../../../qa/20261103_construction.md)只验证了真实材料/中断/拆改/通行与离场施工的部分行为；后续也有有限房间、休息和工资样本，但不等于完整住所/仓储、伤亡、撤权或数日代理管理，下表不整体标通过。当前范围见[FEATURES](../../../status/features.md)。

| ID | 给定与操作 | 必须观察到的结果 |
|---|---|---|
| F2.1 | 获得使用权，以现有库存建住所和仓库 | 材料实际搬入、耗工、完工后发挥功能；无钱/无料不能跳过 |
| F2.2 | 半工封路、工人受伤、取消/拆除，并读档 | 停工有原因；预约正确释放；工地残料和拆回料只归一处 |
| F2.3 | 将唯一出入口堵住，再移除障碍 | 路径/房间/工作能力缓存失效；不会穿墙取物或永久卡住 |
| F2.4 | 普通人请求他人施工；管事凭授权分配；欠薪或撤权 | 命令范围不同，成员可以依法/依约拒绝或离职；库存权限复查 |
| F2.5 | 玩家离场数日，代理管理供给和施工 | 同批人粮不能用于两份工作；归来看见真实进展/缺陷与依据 |

## F3：冲突与败战接续

对应P3。此时可继续无头细算远处战斗；高效远区粗算在F7再验，不能中间冻结。

| ID | 给定与操作 | 必须观察到的结果 |
|---|---|---|
| F3.1 | 近战、远程、施法打断、掩护和暂停下令 | 成本、射程、视线、时间和命中与表现一致；NPC服从相同条件 |
| F3.2 | 运粮小队遭袭，玩家选择弃货撤退并救治伤员 | 货物留在真实容器；伤势/药材/照护消耗存在；败方有后续 |
| F3.3 | 战斗进行一半离场再回来，途中存读 | 原上下文继续一次结算；伤亡、位置/包围和已耗资源保留 |
| F3.4 | 具有任职/担保/承诺的人死亡或被俘 | 动作预约、背包、岗位和承诺按规则清理/转交；机构债务不被删 |
| F3.5 | 唯一管事失能 | 出现明确代办或职位空缺；基础吃住有替代路径；不能永远卡死新手局 |
| F3.6 | 俘虏交换/获救、重复释放或支付 | 人员所在地/自由状态唯一；赎金只转一次，旧执行权不复活 |
| F3.7 | 换普通衣服、重配招式、卸装重穿、同刻互相命中 | 外观不赠攻击/回血/冷却；准备/运转有代价，同刻规则稳定，已发生效果不重抽 |

## F4：修仙与一小时切片

对应P4。用普通操作验证完整体验，不能用测试菜单代替成长过程。

| ID | 给定与操作 | 必须观察到的结果 |
|---|---|---|
| F4.1 | 杂役开局按教程或替代路径谋生、结交、学法、寻材、突破 | 45–60分钟内有实质成长和一次权限/身份变化；不是只涨进度条 |
| F4.2 | 玩家与NPC学习同法，闭关中供给断掉/受伤/接急信 | 都需要资源与条件；已完成进度/损耗明示；按已知打断条件出关 |
| F4.3 | 可选稳妥与冒险突破，反复点击和存读 | 条件与风险影响结果；同一未变事务不重掷；失败可调养/改准备 |
| F4.4 | 后山问题可打、谈、交易或绕行解决至少两种 | 成本与后果不同；战斗不是所有身份唯一通路 |
| F4.5 | NPC先解决短缺或取得宝物 | 任务/库存/消息反映真实变化；玩家接取不让宝物再生 |
| F4.6 | 独立Windows测试包显示中文教程与办事界面 | 无缺字、文本截断或开发机器字体依赖；引入字体有分发许可 |
| F4.7 | 无职业跨域学习、读书未练、非战斗工作/复盘 | 连线不是自动学会；真实渠道/学习进展和准备分开；纯生活路线不需要杀敌刷点 |

## F5：多区、市场和迁居

对应P5。用多个地区而不是改名复制双聚落来检验。

| ID | 给定与操作 | 必须观察到的结果 |
|---|---|---|
| F5.1 | 某地缺粮，消息尚未送达，商人据其所知报价 | 未获消息者不偷看全局库存；获知后才调整计划/报价 |
| F5.2 | 买卖和运输经历封路、变价与途中截货 | 货、钱、合同、在途损失真实转移；可盈可亏，没有双领货 |
| F5.3 | 普通居民携资产迁居并存读，来回切区 | 只有一个身体/背包/住址和行动执行者；原岗位/住房有处置 |
| F5.4 | 地图出口连接远区，毁桥/关隘封锁 | 局部地形与路线图一致；不通过切图绕过控制和耗时 |
| F5.5 | S2多种子推进，遭遇资源枯竭/再生和供给打击 | 源汇可审计；调整生产、贸易或迁居；不暗补库存 |

## F6：组织权力与人走茶凉

对应P6。至少完整复现用户强调的社会分层场景。

| ID | 给定与操作 | 必须观察到的结果 |
|---|---|---|
| F6.1 | 与掌门私交很好，请无权长老支取公仓 | 私交不生成授权；可以担保/申请/违规行动并承担对应后果 |
| F6.2 | 真实公账正确但库存不足；重复拿旧凭据报工 | 保留有效依据，暂缓/协商/补偿；不能重复记功或凭空出货 |
| F6.3 | 旧友退位/死亡，新任与其不和，玩家远行后归来 | 公账、私人恩情、礼数、通行和具体人回应各有不同结果 |
| F6.4 | 用不同合法候选、财政、见证和实际支持重跑场景 | 结果随相关条件有可解释变化；不是固定全认/冻结百分比 |
| F6.5 | 撤销任职或代签，对方持有未用凭据 | 执行复核当前权限/适用政策；旧事实保留，不能继续无限签 |
| F6.6 | 因证据冲突调解/核验，双方不愿接受 | 有限流程可结束或升级；重复传闻不变多个独立证人 |
| F6.7 | 礼服会客、借宗门服、假扮执事、熟人认人 | 衣着可影响具体观察者判断，正式支取仍核权利；换衣不清记忆，不全局加魅力 |
