# 首个动作对练样本

2026-11-03历史工作包。有限对练已接通，证据见[QA](../qa/20261103_sparring.md)；不等于完整战斗系统。

复用原身体位置/体力/控制和世界毫秒。双方自愿约练；疲惫、饥饿、运货或生产中的同门可以拒绝。轻松巡视可由本人答应后中断，实物和原记忆保留。没有刷经验奖励或全局好感加分。

首个基础掌式有起势、短接触窗、收势；几何扇区与显示一致，无命中骰或无敌帧。NPC只用有限状态决策：接近→起手→收势，过远、疲惫或控制丢失就收手。命中损耗原体力、短暂打断；同刻接触先收集再汇总，双方可同时中招。当前是掌力收束的对练，不凭此虚构伤亡或完整修为成长。

对练占用双方的生活执行权，但玩家可走位或空闲时闪身；起手/收势期间不能叠另一主动作。自动旅行、办事、试器和等候不允许穿过对练。NPC原有自主生活在结束后接续。远区对练仅在存在时按50ms处理，不给全部远区常驻高频tick。

保存约练对象、原自主状态、动作方向/时刻/命中过、下次决策与结算边界。根schema7/区域5显式迁旧档为空对练；v1–v6不倒造对练经历，现代缺领域拒绝。进行中存读不能重扣体力、重命中或重置NPC。

验收：几何命中/打空、墙体与高差、阶段耗时、同刻互中、体力实际损耗、互斥/失控/收手清理、暂停、细步/稀疏/离场接续、进行中JSON与坏档原子拒绝；实际K面板、J出掌、WASD/Shift走位与日志/截图。具体动作和阈值是开发可调参数，非新增宇宙通则。
