# C2-a — 有位置、有用途的衣着

2026-11-03，有限首包已接通，验收见[QA](../qa/20261103_clothing_foundation.md)。接[衣着与物品](../../design/systems/appearance_and_possessions.md)，本包先接实物/穿法/纸娃娃/晴雨用途，不预建全种族装备表。下文是当时实现，后续[历法与温度包](calendar_temperature.md)按实际地图矩形查询气候；当前状态见[FEATURES](../FEATURES.md)。

## 体验与规则

人身可在住处拿取自己的靛青常服、蓑衣，实际穿脱、收在包中或留在附近设施。常服改变轮廓颜色与衣襟，蓑衣有独立外层。新局原人物的常服也成为同一规则的实物；旧档不补衣物。基础身体绘制始终保留遮蔽，不强迫管理内衣。

- 每件衣物有唯一身份、原物主和唯一保管位置；穿着是该实物在本人行囊中的用途，占同一穿法位置，不再复制一件到装备栏。常服/外层各一个，冲突须先脱原件。拿走别人穿着或保管的衣服不在本包合法入口内。
- 取放须实际靠近；穿脱须本人能支配人形身体、手头空闲并付共同时间。期间不同时旅行、劳动、对练或做另一器物动作；取消保留原物原位置，完成才改变穿戴/位置。
- 降雨按已有环境脉冲湿润露天穿着的吸水衣物；实际屋面或已经穿好的外层蓑衣遮雨，收在包里不代替穿上。衣物在无新雨时逐步干燥；脱下的湿衣不会立即变干。明显湿透的常服使原精力额外消耗，不加攻击/防御/好感数值。
- NPC与玩家同API。新局老周随身有蓑衣，在原个人决策时遇雨会尝试穿上，需求/原承诺/身体事务优先，玩家离场仍有效。不强迫所有NPC都会同一天气计划。
- 观察者只能在眼前看见表层外观，蓑衣遮住内层细节；衣色/剪裁是线索，不证明任职、修行、物主或通行资格。界面不读他人包内衣物；不会因礼服给全世界加好感。

## 唯一状态与执行

`SimClothing`拥有衣物实例/保管引用/穿着标记、湿润、取放穿脱过程及来源记录。衣物不再同时加入数量库存；数量物资仍只归SimInventory。原人物位置、精力/固定点余数、任职与记忆不复制。持久候选从新局配置和实际完成过程重演衣物位置/穿法，核对原身体互斥/距离/时刻；失败不换活世界。

原`SimWeather`环境脉冲调用衣物湿润，先同步受影响人物再改变后续消耗率；村落通过只读回调加入原精力消耗，不能在渲染里结算。分钟环境采样只计整段处于同一穿法的物件；中途穿上不倒补这一整分钟前的淋雨。新物件/穿法改变记录边界。远区和细步使用同一脉冲，无第二时钟。

本包两地气候归属用原身体格距最近的住处确定，途中同样采样；不是新增位置字段或完整气候分区。穿脱改变遮蔽时，本人的穿着层跳过这一段不完整暴露；取放或脱下物也跳过其改变所在的部分分钟。当前分钟末的位置/实际屋面用于环境采样，不逐毫秒回放途中全部遮雨轨迹。全域晴朗且衣物干燥时不唤醒远区；有降雨或需要晾干时才同步受影响人物，再改原精力速率。

人物视图接只读外观投影；原`PawnVisuals`继续代码分层绘制，无新美术依赖。V衣物页只提交本人意图、显示本人存物和眼前表层；新节点脚本组合，不手改场景资源。

## 验收

1. 拿取/穿脱/存放耗时与距离真实，唯一位置/穿法、原身体互斥成立；重复/取消/无权/不在场不给额外物件。
2. 常服和蓑衣实际可见，包内不可见；晴雨/屋面/已经穿上或只带在包中有不同生活结果，原精力不复制；湿衣脱下/重穿不会洗掉湿润。
3. NPC按自身雨天处境穿衣，需求和既有承诺优先；离场、粗细推进和中途存读得到同一全联合未来。
4. 身份/权限不由衣物授予，观察不泄露他人包/物主或被外层遮住的细节；鸟/魂不能借用人形换装入口。
5. 坏位置/重复穿法/丢失历史/未来时刻/身体并行候选原子拒绝；真实旧档迁空。完整check、正常实机换装/晴雨/真实进行中档完整停开与截图后记录完成。

本包当时不做衣料生产/自由交易、转赠/借用/盗窃执法、任意容器嵌套、衣物破损/清洗、完整人物动画、气温或全身受击护甲。后续已有有限气温和八方向占位；完整动作与正式美术仍待完成，见[FEATURES](../FEATURES.md)。
