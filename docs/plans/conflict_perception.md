# U1-b0：交锋中的有限感知

2026-11-04。状态：已完成最终完整回归、真实档/两次独立停开和原生画面验收；证据见BASELINE与[QA](../qa/20261104_conflict_perception.md)。依赖[真实利害计划](transcendent_stakes.md)，不新增值守、借源或战争玩法。

目的：原有限交锋已有真实几何命中，但NPC决策仍能读取隐藏目标坐标、隔墙起势和同场远弹。本包将物理结算与人物可知信息分开。

## 行为与状态归属

- 复用原共同毫秒边界与原人物位置/朝向/成本/伤势。只在活跃交锋参与者中有限采样，不扫描全世界人物，不依赖玩家迷雾。
- 首版地面人身采用周向视距、同高度和实际墙柜/岩石遮挡。听声、神识、隐身、视锥、飞行与感知能力差异留待真实能力驱动。
- 每名参与者仅保留一条对手最后亲见：时刻、双方当时位置与高度。它属于原交锋记录，不另造人物坐标所有者。当前攻击线索是同边界临时输入，查询不写世界。
- 可见目标允许原剑/气弹决策。目标御起自己的护障、背向起势、超射程起势都不是对本人攻击的证据。失去视线只趋近最后见处，不根据隐藏新位置转弯/瞄准；线索过期停下戒备，交锋仍可因原超时/距离/退让结束。
- 飞弹按眼下位置、视距、同高度、实遮挡、前进方向与剩余射程判断；即使来自别场交锋，也可能威胁本人。原有限护障已成形就继续存在，不因失去视线取消、退款或刷新。
- NPC退让沿有效最后目击的反方向；未知时按自身朝向后退。已经生成的退让方向是原实际决定，读档不重算。
- 一个结算边界先采样并移动，收集所有实际接触后提交伤势，再统一形成各场决策线索，最后提交NPC起势。后一场不提前读到前一场本边界刚决定的新招式。

视距、记忆时限、抵达容差与威胁余量均放在原`conflicts.json`；它们是可调体验参数，不是全局声望或战力面板。

## 存档与证据边界

持久形状升级到根36/区域32/交锋2；其余域不随之升版。新局有明确`perception_since_ms`，旧v35在原保存现在启用、每人线索为空，不推断过去见过的对象位置。原招式、飞弹、气障、费用、伤势、旧退让方向与全部生活历史保留。更早迁移先产生当时交锋1字面形状，再显式升级。

候选严格检查字段、时刻、启用边界、记录双方点的同高度与有限距离。它只验证保存记录内部自洽，不声称完整重演历史：此刻的隐藏位置、门墙和玩家迷雾都不能证明过去的目击。此刻同毫秒也可能有后续合法移动，不能据坐标不相等拒绝有效档。没有无界感知事件日志。

## 验收

遮墙/不同高度不能感知新起势；隐藏移位不能更新线索；最后位置可查看且过期停下；同场远弹/背向弹/射程不足不触发护障，别场眼前来弹可触发；无效新数据原子拒绝；旧v35无补造目击/物资/成本；旧线索在途存读、任意毫秒细步/稀步未来相同。有限借源与看护驱离后续已接入，见[source_loan](source_loan.md)/[source_care](source_care.md)，不代表完整领域完成。
