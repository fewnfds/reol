# 连续身体与日常事务的共同执行

2026-11-03，实施中。延续shared_time_actions，不能以本页冒充功能已完成。

目标：NPC、玩家自动办事和手动走动同用世界毫秒与实际位置。工作仍消耗真实材料/时间，不因换精度或读档重复产出；远处不需要场景节点。

方案：

- Village/Regional增加权威elapsed_ms；旧advance_to(分钟)显式换算到毫秒，tick_index/current_time保留分钟投影给既有社会记忆和长线信息。
- 原生路线以身体实际位置、下一路点和绝对到达时刻推进；工作保存绝对截止时刻。默认人形步速取现有手动240px/世界秒，斜线按长度耗时，不再3分钟/格。重复路径不保存第二份。
- 身体位置归原actor，SimLocalMotion和场景引用该位置。格子是位置的索引，既有容器仍只有一份。暂停/存读保留格内进度。
- 服务/器物等长事务随后使用同一精细开始/截止边界；分钟社会记录只作时间精度投影，不提前发产品。
- 世界调度合并原生事件与分钟事务边界。远区跳稳定区间，读/写先同步；输入、取消、物资和控制在作用时核验。
- schema6显式迁移真实v1–v5，旧物资/预约/私人记忆保留；旧路线在途余时有明确换算，不重置或抢先交付。源fixture不可改写。

验收：现场NPC可见连续走动、自动路线与手动步速一致；途中保存并彻底重启连续；无人区仍自主走路/做事；细步和粗跳结果一致，满仓/断路/失控保留实物；短动作/长任务不会双占身体；过去fixture与新完整档经候选全量校验。每个阶段跑check，最终实际运行/输入/日志/截图。体力恢复和对练在该边界稳定后接，完整游戏Goal保持active。
