# 实施计划入口

当前只有一份[模拟执行架构重构计划](foundation-priorities.md)，统一问题登记、验收情况、四个交付包与规模出口。它允许从最小可玩世界重建，不受旧class、schema、测试数量或已完成样本约束。

- [执行架构规格](../specs/world-engine/execution.md)：计算模型、数据、任务依赖、CPU/GPU、空间/AI和呈现的详细候选合同。
- [产品层次](roadmap.md)：长期游戏方向，不是另一份施工队列。
- [当前接续](../status/handoff.md)：实际授权、代码/文档停点及保护的未提交工作。

领域职责见[七个框架](../engineering/architecture/05-framework-domains.md)，已确认规则见[游戏规则](../../design/rules/README.md)。旧优化包、来源/缓存/响应小阶段和产品清单不再留作当前入口，需追溯时使用[Git历史](../archive/README.md)。
