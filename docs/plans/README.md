# 计划与依赖

本目录只放未来依赖和可验收的工作范围；实现范围看 [功能](../status/features.md)，当前任务看 [接续](../status/handoff.md)，证据看 [基线](../status/baseline.md)。

- [基础优先级](foundation-priorities.md)：唯一的基础架构建议顺序。每次只排定一个小包，完成并报告后再讨论下一项。
- [统一运行效率方案](runtime-efficiency/README.md)：按实际能力、活跃/到期/变脏工作执行，覆盖环境、人物、空间查询、呈现与历史；含静态审计和分包验收，尚未实施，不构成自动执行队列。
- [第一阶段详细实施](world-foundation/README.md)：通用世界骨架的分包步骤、验收和性能口径。
- [环境首轮详细方案](environment-object-loop/README.md)：真实地面来源、缓存、原物联合事务及温度/五行连续响应的候选依赖；每个小包后讨论，普通Main整体接管单独排定。A1之后的单包建议见[分块基础目标缓存](environment-object-loop/cache.md)。
- [路线图](roadmap.md)：从基础运行到游戏玩法、内容及发行的层次关系，不再维护第二套编号队列。
- [长期产品目标](product/full-game.md)：完整世界与可玩切片的目标，尚不代表实现。
- [产品验收](product/acceptance.md)：长期出口需要什么证据，不是当前待办列表。
- [多生命沙盒](product/multiple-lives.md)：较早提出的体验目标；其中编号不决定当前顺序。

详细接口候选已移到 [specs](../specs/README.md)，固定世界规则在 [design/rules](../../design/rules/README.md)，旧样本工作包在 [历史规格](../archive/specifications/README.md)。不要因为旧页写了“下一步”就恢复施工。
