范围：2026-11-07用户要求复核历史框架，合格能力接入游戏，不继续无限打磨隔离系统。结果与证据看[接续](../../status/handoff.md)，本页不代表验收通过。

## 本包唯一出口

在现有普通 Main、原物、共同时间和普通存档中跑通：开发世界编辑按定义放置实物 → 普通人身选中 → 耗时取起/放下 → 取消或截止提交 → 保存、退出、重新进入后继续。复用已有界面，不新建演示世界、背包或时钟。

1. F8开发编辑增加实物定义列表、放置与移除。只开放已有 `physical + placement` 定义；多格物是一件实物。地形笔刷保留，开发造物明确不扣材料，不授予玩家随意生成权限。
2. 普通物品面板将受管实物取放接到原生命周期动作。只取地面、只放本人脚边；他人或场所保管、跨账本及尚未实现的探查动作不开放。既有特殊器物仍按原能力执行。
3. 沿用身体行动占用、共同时间、预约和存档。取放在启动和截止检查触及与遮挡，移动/停止能取消，界面投影原动作，不新增动作状态副本。
4. 定向验证该链和重要拒绝；实际渲染观察与普通存读完整停开；最终代码包一次完整check或对应SHA CI，一次原生静态审查。原四份WIP保持字节不变，在干净隔离检出验证已提交接口，不把草稿当交付。

## 新环境的接入缺口

- 普通人物体感、植物、现有热设备、墙门屋面和部分光源仍读取/写入 `local_heat`。新场未实现这些适配；不能只换面板或把两份温度相加。
- 普通时间推进直接驱动区域世界；新响应会话有封闭pump/边界守卫。普通写入口还未全部进入同一可续事务，直接绑定会话不能保证无半态。
- 新守卫尚拒绝地面生成、移除和材料转移，只处理受限已有实物的位置变化；不能用它阻断本包合法操作。
- 实际温度/五行残留只进入开发验收快照，未进入普通联合存档；必须在独立候选中恢复唯一状态，并明确支持的旧档处理。

后续应围绕这些普通接缝完成一次替换包，复用现有算法；不先要求新极端规模、长期历史压缩、携源尾迹、房温扩展或GPU开关。未替换前如实保留旧模型，本包不声称新环境已进入游戏。
