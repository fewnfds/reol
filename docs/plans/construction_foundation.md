# P2-a：宗门工地、实物施工与拆改

日期：2026-11-03。P2-a有限首包已实现并验收，见[实际证据](../qa/20261103_construction.md)；当前构建只以[BASELINE](../BASELINE.md)为准。

目标：让地面结构经过真实材料、搬运与施工产生，改变人的路线；离开现场不会冻结过程。先实现宗门获准工地中的木墙、木门、开关门、拆除与余料回库。

玩家体验：N打开施工簿，在库房附近登记一处工地，点选格子画蓝图。自己动手，或者留给有该项职责的石头；缺料会等待，仓库补料后再做。木门关闭挡路，开启通行；飞鸟仍能飞越，不能落到实体占地。拆除耗时且只回收部分材料，回收也要真实搬运。

## 规则与边界

- 工地为明确授予的宗门用地/用料权限，所有者是当地机构；首包不是任意占地/完整土地法。规则定义列明获准建造者、日常施工者、库房、尺寸与有效距离。别人的私物和远区库房不能被直接扣除。
- 工地从库房附近可达草地划定；设施、现有人身和地面鸟不能被结构重叠。蓝图本身不挡路，每个格子只能有一个未撤销/未拆除的项目。新蓝图须当面看得到工地。
- 同一身体只做一件事。工人先预约木料，走到库房取出，再携至工地相邻工作格。木料数量只属于原库存账；项目容器记录这一批料，carrier/ground位置说明它在谁手中或哪里，不能另加资源余额。
- 停工释放材料预约、把携带材料留在脚边、保留已做工时。撤蓝图不退木；在地余料可另行搬回。复工从余料真实位置取料，不能重新从库房多扣一份。
- 完成前再查当前地形/站位/占用。墙/关门不能压住身体或正在穿越该格的路线首段；被占就保留蓝图与材料，等清场再续。路途后来被堵则中断，材料不消失，不能穿墙。
- 公告工单仅供工地附近且有日常施工职责的人看到。NPC按身体控制、饥饿/精力、当前占用选择；不会强制打断正在做的工作，不会凭玩家点一下远程获知。
- 木门操作也需走近、耗时。第一版不设门锁/钥匙，不把通行权限等同于物理开门。
- 建筑仅改变地面通行；没有房间、屋顶、家具、温度/风水、承重、攻击破坏、房契转让或全面组织管理。

## 状态与实现

`SimConstruction`拥有工地、项目、进行中工人及公用检查时刻。库存仍在VillageSimulation.inventory，身体位置仍在actor，路线复用SimRouteTravel。RegionalSimulation提供共同边界/互斥/近远推进，ReolWorld只查询阻挡，不存建筑真值。运行适配负责B面板、地面预览与结构绘制。

根存档16/区域13显式加入空施工状态；v15及之前不补造工地或工程。候选先独立恢复/交叉验证，再验证静态地形与候选建筑。当前活世界墙不能污染另一个存档的地形校验；旧路线未来被墙堵住属于可恢复的合法状态，到下一段按规则停下。

## 验收

1. 从非空库房经预约、真实连续搬运与施工才生成挡路木墙；缺料/未获准/身体被占不能开工，蓝图不挡路。
2. 中途取消与JSON恢复保留同一批木料、工时和位置；重复恢复/完成不多扣、不多产。
3. 门开关和拆改真实耗时；关闭拒绝压住身体，拆除留有限余料，实际回收才归库。
4. 有职责NPC在玩家不在场时施工，近/远与不同步长推进同一世界结果；需求紧迫不接新工。
5. 所有地面导航/手动运动/鸟落地读取同一阻挡；飞越不受地面矮墙限制。
6. 进行中联合档完整停开游戏仍得同一未来；坏权限、重复占地、材料/预约/动作矛盾拒绝且不改活世界。
7. 实机N操作、搬运/工地与完成画面在1280×720可读；完整check与旧档回归通过，记录实际限制。
