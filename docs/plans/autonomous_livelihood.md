# P1-g — 为自己的随身口粮谋生

2026-11-03，有限首包已实现，[实际验收](../qa/20261103_autonomous_livelihood.md)。沿用完整游戏 Goal，不把有限计划器当完整人格或经济。

## 体验与边界

石头及河湾同背景人物希望备一份可带走的饭。行囊已有饭便照常生活；缺饭、有钱便尝试购买；缺钱则寻找能签现金差事的人，实际履约、验收领薪后再购买。钱本身不是欲望目标，公灶的原有取食资格不被取消。饥饿、休息、已有照看约定和其他身体事务优先。

寻找只走已知的公共功德堂、药圃，不追踪后台现任位置。实际走到附近才能向眼前的人问门路；付款能力来自本人听到的自述，旧话不会随换任自动更新，真正签约/验收/买卖仍查原权限与资源。无钱、无需求、道路不通或对方不愿答复时退回原日常，按有限间隔再试，不无限点击或空口造工资。

这是确定规则下的一个有限目标序列。尚不做任意长程规划、私人商业、工资谈判、招工广告、迁居或通用行为树框架。

## 所有者与时间

- `SimAutonomousLivelihood` 只存有该意愿的人、公共寻找站序、上次尝试结果和重试时刻；不存第二份钱货、能力、任职、身体路线或劳动工时。
- 行走复用两个明确的原生 visit 动作；劳动仍为原 `actor.active`，工资仍为原预算劳动专款，交谈仍为原双方社会记忆，购买仍为原服务的实际交割。
- 村落决策在处理需求/凭据/照看约定后可预留本次个人决策。区域推进到同一毫秒、原事务结算后再执行它，失败立即回原日常。不得在村落未来时刻递归调用尚未同步的区域服务。
- 自主交谈与签约提供明确的决策边界入口，核对自主本人、原身体空闲、村落/区域共同时间和本次决策戳。外部交互仍须消化完时间欠算；不修改 `target_ms` 绕过。
- 每人每原决策间隔最多一次计划步骤；失败有较长退避。预算耗尽不会刷新钱；已签约的义务不因离场而消失。

## 接入与兼容

定义在 `data/definitions/autonomous_livelihood.json`，新局仅为指定生活背景启用。根26→27、区域23→24，新增计划域1。旧档显式迁空意愿，只加入未来可用的公共拜访动作，不补造过去的动机、介绍、工资、钱货或日程；旧 fixtures 保持原样。现代候选校验参与者/背景、地点/动作、寻找索引、结果白名单与时间，失败不换活世界。

文件：新规则/定义/规则与运行测试/定向 probe；接内容库、村落决策接缝、区域组合与候选恢复、会话迁移。可见行为通过原人物动作/办事状态呈现，不增加全知NPC私心面板。

## 验收

1. 缺随身饭且有实际预算时，自主当面问路、接活、走路取料交付、验收领薪、买饭；钱货守恒，同次无重复贡献。
2. 吃饭/休息、已有承诺、身体占用、没有预算/需求、拒答/旧任职、道路不通均不靠旁路成功；失败后继续正常生活。
3. 只能用本人交谈来源找到付款人，不读后台职位/远人位置；未在场的玩家不自动获得NPC私话。
4. 细碎与大步、近处与离场、寻找/劳动/验收/购买中存读得到同一全联合未来；现代坏候选原子拒绝，旧档只迁未来定义。
5. 完整 check 通过；正常新局实际买饭形成预算，观察自主闭环，保留真实中途档并完整停开复验、截图和日志。未完成项按实际记录。
