# E1：同一时间上的历法与局地冷热

2026-11-03，有限首包已接通规则/交互与真实进行中完整重启，见[QA](../qa/20261103_calendar_temperature.md)，最终构建以BASELINE为准。承接[环境总方案](world_environment.md)，保留原晴雨过程与湿衣/湿床/雨水。这个包没有室内热交换、植物温度响应或致死。

## 体验与规则

- 当前世界时刻派生360日历法、四季和地区昼夜温度。开局仍为原08:00；日期与日照使用同一480分钟偏移，没有第二份时钟。
- 气候按明确地图矩形查询，人物的任职/所属聚落不决定其所在气候。温度为0.1°C整数，曲线为确定性分段插值，雨天有定义降温。
- 衣物的实际穿法和湿润决定等效保暖；携带未穿没有保暖。冷/热负担只加到原精力消耗，不新建体温/HP，不免费生成热量。
- NPC仍先处理需求、凭据和已有承诺，闲时可以为挡雨或减轻寒冷穿自己的外层，晴天炎热时可脱下增加热负担的外层。没有衣物的NPC不凭空取得衣物。
- HUD只显示日期、天气和当前人身体感；鸟不套用人的体感，残识沿原有限感知。

## 时间与持久合同

`SimEnvironment`拥有规则版本、启用时刻、最后采样边界和原人身的环境采样。原精力/衣物/天气/身体不复制。首采样是启用满一分钟后的首全局分钟边界；移动、穿脱发生在两次采样之间时，已有负担保持到下次采样，最多一个采样间隔的延迟，不追补过去。

负担回调只能读缓存。采样会改变负担前，先按旧负担同步对应原区域到变更时刻，再提交新缓存；同刻先完成天气湿润和实际穿脱，再采样未来负担。恢复后按原采样继续，不能重新计算并覆盖进行中的旧区间。

首采样后每个原人身都有一条采样：可能受冷热影响者使用实际位置/气候/衣物；所有地区都舒适者用有界的中性证明，不为了一个零负担同步远区。衣物集合由原事件反推采样后穿脱来核对，最新分钟湿润与原衣物一致；不声称重演所有历史位置/雨量。采样不是新的物件或身体所有权。时间上限的非整分尾段不构成采样；启用是否满一分钟按最近实际全局分钟判断。

旧根29→30、区域26→27显式增加空环境域，启用时刻取原保存时间。保留原雨相/湿衣/湿床/真实雨水和动作，不补算过去的冷热。全部独立候选验证成功才提交；历史fixtures只读。现代候选缺环境域、未来/错相采样、伪造温度/负担、非法衣物/人物引用须拒绝。
