# 工作包：跨聚落办事与互助

状态：已完成并验证。日期：2026-11-02。交付、运行证据与边界见[实现记录](../SETTLEMENT-SERVICES-IMPLEMENTATION.md)，当前总体进度见[BASELINE](../BASELINE.md)。

目标：访客到了另一处仍能生活、找人办事、承担运输和请求合作；所有事务使用真实库存、时间、权限和未结承诺，玩家离场后继续。

## 文件与阶段

1. 文件/文档归属整理；移动 UID 和引用，原检查保持绿色。
2. sim/services/ 定义访客生活、真实运输差事与有条件合作；参数放 data/definitions/settlement_services.json，区域调度调用其时间边界。
3. runtime 接当地设施/服务操作与世界时间；ui 仅发意图。保留人物唯一状态、跨区物品保管和存档。
4. 接报工、机构记账、兑换/授权的分步流程。服务决定与执行分别复查权限/库存。
5. 自动化场景、运行试玩、截图和文档。

## 验收

- 玩家在河湾取食/休息需到相应地点，花时间，消耗实际物资；可中断并存读。
- 山门缺粮，玩家可承担真实运粮工作；取物、在途、交付、报工分别进行，不点按钮凭空完成。
- 人物忙于已有承诺或体力不足时合理拒绝；改变条件可接受合作，答应后实际执行，不重复刷请求。
- 真正完成所需工作后留下依据；有权办理者登记到账，兑换检查余额和库存，权限不能由礼貌直接替代。
- 无玩家输入、离开两地、封路、取消、资源竞争与途中读档不重置、不复制资源或奖励。

不把本轮扩成全体人物迁居、完整市场或政治系统；相应边界在实现记录如实列出。
