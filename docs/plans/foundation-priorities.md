# 唯一实施计划

当前授权/接续见[HANDOFF](../status/handoff.md)，实际能力与测量分别见[FEATURES](../status/features.md)、[BASELINE](../status/baseline.md)。本页安排工作，不复制接口和实验过程。

## 当前阶段：基础运行框架重建

2026-11-12用户否定旧运行链，允许移除已有世界框架甚至重建基础；优先证明速度与真实加速，不继续在旧借还模型上逐个加补丁。旧“优化已结束”停止声明已被本次授权替代。

### 出口

开发机release下，1000个真实活动单位，1×/2×/4×实际世界吞吐达到所选倍率95%以上；画面30/60/120FPS不再因逐帧交接限制模拟；60FPS目标、帧P99≤25ms。保留实际寻路阻挡、命令、资源/直接因果互动、静态结构和环境。不同精度/删除能力必须列明，不能用时钟乘4、视觉点阵或停止工作伪装达成。

这个目标是本阶段判断线，不是所有未来玩法的无条件容量承诺，也不是新的全局开发门禁。

### 下一步候选

先体验新Demo、确认基础运动/交互与数值。之后按实际玩法价值选择恢复内容，不一次接回全部旧框架。恢复SL、命名内容/设施、认识驱动工作、自然生命、战斗等能力时，沿[现有边界](../engineering/architecture.md)处理事实，不重复造世界时间、GPU后端或万能接口。

后续操作方向仍可参考魔兽/星际的左选右移、停止、攻击移动和驻守，但当前只有FEATURES列出的操作可用。输入、战斗、AI的详细范围在真正开发前收敛，不为本轮另开半成品计划。长期愿景见[产品层次](roadmap.md)。
