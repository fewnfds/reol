# U2-a：有来源的本领小网与行气护身

2026-11-04。**状态：产品已实现，定向/普通主局、真实在途档两次完整停开与原生画面已验证；最终完整回归通过。** 实际交付见[QA](../qa/20261104_capability_network.md)，最终证据以 [BASELINE](../BASELINE.md)为准。下文保留实施前规格与验收意图，不把建议范围冒称完整U2完成。

本规格落实[超凡者优先](transcendent_focus.md)、[真实利害场景](transcendent_stakes.md)、[人物领域设计](combat_character_design.md)与[修行学习](../../design/systems/cultivation_and_learning.md)的方向。“行气护身”、下列七项展示、练习流程和参数是开发建议，**不是用户已经逐节点拍板的世界法则**。完整功法、境界突破、大型学习网络与 U2 整阶段尚未完成。

## 1. 最小可玩出口

玩家能看清自己实际知道、听说、读过和练成的少量本领及其来源；已会护障的人可主动完成一次有时间、身体和资源成本的行步练气，获得一个能改变操作的用法：**护障仍在起势或收势时，可以缓步调整位置。**

用现有身体、老师、木剑、气弹、护障和地形验证三种做法：近身木剑与闪身、站定施术与防御、缓步护持与脱身。它们不保证同样收益；脱离危险也是有效结果。不会新节点仍能生活、交流、学习原招式、使用原护障和正常走路。

本包只增加一个改变规则的节点，其余是已有实践与认识的可读投影。不同时添加经验购点、固定职业、全图老师雷达、千节点树、功法槽、突破、法器通用供能、种田或新的生产链。新地点和独特器物随后由 U2-b/U3 的实际局势驱动，避免继续把所有成长留在灶旁。

## 2. 先核对现有代码，不能只给移动锁开一个洞

以下是写规格时实际存在的接缝，不是本包已完成的改动。

| 原文件和入口 | 当前事实 | 本包拟补的最窄接缝 |
|---|---|---|
| [SimConflicts](../../scripts/sim/conflicts.gd) `knows`、`lessons`、`teach` | 三招的背景与完成教学已有证据；现教学会一起示范老师能教、学生未会的招式 | 原教学与旧记录保留；图从原证据读取，不顺手改造成全技能教学器 |
| `SimConflicts.action_blocks` | 活动作或 `ready_ms` 都阻止下一动作；同一结果还被运动与静止查询复用 | 保留动作排他；另投影普通步行的许可与速度上限，不能把 `action_blocks` 改成 `false` |
| [RegionalSimulation](../../scripts/sim/regional_simulation.gd) `owns_for_scope` | `automatic_motion`、`player_action`、`manual_action` 通过同一阶段锁；`stationary` 对交锋也查 `action_blocks` | 仅交锋的普通步行/静止分支识别新投影；身体所有权、发招、闪身、旅行和等待仍用各自原规则 |
| [VillageRuntime](../../scripts/runtime/village_runtime.gd) `_automatic_player_motion`、`_player_can_act` | 原生日常、行旅与交锋阶段会接管或锁定手动移动；闪身另核动作资格 | 普通缓步与闪身分开；允许缓步不能顺便允许同时闪身或另起一招 |
| [PlayerCharacter](../../scripts/entities/player.gd) `_on_time_advanced` | 输入只表达意图；移动写回原 body；自动方与手动方不能同时写位置 | 仍由原 `SimLocalMotion` 提交玩家位移，逐有效时间段应用步行条件，不由 UI 写坐标 |
| [SimLocalMotion](../../scripts/sim/local_motion.gd) `advance` | 连续位置绑定原 body；速度、加减速、扫掠与闪身过程已有实现 | 增加可选的普通行走速度约束；限制目标速度和已有速度，不能只缩小输入而让旧高速惯性越界 |
| [ConflictRuntime](../../scripts/runtime/conflict_runtime.gd) `_on_advanced` | 成功发招后一律 `hold_player_motion(true)`，清原移动速度 | 仅新节点的适用动作按共同规则保持受限缓步；其他发招与教学仍照原规则停稳，不能全局删除 hold |
| `SimConflicts._ai_motion` | 自动参与者有活动作或反应锁时不走位；在原 body 上扫掠移动 | NPC 同样查询步行投影；不启动另一条日常路线，不借玩家移动器代走 |
| [WorldSessionSnapshot](../../scripts/runtime/world_session_snapshot.gd) `stage` | 候选拒绝“正在移动且属于 stationary”；闪身、行旅、等待另有排他 | 只允许能从候选自己的已学证据和当前动作证明的缓步；不能删除整个 moving/stationary 校验 |
| [SimSpiritSources](../../scripts/sim/spirit_sources.gd)、[源候选](../../scripts/sim/spirit_source_schema.gd) | 当前 qi 基线和支出证明明确枚举原器物、寄魂、交锋的来源 | 若新练习支出 qi，必须接原对账与同刻顺序，不能只扣 body.qi 后留下无法解释的余额 |

**已有护障能移动的边界要说清。** 当前 `qi_guard` 的准备、接触、恢复分别为 150/50/300 毫秒，动作合计 500 毫秒；护障在 150 毫秒生效，未被消耗时持续到 2550 毫秒。动作结束后，原规则已经允许人物带着余下护障正常移动。新用法只改变施法动作内的步行条件，不把原本就有的后续移动重新售卖为成长。

反应、受击僵直、AI 动作间歇与施法阶段不是同一原因。新投影不得绕过 `ready_ms` 的独立限制，也不改变起势、命中或成本的时间。

## 3. 七项小网：显示本人认识，不另建能力真值表

首版按用途排一张小图或相连卡片，不先做无限缩放编辑器。节点和边的定义是静态内容；人物状态从原所有者按主体、内容、对象和时刻投影。

| 展示项 | 已有或拟新增的事实来源 | 展示限制 |
|---|---|---|
| 木剑横斩 | 原交锋背景、完成的 `lessons` | 会剑招不等于手里有剑；器物归处照旧核验 |
| 凝气弹 | 同上 | 已学不等于此刻够 qi、能运气或能发招 |
| 护身气障 | 同上 | 实际容量、持续期、伤势与动作占用照原规则 |
| 温石引流 | 原 `artifacts` 个人经历/开局经验、`heat_methods.base_known_from`、具名指导 | 按实际器类/对象和来源判断，不因看过外形自动掌握 |
| 某版温养办法 | 原 `heat_methods` 的不可变版本、本人实际试验/学习证据 | 只列本人有根据知道的版本；改名不生成新能力，不扫描别人的私有草案 |
| 某份记录中的步骤 | 原 `method_records.read_source` 与真实记录实例 | 拿到、读过、练成分开；不是一项新增的全民识字技能 |
| 行气护身 | 本包拟新增的完成练习证明 | 原护障已学只是前提；不会因点开图、满足前置或读一段文字自动学会 |

正常走路、停下、交流与已有闪身放在“身体基础”说明，不为填节点数设置技能锁。节点状态优先用人话：“本人会用”“曾亲自读过”“某人曾这样告诉我”“可尝试练习”“眼下条件不足”。内部保留有类型的来源引用，不把这些词变成一条通用熟练数值。

边至少分清“需要某项本领”“记载了某版办法”“可组合使用”。温养与护障在一张图上，并不意味着温石储热可以直接代替任意术法的 qi；当前 `charge` 明确用于储热、释热和热工用途。

只读查询拟返回：节点 ID、本人认识状态、有根据的来源/时间、当前可尝试动作和不足条件。这个门面不持久化 `learned=true` 镜像，不持有 qi、器物、教学过程或新的全图知识。候选校验使用其候选世界与历史时刻，不能拿活会话今天的“会用”证明过去已经会用。

**认识别人与认识自己分开。** 自己的经历可以自查；看别人的图只显示本人真收到的自述、教学和出手线索，不能调用对方后台 `knows` 后全盘展示。现有限能力自述没有武学/行气条目；若为本包增加一条自述，须经过原当面通信与带来源记忆。图上不显示未见老师的准确位置，不替玩家找遍整个世界。

## 4. 行气护身实际改变什么

本包采用一个自动适用的已学用法，直接作用于原 `qi_guard`，不另放一份“移动护盾”技能实例、快捷槽或护障。它不是持续运转的新主功法。

建议的只读运动投影返回“普通步行是否允许、最高速度比例、依据动作/本领及原因”。名称和字段在实现时确定；它本身不写状态、不扣费用、不创建锁。

| 当前处境 | 普通步行 | 原动作、费用与其他限制 |
|---|---|---|
| 原来可自由移动的空档 | 保留原行为 | 不因开小网改变身体基础 |
| 已掌握行气护身，正在原 `qi_guard` 动作内 | 允许有限缓步 | 原动作仍 active；不能另发招、闪身、办事、长途行旅或等待跳过危险 |
| 未掌握，或正在剑/气弹动作 | 保留原锁定 | 不把一次放宽扩大到所有招式 |
| 受击打断、失控、僵直、教学或另一项身体占用 | 按原原因停下或终止 | 新节点不豁免健康、控制和原唯一执行权 |
| 原施法动作已结束，护障尚未耗尽 | 保留原可移动规则 | 不追加缓步惩罚，也不刷新护障容量或持续期 |

建议 `mobile_guard_speed_fraction=0.45`，合法范围 `0 < fraction <= 1`，放入数据定义、由体验测试校准。它乘在原移动速度上；NPC 已有的 AI 速度比例仍保留，不能额外获得全速优势。当前规则下玩家在完整 500 毫秒动作内的位移上界约 54 像素，足以检验调整弹道与脱身的价值；必须实机比较，不能仅因断言“移动了”就认定好玩。若差异不清楚，先调整这个用法的参数或再评方案，不偷偷改全部护障时序凑收益。

动作开始时对已有速度应用上限；不允许先高速跑动，再靠慢慢减速绕过缓步限制。输入转向只改变原身体走向，不倒改已经承诺的发招方向。生效 origin 仍在真实生效毫秒从原 body 取；护障仍按原方式附随本人，绝不另存一份可随意拖动的“护盾角色”。

## 5. 新增的持久过程：只拥有这一项练习

推荐增加一个有界的纯规则练习所有者，暂名 `SimCapabilityPractice`。它只拥有行气护身的实际练习与完成证明；小网仍是只读投影。不要把 `mobile_guard` 塞入当前严格限定三种攻击/护障的 `conflicts.methods`，伪装成第四种可发射招式；也不要把所有旧 `lessons` 和温养事件搬进新域。

### 5.1 最小获取路径

**已实际学会原护障的人，可进行有目的的自我练习。** 这让旧世界也能从未来真实行动获得新本领，不必给所有旧老师倒造一种从前就会的秘传。原老师仍可通过原教学先教会护障；本包不要求给进阶节点再造一位高级老师。

练习是明确选择的世界行动：“停稳调息 → 在原空地缓步保持引气 → 收束并复盘”。只支持地面人身这一项；鸟、魂或大体型收到不适配说明，不能被强制变成人形训练，也不据此宣称所有种族都完成了学习框架。

建议总时长 60000 毫秒，资源预算暂按原一次 `qi_guard` 的 qi/stamina 成本取值，分别记录为真实练习支出；时间、步行速度与阶段都数据化。开始前检查已学基础、健康、真实通道、可支付预算和小范围可达空地。开始成功才扣一次，失败不扣；取消保留已花时间和支出，不退款、不授技，也不删除原本会的东西。

缓步阶段使用原地图、碰撞和 `SimRouteTravel` 的短路线，来回于起点附近的有限可达点；目标、距离、段时间和剩余路线归练习过程，位置仍写原 body。玩家可以选择开始/取消，不用每次手工敲出固定舞步；过程接管运动期间，手动移动是明确中断，不能同时由玩家移动器和练习路线改同一身体。

**练习不是免费施法。** 这一过程练的是收束、步法与稳定引气，不生成可吸收伤害的战斗护障，不伪造一次 `conflicts.actions` 成功。画面显示练习动作与行步即可，不能让装饰护环误示为有效防御。真正有保护的护障仍由原交锋发招产生并付原费用。

收束完成时复核：原过程 ID、基础在开始时已学、所有必需阶段真实完成、通道/健康与身体唯一性、已付费用及无中断。只有这条成功证明允许运动用法生效。没有百分比加点、击杀经验或重复练习刷强度；同一节点已掌握后不给第二份能力。

### 5.2 唯一所有者

| 事实 | 所有者 | 新域/小网只引用什么 |
|---|---|---|
| 主体、原身体、控制权 | `SimEmbodiment` 与原地区 actor | 稳定 actor/subject ID；不因名字 `player` 永久视为手动 |
| 位置、朝向、qi、stamina、精力、伤势 | 原 actor 与原健康域；玩家瞬时运动由 `SimLocalMotion` 绑定 | 不复制身体或另存“修炼灵力” |
| 原三招已学 | 原交锋背景与完成的 `lessons` | 按内容/时刻查询及引用证据 |
| 温石、版本、纸牍及其经历 | 原 `artifacts`、`heat_methods`、`method_records` | 本人可知的实例/版本/经历引用 |
| 新练习 | 拟新增练习域 | 参与者、节点、开始/阶段/到期、短路线、支出、前态、终态/原因与成功证明 |
| 发招、护障、气弹、命中、退让 | 原 `conflicts` 与健康域 | 新练习不持有第二场交锋或第二份护障 |
| 新用法是否学会 | 新练习完成证明的投影 | 不再另存一份会失配的学会集合 |
| 知道何人会什么、口头说明 | 原具名社会记忆 | 小网不把后台能力查询变成自动目击 |
| 图位置、选中节点、说明文本 | runtime/UI 可重建视图 | 不进入世界权威快照 |

新域有自己的版本、稳定递增 ID、有限记录预算与 schema；仅为实际过程接入原固定域目录、边界、排他、前态恢复、取消和候选。不开新 autoload、ECS、通用工作解释器或永久 50 毫秒空扫描。无活练习时没有高频边界；只更新活短路线和有意义阶段。

新 qi 支出必须在开始前确保原余额基线，并提供稳定费用来源供原源收支核验；结束、取消、引息完成同刻的费用序号须明确。具体包络、计数 floor 和版本号在实现前按 U1-b2 最终基线定稿，本次不预订、不执行迁移。不能以“是新技能”免除原对账。

## 6. 共同时刻和移动执行的必要条件

当前玩家先由时钟回调投影局部运动，地区/runtime 随后结算原世界，发招意图又可能在后续回调提交。不能只在整段开始查询一次许可，就把它套到越过准备、生效、完成或受击边界的整个长区间。

实施时先写一个最小回归探针，证明 `起势提交 → 下一段位移 → 生效点取 origin → 命中/打断 → 后续动作与位移许可` 的实际顺序。普通 50 毫秒帧、任意毫秒发招及跨阶段的显式大步都要拆在真实边界；**不因窗口帧率改变可移动距离，也不让未来的受击追溯撤销已走过的路。** 不为本包全局重排原源完成、交锋命中、看护升级与生活动作。

若现有回调无法让普通步行遵守同一阶段边界，先完成并验证一处局部运动的有名交接，再接新节点；不能靠 runtime 判一次 `known`、随后一直放行做“近似正确”。原身体仍只有一个位置写入者：玩家手动为 `SimLocalMotion`，NPC 交锋为原 `_ai_motion`，练习路线接管时为原路段投影，三者按当前过程互斥。

运动投影必须在世界实际执行和候选验证中共用。候选仍拒绝超速、未知本领、非护障动作、失控、同时闪身/行旅/办事等伪并行；保存中有非零 velocity 不再一概当坏档，也不能反过来无条件接受。既有地形净空、朝向一致、身体位置、同高度、原动作/伤势与 qi 来源证明保持。

## 7. NPC 和离场规则

NPC 可以用同一练习 API 完成同一过程，具备新用法后由原交锋 AI 执行受限缓步，不按 initiator/defender 或 actor 名字决定是否享有能力。其自主前态与真实 motion/action/communication 控制继续逐边界核验；手动玩家不会因为作为 defender 被自动带走。

本包必验“真实 NPC 完成练习后，在无人观看时按同一能力与资源行动”。若没有另外接入一个有需要、能拒绝/延后的自主学习目的，就如实写成“NPC 同规则可练/可用”，不声称全世界都会自行发现并练习。不给所有 NPC 在加载时自动点亮节点，也不为展示效果新造满状态修士。

练习中的 NPC 仍不能同时挑水、吃饭、看护或教人。原需要、伤势、已有承诺或威胁可阻止开始/造成中断，结束后恢复本人原自主策略。玩家离开、切地区、隐藏小网或关闭画面不重置练习、费用、相位或原源量。

## 8. 普通主局路线与可见出口

以下是拟验收的普通路线，不是已有演示。使用正常输入，不注满 qi、不传送、不关 NPC 自主、不直接写学习记录。

1. 杂役开局，找到实际在近处的原老师，请求原有护身示范；共同时间完成后从本人的经历看到“已会护障”。已有正常世界的教学前提继续成立，不刷贡献解锁。
2. 在小网选“行气护身”，看见它需要原护障、可用身体、足够资源和可行空地；进行一次真实练习。暂时不足时可用原生活/借源/休养途径处理，不要求完成一串新增农务。
3. 练习途中可以取消、被打断或保存；成功后本人能解释“我实际完成了哪次练习”，仅此时开放缓步用法。关闭/重开图或换衣不改变掌握与资源。
4. 在原有实际驱离中演示新旧区别：原木剑/气弹仍有动作承诺；新用法允许护障动作内少量侧移，能避开一条已承诺弹道或为退让争取位置。和平借源与停止取用路线保留，不把挨打一场设为学习条件。
5. 用实际保管的木剑、原气弹/护障及行气护身分别处理可比较的危险，记录击退、自保或脱身的真实结果、消耗与伤势；不要求三条路收益相等。已有 `SimSparring` 只含原对练动作，不能只改按钮就宣称它能施放交锋护障；若普通场景要扩为术法陪练，应另列具体过程/同意与效果范围，不能悄悄夹进本包。

小网复用现有本领入口扩一个紧凑页，图与原招式操作分开。只显示本人理解的状态、来源、所需条件、开始/取消和进展；新用法继续作用于原护障按钮。未知来源不显示后台准确参数，观察他人不露出其全盘私有学习史。使用代码像素占位，1280×720 下要能看出缓步、起势和实际护障的区别。

## 9. 旧历史和进行中存读

旧局只在显式旧包络迁入空的新练习域；不补练习、经验、老师、成本、源量、器物或过去的目击。原三招、温石实践、版本与木牍由原证据直接投影，因此旧玩家不会忘掉既有本领；新节点也不会因旧局“已经会护障”被自动授予。旧世界以后仍可通过本节的新自我练习正常获得它。

不改历史 fixture 字节，不借现代常量重造旧中间形状；原在途气弹、护障、交锋自主前态、固定退让方向和实际伤势保留。启用新规则前已经开始的施法不应在读档瞬间换一种移动策略：如动作需要引用其起势时的本领/规则依据，应同包显式保存并验证这项依据，不能以当前 UI 选择倒推。

新练习保存唯一过程、准确阶段/路段、已付费用与前态；世界只前进。候选独立恢复后，交叉验证原身体区间、基础的获得时间、路线/当前位置、费用、终态与成功证明，再整体替换。正在缓步施法、练习途中、刚完成节点与遭打断后均须验证重启同一未来；坏候选不能部分替换钟、地图、身体或小网所知。

本次文档不改任何 schema 或迁移。实施若确需扩原动作证据或 qi 收支 floor，应先列出具体格式变化和历史链，再执行，不以新节点为理由顺手整理所有保存域。

| N10 余下护障 | 原施法动作完成但护障尚存 | 保留原正常移动、到期和消耗；不重复刷新，也不继续强制缓步 |
