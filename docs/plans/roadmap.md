# 长期产品层次

当前施工只由[重构主计划](foundation-priorities.md)规定。本页描述产品依赖，不登记实现进度或另一套编号队列。

1. 持续世界框架：空间、实体/物品/容器、建筑、自然生命、环境、行动与认识形成可复用能力，能够在目标PC承载普通试玩规模。
2. 世界组合：不同布局/内容沿同一因果运行，远区、保存/加载、取消和长期变化成立。
3. 修仙玩法：修行、器物、动作战斗、冒险、创造与组织；普通生产支撑世界循环。
4. 人生与长局：多种身份/身体、迁居、地方差异及有限转生，玩家缺席仍有实际后果。
5. 产品化：正式内容、视听、输入体验、独立导出和长期稳定。

[愿景](../../design/vision.md)与[已确认规则](../../design/rules/README.md)定义游戏方向；详细机制是[设计候选](../../design/README.md)。45–60分钟切片、高差/多层、完整生态等旧提案不自动成为当前前置或容量承诺。
