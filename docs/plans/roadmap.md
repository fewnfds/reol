# 产品层次与依赖

本页描述长期依赖，不记录当前授权、包状态或测试结果。下一项基础工作只由 [基础优先级](foundation-priorities.md) 排序，实际启动项只由 [接续](../status/handoff.md) 登记。

1. **世界运行基础**：共同时间、唯一实物与身体状态、可变平面地图、位置与容器、动作、环境、房间、导航、存读及预算。把已有专用路径接成可复用接口。
2. **世界响应与自主生活**：植物、动物、人物与材料消费环境/动作结果；近远区沿同一因果规则持续运转，允许明确约束的近似。
3. **超凡者玩法**：修行与学习、动作战斗、器物与衣饰、冒险、创造、组织和任务。普通生产先补循环，不以复杂农务挤占修仙内容。
4. **可玩切片与长期世界**：以同一基础装配“一山一宗”、多区关系、出生和有限转生；验证不同身份和多种选择，而非把单一脚本当完整游戏。
5. **产品化**：正式内容与视听、性能和长期稳定、Windows 独立包。先玩法可验，再替换占位资源。

内容编辑能力随基础接口逐步接通，不先搭一个与活世界规则分离的编辑器。规模测试也随每个基础出口开展，不拖到所有玩法完成后才测。

高差/坡道/多层/完整三维、球面物理、运行时模型和复杂农务不属于当前基础前置。Godot 更换或 GPU 启用须依据端到端测量，不能从一个隔离基准推断整个世界的承载能力。

长期出口详见 [产品计划](product/full-game.md)、[验收目标](product/acceptance.md)。当前完整游戏与 45–60 分钟切片均未验收；实际状态按 [功能](../status/features.md) 和 [基线](../status/baseline.md) 判断。
