# 共同时钟与首个短动作

2026-11-03，当前实施包。实际完成以 BASELINE 和 QA 证据为准。

玩家走动和闪身使用同一个世界毫秒时刻；原生生活、服务、器物与远区仍是该时刻的分钟精度投影。正常速度先取一现实秒等于一世界秒，1/2/4倍统一缩放。长事务通过可中断的“等候一刻”推进，而不让两秒钟的动作偷偷消耗半天。数值为开发可调默认。

本包将连续位置/速度/闪身阶段从物理帧移入纯移动状态；场景身体只采集输入和投影视图。闪身有起手、位移、收势、一次性体力投入，不能穿地形，不授予无敌。原生人物仍以分钟格路执行，不宣称已实现完整战斗、NPC精细动作或自由换身。

共同时钟固定50世界毫秒发步；分钟信号在精细步之后结算。显式长推进按分钟边界批算，回调暂停立即停止；有短动作或手动移动时不能启动等候。世界欠算时间、分钟内相位、等候目标、身体速度与短动作均存档。旧v1–v4档链式迁为v5，旧身体速度为零，无凭空动作。

验收：

- 大帧/小帧、暂停/倍速、回调中断、分钟边界有相同顺序和保留欠算。
- 闪身真实扣体力，起手不位移，收势限制重复；无穿墙/悬崖，失控中断不退款。
- 一分钟的产物不在该分钟边界之前生成；短动作从自己的精细开始时刻计时。旧长动作仍按分钟精度，不能称为精确秒级耗时。
- 进行中的闪身与分钟内时刻经保存、彻底重启后继续，不能重复扣费/位移；坏动作或时刻原子拒绝。
- 原生活/器物/跨区/历史档回归，check通过，并以实际输入/日志/截图核对。

实现顺序：时钟及迁移→纯移动/短动作→身体与互斥适配→UI等候与提示→自动与实机证据。

首轮玩家短动作包已接入并实际跨进程验证，证据见 BASELINE 和 QA。后续连续生活执行包见下文；本页早先“NPC仍为分钟格路”是上一版本的边界。
