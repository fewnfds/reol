# Reol — 开发路线图（v0.2）

> 原则：**每 1–2 周产出一个能玩、能验证的切片。**
> 不按“系统清单”开发，按“玩家体验”开发。
> 日期：2026-11-01
> 方向：2D 等距 + 高度层；单机模拟；可暂停即时战斗。决策见 `docs/DECISIONS.md` ADR-0013 ～ ADR-0019。

---

## 总览

| 阶段 | 时间 | 产出 | 成功标准 |
|---|---|---|---|
| **M0 脚手架** | 已完成 | 可运行空场景 + 工具链 + 测试 | `doctor` / `check` 通过，编辑器能打开 |
| **M1 能走能看** | 2–3 周 | 2D 等距相机 + 玩家 + 512×512 区块 + 高度 + 迷雾 + 时间 | 能在地图上跑动、平移缩放、看到迷雾与高低差 |
| **M2 宗门生活** | 4–6 周 | 杂役工作 + 5 个具名 NPC + 需求/日程 + 声望/职位 + 存档 | 玩家能以杂役身份在宗门活 10 分钟并晋升 |
| **M3 能打能修** | 3–4 周 | 可暂停战斗 + 高度/飞行规则 + 前哨 + 秘境 + 修炼突破 | 30 分钟完整循环，暂停/慢放可用 |
| **M4 活的世界** | 3–5 周 | 势力/远区模拟 + 缺席战斗结算 + 传闻 + 流式扩展 | 玩家不在场，世界仍变化并能被感知 |
| **M5 垂直切片** | 2–3 周 | 美术/音效/UI/平衡/教学/打包 | 陌生人能不看文档玩 45–60 分钟 |

> **M4 结束前不要做**：联机、LLM 核心 NPC、真 3D、体素、多出身、完整掌门内政、100+ NPC、模组 API。

## M1 — 能走能看

### 目标
玩家能在一张 512×512 的等距地图上移动；相机固定角、自由平移/缩放；有高度层、战争迷雾、昼夜时间；60 FPS。

### 任务

1. **主场景与等距基准**
   - `scenes/main.tscn`：World + HUD + Camera。
   - 2:1 等距占位 TileSet（64×32 或 32×16），纯色/网格。
   - `IsoGrid` 工具：`world_to_cell` / `cell_to_world` / `elevation_to_offset`。
   - 验收：屏幕上能看到等距网格，坐标转换 roundtrip 正确。

2. **固定角相机**
   - `Camera2D`，不旋转；WASD/方向键/边缘/中键拖拽平移；滚轮缩放（0.75x–1.5x）。
   - 相机限制在地图边界内；`F` 居中玩家；可选“跟随玩家”开关。
   - 验收：平移/缩放流畅，不越界，不旋转，不抖动。

3. **玩家移动**
   - `CharacterBody2D` + `CollisionShape2D` + 占位 Sprite；8 方向移动，等距速度归一化。
   - 与地形/墙体碰撞；Y-sort 正确；脚底对齐。
   - 验收：WASD 移动，撞墙/悬崖停止，角色在树/建筑前后排序正确。

4. **512×512 区块世界**
   - 64×64 区块，8×8；加载半径 2（5×5），卸载半径 3。
   - 每帧最多加载 1 个区块；按移动方向预测；区块节点含 ground/walls/props 三层。
   - 地形由 seed 生成（先简单噪声/手工骨架），地图尺寸不硬编码。
   - 验收：可从地图一角走到另一角；区块加载无可见卡顿；debug 显示已加载区块。

5. **高度层**
   - 每格 `elevation` 0–3；渲染 Y 偏移 + 悬崖侧面；高差阻挡/可走规则。
   - 测试实体：1 个地面单位 + 1 个 `altitude=1` 的飞行占位；影子留在地面。
   - 验收：高低差一眼可辨；飞行单位视觉上离地；影子位置正确。

6. **战争迷雾**
   - 每格三态：`HIDDEN` / `EXPLORED` / `VISIBLE`；10Hz 更新。
   - 视线：网格 Bresenham + 高度/墙体遮挡；已探索持久化。
   - 迷雾层：低分辨率可见度纹理 + shader（或 TileMapLayer），在 world 上、UI 下。
   - 验收：走过后地图保留暗色轮廓；未探索区域全黑；单位在不可见格隐藏。

7. **时间与昼夜**
   - `GameClock`，10 tick/s；暂停、1x/2x/4x；HUD 显示天数/时辰。
   - 昼夜用 `CanvasModulate` 或简单 shader；夜晚可读性不崩。
   - 验收：空格暂停，数字键切速度；昼夜可区分。

8. **测试与验证**
   - 纯逻辑：坐标转换、elevation 偏移、chunk 坐标/加载集合、fog 状态转换、clock 暂停/速度。
   - smoke：`main.tscn` 能实例化；headless 跑 60 帧无报错。
   - 截图/短 gif：等距地图 + 高度 + 迷雾 + 昼夜。

### 里程碑验收
- 运行 2 分钟：能走、能平移/缩放、能看到高度与迷雾、能暂停/快进。
- 512×512 地图流式加载，1080p 稳定 60 FPS（中端 PC）。
- `python tools/godot.py check` 通过。
- 截图/录屏存档到 `docs/` 或 `logs/`（不提交大文件）。

## M2 — 宗门生活

### 目标
玩家以杂役身份在宗门生活：干活、吃饭、睡觉、接任务、攒贡献、晋升外门；5 个具名 NPC 有日程和态度；能存档/读档。

### 任务
1. **Pawn/玩家数据**
   - `PawnDef` / `OriginDef` / `RankDef` 资源；玩家与 5 个具名 NPC。
   - 属性：境界、灵力、体力、饥饿、疲劳、心情、声望、贡献。
   - 验收：选中面板显示数据；数据来自 `res://data/`。

2. **需求与日程**
   - 饥饿/疲劳/心情每 tick 衰减；阈值触发吃饭/睡觉/休息。
   - NPC 日程：晨课、干活、午饭、修炼、晚课、睡觉；按地点/时间段切换。
   - 验收：不干预时 NPC 能按日程运行 10 分钟，不卡死。

3. **杂役工作**
   - `JobBoard` + `Job` + `JobExecutor`；工作：挑水、砍柴、扫地、送药。
   - 认领/预约/释放；失败原因；玩家可手动接/交。
   - 验收：两个 NPC 不抢同一工作；完成给贡献/物品。

4. **库存与交互**
   - 水缸、柴堆、药房、任务板；简单物品堆叠。
   - 验收：挑水→水缸增加；交任务→贡献增加。

5. **对话与关系**
   - 模板/分支对话；好感/态度；5 个 NPC 各有 1 条小线。
   - 对话条件查声望/职位/flags。
   - 验收：不同身份/声望看到不同选项。

6. **声望/职位**
   - 宗门贡献 → 声望 → 杂役→外门晋升；权限/义务变化。
   - 验收：达到阈值触发晋升事件；晋升后可用动作/对话变化。

7. **存档/读档**
   - `SaveManager` v1：clock、玩家、具名 NPC、建筑、物品、faction、fog explored、flags。
   - 原子写 + 迁移骨架；roundtrip 测试。
   - 验收：存档→退出→读档，状态一致；坏档不崩。

8. **UI**
   - HUD（时间/境界/贡献/声望）、选中面板、任务日志、对话、简单地图。
   - 验收：键鼠可操作；1280×720 不溢出。

### 里程碑验收
- 新游戏 → 杂役工作 → 吃饭/睡觉 → 接任务 → 攒贡献 → 晋升外门 → 存档 → 读档。
- 5 个具名 NPC 能按日程运行；至少 1 条对话线因声望/职位不同而变化。
- `check` 通过；无红色报错。

## M3 — 能打能修

### 目标
完成“巡逻 → 遭遇 → 暂停/慢放战斗 → 掉落 → 修炼突破”的循环；验证高度/飞行规则。

### 任务
1. **战斗基础**
   - 玩家 + 3–5 同伴 vs 5–10 敌人；近战/远程；血量/死亡/掉落。
   - 攻击前摇、命中反馈、血条、伤害数字、地面预警。
   - 验收：能打死 1 组敌人，反馈清晰。

2. **暂停与局部慢放**
   - 空格暂停；暂停时下令；速度 0/1/2/4。
   - 每个 actor `time_scale`；高阶技能让敌人 0.3、玩家 1.0；不用全局 `Engine.time_scale`。
   - 验收：慢放时敌人动作/冷却变慢，玩家正常；UI 不受影响。

3. **高度/飞行规则**
   - `altitude` 0/1/2；地面近战不能打空中；远程/对空技能可以；高度差影响射程/命中/视线。
   - 1 个飞行敌人 + 1 个高地远程敌人；影子/偏移正确。
   - 验收：地面近战打不到飞行；对空技能可命中；高地视野更远。

4. **敌对前哨**
   - 1 个敌对势力前哨（3–5 敌人 + 1 个小头目）；阵营颜色/敌友。
   - 清理后占领/掉落；声望变化。
   - 验收：能潜行/强攻；不同方式不同后果。

5. **后山秘境/洞府**
   - 1 个小场景/独立室内（不是无缝大地图）；1 个精英 + 宝箱/灵草。
   - 验收：进入/退出不丢状态；掉落进入库存。

6. **修炼/突破**
   - 1 条线：炼气 → 筑基（或类似）；修为来自修炼/战斗/灵草。
   - 突破需要资源/条件；失败有代价（受伤/走火入魔）。
   - 2 个主动技能（1 攻 1 防/位移）；后期预留时间领域。
   - 验收：能突破 1 次；技能可用；突破改变日常/对话/权限。

7. **存档扩展**
   - 战斗/技能/境界/秘境 flags 进入存档；roundtrip。
   - 验收：读档后战斗状态/冷却/境界一致。

### 里程碑验收
- 30 分钟循环：接任务 → 出宗门 → 前哨/秘境 → 战斗（暂停/慢放）→ 掉落 → 回宗 → 修炼突破 → 存档。
- 飞行/高度规则可演示；`check` 通过。

## M4 — 活的世界

### 目标
玩家不在场时，势力/宗门/远区仍在运转；重大事件算法结算；玩家通过传闻/任务感知；流式地图可扩展。

### 任务
1. **World/Region 模拟**
   - World tick（每天）：势力资源/关系/战争/领袖/教义；Region tick（每小时）：军队/POI/宗门政策。
   - 数据驱动 `FactionDef` / `RegionState`；不创建场景。
   - 验收：快进 3 天，势力关系/资源变化合理。

2. **缺席战斗结算**
   - 统计模型：兵力/地形/士气/将领/补给；种子 RNG；产出伤亡/领土/战利品/仇怨。
   - 玩家在场则切实时战斗；不在场只出结果 + 历史记录。
   - 验收：同一 seed 重放结果一致；结果能解释（不是纯随机）。

3. **传闻/新闻**
   - 事件 → 传闻（距离/阵营/失真）→ NPC/告示/信件 → 玩家。
   - 验收：远处战争能在宗门听到 2 种版本；任务/价格受影响。

4. **具名 NPC 持久化**
   - 具名 NPC 个体状态跨区域保存；普通 NPC cohort 聚合。
   - 验收：离开区域再回来，具名 NPC 位置/关系/状态保持。

5. **流式扩展**
   - 地图尺寸配置化；区域拼接/多区域元数据；加载预算/预测。
   - 验收：512→1024 不需改核心系统；加载无可见卡顿。

6. **势力内政（简约）**
   - 1–3 条 Edict（资源分配/招募/戒律）；玩家作为小头目/长老只做少量选择。
   - 验收：选择影响宗门资源/弟子/声望。

### 里程碑验收
- 快进 7 天：势力状态变化、至少 1 场缺席战斗、2 条传闻、1 个任务受影响。
- 玩家离开宗门再回来，具名 NPC/建筑/关系保持。
- `check` 通过；模拟 tick 预算达标。

## M5 — 垂直切片打磨

- 占位美术替换为统一风格；动画/音效/UI 主题。
- 平衡：需求衰减、工作速度、伤害、突破、声望、事件强度。
- 新手引导 + 键位设置 + 音量设置 + 存档槽。
- 性能：30–50 NPC + 100 建筑 + 5×5 区块稳定 60 FPS。
- 打包 Windows 版本，给 3–5 个陌生人试玩 45–60 分钟。
- 收集反馈，决定下一阶段（多出身/更大世界/更多宗门/内政/LLM 对话）。

## 范围守卫（Scope Guard）

出现以下想法时，先写进 `docs/GAME-BRIEF.md` 的“明确不做”，不要开写：

- “既然有高度，不如做真 3D/自由旋转……”
- “既然有区块，不如做无限世界……”
- “既然有 NPC，不如接 LLM 做核心 AI……”
- “既然有宗门，不如做完整掌门内政/多宗门战争……”
- “既然有出身，不如一次做 6 条线……”
- “既然有战斗，不如做 100 个技能/百人团战……”

**每个系统先问：玩家会因此做出什么新决策？** 答不上来就不做。

## 风险清单

| 风险 | 症状 | 对策 |
|---|---|---|
| 范围过大 | 永远在“做基础” | 锁死 v0.1 范围；每周可玩构建 |
| 等距排序错 | 角色/树/建筑穿插 | 统一脚底 Y + Y-sort；测试多高度场景 |
| 区块卡顿 | 走过边界掉帧 | 每帧 1 chunk；异步；预测；预算实测 |
| 迷雾性能 | 大范围更新掉帧 | 低分辨率纹理 + dirty rect；只更新附近 |
| 高度规则混乱 | 飞行/近战判定不一致 | 先写规则表；单元测试；可视化 debug |
| 模拟性能 | 远区 tick 拖慢本地 | 分层 tick；cohort 聚合；预算上限 |
| 存档腐烂 | 改字段就读不了 | 版本号 + 迁移 + roundtrip 测试 |
| 美术拖延 | 一直在换素材 | 先用占位；M5 再统一 |
| AI 幻觉 API | 编译不过 | 查 4.7 文档/context7；先跑最小示例 |
