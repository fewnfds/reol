## 当前执行顺序：超凡者优先

详细范围与验收见[U0–U5](plans/transcendent_focus.md)，来源见[参考研究](../design/research/transcendent_focus_sources.md)。P/F编号继续用于领域/验收索引，不代表先做完整农业和全建造。

| U1 | [有限驱离冲突](qa/20261103_transcendent_conflict.md)、[本人感知](qa/20261104_conflict_perception.md)、[借源归还](qa/20261104_source_loan.md)与[具名看护](plans/source_care.md)：原剑/术法、成本/伤势、个人记忆、原管事实际验还、原NPC警告/驱离与存读 | U1-b2定向与普通路线已过，完整最终验收已通过；一源一石一人、初始两小时委托和九十秒宽限，非完整领地/战争 |

| U3（当前U3-a） | 一处真实断碑台、本人来源线索、已知地点行旅、原NPC自主寻物与后来结果 | 实施中、待最终验收；仅一处POI/一个有限目的，当前环只可观察/研究外形/取放，非完整冒险或通用规划 |

| U5 | 首小时完整流程、远区规模与独立包 | 远区从U1逐包接，不到最后才补；后续仍须全游戏长期出口 |

普通生产只补供给、材料来源、劳动与恢复路径；深化环境须直接服务超凡能力、战术或世界争夺。玩家可以是非战斗修士/创造者，重心调整不锁固定职业。

U1-b2已把地方规矩接到真实人物，U2-a已把本人来源与一项实际练习接回原护障。当前U3-a先闭合“本人获悉—原路到场—别人也会争取—后来看到结果”，同一NPC仍先顾原生活和承诺，不复制身体或重生宝物。最终验收后，U2-b再让引物环提供新操作办法并接一次具体和平交割，之后扩大多途径冒险。巡逻、产权、没收、完整农业或任意任命不作为前置；已有木剑/三招、看护或一处遗迹都不能代替完整U2/U3。

房间、家具、工作台与各类储藏的长期组合规则见[建造与空间](../design/systems/construction_and_space.md)。用户允许后续按玩法主动补设定；先让起居/炼制/记录等关键组合逐包成立，不把完整家具目录或全城镇建造当U1–U4的前置。

## 2. 当前实施的组织方式

保持“先世界规则和可玩因果，再扩大内容与规模，之后正式视听”。[世界先行W0–W7](plans/world_first_sandbox.md)提前检验不同生命、认识、欺骗、创造和尺度；[人物领域C0–C7](plans/combat_character_design.md)只在其适用范围细化动作/穿戴/学习，不要求所有生命先变成人形战士。

本轮[世界与交互原则](../design/systems/world_interaction_principles.md)扩展未来目标，但不把所有新概念变成下一包：

| 候选方向 | 前提与最小出口 | 与长期阶段的关系 |
|---|---|---|
| 交互共用入口 | 已完成辨材/探查/衔药薄门面；后续按真实用途扩展交流/能力发现，保留原判断/执行/快照 | 连接W样本与P1有限计划；不是先造万能agent平台 |
| 环境/生态与五行 | 一个可观察条件改变两种生活/用途，含远区与存读；精度/法则须原型 | 连接W1作用、P1供给、P4修行与P5地区 |
| 建筑/房间/破坏 | 门墙/屋面/围合/木床/原休息已接，E2引入真实余热后果；后续扩大生活用途 | P2；整屋蓝图是否需要由实际操作验证 |
| 组织与自动策略 | 明确成员、目的、权限、通信与职责；一个常备安排可被执行/拒绝 | 连接P1协作、P3战斗、P6组织；不每帧掷社交骰 |
| 学习与创造 | 已有温养参数试验/具体版本/当面学习/NPC采用；后续增加跨用途组合、实物记录与传播 | W6与P4；不是固定职业树换皮 |

上述是领域依赖。私料加工、预算劳动、有限交谈与[自主备粮](plans/autonomous_livelihood.md)已接；[实物衣着](plans/clothing_foundation.md)连接非战斗用途和可见穿搭，衣着不授社会权限。[身体后果/救护](plans/health_and_recovery.md)连接原温石风险、医患耗时、药材与休养，证据见[QA](qa/20261103_health_and_recovery.md)。E1–E4样本保留；当前从超凡者U1–U4的缺口选包，不继续扩大孤立农务。完整死亡/战斗、45–60分钟切片和整个游戏仍待完成。连续移动热源未来仍须扣同一实物储能，当前定点冲量不作为世界法则限制。真实伤亡须与医疗、死亡及人生接续边界一并设计。
