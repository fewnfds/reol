# Reol — 开发路线图（Draft v0.1）

> 原则：**每 1–2 周产出一个能玩、能验证的切片。**
> 不按“系统清单”开发，按“玩家体验”开发。
> 日期：2026-11-01

---

## 总览

| 阶段 | 时间 | 产出 | 成功标准 |
|---|---|---|---|
| **M0 脚手架** | 本周 | 可运行空场景 + 工具链 + 测试 | `doctor` / `test` 通过，编辑器能打开 |
| **M1 能走能看** | 2–4 周 | 玩家移动 + 相机 + 地图 + 时间 | 能在 128×128 地图上跑动，昼夜变化 |
| **M2 能活能建** | 4–6 周 | 3 个殖民者 + 需求/工作 + 储物 + 建造 | 殖民者能自主吃饭、睡觉、搬运、建造 |
| **M3 能打能存** | 3–4 周 | 战斗 + 袭击 + 存档 + HUD | 30 分钟完整循环，读档恢复 |
| **M4 垂直切片** | 2–3 周 | 音效、美术、平衡、教学 | 陌生人能不看文档玩 30 分钟 |
| **M5 内容扩展** | 之后 | 生物群系、阵营、任务、科技 | 按反馈排优先级 |

> **M3 结束前不要做**：多地图、联机、模组、复杂剧情、50+ 建筑、技能树。

## M1 — 能走能看

### 目标
玩家能在一张有地形的地图上移动，镜头跟随，时间流逝，画面可读。

### 任务
1. **Player 场景**
   - `CharacterBody2D` + `CollisionShape2D` + `Sprite2D` + `Camera2D`。
   - 8 方向移动，速度可调，`move_and_slide()`。
   - 碰撞层：player 与 world。
   - 验收：WASD/方向键移动，撞墙停止，镜头平滑跟随。

2. **地图**
   - 128×128 `TileMapLayer`，地面 + 墙 + 装饰。
   - 用占位 TileSet（Kenney 或纯色）。
   - 地图数据从 JSON/资源加载。
   - 验收：地图边界正确，玩家不能走出地图。

3. **相机**
   - 跟随 + 死区 + 边界限制。
   - 缩放 1.0/1.5 可切换。
   - 验收：镜头不越界，不抖动。

4. **时间**
   - `GameClock` autoload，10 tick/s，1 tick = 1 游戏分钟。
   - 暂停、1x/3x 速度。
   - HUD 显示第几天、时间。
   - 验收：按空格暂停，按 2 快进，时间在 HUD 更新。

5. **昼夜视觉**
   - `CanvasModulate` 或简单 shader 随时间变色。
   - 验收：白天/黄昏/夜晚可区分。

6. **测试**
   - 纯逻辑：时间推进、暂停、速度。
   - smoke：主场景能实例化。

### 里程碑验收
- 运行游戏 2 分钟，能走、能看时间、能暂停。
- 60 FPS。
- `check` 通过。

## M2 — 能活能建

### 目标
3 个殖民者能自主满足需求、搬运、建造；玩家能规划储物区和建筑。

### 任务
1. **Pawn 场景 + 数据**
   - `PawnDef` 资源：名字、速度、初始需求、工作优先级。
   - 3 个 Pawn 实例。
   - 验收：Pawn 能生成、选中、显示名字/需求。

2. **需求系统**
   - 饥饿、疲劳、心情；每 tick 衰减。
   - 阈值触发：找食物、找床、发呆。
   - 验收：不干预时 Pawn 会吃饭/睡觉；需求条变化正确。

3. **工作系统**
   - `JobBoard` + `Job` + `JobExecutor`。
   - 工作类型：haul、chop、mine、build。
   - 认领/预约/释放；失败原因。
   - 验收：两个 Pawn 不会抢同一个物品；工作完成后资源进入储物区。

4. **储物区**
   - 玩家框选区域，设置过滤。
   - 物品堆叠/数量。
   - 验收：木头/石头能堆叠，Pawn 能搬运。

5. **建造**
   - 建造菜单：墙、床、工作台。
   - 蓝图 → 建造工作 → 完成。
   - 材料检查、取消返还。
   - 验收：放置墙/床，Pawn 自动建造，完成后可交互。

6. **生产**
   - 工作台 + 1 个配方（例如木头 → 木板）。
   - 验收：Pawn 能取料、生产、放回。

7. **UI**
   - 选中面板、需求条、工作优先级面板、建造菜单。
   - 验收：鼠标/键盘都能操作。

### 里程碑验收
- 放置 1 个储物区、1 张床、1 个工作台，3 个 Pawn 自主运行 10 分钟不卡死。
- 存档前/读档后状态一致（可先做最小存档）。

## M3 — 能打能存

### 目标
完成“扎营 → 生存 → 建造 → 袭击 → 存档”的 30 分钟循环。

### 任务
1. **战斗基础**
   - 玩家近战攻击；Pawn 征召/简单攻击。
   - 血量、死亡、掉落。
   - 命中反馈、血条、伤害数字。
   - 验收：能打死 1 个敌人，反馈清晰。

2. **敌人 + 袭击**
   - 1 种敌人（近战）。
   - 事件导演：第 N 天触发一次袭击。
   - 验收：袭击从地图边缘生成，寻路到聚落，能造成威胁。

3. **防御**
   - 墙/门阻挡寻路；简单炮塔或陷阱（二选一）。
   - 验收：敌人被墙挡住/绕路；防御设施有效。

4. **存档/读档**
   - `SaveManager`，版本 1。
   - 保存：时间、玩家、Pawn、建筑、物品、chunk deltas、flags。
   - 原子写 + 迁移骨架。
   - 验收：存档→退出→读档，状态一致；损坏存档不崩溃。

5. **HUD/教学**
   - 时间、速度、资源、选中、警报。
   - 3–5 步教学提示（移动、建造、征召、存档）。
   - 验收：新玩家能按提示完成第一晚。

6. **测试**
   - 存档 roundtrip。
   - 工作预约不重复。
   - 袭击生成/寻路 smoke。
   - 30 分钟挂机不崩。

### 里程碑验收
- 从新游戏开始，30 分钟内完成：采集 → 建造 → 吃饭/睡觉 → 击退袭击 → 存档 → 读档。
- 无红色报错；`check` 通过。

## M4 — 垂直切片打磨

- 占位美术替换为统一风格；动画/音效/UI 主题。
- 平衡：需求衰减、工作速度、伤害、袭击强度。
- 新手引导 + 键位设置 + 音量设置。
- 性能：12 Pawn + 100 建筑稳定 60 FPS。
- 打包 Windows 版本，给 3–5 个陌生人试玩。
- 收集反馈，决定 M5 方向。

## 范围守卫（Scope Guard）

出现以下想法时，先写进 `docs/GAME-BRIEF.md` 的“以后”，不要开写：

- “既然有建造，不如加电力/水管/温度……”
- “既然有 Pawn，不如加恋爱/生育/遗传……”
- “既然有地图，不如做无限世界……”
- “既然有战斗，不如做 100 个技能……”
- “既然有存档，不如做云存档/多存档 UI……”
- “既然有 AI，不如接 LLM 对话……”

**每个系统先问：玩家会因此做出什么新决策？** 答不上来就不做。

## 风险清单

| 风险 | 症状 | 对策 |
|---|---|---|
| 范围过大 | 永远在“做基础” | 锁死 v0.1 范围；每周可玩构建 |
| 模拟性能 | 10 个 Pawn 就掉帧 | 固定 tick、分级 AI、性能预算 |
| AI 行为蠢 | Pawn 卡住/抖动 | 可视化调试、失败原因、限制重试 |
| 存档腐烂 | 改字段就读不了 | 版本号 + 迁移 + roundtrip 测试 |
| 美术拖延 | 一直在换素材 | 先用占位，M4 再统一 |
| 架构过度 | 大量空框架 | 按需创建，先写 100 行能跑的 |
| AI 幻觉 API | 编译不过 | 查文档/context7，先跑最小示例 |
