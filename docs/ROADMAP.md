# 开发依赖与长期出口

本页只管理依赖和优先级；授权/暂停见[HANDOFF](HANDOFF.md)，完成度见[FEATURES](FEATURES.md)，验证见[BASELINE](BASELINE.md)。旧M/P/W/U/E编号是不同阶段的工作包标签，不是并行的强制路线。

## 当前工程主线

按[世界引擎总计划](plans/world_engine_program.md)和[唯一执行页](plans/world_engine_execution.md)推进，顺序为：

1. **世界输入与独立装配**：版本化定义/开局、候选隔离和明确兼容；保留原唯一身体/物品/时间。
2. **对象与平面空间**：生成/定位/容器/转移、可改造地块、墙门顶/围合/导航，配最小编辑与诊断。
3. **环境及作用**：地理/日照/季节/天气、冷热、光、五相灵机分开，各由真实源、传播、阻隔和受体产生结果。
4. **行为与持续世界**：动作的预约/耗时/成本/中断/结果，有限自主及近远区一致性，编辑→新局→改造→离场返回→存读重启。
5. **规模验收**：递增地图、实体、源、路径/结构与长时负载；记录实际耗时/内存和因果误差，按结果优化。

各包状态只在执行页维护。A0a代码存在不代表A0全部完成；环境分项见[foundation](plans/world_engine_foundation.md)。高差/完整3D不是当前前置。

## 架构之上的玩法重心

优先超凡者的战斗、器物/衣饰、来源学习网、功法、冒险、组织和世界事件。生产、天气与生态先支撑真实循环，不为农务细节推迟修仙玩法。通用系统先获得可复用出口，再装配具体冲突，不持续围绕一枚环磨特例。

[超凡者方案](plans/transcendent_focus.md)和[世界先行样本](plans/world_first_sandbox.md)保留体验方向；既有局部样本不重做，也不自动恢复其旧“下一包”。

## 长期产品出口

| 出口 | 负责文件 | 与当前工作的关系 |
|---|---|---|
| 45–60分钟“一山一宗”可玩切片 | [完整计划](plans/full_game_program.md)、[验收矩阵](plans/full_game_acceptance.md) | 最近的内容/体验出口，尚未验收；引擎完成不等于切片完成 |
| 多区持续世界、经济/组织、冒险/冲突 | 同上及各领域设计 | 用引擎装配，规模和内容由测量验证 |
| 出生/成长、有限转生及终局 | [有限转生](../design/systems/rebirth_and_new_lives.md) | 保持世界不回滚等已定概念；当前未实现 |
| 正式视听、长期稳定、Windows独立包 | 完整计划与验收矩阵 | 先玩法，后正式资源；代码像素仅占位 |

当前没有承诺固定工期、人口容量或整款游戏完成日期。算法/平衡与常规技术由开发处理，改变游戏概念才由用户拍板。
