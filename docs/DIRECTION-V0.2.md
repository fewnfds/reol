# Direction v0.2 — 修仙大世界 / 低美术高玩法

> 状态：**已定稿（2026-11-01）**。渲染方案已选：**2D 等距 + 高度层**；不做 3D/联机/体素。
> 关联：`docs/GAME-BRIEF.md`、`docs/DECISIONS.md`、`docs/ARCHITECTURE.md`
> 决策记录：ADR-0013 ～ ADR-0019

---

## 1. 最终结论

1. **视角**：2D 等距（2:1），固定约 45° 视觉角，类似 WC3/SC 的镜头感；相机自由平移 + 缩放，**不旋转/不俯仰**；玩家视野外战争迷雾。
2. **世界**：512×512 首区；64×64 区块；5×5 加载；远区纯内存/抽象模拟；无缝流式；尽量少过图/加载屏。
3. **阵营**：WoW 式阵营/敌友/声望；Warhammer 式简约内政；玩家是势力一员（杂役/小兵/头目/长老/掌门/散修/邪修）。
4. **NPC**：复杂关系网；脚本/效用 AI 优先；LLM 后期只做对话风味；AI 托管主角是后期功能。
5. **战斗**：即时战斗 + 可暂停；局部慢放是后期高阶技能（敌人减速、玩家正常）；小规模。
6. **高度/飞行**：WC3 式视觉高低差 + 规则层；不做真 3D 空战。
7. **题材**：修仙；不同身份有完全不同日常体验。
8. **美术**：像素等距 + 国风有限色盘；低美术、高玩法；先占位后细化。

## 2. 三个关键澄清

### 2.1 “2D 倾斜”是等距美术，不是真相机倾斜

WC3/SC 的观感 = **等距/斜 45° 美术 + 固定角度相机 + 平移/缩放**。
真正的“自由旋转/倾斜镜头”需要 3D 或 2.5D。

- **2D 等距 + 高度层**：便宜、RimWorld 式可读性、适合低美术；镜头固定角，不旋转。
- **3D 正交 + billboard**：真相机旋转/倾斜、真高度/飞行、迷雾更自然；但 3D 导航/碰撞/美术管线更重。
- **2.5D（3D 地形 + 2D 角色）**：中间路线，成本仍高于纯 2D。

**已定：2D 等距 + 高度层。** 理由：本项目的核心卖点是系统/身份/势力/战斗，不是镜头表演；2D 把美术和迭代成本压到最低，单位可读性最好。3D 的额外成本（相机、拾取、地形 mesh、动画、光照、UI 投影）会直接吃掉玩法开发时间。

### 2.2 “网游感”不等于联机

“世界像一个网游”用**单机分层模拟**实现：
- 阵营/声望/关系网
- 远区势力/事件在内存里推进
- NPC 有日程/记忆/传闻
- 玩家听到远处战争/秘境/宗门变动
- 玩家不在场的重大事件用算法结算（类似全战/Paradox 的战略层）

真正的 MMO 需要服务器权威、复制、持久化、反作弊，是另一个量级的项目。
**已定：单机模拟的网游感，不做联机。**

### 2.3 AI NPC / AI 托管主角是“层”，不是地基

- **核心模拟**：规则/效用 AI/行为树，确定性、可存档、低成本。
- **对话层**：模板/分支，后期可选 LLM 生成风味。
- **托管层**：AI 用和玩家相同的 action API 操作主角；是后期功能，不是 v0.1。

不要让核心玩法依赖 LLM 的延迟/成本/不确定性。

## 3. 渲染方案对比（已拍板）

| 维度 | 2D 等距 + 高度层（选用） | 3D 正交 + billboard | 2.5D 混合 |
|---|---|---|---|
| 观感 | WC3/RimWorld 混合 | 真 3D 镜头 | 3D 地形 + 2D 角色 |
| 美术成本 | **低** | 中 | 中高 |
| 相机 | 平移/缩放，固定角 | 平移/缩放/旋转/倾斜 | 平移/缩放/有限倾斜 |
| 高度/飞行 | 伪高度（分层/偏移） | 真高度 | 真高度地形 |
| 迷雾 | 网格遮罩 + shader | 平面/体积遮罩 | 混合 |
| 导航/碰撞 | 2D 网格，简单 | 3D，复杂 | 混合 |
| 开发速度 | **快** | 慢 | 中 |
| 适合 | 低美术、大量单位、RimWorld 式 | 飞行/自由镜头是核心 | 想兼顾但预算足 |

**最终选择：2D 等距 + 高度层。**

- 镜头：固定 45°，平移/缩放；不做旋转。
- 高度：每格 `elevation`（0–3），实体 `altitude`（0/1/2）；渲染偏移 + 影子；飞行 = 忽略地面障碍。
- 迷雾：网格可见性 + 迷雾层。
- 如果以后必须真 3D，至少坐标/数据/模拟层可以复用，渲染层重写。

**为什么不做 MC 式 3D**：MC 的核心是体素破坏，不是低多边形；体素分块/网格/物理/存档 delta 会吃掉大量玩法开发时间。我们要的是“平面系统深度 + WC3 式高度表现”，不是立体沙盒。

## 4. 世界模型：分层模拟（“远区纯内存”）

| 层级 | 内容 | Tick | 渲染 | 持久化 |
|---|---|---|---|---|
| **World** | 阵营、战争、外交、经济、大势 | 每游戏天 | 无 | 全部 |
| **Region** | 宗门/城镇/灵脉/秘境、人口、资源 | 每游戏小时 | 地图/图标 | 关键状态 |
| **Settlement** | 宗门内部、建筑、职位、任务 | 每几秒/游戏分钟 | 靠近才渲染 | 建筑/职位/关系 |
| **Local/Chunk** | NPC、工作、战斗、物理 | 10Hz | 是 | 实体状态 |
| **Detail** | 动画、粒子、UI | 每帧 | 是 | 否 |

规则：
- 远区只跑 World/Region；不创建场景、不跑物理。
- 靠近时把数据“提升”为场景实体；离开时“降级”为数据。
- 具名 NPC 永远持久化；普通 NPC 可统计/池化（cohort）。
- 玩家不在场的战斗用统计模型结算（兵力/地形/士气/将领/补给），产出伤亡、领土、战利品、仇怨。
- 玩家听到的远区事件通过**传闻/新闻/任务**呈现，不直接模拟每个 NPC。
- 每个领域独立种子 RNG；存档记录 `sim_time`；读档按粗粒度补算并设上限。

### 4.1 区块与无缝加载
- 首区 **512×512**；区块 **64×64**（8×8）；加载半径 2（5×5），卸载半径 3。
- 一个持久 `World` 场景；不切地图；POI/洞府子场景异步加载。
- 每帧最多加载 1 个区块；预测玩家移动方向。
- 地形由 seed 重建；存档只存 deltas。
- 地图尺寸不硬编码；后续扩到 1024/2048 或区域拼接。

### 4.2 战争迷雾
- 每格三态：`HIDDEN` / `EXPLORED` / `VISIBLE`。
- 可见性 5–10Hz 更新；视线用网格 Bresenham + 高度/遮挡。
- `FogOfWar` 层（低分辨率可见度纹理 + shader 或 TileMapLayer）在 world 之上、UI 之下。
- 已探索区域持久化；可见区域实时重算。
- 只更新玩家附近区块。

### 4.3 高度与飞行（WC3 式）
- 地形 `elevation` 0–3：影响移动成本、视线、远程射程/命中、遮挡。
- 实体 `altitude` 0/1/2：地面/低空/高空。
- 渲染：`screen_offset_y = -altitude * PIXELS_PER_ALTITUDE`；影子留在 ground position，随高度变小/变淡。
- 规则：地面近战不能打空中；远程/对空技能可以；高度差修正命中/射程；飞行忽略地面障碍，但受禁飞区/室内限制。
- 不做：真 3D 空战、自由俯仰、空中碰撞体积。

## 5. 阵营 / 声望 / 身份

### 5.1 数据模型
- **Faction**：id、类型（宗门/王朝/部族/散修联盟/邪道）、领袖、领地、资源、教义、关系矩阵、职位表、颜色/徽记。
- **Rank**：杂役 → 外门 → 内门 → 真传 → 长老 → 掌门；每个职位有义务/权限/声望门槛/修炼门槛。
- **Origin**：起始势力/职位/位置/物品/任务/flags；Demo 只做杂役，后续多出身靠数据。
- **Reputation**：对势力 + 对具名 NPC；事件驱动（任务/送礼/杀人/贡献）；阈值解锁职位/商店/对话/任务。
- **Relationship**：NPC 之间的关系（师徒/同门/仇敌/道侣/债主）；影响对话/援助/背叛。
- **Edict**：势力方针（资源分配/招募/建设/戒律/外交/战争），玩家作为首领只做少量决策。

### 5.2 身份体验
| 身份 | 日常 | 权限 | 核心张力 |
|---|---|---|---|
| 杂役 | 挑水/砍柴/炼丹房打杂 | 低 | 生存 + 偷学 + 攀附 |
| 外门/内门 | 任务/修炼/比试 | 中 | 竞争 + 资源 |
| 真传/长老 | 带队/管事/传授 | 高 | 派系斗争 + 责任 |
| 掌门 | 内政/外交/战争 | 最高 | 战略取舍 |
| 散修 | 自由/接单/逃命 | 无 | 无靠山 + 机缘 |
| 邪修 | 禁术/掠夺/被追杀 | 无 | 力量 vs 代价 |

**v0.1 从“杂役”开始**：教学自然（杂役工作=游戏系统）、逆袭弧线清晰、能串起所有系统。
架构上把出身做成 `OriginDef` 数据；后续换出身 = 换数据 + 少量专属任务脚本。

## 6. 战斗与时间

- **实时 + 暂停**：空格暂停，下令，继续；速度 0/1/2/4。
- **子弹时间**：高阶技能；敌人 `time_scale=0.3`，玩家 1.0；不是全局 `Engine.time_scale`。
- **实现**：每个 actor 有 `time_scale`；移动/AI/冷却/投射物乘自己的 delta；物理用 `CharacterBody2D`/自定义投射物，避免依赖全局物理减速。
- **战斗规模**：玩家 + 3–5 同伴 vs 5–10 敌人；不是百人团战。
- **高度**：地面近战不能打空中；远程/对空技能可以；高度差影响射程/命中/视线；视觉用偏移 + 影子。
- **可读性**：阵营颜色、血条、施法条、地面预警、仇恨/威胁提示。
- **技能**：1 普攻 + 2–4 主动；修炼体系提供剑诀/符箓/阵法/身法；后期解锁时间领域。

## 7. 美术方向：低美术、高玩法

### 7.1 选定风格
**像素等距 + 国风有限色盘**（墨黑、纸白、青玉、朱砂、金）。
- 2:1 等距 tile（64×32 或 32×16）。
- 角色纸娃娃：身体 + 发型 + 服饰 + 武器；不做每个 NPC 独立立绘。
- 建筑模块化：墙/屋顶/门/窗/装饰组合。
- VFX 用 shader/粒子：剑气、符光、墨爆、灵气。
- UI 以文字/图标/列表为主，减少大图。

### 7.2 备选（后期统一时再评估）
**水墨简约**：更强的风格，但资产更依赖手绘/生成一致性；适合后期统一，不适合先用占位。

### 7.3 压缩美术的手段
- Tile atlas + palette swap（阵营/季节/境界）。
- 2–4 帧循环动画；关键动作 6–8 帧。
- 模块化建筑/服装。
- 用 shader 做发光/描边/溶解/雾气。
- 复用 Kenney/LimeZu 占位；M5 再统一。

## 8. 首个可玩切片：“一山一宗”

> 目标：45–60 分钟，证明“杂役逆袭 + 活宗门 + 可暂停即时战斗 + 大世界流式”的核心幻想。

### 必须有
- **512×512** 区域；64×64 区块；5×5 加载；战争迷雾；至少 3 级高度。
- **一个小宗门**：山门、练功场、丹房、杂役院、后山。
- **玩家：杂役**；5 个具名 NPC（师父/师兄/对头/商人/神秘散修）+ 普通弟子。
- **日常**：杂役工作（挑水/砍柴/扫地/送药）、修炼、吃饭/睡觉、接任务。
- **成长**：1 条修炼线（炼气→筑基或类似）、2 个技能、1 次职位晋升（杂役→外门）。
- **战斗**：实时 + 暂停；1 个敌对势力前哨；1 个后山秘境/洞府；掉落/资源；至少 1 个飞行/高地场景验证高度规则。
- **阵营**：声望、宗门贡献、1 个敌对势力、1 个中立商人。
- **世界**：昼夜、区块流式、存档/读档、至少 1 条远区传闻。
- **UI**：HUD、对话、任务日志、声望/职位、简单地图。

### 明确不做
- 联机、LLM 核心 NPC、AI 托管主角。
- 真 3D、自由旋转/俯仰、体素破坏、真 3D 空战。
- 掌门内政/大规模战争。
- 多宗门/多地图/多生物群系。
- 完整修炼树/炼丹/炼器/阵法（各留 1 个最小循环即可）。
- 100+ NPC、完整世界模拟、模组 API。

## 9. 架构影响

新增系统（按需创建）：
- `IsoGrid`：等距坐标/高度/排序。
- `FogOfWar`：可见性/已探索/迷雾渲染。
- `ChunkManager`：流式加载/卸载/deltas。
- `WorldSim`：World/Region 层抽象模拟、缺席战斗结算。
- `FactionRegistry` / `ReputationSystem`：阵营/声望/关系。
- `RankSystem`：身份/职位/义务/权限。
- `TimeDomain`：全局暂停 + 局部时间缩放（子弹时间）。
- `ActionAPI`：玩家/AI/托管共用动作接口（先留形状）。
- `PlayerAgent`（后期）：AI 托管主角。

存档新增：
- world seed、chunk deltas、faction state、named NPCs、player rank/reputation、fog explored、quest flags、sim_time。
- 普通 NPC 不逐个存；具名 NPC 存。
