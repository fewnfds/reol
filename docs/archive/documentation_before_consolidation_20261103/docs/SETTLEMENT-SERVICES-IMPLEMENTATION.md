# 跨聚落办事与互助交付记录

日期：2026-11-02。本页记录本次交付证据；当前总体进度以 [BASELINE](BASELINE.md) 为准。规则见 [设计](../design/systems/settlement_services.md)，范围见 [工作包](plans/settlement_services.md)。

## 已交付

- 两地访客取食和休息：实际走到设施，消耗世界时间、饭和盘缠。自带饭直接消耗；买饭在取走时付款，中断后饭仍在原背包，继续不会重复付费。
- 运粮：先核对真实短缺并预留需求，再去河湾取6份粮、带回山门交货。NPC 自动运输计算已承接需求；取货时重新核对留粮底线和可用库存，不凭空生成货物。
- 机构办事：交付凭据与实际操作相连；另到功德堂报工，有权且在场的管事核验后记3贡献。同一凭据只能入账一次。花1贡献兑换有库存的饭；余下2贡献可以申请药圃通行，再实际入圃取药。
- 账本分属当地机构。人在河湾时仍使用原人物、身体和背包；山门贡献不会自动变成河湾贡献。资格、授权、实物交付分别复核。
- 运粮人合作：距离、体力、既有承诺、道路、实际需求/余粮、报酬和有种子的请求判定共同决定。接受后托管2钱，绑定具体货物批次；真实交货后只付款一次，封路时保留未结承诺。
- 服务进入共同时间调度，原本地执行器和玩家行程不能同时接管人物；取消、死亡、超时保留已取出的物资。存档包含事务、证据、授权、随机状态、托管及付款，完整校验候选后才替换。

## 试玩入口与限制

F6/F5或运行主场景，先暂停，左下“承接运粮”，恢复时间并可按4加速。交货后依次“去报工”“换饭”“申请通行”“凭据取药”。右下可前往河湾，当地吃住、去仓库等运粮人、开口或出2钱协商；右下仍可切换测试道路和保存/读取。WASD或停止按钮可中断。若补给已被NPC满足，差事会拒绝，不为了玩家刷新假需求。
