## 当前是什么

可运行、有持久世界和几条相通生活循环的系统原型。仍属M2活社会切片，尚未达到45–60分钟稳定内容量，不能称为完整修仙沙盒或发布版。

## 已能实际操作

- 首区512×512、区块加载、高度、视野/探索、共用时间、暂停/倍速/等待、真实走动/闪身。
- 两聚落各自日常与运输/延迟来信；人物、货物和未完成事务在离场与存读后继续。
- 亲自搬柴、挑水、运粮、下厨、采集，实际交付后向机构记功，再兑换现有饭食/申请通行；私人关系不直接变成机构账面。
- 个人所知与实物状态分开，库存说法可以过时/错误；请求会根据处境接受或拒绝，报酬托管后实际完成才付款。
- 温火石可以有限探查、反噬、请人辨材/指导、做饭或烘药；各人理解不同，材料裂损与个人手法分别保存，NPC有有限办法选择。
- 原人身与同门可约练，使用同一位置/体力，起势、几何接触、收势、闪身与疲惫收手。
- 新开局可一次选择杂役、雀妖或戒中残识。雀妖飞行/觅食/歇翅/携轻药；残识只能有限感知、传意、请求他人实际携戒、休眠自醒。原人身继续自主，不能免费运行中换人。
- 最新资格样本：阿禾未采信，石头暂信并允一次取药，玩家实际取到一枝药后仍无正式通行、贡献仍零。管事核验缺档不广播；真实出示回执才改变石头的依据。重复声称不重掷、不补额度。

## 这些只是局部证明

远区连续性只在当前双聚落规模验证；物品只有当前库存与少量独立器物，非完整物品/产权系统。对练不是正式战斗；个人理解不是通用知识推理；几种身体开局不是完整种族冒险或转生。NPC日常与有限办法选择已运行，NPC自主欺骗/政治经营、通用规划与大规模文明模拟未实现。专用样本仍较多，尚未形成充分通用的动作组合。
