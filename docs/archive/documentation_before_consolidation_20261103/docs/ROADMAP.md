## 完整游戏路线

用户新范围是持续大世界、修仙RPG、城镇/宗门经营、多身份与地区冲突；先玩法闭环后正式美术。推荐1.0内容量和容量尚待验证。下表只作导航，规则和每包依赖不在此重复维护。

| 顺序 | 内容 | 状态 |
|---|---|---|
| P0 | 测量、完整持久化/迁移、战斗时间语义试验 | 探索/生成/历史档迁移、共同毫秒执行、NPC/自动路线和体力恢复已接；当前小世界呈现复查已交付；规模性能与完整未来领域出口待做 |
| P1–P2 | 生计生产、有限自主计划、建造与经营 | 劳动换饭与库存说法影响补给已有小样本；市场/再生产/通用规划/建造未完成 |
| P3–P4 | 战斗/伤亡接续、修炼/交涉/冒险、一小时切片 | 首个几何动作对练已实现；伤亡/修炼/冒险/内容量待实施 |
| P5–P7 | 多区生成/贸易/迁居、组织继任、战争/历史/多出身 | 待实施 |
| P8 | 完整玩法Alpha、长稳/平衡/试玩 | 待实施 |
| P9–P10 | 正式视听、独立包性能与发布验收 | 待实施 |

资源研究与Goal接续见[搜集工作包](plans/resource_tooling_scout.md)，本机Skill/MCP实测见[工具审计](DEVELOPMENT-TOOLS-AUDIT.md)。候选资源未安装，不自动成为依赖。
