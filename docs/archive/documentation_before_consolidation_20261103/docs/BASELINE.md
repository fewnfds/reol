- 统一面板恢复亲自劳作，接通真实劳动→凭据→机构登记→兑换饭食→吃随身饭；0钱也可走这条路径，中途存读接续。
- 库存说法与实际存量分开：个人亲见/听说/来源/过时与冲突形成有限预期；NPC补给按所知安排，询问按所知答复，亲自查看纠正本人。山门交谈页已可操作，移除聚落面板直接显示后台仓库总量的文字。尚非完整通用信念/骗术系统。
- `SimEmbodiment`分开现有居民的主体、身体引用、居留与移动/行动/通信控制；原身体位置、物资与个人记忆仍由既有领域持有。原生劳作、访客服务、手动/自动移动与谈话使用同一控制查询；失控中断保留实物，读档不重发控制。后续avian_body已引用实际雀身；古兽仍是纯代用品；雀妖开局与实际封魂载体/独立NPC寄魂与寄魂玩家开局已接。
- 首件生活器物温火石：新开局灶房有唯一实例；按I或点击石头，可走近/端详/取放/付出灵气探查/催火/温养。未知用法可能回卷损耗体力，学会后的有限储能可替柴烹饪，仍消耗真实米水并生成饭和原有待记功凭据。个人经历、投入/进行中动作与容器位置存读；展开不学习，UI不读隐藏储能。旧档迁为空器物领域。效果耗时仍用分钟定义，但从实际开始毫秒计满时长；是专门规则，非通用法器/热力学/创法。

- 玩家速度/闪身阶段由纯SimLocalMotion持有，位置直接引用原actor身体；节点只采输入和投影。Shift有起势/位移/收势，真实扣体力、扫掠地形、失控中断，不授予无敌。结束后延迟1000ms，再以8体力/秒恢复到原身体上限。真实v5闪身与v6自动途中档保留跨进程证据。走进聚落和身体资源读档立即刷新交互/HUD。
- 首个山门同门对练：K面板约练、J试掌、WASD走位和空闲时Shift。NPC按精力/饥饿/手头工作决定是否答应；双方共用原位置/体力和执行权。起势→扇区接触→收势，地形/高差资格、同刻互中、实际位移避开、有限接近AI和主动/疲惫/失控收手已接。进行中保存/重启不重扣、不重命中，结束恢复原自主生活；旧档迁为空对练。仅受控练习，不含永久伤势/死亡、武器、通用学习网或经验奖励。见[样本范围](plans/sparring_sample.md)和[实际验收](qa/20261103_sparring.md)。
- 温火石第二用途烘药与NPC有限办法选择：同一供热/库存事务做饭或将原草药变成干药，余热/灵气/材料实际消耗。阿禾可按自己的库存预期与经历端详→探查→以石代柴；实际试出没热后才考虑本人注灵。玩家不自动学会。中途存读、缺料/容量/预约原子失败、粗细推进及分数分钟完成面板已验证。见[实际证据](qa/20261103_heat_methods.md)。干药医疗/市场和长期再生产尚未完成。
