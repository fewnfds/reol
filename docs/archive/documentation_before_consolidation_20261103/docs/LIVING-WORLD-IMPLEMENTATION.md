# 世界模拟框架：首个运行版本

日期：2026-11-02。基于 [总体计划](../design/systems/living_world_framework.md)。这一版接通日常、交互、信息、账目与存读；长期政治和世界演化尚未接入。
> 后续连续性已接入：双聚落调度、远区批算、真实运粮、延迟消息、途中返回和联合存读已验证。最新 **37 组 / 1,082 断言 / 0 失败**，见[双聚落实现记录](WORLD-CONTINUITY-IMPLEMENTATION.md)。本文保留首个单聚落版本记录，未同步的“尚无远区”描述属于历史。

## 试玩

运行主场景。现有 5 名 NPC 会按身体需要和工作职责自主行动：取食、休息、做饭、挑水、送柴、运粮、巡视和报工。灶房缺柴时，阿禾会向附近人物求助；是否接受受到精力、正在做的事、职责、交往预期和个体偏好影响。

- 左下角“生活与往来”：让玩家取食、休息、搬柴或去交工。
- 左键选中附近 NPC，可请求帮忙搬柴；距离过远、正在忙或精力不足可能被拒绝。
- WASD 手动移动会取消自己的托管行动。已取出的物资留在随身容器，之后可以续用。
- 搬柴完成后还需报工，贡献由有权的记账人登记。无需求的重复搬运不会持续刷贡献。
- 空格暂停，1/2/4 倍速；移动、工作与需求使用同一游戏时间。
- 面板按钮保存/读取近况；同时保留 F5/F9。编辑器嵌入窗口的合成 F9 输入在 QA 中触发过原生调试挂起，按钮读取已验证不触发该现象，编辑器内优先使用按钮。

界面仍是开发期样式，身体数值和设施使用占位显示；完整对话、关系展示与美术后续再定。

没有新增 autoload、依赖或场景文件；没有修改第三方插件。原来的 `PawnState` 保留人物表现所需的身体与身份视图，贡献和总声望字段已移除。出身带来的初始贡献作为机构开账记录保存。晋升资格读取已认可的账目，审批 API 另查决定者权限。

人物实例 ID 与定义 ID 分开，可以用同一定义初始化多个独立人物。当前画面仍装配原来的玩家与 5 名 NPC。

## 信息与执行边界

事实日志包含结算与排错所需数据；人物只获得参与、附近观察或具体来源传递的副本。私人原因不会自动进入见证者认知。关系更新需要人物已知的事件依据，重复同一证据不能重复加关系。

请求的决定按语义条件缓存；公开/执行进度单独保存。同议题没有实质变化时不重骰，也不重复启动已经完成的承诺。下一轮真实短缺有自己的局势 ID。

人物只以其观察到的库存摘要形成工作意向；执行预约和取物再检查实际资源。物资取出后进入携带者容器，取消不退款造物；重新吃饭或生产能复用袋内材料。生产检查所有输入和输出容量后才结算。

## 存档边界

默认文件是 Godot 用户数据目录下的 `village_save.json`，备份为 `.bak`。临时文件验证后替换，损坏或不匹配的读取保持当前世界状态。

当前快照覆盖模拟人物、位置、身体/成员层级、物资、预约、行动进度、消息、关系、请求、账目、授权、局势、随机状态、时钟与玩家精确位置。随机状态按字符串保存；人物执行/观察使用稳定顺序，避免 JSON 键排序改变结果。

这是版本 1 的模拟快照，要求当前配置和固定地形种子一致；尚无旧版本迁移。迷雾探索、未来地形改动与建造数据未纳入，不能据此宣称完整世界存档已经完成。
