## 用户要求与当前边界

玩家是世界中的普通参与者。其离开某处后，当地人物仍根据自身需要、个性、职责和所知情况行动；生产、交易、交往、冲突及其他大小事务继续发展。返回时看到的是这些过程延续至今的现状，可以接续途中事务，并通过痕迹和知情者理解部分经过。

“百年闭关”是说明时间影响的例子，不是优先制作的专用功能。离开几分钟、几天和更长时间，遵循相同的连续性要求。

原有 `VillageRuntime` 的 5 名 NPC 不按视野停模拟。最新版本增加双聚落调度、稳定区间批算、在途货物、延迟消息和入场接续；交付与限制以实现记录为准，不能等同完整大世界模拟。

地图渲染区块与模拟区域是不同概念：一个聚落或事务可以横跨多个地形块。卸载地形不能顺带销毁人物、工作或社会状态。

## 连续性契约

| 内容 | 远近切换时保留什么 |
|---|---|
| 人物 | 稳定身份、身体与能力、目标、职责、认知、关系和关键经历 |
| 行动 | 当前计划、阶段、时间进度、目的地、受阻原因与重评条件 |
| 资源 | 数量、实际位置/容器、在途保管、预约与已结算操作 |
| 社会事务 | 承诺、期限、担保、职位、账目、授权和正在发展的争议 |
| 时间与因果 | 已推进至何时、下一事项、相关版本与随机状态 |
| 消息 | 来源、知情范围、发送/到达时间及尚未送达的内容 |

世界状态独立于场景加载。同一对象在同一时刻只有一个负责结算的执行方式，远近模式不得同时推进它。切换精度不重建人物或重抽已经确定的结果。

两种精度可以产生不同的细节轨迹；必须保持资源约束、时间顺序、已发生事实和未结责任。玩家入场后采取行动，可以改变尚未发生的结果。

## 算法提案：按下一次变化推进

远区保留人物和组织的行动理由，省去逐格行走、物理碰撞、动画和每帧查询。日常稳定阶段批量计算，需要作决定或处理变化时才唤醒相关人物。

每个区域记录 `last_simulated_time`，人物/组织保留当前计划与下一次待处理时刻。使用游戏世界时间，不默认推进玩家真实离线期间。

```text
取出最早到期的事项
  → 将相关过程推进到这一时刻
  → 结算到达、完工、需求阈值、库存边界、期限或消息抵达
  → 使受影响的旧预测失效
  → 相关人物依据自己获知的情况选择后续行动
  → 排定下一事项
```

在输入、人员和规则稳定的一段时间内，可以批算资源消耗、工作、休息和沿路线的旅途进度。区间必须在最早约束边界结束：例如材料耗尽、容量达到上限、人物需要吃饭、期限到达或途中受阻。

多个行动竞争同一资源时使用共享预约和稳定的同刻结算规则。缺货、死亡、道路或职位变化会打断相关批算，使有关计划重新评估；不能把这些影响抹平成固定日产量。

人物需要、职责、偏好、承诺与认知继续决定选择。远区只减少状态未变时的重复评估，把具体动作替换为耗时过程；需求越界、缺货、受阻或消息抵达等必要决策不能因距离变远而延后。例如运输仍依赖路线、速度、货物和风险，消耗同一份时间和资源。物理结算可以发现真实道路受阻；人物在途中发现或收到消息后才理解它，不能提前知道秘密。

具名、已交往或承担重要事务的人物保持个体身份。大量尚未细化的背景人口后期可按职业群体汇总；已经形成持久关系的个体不能随卸载丢弃、回来再随机生成替代者。

## 跨区、预算与接续

货物离开 A 后进入在途容器，到 B 后再交付。人物只有一个 ID 和当前位置/路线进度，跨区结算有稳定操作标识。跨区标识不能直接复用各聚落内的自增序号；首版可采用持久区域 ID 加本地序号，或由统一调度器分配，并纳入快照。相邻区域通过具有到达时刻的运输、人员和消息相互影响。

调度按活跃事务、关键人物和决策节点分配计算，空闲区域可跳到下一事项，同类低影响日常可合并。首版由统一调度器按世界时间处理各区域事项和跨区事项；A 的批算不能越过来自 B 的更早影响，处理影响后再预测后续。同刻采用稳定结算规则，互有关联的区域不能任意互相超前。预算不足时分帧处理并限制世界推进速度，保留待处理时间，不能静默丢掉时间造成事实断层。

进入近区前，在一致结算点把相关对象推进到当前世界时间，移交执行责任，并展开未完成行动。人物可以在途中、工作台旁或交战现场，不统一回出生点或日程起点。

离开时保存动作和资源状态交给远区执行。切换使用缓冲或迟滞，避免边界来回走导致反复重建。战斗、交易、运输各有接续规则；尚无可靠粗算器的领域可暂保留其执行，不能直接取消或重置。

重要随机结果绑定人物/事务和发生节点，保留已确定结果与随机状态。进出区域不能重抽战果。新事件可以使未来预估失效，但不能改写已经发生的历史。

## 玩家如何感受到它

实际发生、消息送达和玩家知晓是三个时间。玩家可能先见到缺货、伤员、换岗或人物缺席，再听到原因，也可能听到过时传闻。人物的记忆、计划和信息不因切换精度变得全知。

世界也可以平稳运转。变化由现状、人物行动和环境推动，不强制每次返回都发生大灾变；玩家升级或接近某地本身不作为远方人物开始生活的开关。

## 已实现首轮：两个小聚落验证

先建立两套小型生活循环和一条有限运货路线。复用现有状态、动作、库存、记忆与账目，新增区域调度、远区执行和接续边界；先不扩大地图面积或人口规模。

1. 玩家从 A 去 B，A 继续生产、消耗、休息和处理短缺。
2. A 的人物按需求向 B 运货，玩家不在场时仍产生有依据的到达、延误或缺货结果。
3. 两人竞争同批材料，或中途道路受阻，相关计划改变，资源不复制；来自另一聚落的更早到达/消息能打断原批算，不被较晚结算覆盖。
4. 玩家在运输或其他未结事务中返回，位置、进度和状态连续，可以干预后续。
5. 消息经过渠道送达，玩家与不知情 NPC 不自动获得全历史。
6. 途中保存、读取并反复进出，身份、资源、关系、账目和责任不重置、不重复结算。
7. 对简单场景比较细算与粗算的守恒、因果、耗时及约定误差；各自同初态与调度可复现，不要求两精度逐位相同。

基础连续性优先于扩大组织服务、编写更多冒险或制作长期跳时演出。验证后再增加区域、人口和可粗算的行动种类。
