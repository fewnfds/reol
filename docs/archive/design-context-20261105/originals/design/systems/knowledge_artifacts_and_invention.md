## 1. 三条不同的链

2026-11-03补充：[所见、所知与所在意](perception_and_understanding.md)进一步分开信号、理解、关注和表达。小道士只觉古剑不凡，武学大家能识别部分深层用法，工匠能看懂铸痕；普通衣食可默认简述，处境改变或主动查看时再展开已有依据。兴趣不改真值、不封锁调查，修为不授予所有领域的全知。

    事物是什么、能发生什么             → 世界状态与作用规则
    某主体看见什么、相信什么           → 感知、认识、消息与证据
    某主体知道怎么做、能否承担并控制   → 所学方法、载体、准备与处境

它们可以不一致。凡人拿着仙器，可能只看出材料珍贵；低修为器匠可能认出机关，却无法驱动核心；高阶强者可能能强行输出，却完全不懂某派禁制。世界不统一问“人物等级≥物品等级吗”。

有些性质可测，有些历史只能依靠遗迹与证言推断，有些权利本来就在争议中。所谓世界真值不意味着世界有一个客观“此物该卖多少”“谁在道德上正确”的万能答案。

## 2. 物品不是一串默认公开的词条

物的真实定义可包含材料/结构、可发生的作用、储能/供能接口、维护需求、损伤、容纳/封存、绑定/授权和重要来历。只有需要独立身份或状态的物才建实例；普通粮食仍可按可区分批次与数量管理。

观察不是读取全对象。每次检查指定目标、方法、媒介、接触程度、耗时、观察者已知基础和可能暴露的自身行为。

| 识别层次 | 可能获得什么 | 典型依据 |
|---|---|---|
| 表象 | 色泽、尺寸、温度、纹样、磨损、声音 | 当前感官与遮挡；某些信号可伪造 |
| 构造/材料 | 层次、接缝、材质、修补、承力 | 工艺经验、工具、取样或已知比较物 |
| 反应 | 输入少量灵机/热/动作后出现何种现象 | 有界试验、仪器、见证；试验可能影响对象 |
| 功能模型 | 在什么条件下能做什么、大致风险 | 文献、师承、拆解、多次试验与解释 |
| 来历/权限 | 谁制造/持有/认可，何种用途被允许 | 来源链、账目、印记、证人；不是全部可由扫描证明 |

并非必须按这五层顺序解锁。你可以先从老人得知操作法，仍不知道金属成分；也可认识材质却不知历史。界面按性质记录已知内容、来源、时效与把握，不使用一根“鉴定进度条”掩盖不同知识。

### 2.1 “实力不足看不穿”要落实到原因

- 感官达不到：看不见某层灵机、听不到某频段；可找仪器、合作者或换观察方法。
- 分辨能力不足：能察觉反应，但无法区分两种相近现象；练习、对照物和多次不同条件试验有价值。
- 知识缺口：没有学过符式、材料或该派术语；高境界不自动补全。
- 访问受限：封印、遮蔽、绑定或器灵拒绝；应对方式属于具体机制。
- 不能安全承受：测试所需输入、接触或暴露超过身体/载体边界；可隔离、限流、远观或委托。

这些原因可以叠加。低阶不等于永远不能知道，高阶也不等于全知。若某种遮蔽确实只容许特定层级感知，就写清其机制与可见痕迹，不把“高级物品”当全球统一锁。

### 2.2 认识能出错，也能彼此矛盾

现有事件/转述结构记录“发生过什么、谁获知哪一部分”，不足以单独承担全部认识。扩展时须分开说话/观察事件、其中表达的命题、某主体对该命题的接受/怀疑与验证状态。说话本身确实发生，所称的宝物性质、旧经历或桥梁状况可以错误，甚至根本没有对应的真实事件。

同一问题允许保存多个冲突说法，各有来源、获知时刻、依据和有界把握；新证据通过实际获知才促成修订，不直接把全世界认识覆盖成后台真值。直接观察也可能被幻觉或方法局限影响；观察结果是当时所得信息，不能在恢复时静默改成真实对象的完整快照。

这里的命题/说法不是机构Claim：个人可以相信未获机构承认的事，机构也可以依据错误信念签发真实凭据。保留旧事件隐私与来源校验，为新认识层单独校验，不能简单放松旧验证器让任意字段通过。

## 3. 从拿到到安全使用，中间至少七个问题

| 问题 | 例子 | 不满足时的可能路径 |
|---|---|---|
| 是否实际可接触/持有 | 宝物在柜中、他人身上或封存空间 | 获准、借取、交换、盗取；世界分别处理合法性与实际控制 |
| 是否知道要用哪个功能 | 炉能加热，也能开启旧封印 | 观察、询问、示范、试验；不自动显示所有按钮 |
| 是否理解操作方法 | 输入次序、姿态、符印、共振节奏 | 学习、按记录尝试、合作代操 |
| 载体/接口是否适配 | 鸟爪能否触发、灵机性质是否相容 | 转接器、改变媒介、调整方法、另找操作者 |
| 是否有足够而合适的供给 | 需要稳定输入，不能靠瞬间暴冲代替 | 外接来源、低档位、分工协作、暂停 |
| 是否能控制并承受后果 | 引流精度、热、反冲、神识负担 | 限流、隔离、牺牲部件、练习或退出 |
| 是否获得所需配合或许可 | 绑定者、器灵、守护机构 | 解除/转授权、协商、破解；强行做要有真实方法与风险 |

这不是七次都要掷骰的繁琐流程，而是每种器物只声明相关条件。普通茶杯不需要神识鉴定；“持有”与“会用”已经明确的常用工具不重复确认。

允许低能力者借高阶器物取得巨大优势，前提是实际满足某个可用方式。例如触发预存的一次护持、使用不依赖自身修为的低档位、请器灵代操。不是所有高级功能都必须先修到同等境界，也不是拿到就能无成本全部开启。

### 3.1 反噬必须有发生机制

| 原因 | 可观察的前兆 | 结果与恢复方向 |
|---|---|---|
| 过量/过快输入 | 发热、鸣响、引流不稳 | 烫伤、器物裂损、泄漏；减载、散热、修补 |
| 介质不相容 | 异响、反应偏转、介质污染 | 供给污染、功能异常；清理、隔离、换媒介 |
| 控制不足 | 轨迹偏移、持续失稳、注意耗尽 | 误伤、逸散、动作中断；练习、辅助引导 |
| 封印/绑定被触发 | 警示纹、拒绝响应、守护反应 | 锁闭、回击、追踪；知情解除或另寻入口 |
| 独立意志反对 | 拒答、谈条件、撤回配合 | 功能不执行或明确的反制行动；协商/强制都需规则 |

未察觉不代表绝无前兆；玩家能逐步探索，专业者能发现更多。风险来自当前条件与方法，随机只表示剩余波动，不能“高阶宝物随机扣50%生命”后再补故事。

中止按已发生阶段处理：未投入的材料保留，已消耗的灵机不退，温度和裂损不会因关面板归零。离场、换装、交给NPC或读档也不刷新风险状态。

## 4. 《骗经》：改变他人看到和相信的，不是万能修改真相

《骗经》可以同时包含社会手法与真正的超自然术法，不缩减成“魅力检定＋好感条”，也不自动赋予所有领域的免检通行。

| 方法族 | 改变什么 | 约束与留下的线索 |
|---|---|---|
| 言说与安排 | 选择信息、借身份、编解释、布置误导现场 | 需要对方能理解/接触；前后矛盾、见证与时间可检验 |
| 伪物与伪证 | 外观、纸张、印迹、道具、仿制记录 | 工艺、材料、保管与签发链；伪证真实存在，但所称权利未必成立 |
| 声色与气机伪装 | 对特定感官通道发出的信号 | 范围、持续、媒介、可覆盖对象；不能自动骗过另一感官或核验机制 |
| 注意引导与幻觉 | 接收者在某范围内的知觉或注意 | 具体入口、目标、维持代价与抵抗/干扰；不是让所有主体同时遗忘 |
| 命理/天机层欺瞒 | 若未来加入，作用于某种占验或追索协议 | 必须先定义被欺瞒的机制，不能拿“骗天”当跳过所有规则的字符串 |

### 4.1 一次行骗怎样结算

1. 明确意图：想让谁相信什么、因此做什么。让守卫相信来访身份与让账房承兑欠款是两件事。
2. 检查触达与手法：对方看见/听见哪些信号，是否懂得该身份或协议；假印章是否真的存在。
3. 接收者按所知判断：与已有证据是否冲突，愿意承担什么风险，有没有核验、推迟、问别人或只部分配合的办法。
4. 对剩余不确定性判定：可有受方法、局面和个人偏好影响的波动；不是一条“社交攻击力”打所有人。
5. 执行实际动作：信了不等于能开锁、有货或有权支取。守卫放行不等于功德堂产生正式额度。
6. 保留所说内容、出示物、接触者与重要痕迹；后续核验会基于这些继续，而非过场结束后世界失忆。

相同说辞、相同证据、相同局面不因反复点击无限重掷。新证据、新手法、风险或态度变化才构成新的尝试；当事人可能记住反复纠缠。

### 4.2 制度也可能被真的骗过

官方记录不等于绝对客观真相。账房可能被误导而签发真实但依据虚假的凭据，腐败者也可能违规记账；这是一次真实签发，保留记录者、权限、依据与事件。

后来审计可能冻结、撤销、追责或仍决定维持承兑；不能默默把当时发生过的交易抹掉。若直接篡改账簿，需要能接触和修改相应载体/权限的行动；说谎本身不会遥控修改数据。

某法器若只检验外观符印，精良伪印可以欺骗它；若检验不可由该手法复制的绑定响应，就失败。这由装置协议决定，不把所有法器统一设为“反骗免疫”或“魅力够高必过”。

## 5. 戒中老人既不是完整百科，也不是免费技能树

老人拥有独立主体ID、记忆来源、感知渠道、目标、关系和合作条件。戒指的结构/封印属于载体；储物、护持、传意、寄魂等功能可以分属不同规则。修好戒指外壳不自动修复老人记忆。

老人能说真话、误记、隐瞒、猜测或故意误导。对三百年前的机关很熟悉，不表示知道如今城主和商价。没有收到消息，就不能因游戏后台已更新而知道旧宗门被灭。

合作可以包括：提供线索、演示一段方法、在约定条件下代操、验证某种反应。它占用注意/能量/准备与个人意愿。所谓“老爷爷帮你开挂”在世界里应是具体代理行为，能够拒绝、失误、履约和留下关系。

使用者也可成为戒中老人；核心操作围绕自己能感知和传达的范围展开。两方知识界面分别授权，玩家不能切到戒指面板就免费读完另一主体的秘密。

## 6. 工法不是只能掉落，也可以被创造

### 6.1 功法、技法与实现分开

功法是一套长期调节与实践的方法；技法是可以执行的局部操作；记录只是它们的某个版本说明。一本书可能残缺、误抄、吹嘘、加密或只适配某种身体。拥有文本不等于理解，理解不等于练成，练成不等于当下能安全执行。

世界里的知识图不是预先公布的宇宙全部答案，而是某主体已知的方法与依赖。创造、翻译、改造和失传会改变图；已有40节点只是人类入门内容候选池。

### 6.2 玩家怎样创造，而不写游戏代码

以“想解决的问题”进入创法：让染料慢慢受热、让鸟妖携物时不脱爪、让传音只被某个载体接收等。选择自己理解的作用、媒介、步骤和约束，先搭可试验的草案；可以命名、写原理笔记和记录试验。

每份可执行方法至少包含：

| 内容 | 需要定义什么 |
|---|---|
| 意图与效果 | 实际改变的对象/状态，不用方法名代替效果 |
| 媒介与目标 | 通过什么作用于什么、范围/接触/传播条件 |
| 施行步骤与控制 | 顺序、时长、输入、可中止点、所需精度 |
| 适配与基础 | 身体/载体、已学基础、工具/场所、可接受替代 |
| 供给与限制 | 起动/持续代价、来源、容量、排出或副产物 |
| 故障与痕迹 | 条件变化时怎么失效、风险、观察者能察觉什么 |
| 验证与传承 | 方法ID/版本、创造者、已试范围、证据、谁获知哪个版本 |

首版先允许组合/调整已定义作用与过程，像做一次有条件的实验；不是把任意词拼在一起就自动实现。描述超出现有作用时，可以保留研究目标和原理草案，但须明确“尚无已验证的实现”，不消耗材料后编造全能成功。

后续内容开发可以扩充作用族，使以前不可做的设想成为可执行方法。设计边界应可扩展，不能把第一轮几个积木永久当宇宙定律；也不能宣称一套自然语言框架已支持无穷术法。

### 6.3 创造过程

    已知基础与目的 → 原理草案 → 小规模隔离试验 → 记录反应
          → 定位缺陷/调整步骤 → 在已验证条件下重复 → 形成可传授版本

- 高手的优势来自能观察、理解、控制更多过程，并掌握更好的试验条件；可以跨领域顿悟，但灵感不直接替代验证。
- 试验成功与掌握方法分开。偶然做成一次，可能还说不清原因；反复出现的证据才能支持更可靠的用法。
- 成功有适用域：只试过干燥木料，不能宣称对雨中湿木和活体都安全。
- 缺陷是条件关系，例如“潮湿时漏流”，而非随机生成一个永远看不懂的诅咒词条。
- 改名不改变规则，不刷新消耗和冷却；不允许把同一方法换十个名字就得到十份独立能力。
- 原版与改版分别保留。老师教旧版，弟子不自动获得新修订；翻译、误抄、保密和专门适配会形成不同传承。
- NPC也可在少量已知办法中改良、求证和学习；首版用有界候选与事件触发，不要求NPC凭空发明整个规则引擎。

### 6.4 一个例子：《缓火养息法》

学徒本想做火弹，却只得到很慢的热流。若热流真实稳定，可试验隔热壳、限流与材料反应，把它改成温养药材的方法。

第一版或许需要一直看守，潮湿时会漏流；第二版加入断流条件，耗材更多却可安全停机。匠人、药师、鸟妖和修士可以贡献不同信息；发明者不因独占命名权就自动拥有全世界的收益。

传播后，别人可模仿、购买指导、抄书或独立发现。社会是否承认秘传、收徒义务或商业限制，要靠具体组织和约定；没有全宇宙自动生效的专利系统。

## 7. 共同接口与状态归属

| 信息 | 持久负责人 | 其他系统怎么用 |
|---|---|---|
| 物的结构、位置、储能、损伤 | 物品/载体状态 | 行动执行查询，界面按观察权限呈现 |
| 主体掌握的性质/方法及来源 | 个人知识与实践记录 | 计划生成、鉴定、风险预期与可见图 |
| 器灵/寄魂者的意图和秘密 | 独立主体状态 | 合作/请求、传意与代理行动 |
| 方法定义与版本 | 内容定义＋保存的已验证新方法 | 多主体引用同一版本，学习程度各自记录 |
| 误导、试验、交接等进行中过程 | 行动/事务状态 | 保持预约、投入、阶段、取消与幂等提交 |
| 官方签发与撤销 | 机构记录 | 正式受理、兑现、争议；不覆盖个人所知 |

新方法由数据定义并通过规则校验，不在存档中运行用户字符串代码。知识变化与事实变化分别发送事件；调试广播不让所有主体获得秘密。

## 8. 组合场景验收

| 场景 | 必须验证的区别 | 允许的惊喜与后果 |
|---|---|---|
| 凡人工匠检验仙器 | 材料知识与灵性操控分开 | 能找出修补痕迹，仍不能使用核心 |
| 低阶者借一次护符 | 有预存功能、有激活条件 | 可保护自己一次；次数真实消耗、不因归还重置 |
| 鸟妖尝试人类法器 | 操物、接口与负载分别检查 | 可找转接/代操，不必升级成人；不自动适配一切 |
| 已知裂戒高功率输入 | 过量和裂损确实相关 | 预警、泄漏或碎裂符合机制；低功率可能可用 |
| 骗子冒名通过守卫 | 守卫所知与职责/风险 | 可能放行、核验或有条件接待；不凭成功直接获得官职 |
| 同一骗术碰见印契核验器 | 设备实际检查哪个信号 | 伪外观可能失败；复制对应信号需另一套方法 |
| 账房被诱导签发真凭据 | 真实签发与依据虚假分开 | 可能先被承兑，后续冻结追责保留当时交易 |
| 老人教出过时法门 | 记忆有时效，世界条件已变 | 小试发现异常；持有者可核实、改良或承担风险 |
| 工法试验失败却有稳定副效果 | 真实效果不依赖原用途标签 | 可改作工艺，需新的验证，不自动“获得传说功法” |
| 同法改名并重复装配 | 名称不等于独立实例 | 共享真实资源/过程约束，不能凭改名无限叠加 |
| 新方法跨聚落传播 | 教授/记录/消息需要实际渠道 | 到达者可学、未接触者不知；旧版与改版共存 |
| 驱器或行骗中离场存读 | 进行中过程与知识分别保存 | 不退还已耗材料、不重复签发、不重掷既定结果 |

## 9. 首次实现的最小范围

先用一件有显性用途和隐藏功能的器物、两种观察方法、一种限流试验、一段有条件的指导验证前述分离。随后加入一种伪装/核验与一个方法改良，不同时建设完整幻术、誓约、炼器、夺舍和法术编程。

对外应能说清：我知道哪些性质；这些认识从哪里来；我准备怎么试；缺什么；我看到了什么结果。先把这种探索做成可玩的过程，再扩充传说宝物与更多效果。当前实施顺序与回归要求见[世界引擎执行计划](../../docs/archive/specifications/world_engine_execution.md)。
