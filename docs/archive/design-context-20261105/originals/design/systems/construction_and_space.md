# 建造、空间与共同生活

更新：2026-11-03。用户要求房间、家具、工作台、储藏与人物共同支撑世界运转，兼顾环世界式的组合用途与RPG场景的生活感、美观和叙事。本页保留已有规则，并整理可随玩法主动扩展的长期领域设计。除“当前实现”明确列出的范围外，均为开发建议，须逐包验证与修订，不是完成清单，也不要求先造完全部设施才能推进修仙玩法。

玩家入口/限制见[FEATURES](../../docs/status/features.md)，当前构建与唯一最新验证见[BASELINE](../../docs/status/baseline.md)。证据见[施工](../../docs/qa/20261103_construction.md)、[早期床铺](../../docs/qa/20261103_rooms_and_rest.md)和[自然/值事房](../../docs/qa/20261103_natural_world_workplaces.md)。早期QA中的“没有屋面”等限制只描述当时版本。

## 当前实现与界限

| 范围 | 已有事实 | 当前边界 |
|---|---|---|

| 环境接缝 | 屋面接遮雨，门墙/屋面接有限余热，地面有物性与五行亲和 | 完整室内气候/五行场/风水、家具火灾和攻击破坏待做 |

## 已有闭环

土地使用依据 → 蓝图意图 → 同一库存预约 → 工人到源取料 → 身体携带 → 工地到料 → 持续劳动 → 实物结构 → 物理通行变化。

首版为宗门明确批准的一处工地，允许杂役与石头施工，石头另有日常看工单的职责；不从私人关系自动推导建造权。公料属于宗门，授权只用于指定工地。工人仍有自己的身体、饥饱和其他工作；自动施工不是远程万能命令，也不会因玩家离场停下。

蓝图不阻挡地面，木墙和关闭木门阻挡，开门可走。空中雀身不依地面墙寻路；落地仍检查实体占地。身体位置、材料数量和结构占地是各自的权威事实，不由画面或另一套建造资源条代替。

## 取消、拆改与认识

- 预约不是取料。取出前取消释放预约；取出后停工则在脚边留下那批料，续工从其真实位置取回。
- 到场材料与已做劳动分别保留；清场失败不退成从未发生。完工/关门不能压住身体、正在跨入占地的路线首段或地面余料。
- 撤蓝图不等于退款。拆除要实际劳动，且只留下部分余料；回库也需要实际搬运。
- 人只在场看见工单；NPC依据本人的库存记忆选择，真实预约/取料仍可能失败。玩家离场后没有施工实况瞬传。
- 土地授权和门的物理状态是不同问题。首版未实现钥匙、锁或因社会资格自动穿门。

## 状态边界

`SimConstruction`保存工地/项目、材料物理归处、工时与活动；`SimInventory`保存唯一数量/预约/凭证，`actor`保存唯一身体位置，`SimRouteTravel`推进实际路线。动态阻挡由结构状态投影给ReolWorld，存档候选用自己的结构与静态地形检查，不复用另一世界的活墙。更多房间查询应由真实结构推导，不再存一个可与墙矛盾的“房间已建好”按钮状态。

## 围合与生活用途

有限工地内四邻接洪泛，只有完工墙和门构成空间边界；蓝图/床不是边界，触及外部就是开放空间。门口本身可作为分界，同时其开关决定真实通行。空间缓存来自结构，不保存房间完成标记。平整、面积、围合与覆顶分别报告；已有上层屋面提供实际遮雨，不能仅因围合就假装有完整保温或风水。

木床是同一材料/工时/拆回流程造出的矮家具，可跨越；床位安排属于宗门公物使用关系，不能冒称全面物权。`SimResting`保存分配和在途/睡眠/让位事务，床的存在取施工域、精力及小数余量取原身体。到床才持续恢复，取消保留实际恢复；饥饿、精神充足或最长时限使人起身，身体走离床格才结束自然占用。四周堵死不会瞬移。

NPC在近邻范围按权限、通路、自身需要找床，仍未做独立空间记忆/完整视线。无合适床保留杂役院原休息；休息和施工不会因玩家离场停住。忙碌床不能拆或改分配，拆围墙不抹掉床或已发生的休息。

## 组合场所的层次（以下为长期设计）

房间是空间事实，区域是使用安排，家具提供能力，容器保存东西，人物执行并承担责任，组织赋予某些行动效力。它们可以组合，却不互相替代。

| 层次 | 负责的问题 | 例子 |
|---|---|---|
| 地形与结构 | 哪里可站、可达、遮蔽、隔断、承重 | 山洞、地台、墙、门、窗、屋面 |
| 空间 | 当前有哪些连通区域、开口与覆盖 | 房内、院落、洞厅、廊下；围合与覆顶分开 |
| 用地/用途安排 | 谁希望在哪里做什么、哪些规则在此适用 | 客房、药田、禁地、晾晒区、工坊操作区、待客席 |
| 家具与器具 | 支持哪种动作，容量与代价是什么 | 床、蒲团、案台、炉、砧、屏风、座椅 |
| 物品与容器 | 实物在哪里，如何取放/保管 | 柜内食物、炉中半成品、书架上的玉简 |
| 人与组织 | 会不会做、愿不愿做、有没有权 | 师傅、学徒、值事人、客人、器灵、受托保管者 |
| 工作过程 | 正在做什么，消耗了什么，何时继续 | 开炉、喂火、锻打、记录、封存、交付 |
| 观察与表现 | 谁看到什么，怎样读懂用途和经历 | 烟、灯、匾额、磨损、个人陈设、工作动作 |

用途名只是称呼和安排。放匾“炼丹房”不会产生炼丹能力；有炉但无人懂方法，也不会自动开工。有适合炉具、方法与安全条件的山洞或露天院落可以炼制，不强制先拿到规定面积的“房间认证”。某些秘法确实要求封闭、避光或阵位时，由该方法检查真实条件。一个炼丹处由炉、器具、材料、方法、实际操作者、环境和适用权限共同支持；墙、家具、人与账册分别是各自的对象和条件，不能用一个《魔兽争霸》式功能建筑单位代替。

同一空间允许多用途：白天授课、夜间待客，餐桌也能抄书；冲突落到时间、座位、桌面、物品、噪声、安全和约定。布局允许小屋套院、洞府兼工坊、私宅夹书房，不限定“一屋一种职业”。自然洞窟与人工房屋共用可达/遮蔽/使用条件，但开凿、支撑与风险以后按真实来源实施。

### 地块、实体与占地合同

方格是地表与空间索引，不规定世界对象只能占一格。灵木、巨兽、丹炉、床榻或其他实体按自身形状、朝向、体型或生长状态具有一个或多个覆盖格；锚点及所有覆盖格共同指向同一实体和原状态，不能按格复制对象、库存或产出。实际接触、可站立处、操作位和移动净空按对象能力分别判断；图像超出的部分不自动变成物理占地。

同一格可以同时有地表、合适的地面实体或物品、上方覆盖和一个或多个用途区域；能否重叠由各自空间层、体积、碰撞、承载和使用条件决定，不设“每格只能有一个对象”的全局规则。移动、转向、成长、拆改或改变遮挡时，先核完整新占地及相关身体、在途路径、材料和使用状态，再原子提交并使受影响的通行、空间与环境派生结果失效；失败不复制或丢失原物。占地索引和画面可重建，不能成为第二份物品或身体状态。

当前只有特定的单格施工和3×3山兽样本，尚未实现上述通用多格建筑、植物或所有对象的重叠规则。当前原药丛仍是原地点与来源锚点，不是可框选的种植区。见[实际功能](../../docs/status/features.md)；本节是后续合同，不表示已实现。

### 区域、药田与禁地

药田、禁地、储物区和工坊操作区是对一组位置的用途或规则安排，不是一栋自带产出或权威的建筑。区域可调整、重叠并与房间、屋面或露天空间组合；指定区域本身不创造植株、改变土地所有权、赋予他人权限或令人物立刻服从。命令、土地使用权和实际劳动仍分别处理。

缩小、改名或撤销区域只改变用途安排，不删除其中的植株、物资、在制物或环境状态；实际移除仍需相应世界行动。区域可以引用原对象，不能另建一份作物或库存真值。

未来种植需依据各处真实地表、可用土水、温度、光照及实际灵机等已支持条件，使用有来源的种子或种苗，由有能力且愿意或承担职责的人到场、消耗时间和材料。作物在实际播种后由自身或明确批次的原状态生长、成熟、受损与收获；区域只引用安排，不能复制植株或凭区域面积直接发放产物。灵木长大若扩大占地，要重新检查完整空间；缺水、封路、材料不足或中断都保留已发生的后果。

室外灵田、盆栽、温室、混植和不同土地安排是可扩展的用途，不作为一次性完成清单。近区、远区、快进及存读共用时间和原资源；可用边界与批次降低计算，但不能因离场或重载重种、重发产物。普通农务保持够用的世界循环，优先服务修行、灵植与冒险，不先铺完整农业产业。

## 家具怎样成为设施

可交互家具需要稳定身份、位置/方向/占地、可接近的操作位置和可提供的动作；定义按需要声明材料、体量、承载、适用对象和连接代价。操作位、座位、物料口可以分别存在，不把来客、值事人和搬运者都压进同一格。外观朝向与实际操作面一致。

能力按需组合：桌面可以放置和书写，座椅支持坐姿，炉具容纳与加热，阵盘引导特定灵机。拥有桌面不代表满足全部锻造、手术或炼器要求；必要条件须能被理解。也不为统一接口，要求每把椅子都有完整人物属性、AI和每帧Node。

不同生命需要不同尺度与动作条件：小妖可用矮台，巨兽需要净空/承重，鸟巢或栖架可替代床，植灵可能需要植根空间，器灵可通过合适器具操作。法术可代替手、火或搬运，仍须真实能力、媒介、成本和意愿，不给所有生命套人类床和固定家具槽位。

## 储藏：实物、保管与知识分开

物品只有一份权威归处：地面、某容器、某携带者，或明确的在制过程。柜子记录容量/位置和容纳关系，不再复制同名库存。堆叠材料按批次保存数量，唯一法宝、账簿和有独立来历的器物保留身份，不把每粒米都变成实体。

地面掉落按2026-11-05规则：不同物品分散铺放，同类且状态相容才合堆；同类堆的环境逸散只算一件强度，不按数量放大。此处只约束地面堆，不把柜子变成只能存一种物品，也不禁止墙、地表、屋面与区域等兼容空间层共存。人物及其携带物的五行辐射暂缓，未来由人物整体映射；细则及邻堆叠场未决边界见[环境方案](../proposals/environment.md#地面堆叠与本轮来源边界)。这些仍是待实施合同，不代表通用掉落和地面批次已接入。

| 容器侧重 | 可提供的条件 | 不应隐含发生的事 |
|---|---|---|
| 衣柜、杂物箱 | 整理、保管、取放、个人使用范围 | 入柜即转所有权 |
| 粮柜、粮缸、地窖 | 按实际密闭/干燥/温度保护食物 | 自动冷藏、永久保鲜、隔空供给 |
| 药柜、材料匣 | 分类、相容隔离、封装、查找 | 普通柜自动识药或消毒 |
| 简柜、档案柜 | 定位知识载体、限定访问 | 入柜全员学会，柜毁全员忘记 |
| 兵架、宝匣、镇物台 | 展示、固定、封存或隔离 | 展出即认主、封存必安全；封印须方法/材料/维持条件 |
| 储物法器 | 在具体法则内改变携带/空间条件 | 无限容量、人人可用、失主即归拾取者；认主/反噬归器物规则 |

物理持有、看守、所有权、使用权、机构职权、钥匙/封印能力分别判断。管理员能接触公物，不等于能私卖；有钥匙不代表合法，有贡献不自动开锁。未来偷取、借用、托管的物理行动与社会后果各自成立，不能用一条“不可交互”代替全部规则。

过滤、优先级、柜名是整理政策，不能移动物品。搬运须知道来源/目标、预约真实容量、沿路到场；改过滤不吞旧物。容器破损或搬走时内容有明确去处；容量不足时留在原处或产生可解释的溢出，不悄悄销毁。套娃容器须拒循环引用，深度与查询预算以后测试定。

知识载体、内容、真实性/官方效力、人物已学知识分开。迁柜只搬书；毁原本可能损失独有信息，却不抹抄本、证人、记忆或既存债权。读账不等于有记账权；个人私簿进入公账柜也不会变成机构承认。法器记录须有登记、访问和同步规则。完整载体搬运/损毁与多副本同步仍待实施。

## 工作是一段共同世界中的过程

统一请求表达“谁希望谁，以什么物/方法，在什么条件下做什么”。无AI时可选动作/对象/条件；未来AI辅助理解/计划，最终仍用相同规则。工位可说明操作，人物可自述本领，接受委托和真正完成分开。

推荐链路：提出/发现机会 → 理解协商 → 查能力/意愿/权利 → 预约资源与操作位 → 取料/移动 → 分阶段操作 → 当场形成结果 → 检查/取走/交付。环节可简化，不能省掉其实际承担的物质/社会条件。

- **竞争**：同一双手、炉膛、桌面操作位、同批料不能同时用于互斥工作。按真实容量处理，不为每个系统再造一份“人物忙碌”真值。
- **在制物**：炉中丹液、半刻器件保存材料、阶段、位置和已投入劳动。接手要有方法与约定；停工不自动退料或交付。
- **阶段**：搬运、升温、锻打、冷却、刻写、检查可有不同条件。有的可无人看守，有的须持续控火；不把一切变成“点一下等倒计时”，也不先模拟全部微观过程。
- **中断/失败**：离位、受袭、缺料、熄火、器具损伤、方法失误分别影响暂停/返工/降质/报废。实际燃料/灵机支出不返还，副产物有去处，随机不能替代能力与条件。
- **替代/创造**：凡火、地火、御火可支持同类步骤，但火性、控制、来源与代价不同。露天修剑、借炉、两人分工应能成立；替代须有因果，不能一句描述绕过世界规则。
- **交付/责任**：材料、工钱、成品、余料各有所有者/受托人。委托锻剑不授权取师傅全部材料；拒办/离岗保留实物与未结责任。

炼丹、官方记账、治伤各有领域规则，共用取放、到场、预约、时间和记录接缝。不每项工作新建一栋功能建筑，也不把全部独特效果塞进万能配方解释器。

## 人、组织与有限认识

NPC和玩家共用到场/取物/操作规则。选择休息、钻研、会客、当差或逃离，依据身体、个人目的、经历、已知地方、承诺与风险。“安排工作”是须传播的请求/命令，不直接改写NPC意志；器灵和守门妖物同样有理解与意愿。

设施可以归宗门、商号、家庭、个人或松散共用。谁值事、谁可用、谁维护、收费与交接来自组织/约定，物件不产生权威。土地、房屋、家具、内装物可以属于不同主体。开放工坊、租炉、客房、隐秘会所由这些关系组合，不先限定为“招人种地”。

人物凭看到、听说、登记、亲用认识场所。匾额、布置、守卫、火光提供线索，可能过时或伪装；不在场不读柜内实时清单。依旧记忆找药柜却发现空了，应能询问/替代/等候，不能暗中补药。

隐私与礼仪不全压成“房间分数”。闯卧房、坐错主位、展示仇敌法宝、翻私簿，影响谁取决于知情、文化、关系和制度。高手未必在意华丽摆件，却可能在意藏经、安静或阵位；同一装饰对不同生活者有不同含义。

## 美观与功能共同表达生活

场景应看得出人在哪睡、写字、取物、开炉：铺盖、桌面工具、衣物、残料、书卷、私人物件表现经历和偏好。先用可读像素占位，后换正式资源，功能不绑一张贴图。

装饰可分为纯样式、实际影响通路/遮蔽/光照的物件，以及携带来历/礼俗/知识/器性的对象。纯细节可批量绘制；会被移动、借用、损坏或参与争议的东西接真实对象/物品批次，不复制“装饰法宝”和“隐藏可用法宝”。

同类墙桌柜可有材质、风格、磨损与陈设变体，外观不暗改占地。若材料确有导热/易燃/避水/五行作用，来自同一材质定义，并能被对应人物认识。整齐华美影响具体人物感受或接待判断，不默认对全宗门叠全局效率。

切开屋面、近墙淡出、分层选取应保持真实覆盖和障碍；藏屋顶不等于没屋顶。座位/操作朝向与真八方向持物、前后遮挡一致。新摆件不挡关键提示，生活故事也不全靠功能按钮列举。

## 环境、破坏与搬迁

屋面、开口、材质和真实来源决定遮雨、通风与热/五行作用。围合、覆盖、用途、环境适性分别查。按2026-11-05已定规则，木柜等普通物品也持续贡献非消耗的五行环境影响，摆放可以改变适性；这不自动发行可领取的无限灵气余额或通用吉凶。可吸收灵气由原物品另持储量，环境中积攒的容量/速率/变化后置；炉的热量和阵法实际消耗仍回各自领域。

同日最新温度方向为室外中性温度＋欧氏圆形场、室内一房一温。冷热有效等级先抵消再查表，房内按各格净等级的面积平均生成目标，火墙/冰墙是原物来源，普通家具不按数量参与平均。房间温度由环境域唯一保存、结构只推导空间；拆合接续及门漏热见[规范](../proposals/environment.md#室内一间房一个温度)。本轮不因此令五行也全房均匀，现有四邻热样本尚未转换。

改建先结算旧布局到变更时刻，再改结构并失效受影响空间/路径/工位缓存，最后影响未来过程。拆墙可只改遮蔽，不使整坊所有动作瞬消；拆炉膛、毁唯一账簿、封操作位分别处理必要依赖。维护复杂度逐包定，不为生活感先铺整套维修劳动。

移动家具处理内容、占用者、在制品、连接和搬运能力。迁办事房还要有效记录、人员/使用权和通知；旧地址记忆可保留并导致跑空。空间分合不重生成库存，门锁不传送室内人。容器损坏、火灾、盗窃、围攻与逃离以后服务冒险和组织冲突，不冒称当前固定房间已有。

## 状态归属、存档与近远连续性

以下是扩展约束，不要求现在创建同名新模块：

| 事实 | 当前归属或后续单一所有者 | 可派生信息 |
|---|---|---|
| 地形/旧高度 | 原`WorldMapData`；历史样本含单地表高度，新世界先采用平面地块；可变地表有真实施工来源后再接 | 静态空间候选 |
| 结构/家具 | 原工地`SimConstruction`；固定值事房原`places.records.workspace`，通用化须显式迁移 | 阻挡、覆盖、围合、操作面 |
| 身体/动作 | 原人物/非人及领域活动，共用身体占用查询 | 可达与是否有空 |
| 实物/预约 | 原`SimInventory`及唯一器物领域；容器不复制库存 | 柜内目录、余量、画面 |
| 过程/在制物 | 原领域已有活动或其扩展 | 工位忙碌、可续工 |
| 权利/任职/约定 | 原机构、个人约定或明确新物权事实 | 可办理/取用/分配者 |
| 记录与知识 | 载体内容、公账、个人认识分别保存 | 本人可读信息与可核查结果 |
| 环境/源流 | 原天气、余热、灵源等领域 | 适用条件与风险 |

连通、房间用途汇总、服务可用性和画面是派生查询，不与墙/物品各存矛盾的完成状态。命名区域、归属、床位、整理政策是人的持久安排；拆墙后可保留为失效/争议安排。缓存按受影响地块/连接失效，不逐帧全图扫房柜。

远处可不展动画和逐步脚步，不能离场免费完工或归来重抽结果。保留参与者、输入物/在制品、阶段、条件、关键时刻、未结责任；到缺料、受伤、源枯竭或设备受损等边界就停下/改走真实后续。近远成本与结果一致，重大事件和消息再影响当事人。

存档保存变化和进行中上下文，独立候选查位置/占地/容量/物品唯一性/引用/预约/权限/时间，不反查活世界。迁移不以新模板重建旧屋、补造家具、清旧账。当前固定值事房的严格模板校验不适合直接承担自由装修；通用化要明确格式/迁移，不能只放宽检查。

## 实施顺序与情境验收

按[超凡者优先](../../docs/archive/specifications/transcendent_focus.md)穿插实施，普通吃住维持循环。以下是领域递进建议，不自动启动新包：

1. **一组可变设施**：选值事桌柜或工地床具，接真实摆放/操作位/唯一记录或物品/在岗/搬迁，验证空房无权、离岗可等、记录可寻，不一次通用化所有生产。
2. **一条超凡工序**：围绕温石、原方法和有限灵源，选修补/温养/刻写中的一种，接工作面、在制品、耗用、分工与中断，再扩炼器/丹法。
3. **一种共享生活场景**：床榻/客席或餐桌接原食物、关系和用途安排，体现借宿/款待/隐私，装饰只加能带来新选择的部分。
4. **知识与组织场所**：载体取放/借阅/复制、交接、有效公账/私笔记和通知，再扩藏经、授业、租炉/代工。
5. **破坏与不同尺度**：设施/载体/开口损伤的实际因果、小妖工具/巨兽净空与远区事件，服务争夺/救援/冒险。

每包按相关情境验证，表内是未来验收，不表示当前全通过：

| 给定与行动 | 应有结果 |
|---|---|
| 空房摆同样桌柜，无人获授权 | 可放物书写，不能记官方贡献或领公库 |
| 同桌上午抄书、晚上吃饭，争同一操作位 | 按实际容量/约定安排，不复制桌子或同时完成互斥动作 |
| 修士在院中用真实御火替燃料 | 方法允许则付实际代价，不因无炼器房匾额拒绝 |
| 食物入柜，柜子搬到另一处 | 总量/产权不变，取食者须认识并到新位置 |
| 秘籍入柜，一人借走后另一人来读 | 不能远程读已不在的原本，借阅者是否理解另判 |
| 账簿遗失，但有抄本/证人/既存公账 | 不凭柜空抹债，可访问性、证据、机构承认分开 |
| 开炉中途撤人、熄火或拆必要器具 | 已用燃料保留支出，在制品有位置，按阶段暂停/受损 |
| 炉旁门墙改变或拆屋面 | 先结旧环境再影响未来，不依赖受损部件的过程可继续 |
| 小妖/巨兽尝试同床、门、工作台 | 按尺度/能力/替代工具判断，不统一套人身资格 |
| 同过程近场、离场、保存再重启 | 身体/实物/阶段/成本/结果一致，归来展开当前状态 |

## 后续新增设定的准入

用户已授权开发在玩法需要时主动扩展。新增床具、工位、储藏或场所，先说明让谁能做什么、接哪些已有对象、来源/知识/权利、失败和中断留下什么、玩家怎样察觉、远区和存档如何保持同一事实；复用动作、容量、物品和授权接缝。

仅有名字、图标或被动倍率的建筑先留候选；纯为美观就明确可选陈设，不假装生产必需。工时、容量、配方和偏好由开发测试；改变世界概念或玩家控制方式再请用户拍板。不预建万能ECS、全量设施目录、数十空autoload或插件来替代一个可玩的组合。
