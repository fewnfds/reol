# 有限重生与新生候选：同一世界中的多段人生

日期：2026-11-03。状态：**用户概念已确定；以下执行细则为设计，尚未实现**。本页取代此前“机会耗尽后还可免费换新人续玩”和“返生时间语义待定”的设想。当前代码、测试与完成度只见[BASELINE](../../docs/status/baseline.md)。

配套：[众生与生活方式](beings_and_lifeways.md)、[人物视角](perception_and_understanding.md)、[状态契约](../../docs/archive/specifications/world_state_contracts.md)。出生、成长、抽选和重生次数尚未实现；何时实施由[HANDOFF](../../docs/status/handoff.md)和实际执行计划决定。

## 1. 用户已确定的概念

| 项目 | 当前方向 |
|---|---|
| 世界时间 | 不回滚；重生不必立即发生，可小范围向前跳时 |
| 新一世 | 从随机提供的若干新生人选中选择；包含人、小动物、小妖等，不限人类 |
| 选择扩展 | 可以设计重新随机、自选、提高候选稀有度等功能，形式可借鉴抽卡；具体成本/数量由开发决定 |
| 次数 | 重生机会有限；难度越高，次数越少；耗尽后本局结束，不提供免费换人旁路 |
| 补充机会 | 极难获取；**当前不设计或实现增加渠道**，不沿用上一轮“先安排剧情补充”的实施建议 |
| 防操纵 | 不能靠屠杀幼体、只留少数特殊孕育者、反复自杀等做法锁死极品候选 |
| 世界基调 | 普通生命不会人人无限轮回；主角的有限重生是有明确范围的例外 |

以下为落实这些概念的开发方案，不将档位算法、时间窗和具体数值冒充用户逐项拍板。

## 2. 人生、记忆与新身体分别记录

建议把“这一局的主角连续性”“每一世的主体/社会身份”“新身体/载体”分开。新生不是给旧身体洗血重置，也不是随意夺取一个已成长NPC的控制权。

跨生保留主角已获得的必要记忆与理解作为推荐方案；准确保留程度后续由玩法测试细化。记得某本功法不等于新身体能立即承受与施展；武学判断与身体练习、经脉条件、语言发声、飞行操物分别成立。

新身体有真实出生来源、亲缘/照护、生境与物理限制。旧身体死亡、遗物去向、职位、债务、他人所知和世界变化照常处理。记得旧友不让对方自动认出新一世；知道一处旧藏也不保证它仍在那里。旧世界地图可作为记忆，不能同步获得离场后的新真相。

生理成长需要时间与条件。人类婴儿不能立即拿剑，幼鸟不一定会飞；幼年推荐用关键选择、照护依赖和可中断成长过程表现，不要求逐日育儿微操。**寻找入生机会的小幅跳时与出生后的成长快进是两段过程**，不能悄悄把“等几日出生”写成整个世界瞬间跨过十六年。

未做出可玩的幼生/成长入口的形态，不放进正式候选让玩家卡住。强大种族幼体也有自己的当前能力，不把“罕见出生条件”直接换成成年战力。

## 3. 候选是世界中的入生机会，不是卡牌仓库

推荐预览“即将入生的新生命机会”：可以来自持久孕育/繁殖过程，也可来自区域背景群落中有数量与条件支持的出生过程。人类、动物、妖类不必套同一怀孕模型，繁殖/化生方式由相应生命定义。

候选预览在入生前形成，最终在实际出生的提交边界绑定主角连续性。不回到过去改写已出生主体的经历，也不把另一个已有意识的婴儿抹掉来解释主角到来。若以后确实加入夺舍，那是另一种世界内方法。

预览只给已确定的先天/形态与大致处境；父母生存、生产条件等未完成部分是有条件的机会，不承诺未来一切事件必然发生。确认后世界继续推进到相应出生点，届时再次校验条件；无法兑现时保留原周期、已耗抽取预算与剩余机会记录，按有限规则处理，不回滚历史。

未选者照世界规则出生、生活或遭遇风险，不因“没有抽中”被删除；候选界面不是从虚空生成一批只为玩家服务的婴儿。多个候选引用同一孕育过程时不得复制一胎，默认避免同一生命重复占槽。

跨区背景出生可以在细化时实化，但须扣除相应群落份额并保留过程来源；不能在世界确已绝育/灭绝后临时编造一个“原来还有”的部族作无限兜底。

## 4. 抽取预算与人口事实分开

### 4.1 不采用“幸存者中均匀抽样”

如果普通候选死掉后，把全部概率重新分给剩下的三个极品孕育者，就把人口暴力变成了稀有度提升器。仅扩大候选时间窗，也会受到同样操纵，不能声称已经解决。

建议分两步：

1. 先按本局难度、已明确的选择规则/修饰与独立随机流，确定本周期各候选槽的允许档位、地域/生命类别范围与搜索上限。
2. 再在这些条件内匹配有真实来源、能在有界前向时间窗中成立的新生命机会。不能匹配就标记不可用，不把配额自动转给别的极品，不降条件再无限重抽。

档位只是此处抽选权重/生成条件的分组，不是全世界可见的统一人物战力或修行潜力总分。先天好、种族少见、出身优越和当前生存处境可以不同，不全部折成一颗星。

### 4.2 抽取规则不因屠杀自动升档或缩圈

- 不根据“当前只剩哪些幼体/孕育者”重算稀有度权重，也不按幸存比例压缩为必出某家系。
- 地域/类别范围来自版本化政策与本周期记录，不随玩家死亡位置或刚刚清空的局部名单收缩。
- 一个目标的家系条件即便很好，也必须同时符合该槽的档位与机会域；不能把唯一幸存的极品硬塞进普通档位作为免费替补。
- 当前生命造成的生态/人口变化仍改变真实出生机会；没有合格来源时，候选变少、某槽落空或寻找失败，而不是让暴力删除转化成额外稀有保底。
- 不为防利用而把真实出生天赋偷偷改差、把死者复活或生成惩罚怪；限制的是主角可触及的重生机会，不重写已发生的世界。

这能阻止“删掉普通候选→剩余极品占比变100%”的直接路径，不能仅凭文档保证所有策略组合都已无漏洞。有限人口、遗传/适配、过滤与时间窗交互还须做对抗测试和统计检查。

### 4.3 有意经营与利用缺陷不同

照顾族群、改善生境、建立家族、传授方法都可真实改善后辈条件，不应一概判为作弊。抽选不保证玩家死后回到自己安排的某一胎；若未来开放合法的定向自选功能，必须通过明确的能力/资源与范围实现，不能由消灭其他选项免费替代。

极端改变全世界会真实减少可用生命，不承诺玩家破坏一切后仍获得理想出生。世界自由不等于随机系统必须保证任何人口状态下都能发满优质候选。

### 4.4 一次解析校验，避免看错概率指标

本轮用临时Python做了纯概率计算，**不是游戏参数、不是出生/抽选实现测试**：假设三个独立槽位，原始来源有3个稀有与997个普通；这里只比较档位，不模拟去重、来源域与出生条件。

若按幸存者重新归一，删除全部普通来源后，“一批至少一次稀有”的概率会从约0.8973%变成100%。若先以固定0.3%档位概率决定每槽、不把落空槽免费重抽，该概率仍约0.8973%；极端删除后可用机会却会大幅减少，成功批次中的稀有比例仍可能是100%。

因此不能只看“实际显示者有多少极品”评估防利用；必须同时测无条件稀有概率、能否获得任何可用出生，以及剩余候选的条件比例。此计算支持分离档位与来源的设计理由，不证明完整系统不存在其他漏洞。

## 5. 随机、重选、自选与提高稀有度

推荐首版只做“有限批次候选＋从中确认”，后续功能预留清晰契约，不一次建抽卡经济：

| 功能 | 允许改变什么 | 必须保持 |
|---|---|---|
| 重新随机 | 在剩余预算内推进到下一批机会 | 已展示批次不因关面板/重载重新摇；无免费无限刷新 |
| 自选/筛选 | 在已解锁范围选形态、背景或某类条件 | 筛选不匹配可以落空；不能免费把一星池过滤成必出极品 |
| 提高稀有度 | 显式改变某批的档位权重/条件 | 先有明确权限/成本，再抽取；不是杀人、重复死亡或反复无效查询带来的补偿 |
| 查看更多信息 | 按重生选择机制允许的先天/开局信息展示 | 不顺带揭开地点宝藏、父母秘密、未来事件或所有隐藏天赋 |

刷新预算与剩余重生次数是不同概念。刷新不能免费增添下一世；使用重生也不默认附送无限刷新。具体数量、价格、保底是否存在、稀有度分组和难度曲线由开发/测试决定，不在本轮拍数值。

不存在的功能不能先用隐藏规则补齐：当前暂不接增加重生次数的剧情、商店、付费内容或保底赠命。

## 6. 不回滚的小幅前跳

从死亡已提交时刻起，只朝未来寻找，在政策给定的有限窗口与预算内处理实际世界过程。候选预览本身暂停操作时间，不能开着窗口等世界无限刷新。

确认候选后，推进到其出生边界；资源、人口、运输、争端、旧角色身后事和消息一起演算。不能只让目标胎儿成长，其他世界冻结；也不能先给未来角色发货，再补算过去。

小幅前跳不许延展到“直到必出极品为止”。窗口耗尽与计算预算耗尽是不同结果：前者按玩法给出缺少入生机会的明确结果，后者是继续处理/进度提示，不能误扣生命或判游戏结束。

若真实世界在允许范围内确无可用新生机会，推荐显示明确的无法续生结局与原因摘要，可查看本局/返回菜单，不无限等待或凭空造候选。这是极端世界状态的设计提案；正常内容和种子要通过出生供给与边界测试保证可用，不能用它掩盖未实现模板或生成器故障。

## 7. 次数、难度与本局结束

推荐把剩余次数定义为“还能完成多少次转生”。活着时剩余0不杀死当前角色；该生命结束时无可用次数才结束本局。消耗最后一次成功进入新生后，可以完整玩这一世，下次死亡无机会再转生。界面明确当前世次与剩余机会，避免“最后一张刚抽中就Game Over”的歧义。

本局难度在开局确定对应初始重生预算，高难度更少；具体档数与次数由测试定。途中是否可改难度属于后续模式规则，不能通过菜单切换重置本局已耗次数。

死亡后先锁定本次续生事务并预留机会；确认并成功绑定新生命时提交使用一次。重复死亡回调、候选无效重试、保存恢复都引用同一事务，不能重复扣次、重复绑定或退回一份已使用机会。取消到主菜单不恢复已使用的机会，也不把同一未完成候选批次洗成新批次。

机会耗尽后不再提供免费普通新人、任意附身、退隐切人、建立旁系主角等通道绕过终局。退隐可继续作为人物的生活状态/结局，但不提供免费换人按钮；主动结束此生进入续生也遵守同一预算。

结束的是这局主角历程，历史仍可用于结局展示；是否做结局观战/导出属于后续呈现，不在此偷偷增加可继续操控世界的模式。

普通存读与世界内重生仍分开：用户未要求铁人、后台跨档扣次或账户惩罚。本次防利用针对同一续生周期的幂等、锁批次和概率不被人口筛选抬高，不暗改普通存档功能。

## 8. 随机与存档所需的最小状态

建议由一个本局连续性负责人保存以下语义，不作为所有NPC的必填面板：

- 本局/连续性ID、规则版本、难度策略与初始/剩余/已预留次数。
- 当前世次、死亡事件ID、续生事务ID、所处阶段与唯一绑定结果。
- 独立随机上下文、当前批次索引、已展示候选、刷新/筛选/提升的剩余预算与已提交成本。
- 候选槽的档位/范围、来源过程引用、预测/实际时刻、有限搜索窗口与进度。
- 新生命/身体引用、跨生记忆的允许部分，以及需清理/延续的旧身体、物权和消息事务。

世界随机流与候选随机流分开。反复开窗、读档、让其他NPC多做一个动作，不能直接消耗候选流来洗牌；候选须与当前实际世界校验，但不能因世界变化自动获得新的高档抽取。

候选随机根应在开局/进入本世时从专用流确定并保存，按世次/显式刷新索引使用。死亡事件ID用于幂等关联，不能拿可由杀人数量改变的通用事件序号当新的随机种子；改变几个世界事件的先后，不应免费改变本世已经确定的档位抽取。实际出生条件随世界变化，属于匹配变化，不是重新摇档位。

同一批次的展示内容与状态随快照保存；恢复先构造候选并校验出生来源、资源预留和唯一绑定，再一次替换。新机制依赖W0主体/载体/引用、P0时间/保存及出生/成长过程，不能只在HUD加一个次数与抽卡按钮宣称完成。

## 9. 对抗与连续性验收（全部待实现）

| 编号 | 操作/场景 | 应当得到的结果 |
|---|---|---|
| L1 | 正常死亡，余次大于0 | 有限候选来自合法新生机会；确认后扣一次、绑定一次，世界向前 |
| L2 | 消耗最后一次成功转生，再次死亡 | 最后一世可玩；再次死亡结束本局，不能免费选普通新人 |
| L3 | 同难度与种子，对照删掉大量普通幼体/孕育者 | 抽取档位/范围不会因删除自动升高或归一到极品；候选可能减少，不能宣称保证全无概率影响而不做统计 |
| L4 | 世界仅剩少数特殊孕育者 | 不自动发满它们的极品后代；不匹配的槽不转化为极品保底，不凭空补出生 |
| L5 | 候选窗口期间关闭/重开、保存/恢复 | 仍是同一批与相同已耗预算，不反复免费重抽 |
| L6 | 自杀、重复死亡通知、失败恢复 | 同一死亡不重复提交；真正新一世再次死亡耗另一有限机会，不返次数 |
| L7 | 重新随机/筛选/升档后中断 | 显式预算/成本准确接续；筛不出时不免费放宽稀有条件 |
| L8 | 选中出生过程的父母/环境途中失效 | 按真实条件处理；不回到过去救活，不扣两次，不无限免费换批 |
| L9 | 未选候选后来被玩家遇到 | 仍有实际来源与持续身份/经历，不因没选而删除或复制 |
| L10 | 人、幼兽、幼妖分别转生 | 出生/成长与动作限制符合形态；不把幼体直接装配成人形背包战士 |
| L11 | 旧角色遗物、职务、欠款与密信跨转生前跳 | 根据实际规则处理；新生不自动收旧信、继承职位或取走旧遗物 |
| L12 | 无真实出生、未实现模板、预算耗尽三种情况 | 明确区分玩法无机会、内容错误、计算未完成；不混为随机Game Over |

除固定种子回归，还需多种子对照测试抽取档位、来源分布、极小候选池、有限窗口、刷新与筛选组合。指标至少分开“是否获得任何可用出生”“可用者中稀有比例”和“每次续生获得稀有机会的无条件概率”，不能只看幸存者中的比例声称公平。

本文第4.4节记录了简化概率解析；上述完整机制、多种子对照和对抗回归尚未执行。候选筛选与有限重生应在其依赖成立后接入，不以新增文档或简化计算替代运行证明。当前授权和顺序见[HANDOFF](../../docs/status/handoff.md)。
