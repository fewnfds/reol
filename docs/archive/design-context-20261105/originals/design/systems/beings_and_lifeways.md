# 众生与生活方式：身份、身体和可玩的处境

成文：2026-11-02。**总体设计，已有主体/载体/控制及人、鸟、魂短生活样本；不是全部生命/种族出口完成。** [FEATURES](../../docs/status/features.md)说明实际范围，[BASELINE](../../docs/status/baseline.md)保留验证。古兽仍为代用品，出生/成长/转生未实现；当前授权见[HANDOFF](../../docs/status/handoff.md)。

配套[世界总纲](self_consistent_world.md)、[知物用器](knowledge_artifacts_and_invention.md)与[最新世界/交互原则](world_interaction_principles.md)。树类开局只是扩展例子：优先已有微弱意识和选择空间，被动终老留给玩家主动选择，不随机强加，也不要求全部植物觉醒或化人。

## 1. 什么使一种存在值得扮演

不是同一人物换一张鸟皮、鬼皮或大贴图，而是有不同的感官、行动方式、依赖、理解与交往渠道。差异能产生困难，也要产生独有机会。麻雀、寄魂者、古兽不必先化成人，才获得“正式游戏资格”。

每个可玩起点至少回答：如何维持自己；眼下关心什么；能察觉和影响什么；如何表达或合作；会被什么限制；失败后还有什么选择。创建角色可以提供这些处境的预览，不用“坦克/治疗/输出”概括其一生。

不是所有设定都必须同轮实现。先选几个最能暴露架构假设的样本，再增加种族内容。普通生命、妖化、修持和身份是不同维度，不能只用种族ID决定善恶、智力、阵营和所有动作。

## 2. 四件事必须分开

| 概念 | 负责什么 | 边界 |
|---|---|---|
| 主体 | 记忆、目的、经历、关系和个人承诺的连续性 | 不等于节点、皮肤、公开名字或唯一身份证件 |
| 身体/载体 | 形体、位置、感官、结构、损伤和物理/灵性承载 | 可以是生物身体、器物或有规则的灵体载体；无身体不等于无限穿墙 |
| 控制关系 | 此刻谁能指挥什么动作，经过何种通道 | 正常自身控制、契约代理、傀儡指令、附身争夺有不同语义 |
| 社会身份与被识别身份 | 名字、任职、师承、物权、他人认为你是谁 | 冒名不创造任职，换身体不自动使所有旁人认得你 |

稳定主体ID是模拟层的连续性工具，不是所有NPC都能查询的灵魂身份证。一个人用了假名，世界仍能存其经历，旁人却未必知道关联。社会对换身后债务或继承的承认可能有争议，不能从后台ID直接让全世界达成一致。

同一物品/载体的实际位置唯一；同一控制权限有明确范围与执行顺序。若一个主体能分心控制多处，必须有感知通道、命令延迟、注意代价和控制中断规则，不因多实例场景生成多个背包或免费劳动力。

### 2.1 换身、附身与死亡

- 换身先检查新载体是否可承载、原控制是否释放、物品放在哪里；变身不缩小行李的真实体积，也不复制伤势前的旧身体。
- 原身体损伤属于原载体；记忆缺损、魂伤与身份关系可能属于主体。哪些可以转移由具体方法定义，不用一项万能血量包办。
- 封魂术可以保住濒死主体，但需要适合载体、时间与施术能力。不能默认每个角色死后自动变成不受任何限制的幽灵。
- 附身涉及实际入口、防御、控制争夺与目标意志。仅持有戒指、签雇佣契约或成为掌门，不产生他人身体控制权。
- 真正主体死亡、载体毁坏、暂时休眠、意识失联分别表达。继承、遗物、职位和消息据实际结果处理。

第一轮只需“正常身体控制＋封魂戒指中的独立主体”，其余留为有边界的扩展，不一次写完整夺舍与多身系统。

2026-11-03用户确认：普通肉身死亡通常伴随灵魂消散，保魂、寄魂或转世需具体条件/方法。主角有有限重生机会，世界不回滚，可小幅前跳，从跨种族新生人选中接续；机会耗尽结束本局，高难度次数更少，当前不设计增加渠道。详见[有限重生与新生候选](rebirth_and_new_lives.md)；这不泛化为全体NPC常规轮回。

### 2.2 主角的有限重生机会

已确定的概念是“通常有终结的世界＋主角有稀缺的例外”。这不意味着NPC永远不能保魂复生；NPC可使用已经定义的仙侠方法，但不自动拥有主角的同款机会计数或无限轮回。

机会属于本局主角连续性记录，和各世身体/身份分开；不是全体生命必填属性，也不能靠控制新角色复制。初始预算按难度决定，原型先不实现剧情补充。刷新、自选、提高稀有度是可设计扩展，需显式预算与规则，不能成为免费增命或屠杀筛选的旁路。

候选必须有实际孕育/群落出生来源，按有限机会域和前向时间窗匹配；不在所有幸存幼体中重新归一抽取。死亡、刷新、确认、跳时和绑定用持久事务记录保持幂等；详规与L1–L12未来验收统一在rebirth_and_new_lives，不在本文重复维护参数。

“主要角色有例外”不表示NPC全都知道它。亲历、传闻和证据可以改变旁人反应；后台特殊标记不会让仇人免费知道主角的复生条件，也不会让旧组织自动归还职位与财产。

普通读档与世界内重生分开。用户没有要求铁人或跨存档惩罚，本轮不暗设全局重生扣次、不修改用户存档策略；防利用首先约束当前续生事务、有限抽取与候选来源。机会耗尽后没有免费换新人继续的玩法。

## 3. 身体是一组可查询的条件

2026-11-03用户确认修行机会以开放为主：大多数生命有适合自身的方法路径，少数当前身体/载体不能直接修行，但可能经具体改造/迁载改变。它不是所有方法皆可学的承诺，也不自动让无心智物体成为可控主体；先天差异改变条件与代价，不一概折算成同一资质分。

| 方面 | 原型需要的表达 | 会产生的差异 |
|---|---|---|
| 几何与尺度 | 占地、通行净空、接触面、可伸达范围 | 进入缝隙、经过门桥、在边界递物 |
| 移动 | 步行/攀爬/飞行/依附等方式及条件 | 地面道路、屋脊、风带、水域与休息点 |
| 操作 | 手、喙、爪、触须、法术牵引等操作通道 | 抓取、拆装、携带、指点，精细操作可能需要工具或协作 |
| 感官 | 可接收的光、声音、气味、灵机等及范围 | 同处一室得到不同线索；感知不到不等于目标不存在 |
| 维持 | 适食对象、摄取方式、休养/休眠、环境耐受 | 人粮不是所有生物的食物，睡床不是所有主体的必需品 |
| 结构与承受 | 原型相关的损伤、行动受限、承载适配 | 伤翼影响飞行，裂戒影响封魂；未用到时不细算每片组织 |
| 表达与理解 | 声音/姿态/文字/神念等产生和接收条件 | 能看见字不一定识字，能传意不等于跨语言无损通信 |

这张表是设计检查表，不是七条全局属性条。某对象没有某结构就不存伪造数值；过程只查询需要的信息。不同形态共享“能否把这个对象移到这里”的问题，计算条件可以不同。

身体能力、学习过的方法与持有工具可以补足彼此。麻雀不会缝衣，但可请匠人做能用喙打开的扣；寄魂者不能抬炉，却可以指导愿意合作的持有者。合作方依然能拒绝或索价。

## 4. 五种完整生活样本

以下是设计验收样本，名字和细节可更换，不是已实现开局或最终种族清单。

### 4.1 凡人匠人：力量有限，理解可以独到

- **维持**：吃住、工钱、工具、原料和休息；并非每分钟都要处理一个生存告警。
- **近期目的**：修桥谋生、为徒弟找材料、保住欠款、恢复家传手艺。
- **独到机会**：辨认接缝、铸痕、受力和工序；能给高阶器物做外壳修补，但不自动会修灵性核心。
- **限制**：无法直接进入某些危险环境，不能靠徒手承受高阶灵机；可选隔离工具、低功率、委托他人或放弃。
- **交往**：合作、信用、徒弟、同行、采购；衣着、工具与作品形成实际线索，名气可能远超过个人武力。
- **失败接续**：赔偿、返工、转行、求助、搬家、修行或维持凡人生涯。不能把长期当凡人判成“未开始游戏”。

### 4.2 修士：选择方法，承担方法带来的生活

- **维持**：身体生活、适配环境、练习材料、师承或自学途径；境界改变需要，但不抹去所有依赖。
- **近期目的**：护人、求学、隐居、争取场所、创造方法，或以术法服务日常工艺。
- **独到机会**：在明确范围内御火、护持、传意、驱器；修习《骗经》者可研究表象、身份与知觉，而不必擅长正面斗法。
- **限制**：知道一种术不等于知道所有术；能飞不等于能装下货车；高手可以有真正强大的优势，仍受具体方法边界约束。
- **交往**：传承、保密、共享设施、承诺、忌讳和对异类的不同立场；不把世界统一成修为等级序列。
- **失败接续**：疗伤、停修、改法、寻找援助、接受损失；反噬要有可定位原因，不能只扣一条抽象经验条。

### 4.3 麻雀小妖：小尺度有自己的地图

- **维持**：种子/昆虫等适食来源、水、避风处、巢和安全落点。修持可能扩大食谱或改为部分吸纳灵机，依具体方法而定。
- **近期目的**：保巢、找同伴、探查新地、交易轻物、寻求能理解自己的交流者。
- **独到机会**：屋檐、梁缝和枝头可达；搬运纸条/种子/少量药材，观察人类遗漏的高处与小孔。
- **限制**：风雨、捕食者、伤翼、很小的负载与精细操作能力；不能默许背包装十把人类长剑。
- **交往**：可经姿态、声音、已学语言、刻痕或有条件的传意交流；说不出人话时仍应有明确的小范围交换与求助入口。
- **失败接续**：换巢、躲藏、寻医、投靠保护者、改做情报或引路；不是“先升级化形再开始社交”。

可见外观可以是羽饰、色泽、绑带、系在身上的小物。穿戴按体型、承载与穿法生成，不能显示一套人类鞋帽栏后全部灰掉。

观察别人写字只生成看见的图样；识读和解释需要方法。鸟妖可以记图找人翻译，不能因为玩家是人类就让角色无条件读懂所有字。

### 4.4 戒中寄魂者：依赖别人，也有自己的议价空间

- **维持**：载体完整、封印稳定、适合的补给或周期休眠；具体魂修法可修改条件，不能统一靠“吃一颗丹”解决。
- **近期目的**：修复记忆、偿还旧债、重见某人、获得新载体、教出传人，或仅希望不被强迫劳动。
- **独到机会**：保有部分旧知、感知近处特定灵机、传意、提供识别或方法指导；都需要实际来源与范围。
- **限制**：不能自行搬戒指，不能看穿所有墙和持有者内心；古老记忆可能过时、破损或主观。
- **交往**：提供知识、示范或封存功能换取修复/出行/保密；持有者、保管者、合作方和原物主可能不同。
- **失败接续**：撤回合作、请求第三人、保存有限信息、休眠或迁载；若被彻底封存，玩家可选择等待到有界事件、切换世界中的另一身份或结束该人物经历，不能假装无操作等待就是丰富玩法。

老人可以骗持有者，也可能被持有者骗；它只知道自己的感知与被告知信息。戒指被卖出后，老人不会自动接受新主人。交换指导、保守秘密、拒绝附身与逃离封印都应有独立意图与方法。

### 4.5 古兽：规模本身是一种处境

- **维持**：相符的领地、食物或灵机来源、休眠/恢复空间；具体古兽可以靠特殊生态维持，不能只按普通人饭量处理。
- **近期目的**：迁徙、守护栖地、寻物、接近同类、对干扰作出反应；也可成为有意经营互助关系的庇护者。
- **独到机会**：清障、重载、改变通道、形成区域安全影响；人与鸟妖可能在其体侧或附近建立有条件的合作。
- **限制**：真实占地、转向、道路净空、地形承载、补给与隐蔽困难；无法进入街巷时可在城外接触，不能靠缩小碰撞盒假装走进客栈。
- **交往**：叫声/动作/已学表达/使者均可；使者是有目的的独立主体，命令有传递过程与拒绝风险，不是免费的人类分身。
- **失败接续**：退避、迁栖、休眠、谈判、改变食源、接受医治；不必强制化形，也不把所有人必然判为敌对。

第一项几何试验只证明多格占地、边界接触和路径约束，例如用3×3测试载体；它不能冒充已经支持占据几座山的神话生物。超大身体需要独立的局部接触面/区域移动原型，验证后才开放对应内容。

## 5. 角色进入世界的方式

用户在整体评审中选择以单角色人生为主，随后明确通过有限次数的跨种族新生候选接续；世界不回滚、次数耗尽结束本局。下列多种开局用于世界装配与身份差异验证，不默认随时自由附身；退隐不提供免费换人绕过终局，同伴/经营仍可通过授权与协作交互。

开局由“主体经历＋身体/载体＋所知＋所携/所依靠＋关系＋当前处境”装配，而不是一个职业枚举。推荐将生活目标作为可修改的建议，不把它变成必须完成的主线。

同一世界种子可分别从匠人、鸟妖或寄魂者开始，保留局势、人物与资源分布。起点可以不对称，但要说明压力和可用机会。强力古兽开局不是禁用按钮；它的难点可以来自尺度、信息、供给和长期关系，不必把战力削成和小麻雀相同。

创建/切换身份不创造私人副本，不把原主体从世界删除，也不替新主体继承玩家知道的全部秘密。玩家在脑中记住信息不可完全阻止；角色是否掌握方法、证据或语言仍要按世界状态判定。

同局新一世走有限重生规则，选择新生机会，不再把任意在世NPC或免费普通新人作为机会耗尽后的替补。跨生保留哪些记忆是[候选方案](rebirth_and_new_lives.md)，须与新身体的成长和适配分开验证；旧物、关系、职位和正式权利不自动继承，原世界不重建。其他世界内迁载/夺舍方法依各自真实条件运行，不是预算归零后从菜单绕过结束的功能。

## 6. 相遇与共同生活不必先说同一种人话

交互先确定可接触范围、可交换信号与双方已有经验，再选择能表达的内容。默认提供少量直观语义：展示/指向、给物/拒物、靠近/退让、求助/警告；复杂条款需要语言、文字、媒介或翻译。

通过反复一致的交流可形成局部约定；这属于双方经验，不是全世界同步学会新语言。误解可以发生，但反馈要说明观察到什么，避免每次点击都随机翻译成相反意思。

和平共处可以依赖实际用途和互不干扰，也可以有个人喜爱、仪式或文化意义。鸟妖不是必须当快递才值得存在；巨兽不是只在充当战车时才有玩法。嬉游、筑巢、收集、探访、教学、观景与创作可以改变归属感、作品、记忆和关系，不必都产出金币。

不同社会可能歧视、庇护或利用不同生命。反应来自地方规范、具体经历与认知；不要用“种族好感-100”永久决定每个NPC。也不要保证所有排斥都能靠一句好话解除。

## 7. 表现与存档对架构的要求

- 角色视图绑定主体与当前载体；释放场景节点不结束主体生命。原人形代码可先用适配器，不进行全量迁移。
- 物品位置可表达地面、容器内、某身体部位/挂载点、封存空间；显示列表只是引用，不重新增加库存。
- 分开保存主体、载体、控制关联、形态变更中的事务、知识、关系和物品位置。载体转移需验证两端，失败不留下半个魂或两份戒指。
- 远区按身体移动条件、维持与交流通道算结果；粗算不能让鸟妖免费运整车货，也不能让寄魂者自动获得所到城市全部知识。
- 未参与具体互动的背景动物可做群落过程；一旦成为被记住、被契约约束或被玩家扮演的个体，持久化该个体并扣除群体份额。
- 对鸟妖提供落点与轻物提示，对巨兽提供占地与边界交互，对寄魂者提供感知/传意/协商。无效人形界面不承担这些玩法。

## 8. 可验证的边界场景

| 给定 | 行动 | 必须得到的结果 |
|---|---|---|
| 鸟妖能通过屋檐缝、不能携带人类剑 | 带着纸条通行；再尝试搬剑 | 纸条有真实转移；剑因抓持/负载不足失败，不因“任务道具”豁免 |
| 鸟妖不识字但能记图 | 观察收据并找识字者 | 得到的是有来源的解释，不自动创建官方贡献或全知证据 |
