# 社会互动评审笔记：人物、处境与后果

> 日期：2026-11-02。状态：讨论提案；其中完整决策模型未定稿。游戏已有有限请求与社会互动样本，具体范围见[FEATURES](../../docs/status/features.md)，不能据此宣称本文整体实现。
> 用户已明确：允许内部骰判/概率算法；因素由助手参考心理学、社会学选择；保留游戏可理解、可实现的复杂度。
> 下文的因素分组、流程和实现边界是设计建议，不代表经过科学验证的人类预测模型，也不代表用户已批准具体权重。

游戏机制的比较研究见 [社会交互游戏研究](../research/social_interaction_game_references.md)。该研究先区分成品、开发设想与真人参与，再讨论信息、记账、承认和执行；不将旧 Claim 方案或继任权重视为已定框架。

## 目标

NPC 有自己的生活与目标，NPC 之间和玩家与 NPC 使用同一套交互规则。
在玩家缺席时，生产、求助、合作、竞争、承诺与纠纷仍能继续发生。
关系、机构资源和制度执行应随具体行动产生变化，变化又影响下一次行动。

内部数值可表达体力、物资、预期、风险或决策倾向；不能让抽象的进度分数替代这条因果链。

## 用户明确的愿景补充（2026-11-02）

以下是用户说明的方向；后文因素、对象和算法仍是提案。

- **个人、组织与阵营分别形成评价。** 对一个门派、地域群体或正邪阵营的看法，可以影响对某人的初始判断，但不完全等于对这个人的了解与评价；身份与归属也可能重叠。
- **礼貌和实际付出有不同边界。** 尊敬、点头之交、信任、授权、提供资源和冒死相助不能等价。不同请求应结合事项、关系、代价、职责和处境判断。
- **模拟网游/修真小说中的活社会。** NPC 像玩家一样有自身关注、打算和个性；玩家缺席时仍会寻求资源、交往、合作、竞争并承担结果。
- **群体有目的和立足之本。** 门派与势力依靠具体资源、技艺、地盘、组织能力、合作或其他条件存续；共同目标通过成员和职位落实，允许派系、私意与规则发生冲突。
- **不同身份应能参与同一个世界循环。** 以“任意身份进入是否仍有处境和行动机会”检验真实性：人物应有生计、目标、关系、义务、依赖和风险。具体可选出身范围尚未据此确定。

设计解释：有算计不意味着所有人物只追求个人利益；善意、情义、原则、归属、冲动和误判也能构成行动理由。点头之交不必自动送资源，但人物仍可能出于救助职责或个人善意帮助陌生人。

这要求框架同时容纳日常合作、资源竞争、群体存续与私人情感。账本和继任用于其中相关场景，不能代表整个社会交互目标。

## 一次互动的流程

1. 需求或事件产生一个目标；既有职责与习惯可产生日常计划。
2. 人物根据自己知道的人、资源与机会，形成请求、提议或行动。
3. 接收者根据自己的认知生成少量回应方案：接受、有条件接受、拒绝；有实际原因时再出现延期、隐瞒等方案。
4. 对方案评估；处于犹豫区间时使用局部概率判定。确定的日常承诺无需反复掷骰。
5. 承诺进入实际执行，消耗时间、物资与行动机会；答应不等于成功完成。
6. 参与者和获知消息者解释后果，更新记忆、预期、义务与后续计划。

已知事实与人物信念分开。人物可能接受自己其实办不到的事，也可能因误解而拒绝。
客观资源不足不能被骰子凭空补足；制度禁令可以被违反，但应涉及发现、追责与执行过程。

## 用于决策的六组信息

| 分组 | 实际问题 | 游戏中的信息来源 |
|---|---|---|
| 当前需要与目标 | 这件事对我现在有什么意义？ | 生理状态、当前计划、重视的人或事 |
| 预期代价与风险 | 我要付出什么、放弃什么，可能损失什么？ | 已知物资、时间占用、危险、其他承诺 |
| 人际经验 | 我预计对方会怎样对待我？ | 共同经历、履约记录、领域相关的可靠性判断 |
| 身份与交往规范 | 按我们这段关系，我觉得应该怎么做？ | 亲友/师徒/同门等关系、承诺、职责、群体规则 |
| 权力与公开情境 | 谁会知道，谁能奖惩或支持我？ | 在场者、传播渠道、实际控制力与执法能力 |
| 个体差异与当下感受 | 我特别在意什么，现在处于什么状态？ | 少量价值偏好、风险倾向、相关情绪 |

六组是输入分类，不是六个通用属性条。每种互动只读取相关信息；需要决定某种收益的重要程度时，避免又把同一需要作为独立加分重复计算。
初版每次决策保留少量主要理由和所依据的经历即可，不建立几十项独立人格量表或无限递归的心理推测。

## 关系与制度

- 关系应容纳角色、共同历史、正在履行的承诺，以及按领域区分的预期。
- 亲近、守信、能力和畏惧可以分别概括，但应能追溯到经历；“一起出生入死”和“天天收礼”不应变得完全等价。
- 同一关系可以包含共同体、上下级、互惠、交易等交往预期；不同人物也可能对当前关系有不同理解。
- 制度通过具体的人、权限、资源、记录、程序与执行行动生效。账本负责可登记的权利、义务和凭证，Claim 作为候选子系统保留，不统包亲密、记忆、情绪与个人理解。
- 失约后的解释至少区分故意违背与能力/处境导致的失败。认知不同可以形成误会，后续解释或证据可以促使修正。

## 骰判边界

- 每个实际可选的回应先有条件与理由，再决定概率；不先掷“好感成功”再补写剧情。
- 概率和权重由游戏场景校准。强烈倾向应保持稳定，随机性主要处理相近方案和未细分的情境波动。
- 同一提议在处境未变时不反复重抽。新报酬、证据、时机、见证人或其他实质变化才值得重新评估；重复施压本身也可以成为新事件。
- 选择、执行与社会后果分开结算。一次互动不需要为每个小步骤都掷骰，确定行为直接执行。
- 随机状态与重要决定应能保存、回放，供开发排错；玩家可见解释受其实际获知的信息限制。

## 评审场景

一名弟子受伤导致劳力短缺。他向丹房求药，丹房实际有库存但需要保留应急药。
负责者可能按救治职责发药、要求担保、提出延期偿还或拒绝。
同伴可代工或担保，但会占用自己的时间或承担责任；因此是否愿意取决于自身目标、交往历史和风险。
履约、意外失败与故意赖账形成不同的理解；消息只通过参与、目击或传播进入其他人物的认知。
救治改变伤势，代工改变生产和疲劳，追偿又可能改变合作方式或分配规则。

验收重点：移除玩家后，这段链条仍可由 NPC 自主触发；改变资源、历史或认知能解释行为差异；不能仅靠增加一个总好感值覆盖全部条件。

## 研究依据与适用范围

以下研究为因素选择提供参考，不提供本游戏的骰点、权重或修仙社会参数。

- Michie 等（2011），[COM-B / 行为改变轮](https://pubmed.ncbi.nlm.nih.gov/21513547/)：借用能力、机会、动机的区分。原研究用于行为干预框架，不是完整的人类决策模拟器。
- Zakharin 与 Bates（2023），[关系模型理论的检验与复现](https://pmc.ncbi.nlm.nih.gov/articles/PMC10275437/)：参考共同体、权威等级、互惠平衡与市场交换等关系模式；不将其当作穷尽所有文化的固定分类。
- Fehr 与 Fischbacher（2004），[社会规范与人类合作](https://pubmed.ncbi.nlm.nih.gov/15050515/)：规范执行和惩罚可涉及非自利动机，合作不能只以即时物质收益解释。
- Tyler（2023），[合法性与权威的综述](https://www.annualreviews.org/content/journals/10.1146/annurev-lawsocsci-110722-074236)：参考人们对权威的承认及其情境差异，不将武力、职位和自愿服从混为一谈。
- Monroe 与 Malle（2017），[故意性如何影响责备判断](https://pubmed.ncbi.nlm.nih.gov/28054816/)：参考故意行为的理由与非故意行为的可避免性，对失约解释做简化区分。
