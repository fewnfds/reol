# P1-a：有限自然来源与实际采集

2026-11-03。P1-a有限样本已实施并验收，见[实际证据](../../qa/20261103_renewable_livelihood.md)。当时为避免断供先补长期生活来源；后续W4已有有限寄魂样本，当前顺序和授权见[执行记录](world_engine_execution.md)与[HANDOFF](../../status/handoff.md)。

体验：柴粮库周边有可拾落枝，药圃边有野稗穗丛与野药，井下有缓慢回补的泉水。它们不是随时取之不尽的仓库；采集需真实身体前往、花时间取得有限实物，再携回原设施。NPC在自己的补给责任和库存认识下考虑采集，不能只让玩家承担世界再生产。

实现：新增纯`SimLandResources`，由各Village持有有限资源源、实际增长相位与生产/采出汇总；实物仍在原`SimInventory`，资源源容器与仓储分开。数据定义生长间隔/容量/量与采集工作，开局仅装配既有设施周边的小来源。不新增聚落设施位置，旧版地形布局仍可兼容；旧档迁空资源源，不倒造野外产量。

原执行器增加`gather`：预约源中有限实物→到源地点→完整采集工时→实物到本人→携回设施。手动中断/失控保留已采物、释放未采预约；再次提交先交手里已有物，不能复制采出。成果凭据依完成时实际需要生成，仍须机构登记，不发全局声望。远区在增长/行动关键边界结算，与近处细推相同；满容量不储存无限成熟量。

NPC补给办法只针对原职责的供应链：先履行有料的送柴/运粮/挑水，仓储不足则按个人近期认识调查或采集。不会查看全地图隐藏库存决定计划。UI在同一生活面板增加独立采集页，避免拥挤原劳作页，并说明具体来源/劳动；只展示本人近处能看见的情形，不展示资源后台总量和全局产量。

存档：根11/区域8/村落3加入资源相位与来源，v10及更旧逐级迁移；旧村落2迁空资源源与原有配置，当前格式缺领域/坏来源/超容量/预约错源/虚构产量原子拒绝。真实v1–v10和overload_v10不改写，新实际进行中另捕获v11。

验收：有限资源能耗尽；等待产生有来源增量且满容量不囤积；无劳动不进入仓储。途中/采集中取消不复制或丢物，失败释放预约，存读继续。两人竞争同源不会超取；携带物恢复优先交付。旧库存说法继续影响NPC，缺料NPC可真实采集再供饭；粗细/远近/JSON与完全停开接续一致，坏状态不动原世界。1280×720实际输入完成至少一次采集并看到库存变化。长局低库存情景记录来源与去向；不声称通过所有饥荒/经济/性能出口。

边界：本包是野外有限再生与井泉，不是耕作、留种、天气、农田产权、矿业或无限自足保证；粮食仍有配方转化和消费。需求耗尽后的医疗/死亡、农业与市场后续成包。不安装依赖、不改addons、不覆盖用户原档。
