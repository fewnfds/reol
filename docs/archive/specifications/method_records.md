# W6-a 实物方法记录与有限传播

状态：有限首包已实现并验收，2026-11-03，见[实际证据](../../qa/20261103_method_records.md)。不代表通用书籍、识字、误抄、科研或门派藏经体系完成。

目标：温养版本能够被写到实际木牍上，经携带、放置和自愿交接传播到另一聚落。人物读完才获知该版步骤，仍须引流基础与原温石实践才能掌握。后台方法目录不向未接触者开放。

规则：木牍耗用原行囊中可处分的木料；写刻、阅读与交接占原身体和共同毫秒。耗材在开始刻写时投入，中断不退、不生成半成品能力。方法版本不可变，修订不会改旧木牍；抄写只复用已知版本，不制造新工法。第一版为精确抄录，不实现伪作和文字语言。

唯一状态：`SimMethodRecords`只拥有木牍的唯一位置、指向温养版本的内容、动作和本人阅读来源。木料/受托限制仍归`SimInventory`，身体/需求仍归Village，实际练成仍由原Artifact成功事件认定。木牍不是第二份木料，也不塞入温石专用储热状态。容器引用沿原地点/人物容器，随持有人移动。

交接：本人拿取公共放置点的木牍或把随身木牍放在眼前设施；不能越过别人行囊。交给同门先经原有向关系/精力/忙闲的社会判断，对方可拒绝；答应不等于当场读懂，交接过程结束才改持有位置，双方仍须在场。NPC收到后在吃饭/休息和已承担事务之外找空阅读；实际需要补热且已有基础时才尝试已读安全版，未接触版本不会采用。

界面：M的“实物记录”页列眼前木牍；正文与可用方法只来自本人作者/实践/阅读来源。提供刻写、阅读、抄写、取放、自愿交接与照已读步骤尝试；不显示远处当前持有者或NPC读懂结论。无LLM可操作。

存档：根22→23、区域19→20，新增记录域显式迁空，不倒造历史实物/阅读；已有真实v1–v22不改写。现代缺字段拒绝。候选核对耗材操作、不可变版本、位置流转、阅读先于引用、有限过程/控制/双占及社会同意；失败不改活世界。

验收：真实材料不足/受托材料拒绝；刻写中断不退、无成品/阅读；持有不授知识、读完不授本领/新修订；跨区实际运输后才可接触；自愿交接可拒绝且失败不丢物；NPC需求与原行为继续；写/读/交接/练习中途JSON、近远粗细与完整进程重启未来一致；坏引用和删领域原子拒绝；正常M入口及1280×720可见测试、全量check与文档。

顺序：纯规则与候选→原时钟/运行适配→M页→自动回归→实机及真实v23 fixture→当前状态文档。正常游戏不装依赖，不改第三方插件。
