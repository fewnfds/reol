# A1：共用真八向外观技术样本

2026-11-03实施包；总合同见[eight_direction_appearance](../../specs/presentation/eight-directions.md)。本包先验证方向、解剖左右、共享相位与原穿法，采用原创代码生成占位素材，不等于正式人物美术或完整战斗动画。

## 范围与状态归属

- 一套人形、八个独立朝向，待机8帧、行走16帧、生活短动作16帧；原常服颜色与蓑衣复用动作/图集。
- 原actor仅新增最后面对方向，`SimLocalMotion.facing`代理这一字段；路线按真实段方向更新。重定位不生成路程，视图错开不改变朝向。
- 本包步态取共同世界时刻，不在转向、换路段或换衣时复位。它是确定的技术采样，**尚非与实际步长锁定的最终步态**；不为了美术修改原速度/身体消耗。距离同步的进一步优化须有不随细批推进漂移的合同。
- 原衣着继续唯一拥有物件和穿法，显示仅投影。左手剑/右腰玉佩只在明确技术预览中出现，不给玩家/NPC新增兵器、物件、能力或权限。
- 玩家、两地NPC、V纸娃娃共用采样/绘制器；阴影/选择圈、名字和高度仍走原呈现。远区无动画节点。
- 根30显式迁31、村落4迁5；旧NPC默认朝南，旧玩家保留原motion朝向；迁移不补过去的转身事件。历史fixture只读。

## 验收

1. 全方向/全动作数据完整，脚点一致、所有层共用帧与相位；缺方向/坏锚点明确报错并保留占位回退。
2. 左手剑/右腰佩玉在八方向关键相位与前后遮挡中均保持身体侧别，图集不整身翻转。
3. 原真实路线、手动移动、急停/碰墙、换衣和暂停/倍速正确选择动作；视图采样不提交业务影响，不移动原身体。
4. V预览独立转向不写身体；八向技术样例不改变原物品集合。
5. 近远、细批、进行中存读/完整停开后原世界与朝向继续一致；坏候选不能部分替换。
6. 实机1280×720、八方向接触表/时间序列、48视图性能与纹理预算，完整check通过；未验项目如实列为限制。

素材生成器/manifest/来源由素材包提供；原身体迁移、共用采样器、运行接入分别独立实现，组合后再跑完整检查。各项完成以BASELINE与QA证据为准。
