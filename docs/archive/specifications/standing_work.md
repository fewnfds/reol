# P1-d：当面商量一段时间的劳动协作

状态：已实现，定向/全量、实机与完整停止/启动接续通过，2026-11-03。承接[受托公物](entrusted_goods.md)，证据见[QA](../../qa/20261103_standing_work.md)，当前完整验证/格式仅见[BASELINE](../../status/baseline.md)。目标是从一次帮忙走向有限常备协作，不把NPC变成遥控部件，不先做完整组织平台。

## 玩家体验与范围

C向眼前同门提出“替我照看一阵灶房供给”，选择补柴或挑水。对方按原有向关系、当下忙闲/身体、职责与约定负担答应或拒绝；不授予玩家宗门任免权。答应后，在有限期限内把这项劳动放进自己的日常，仍先吃饭/休息/报工，再按本人所见或听闻检查需要、取真实公料或到原有限来源补料。玩家离场后继续。

首包为无偿、自愿、固定时段的两种照看安排；默认期限/权重放data供测试调整。请求方也可以是NPC，受控玩家不被自动替代选择答应。工资/雇佣、任意脚本、完整组织成员/职位/土地权限、自动招人不在首包。

## 规则

- 经原统一请求边界检查对象、距离、表达/理解、通信控制；只向同一聚落内实际在场、可自行决定日常的人提出。已有劳动/服务/对练/身体安排不能被新约定挤掉；同一角色同时只承担一项本包安排。
- 原SimSocialMemory.evaluate_request负责有向关系/处境评分和相同情境缓存，不每帧掷骰；同条件重复表达复用原决定，同一活动约定重复请求不延期。拒绝不自动扣关系。新的时段或实际条件变化才可能形成新判断。
- 安排只提供临时劳动意图；原actor.autonomous、身体/需求/位置、工作执行器、本人库存认识、实物/预约和公差凭据继续权威。不能改config.actor_profiles里的原职责或复制工作/物资。
- 期限到后不再认领此安排的新工作，已经取料/开始的原过程继续正常收尾，不凭空退料或删公物。协作者可主动撤回；请求方撤回须当面让对方听见，远处不能一键清空对方打算。
- 接受不保证库存增长/一定成功，缺料、封路、饥饿与其他真实需要会改变结果。功劳仍归实际劳动者，原登记链决定认可，不因“安排过”把功劳自动算给玩家。
- 玩家只能看自己当时商量的内容/期限；实际在场才看当前公开活动。离场不读后台完成次数/库存，不把约定期内当作已交货，更不自动获知远处撤回。

## 状态与依赖

SimStandingWork保存约定条款、原社会决定/见证引用和有效期限/终止事实；不是独立库存或任务队列。VillageSimulation在原需求优先/报工之后，查询临时劳动意图；原日常执行器继续实际选路/预约/干活。原自主开关不被改写。

RegionalSimulation按同一绝对毫秒处理约定边界、近远同步/失效和独立候选恢复；候选校验双方、原社会同意、稳定计划ID/时段/期限、互斥/终止引用，成功才替换活世界。根21→22、区域18→19，旧档迁空约定，不倒造旧承诺；真实v1～v22与overload_v10不改写。

文件预计：`data/definitions/standing_work.json`、`scripts/sim/standing_work.gd`，原content/村落职责查询/区域调度与候选、请求门面/运行UI/会话迁移；sim与runtime测试，最终QA/当前文档。无新autoload/依赖。
