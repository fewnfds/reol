# P1-e 私料加工与自用/交易

2026-11-03；有限首包已实现并验收，见[QA](../../qa/20261103_personal_production.md)，最新构建以[BASELINE](../../status/baseline.md)为准。不是完整产业或NPC商业规划。

目标：接通自留原料、真实劳动、在制物、成品和自用/有限交易；保留公共做饭与原公差，不把它们换成私人收益。使用原身体/行囊/时钟/货币。

## 本包的可玩过程

1. 人身用原自留采集取得柴、粮、水或药草。在当地公共灶房/药圃使用现有场所做一批私人饭食或干药；原材料必须可自行处分，不能用公差受托物。
2. 预约原行囊里的材料，人物实际走到场所，才把本批材料转进原库存账本的独立批次容器。点火消耗柴，原粮水/药草留在在制容器；本包不允许把加工中的半成品当原料取回。
3. `SimPersonalProduction`只保存批次所有者/场所/阶段/工时和原身体的进行中动作，不复制材料/钱/体力。停工释放身体，已投入材料/燃料和已做工时保留；继续同批不再取料或点火。完成才原容器transform产出，仍留在现场，人物须实际取回。
4. 同样规则可由NPC身体调用；本包不新增NPC私人产业规划或雇佣代工。原公共做饭/温石不会改私有收益，私人加工不自动记功。现有场所代表可共用作业空间，尚无独立锅炉/工位容量排队。
5. 原随身吃饭消耗做出的饭，原C有限买卖新增干药收购，仍受公库现金、实际需求、授权与清点约束。无启动金、全知市场价或无限收购。

## 原规则接缝

库存/预约/consume/transform/transfer仍在原SimInventory；批次容器按所有者的原账本保存，物理位置引用工作场所。跨聚落访客仍用原人身和行囊，不能复制访客或瞬间转移批次。

原RegionalSimulation管理必要边界，原SimRouteTravel推进人物；生产期间占用原身体，不能同时旅行、短动作、别的劳动/用器。沿原需求余数计劳动精力，不造第二精力条。失去控制/死亡/道路阻挡中断原过程，已投入不消失。粗细/远近推进和正在走路/加工/取物的快照必须接续。

新增定义、纯生产域/独立候选和原生活面板的“制作”页；本人批次页说明成品所在地，独立地面物件投影后续接。不创建新autoload、第三方依赖或手改场景。根24→25/区域21→22/生产域1，v24显式迁空批次，新增的未来收购政策不倒造钱货/生产历史。原v1～v25及overload_v10不可改写。

## 验收

- 两条真实链：柴粮水→饭→随身吃饭；柴药草→干药→实际有限收购。没有原材料不能开工，受托与私物混合时只可处分私物。
- 到场前不转料；点火后柴不退；中途取消保留在制物/工时，再续只做剩余部分；产物做好未取仍在原场所，不能在远处领取。
- 各腿完整预检，无半批转移/重复产出；满包失败原成品仍在现场。公差/贡献保持原语义。
- 跨区同一人、同一包/钱，场所引用唯一；忙碌/控制/移动/存读互斥。坏候选原子拒绝，旧档只迁空新状态。
- 完整check、实机鼠标操作/截图、真实进行中保存和完整停开同一联合未来；文档只写真实完成范围。尚无品质、腐败、私有土地/设备/工位排队、产业链自主计划或完整市场。
