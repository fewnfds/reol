# W4-a：戒中寄魂者、约定与实际指导

2026-11-03。NPC有限样本已验收；[实际证据](../../qa/20261103_soul_vessels.md)。后续W4-b的[玩家寄魂开局](soul_player.md)也有有限样本；两者不代表整个W4或完整非人冒险完成。

体验：山门有一枚裂纹旧戒。杂役可携带、唤醒、听老人说有限旧事，答应带他看看药圃并实际履约；老人随后可用自己保留的手法，指导持有者亲手练习温火石。未履约、疲惫、休眠或缺少适用器物会拒绝。把戒指交给别人，改变的是保管人，不是老人的身份、记忆或执行权。

状态归属：新增纯 `SimSoulVessels` 及独立schema，持有唯一戒指位置/裂损、独立寄魂者精力/旧知/休眠、逐人约定和进行中交流/练习。`SimEmbodiment`只登记实际 `soul_vessel` 引用与通信控制；不制造人形身体/背包，不给持有者戒中主体的控制权。温火石仍归原专用器物域，不为戒指假造charge/烹饪配方；器物只通过只读学习证据接口识别完成的指导。

规则：所有人身动作走共同毫秒、原身体/灵气与排他执行。开始支付不因取消退回；指导还支付老人注意，完整亲手练习后才留下个人方法来源，旁人不自动学会。听旧事只收到明确年代/来源的说法，不读取现今仓库或关系。药圃履约须持戒在真实目标旁做一次短交流；不按每帧距离触发，保证远近/分步结果一致。睡眠按共同时间有限恢复，不积攒超上限精力。强行唤醒额外损伤真实封纹，损伤与记忆不互相修复；强唤会破坏本人原有合作，重做约定可修复合作而不能修复材料。

位置与同意：近处无主设施戒可取，持有人可放在近处设施或向同聚落的近处同门提议接手；接收方按原社会请求算法/处境决定，不能偷走别人手中戒。转交使尚未完成的原持有人约定破裂并留记；已履约的个人经历仍保留。新持有人不能继承别人的信任或全部交流记录。

运行入口：新增O/点击旧戒弹窗，提供走近、取放、唤醒/听旧事/约定/履约/指导/休眠/强唤/转交，显示本人收到的话和本人活动。指导对象只按本人可见选择，再由规则复查能否亲手操作；不按隐藏条件自动选对答案。复用原自动路线和生活活动栏，WASD/停止/失控中断，跨区离场数据继续。

存档：根12/区域9加入寄魂域1；旧v11及更旧显式迁空域，不补造戒指或老人。恢复先独立构造所有候选，验证实际载体引用、唯一位置、约定/学习来源、时刻/投入/执行冲突，再整体提交。原样v1–v11及overload_v10不可重写；本版另捕获真实进行中v12。

验收：独立主体/有限感知和知识不泄漏、未履约拒绝、实际携戒履约和完整练习、真实消耗/取消/失控、接手同意与保管唯一、睡眠恢复和裂损持久、远近/粗细一致、现代坏候选原子拒绝、旧档迁空/新旧反复读入。完整check＋真实输入/1280×720截图＋指导中途保存、完整停开游戏相同未来。

边界：一位寄魂者、一枚载体、有限两项旧知与一种实际指导；不含通用夺舍/储物戒/灵魂死亡、全部对话或学习图、载体修复。W4-b将给玩家感知/传意/协商和等待路径，不能用本包替代。
