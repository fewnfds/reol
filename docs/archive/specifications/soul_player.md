# W4-b：从旧戒里开始的人生

2026-11-03。有限开局样本已实现并验收，见[QA](../../qa/20261103_soul_player.md)；NPC寄魂底座见[soul_vessels](soul_vessels.md)。不将一个开局等同完整非人冒险；当前Goal状态见[HANDOFF](../../status/handoff.md)。

目标：在原世界选择晏衡的同一段残识，从有限灵机感知、传意、请求他人帮忙和休眠等待开始。原杂役/雀妖仍自主，不复制戒指、记忆或一具可移动的幽灵身体。

体验样本：残识在灶边旧戒苏醒，只能感到近处呼吸/灵机；选一个感到的气息传意，请其携戒到药圃。对方按自己精力、工作、性情和双方经历答应或拒绝；答应者实际走到旧戒、花时间收起、携着同一物走到药圃。玩家在途中随载体改变视野，自己不能控制对方步伐，随时可撤回请求或收敛休息。到达后玩家亲自观察药木，留下当前有来源的新经历。人帮忙结束后恢复自己的日常，戒中人仍随当前保管人生活。

只提前接足够验证身体与意志分离的一条循环，不一次实现通用对话、代操/夺舍、任意交易、飞魂或全部学习网。W4-a的原指导与人身界面继续回归；本包玩家残识暂不把全部旧知转换成任意口述法术。后续教学/互利和更多目标另包扩大。

## 状态和执行

- 新纯 `SimSoulAgency` 作为寄魂域协作者，持有手动意志绑定、自主传意/观察/休息动作、已同意的携戒差事、与人类之间专属接触/请求记忆。它不复制原人类之间的关系，只有实际接触过的跨域边。
- 仍以原寄魂者energy/awake/旧知和原戒指位置/裂损为真值；新的动作只引用它们。所有时间为原共同毫秒，耗时/精力/感知距离放定义。
- 传意开始支付注意；取消不退。NPC的接手决定用已有请求算法/缓存原则和自己的原状态，不能按隐藏善意/忙碌自动替玩家选人。
- 携带差事占用原人身，与原劳作/器物/服务/对练互斥；原导航和连续路线投影执行接近→收起→携行→到达。不凭空移动、不调换身体控制、不复制物品。中断前未取则戒仍原处，中断后已取则戒仍由该人保管；恢复日常不退回起点。
- 传意通道或原身体失控会中断对应动作；载体封纹断开阻止新交流，不将材料损伤当魂死亡。离场/快进只改变运算方式。

## 人生与呈现

开局增加第三个一次性选择，保存引用原soul主体；不开放运行中免费选人。显式区分human/bird/soul，清除所有“非人即鸟”的分支；主体源不在运行层复制。控制单元投影为载体位置，WASD/Shift不驱动持有人。

寄魂用专门灵机视图遮住普通地形/人物名字/库存和人类HUD，仅画自身封纹与范围内真实可感到的气息，标签在对方实际回应/自报后才出现。界面数据由纯规则的授权投影提供，不直接接后台人物字典。普通时间控制仍可用，T等候、危险/中断边界保留；休眠仍有唤醒路径，不因没人持戒卡死。
