# U1-a：可读的驱离冲突与共同动作

日期：2026-11-03。实物木剑、两种术法、敌意动作、挫伤/退让与存读已接为有限样本，证据见[QA](../../qa/20261103_transcendent_conflict.md)和BASELINE。后续[有限看护/借源/驱离](source_care.md)也已接入；不代表完整领地、产权、任务或战斗系统。当前世界引擎顺序见[执行记录](world_engine_execution.md)。

## 体验与有限出口

先让玩家处理一场有利害的超凡冲突：实际守护者要求停止取用受其看护的地方，人物可回应、暂退或用已会手段驱离/抵挡。警告、察觉、敌对行动与停手有明确原因，不把附近所有NPC变成全知敌人。原有限资源不会因为“挑战开始”刷新。

首包以明确的非致命手段验证动作和后果；这是一种具体冲突意图，不是全世界暗中免死。失败保留已付体力/灵力和可恢复伤势，允许撤退、求助或恢复后再来。致命冲突、死亡清理与有限转生必须另成闭环；不调用现有`remove_actor`假装已经处理死亡责任、物品继承与人生接续。

| 手段 | 有意义的区别 | 成立条件与后果 |
|---|---|---|
| 木剑试招 | 近身扇形，读前摇、距离与收势；空挥仍耗力 | 唯一真实武器在手、具备基本方法；接触按同一几何规则，不能用V页左剑预览当装备 |
| 凝气弹 | 有飞行时间的直线施压，可走位避开，被实际障碍截住 | 本人会方法、能支配身体且有原qi；发出即支出，取消不退已发气弹 |
| 护身气障 | 有限时间/承受量，帮助挡下一次压力与撤退 | 消耗原qi，抵挡提交一次，不是永久无敌；不能停开/重穿刷新剩余量 |

名称、时序、成本和练习资格是开发起点，放入内容定义后测试调配，不是锁死的技能/职业体系。通过具名人物明确示范/原经历获得首批资格，不把新招式全知授予所有生命，也不要求先实现大型学习网。现有普通衣服保持生活与外观功能。

## 实际代码起点与不能绕过的约束

| 原实现 | 本包复用 | 本包须处理的限制 |
|---|---|---|
| 原actor、`SimRouteTravel.point/put`、`SimLocalMotion` | 唯一位置、朝向、qi、stamina与闪身 | 不造战斗人物副本或第二时钟；动作限制逐阶段判断 |
| `SimSparring` | 扇形接触、前摇/接触/收势、同刻收集后提交、命中去重的规则经验 | 单一双人bout仍只管自愿对练，不能扩为全世界只打一场的单例 |
| `SimArtifacts` | 实物唯一位置/保管与观察边界 | 现有定义/候选严格绑定温石工序；木剑不能伪造储热/灶台配方，先拆清能力类别与通用归处 |
| `SimHealth` | 原人身后果、诊治/恢复、同一时间和身体 | 当前只认温石反噬造成经脉灼涩；新挫伤须有实际命中来源、具体限制和恢复，鲜药护理不能无条件治一切 |
| `SimSpiritSources` | 已有有限引息恢复原qi | 当前对账只统计器物/寄魂支出；施法成本须进入同一可核验收支，不能扣完qi让正常档变坏档 |
| `RegionalSimulation` | 边界推进、结算阶段、占用用途与独立候选 | 新冲突进入同一调度/取消/自主恢复；近远都执行，不只在Node存计时器 |
| 原地图/门墙/桌柜/多格身体 | 实际空间和独立候选查询 | 步行通路不等于投射射线；水面/高差/实体分别定义，对方高度不能读取全局玩家altitude替代 |

现有图集与几何可作占位；本包无需新插件、运行时模型或正式美术。若改变物件格式，先冻结真实进行中档与内容基线，不批量修改历史fixtures。

## 状态与流程

冲突域拥有`conflicts[id]`、参与/意图、技法阶段、时刻、已付成本、投射/气障、接触去重与结果凭据。身体、资源、伤势、物品各沿原所有者；人物到冲突的索引和视觉阶段只派生。至少验证两地各一场冲突可以同时推进，同一身体不能同时处于两场冲突或旧对练中。

动作提交流程：请求→核验控制/本领/持物/原身体占用→支出并保存开始→按共同边界推进→收集同刻接触→分别核验阻挡/气障→一次提交效果与来源→收势/取消/脱离→恢复合适自主。先收集再提交，避免遍历顺序使同刻出手被吞掉。

输入是意图，不直接扣血。暂停可选择下一动作，世界时间未推进前不提前造成接触或消耗；是否在接单时先收取成本须与实际开始明确区分。危险能在玩家实际感知后取消等待/降速；远处未获知的交战不能通过HUD或突然降速泄密。

NPC按已察觉位置、动作线索、职责、距离和原资源选择靠近、施压、防护或退让，不读尚未提交的玩家按键。首包用少量有解释的决策，不预建通用行为树。警告/驱离与可见交互共用真实人物，切换界面或离场不重建对手。

## 存档与交叉校验

实际引入新持久域时预计根34→35、区域30→31，并升级实际形状变化的子域；最终版本以实施时真实需要为准。未写代码前不先升版本，不用空字段迁档。旧档迁入空冲突，不补造剑、敌人、技能、伤势或过去灵力支出。

候选依次建立独立地图与原身体/物品，检查冲突形状和引用/阶段/成本，再交叉检查健康来源、身体排他、灵力收支及玩家在途/闪身状态；全部通过才绑定提交。读取活地图、把未恢复领域当空或只放宽旧校验来“兼容”都不成立。

施法成本使用稳定分配序号，进入原灵源`qi_baselines`与引息结果的成本floor/同刻顺序；明确旧基线起点，不倒补过去账。战斗伤来源为一次真实命中结果，不能用UI按钮直接附加伤势，也不能重复加载重复生成。

近景和远区先用同一个有限纯规则上下文持续推进，以共同边界/固定步结算；无视图不冻结，也不先做一个总战力骰子替换。离场/入场仅换显示或后续输入，中途可介入；高效粗算与完整势力事件队列后包扩。

## 工作拆分与完成标准

1. **共同动作规则**：从原对练可复用部分提取无状态阶段/几何计算；原对练未来等价。定义武器/技法内容及阻挡语义，验证同刻接触、扫掠与去重。
2. **实物与来源**：让原物件所有者能表达真实木剑而不要求温石字段；接原取得/持有/放回。扩健康来源与原qi成本对账，用可重复场景证明正常保存能恢复。
3. **冲突执行**：接有界多场冲突/原身体/原调度，先纯规则与独立候选，再接NPC。首包明确可恢复伤势与撤退，保留原对练。
4. **可玩入口和反馈**：实际看见/交谈守护者、得到方法和木剑、选择三种手段；代码图形清楚展示前摇、剑弧、飞行线与有限气障。移动/闪身/暂停继续有效，资源和后果可理解。
5. **实机闭环**：引息准备→交战→有伤撤退→原时间恢复/求助→离场与再次到达；真实投射/护障中途保存、完整停开并验证未来一致。更新当前功能与证据，再进入U1后续。

上述拆分是工作顺序，不把仅完成纯函数或菜单当作首包玩法交付。工作中每个可验证停点保留测试/真实状态，U1完整出口仍看U方案。

| 场景 | 必须成立 |
|---|---|
| 原对练/日常/天气/房间/旧档 | 旧规则与未来保留；新的显式技法不偷偷改变普通人 |
| 引息→施法→存读→再引息 | qi收支有效、取消不返已付、无免费补满 |
| 剑击同刻互中、气弹扫掠 | 不因遍历/帧率漏接触或重复受伤；墙柜实际挡住 |
| 护障中途取消/结束/重启 | 余量与时限保持，一次抵挡只支出一次 |
| 驱离/撤退/休养 | 有实际恢复途径，不把死亡标记当作战败捷径；不删原责任/随身物 |
| 玩家离场、两地同时冲突 | 不冻结/复制/重抽，玩家在场高度不影响远处接触 |
| 前摇/飞行中真实存档停开 | 原人物/阶段/伤势/成本/物品和之后世界未来一致 |
| 坏成本/伪命中/双保管/活动冲突 | 独立候选拒绝，活会话逐字节不变 |
| 新档→旧档→新档 | 无房/武器/技法历史补造，原不可变内容基线保持 |
