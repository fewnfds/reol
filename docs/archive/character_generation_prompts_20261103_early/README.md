# 八方向纸娃娃：外部图像生成任务包

2026-11-03。给外部文生图/图像编辑模型使用；当前代码八向技术样本仍独立保留，未收到或采用外部正式素材。

**推荐做法：贴身基础衣的人体母版＋独立衣帽/持物/挂件；先做八向静态小样，再做逐帧动画。** 不需要全裸，不要只生成一套无法拆开的穿衣人物。成年中性母版穿灰色贴身短衣短裤，作为画面打底；它不授予游戏中的可交易衣物或护甲效果。

**现在只需要先做[这一张南向母版](00_start_here.md)给我看。** 选定后再按以下顺序扩展，不必一次做完所有提示词：

1. [固定规范](01_fixed_spec.md)：本包全部图像的唯一镜头/尺寸/朝向合同。
2. [人体母版](02_body_prompts.md)：先复制“南向母版”整段，选出满意的一张；随后每次都附同一张已选母版，生成其余七向。每方向各一张256×256 PNG，比一次赌整张八向表可靠。
3. [粗布常服](03_robe_prompts.md)：附对应方向母版，逐向生成穿上同一件常服的合成参考。
4. [独立衣帽图层](04_layer_prompts.md)：附同方向母版与合成参考，输出可替换层；帽子是独立附着，不重新生成整个人。
5. [不对称剑佩](05_sword_jade_prompts.md)：先做南、北、东、西四向，再补四斜向。左手剑、右腰玉佩不能换边；两件各自独立层，并附合成参考核查遮挡。
6. 把这一轮原图交回，按[验收/回传](07_acceptance_and_return.md)核对；通过后再用[动画后续任务](06_animation_prompts.md)扩帧。

每份提示词都是完整可复制的正文。把对应模型支持的参考图、透明背景开关、固定seed等设好，再粘贴即可；**不要把“固定seed”当成多视角必然一致的保证**。文档中的文件名用于保存输出，不让模型在画面写文字。中文提示词可直接使用，不强制换英语。

如果模型一次只能产出穿好衣服的整个人物，可以先交合成图确认风格；它属于候选参考，还不能宣称已得到可换装纸娃娃。模型不保证精确脚点、真透明、隐藏服饰形状或跨帧稳定，后续仍需规范化和实机验证。

已建立[Godot商店/资产库候选核查](08_godot_options.md)，不安装插件、不购买资源。来源、版本和免费内容以该文逐项核对为准。

后续图像请放到项目根 `art_inbox/character_generation/`（已建接收说明），或直接在聊天里返回原PNG；不要覆盖现有 `assets/characters/humanoid_sample/`。大于50MB的单文件先告知，避免直接入库。
