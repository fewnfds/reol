# 后续动画：静态母版验收后再生成

**这一轮先不要批量做本页。** 先让八向母版、常服、帽子与不对称剑佩在引擎叠合通过。下面为下一轮固定任务，不要求把八方向与数百帧塞进一张图一次完成。

一张动画表只包含**一个方向、一个部件、一种动作**。顺序按从左到右、从上到下。每格256×256、脚点(128,174)、人物高约120像素。行走16帧用4列4行1024×1024；待机8帧4列2行1024×512；生活展示动作16帧4列4行1024×1024。动画不在画布上移动角色根位置。

先生成某方向人体动作，逐帧验过后，所有衣物与剑佩复用这组实际动作参考。不能让身体、衣服和挂件各自独立创作一套“走路”，最后指望自然对齐。第一批建议南向行走母体；无时间连续生成能力时宁可交关键帧，也不要交伪16帧的变脸角色。

## 待机与生活动作的固定节奏

待机：8帧、一个1600ms循环，轻微呼吸，双脚不挪位，手臂与衣摆只有小幅变化；不是八个方向。

生活展示：16帧、一个1200ms循环，只抬起角色本人左前臂再放下，不握拳出击、不挥砍、无伤害效果。帧0静止，帧4开始抬手，帧8抬到胸前，帧12放回，帧15接近帧0。其用途只是验证附着与遮挡，不能当完整攻击动画。

服装/持物跟帧：附已通过的同方向16帧身体表和对应静态服饰，要求输出相同格序的独立完整层；逐格完全对齐，不新造身体，不改变起伏/手腕相位。需要前后遮挡分片时保留同一物件的完整源层及合成预览，逐帧制作实际遮挡。模型如果做不到，保留源图回传，由我们缩减内容/修正生产路线，不把不对齐素材硬塞进游戏。
