# 固定规范 CG-HUMAN-01

这是本轮成年标准人形家族的制作合同，不把所有种族、年龄、体型锁成同一种人。先验证本家族，再逐家族适配。外部模型输出是候选，不保证直接可导入。

| 项目 | 本轮固定值 |
|---|---|
| 风格 | 中国古典修仙日常，简洁手绘2D游戏精灵，少量柔和明暗，大色块、低细节密度；非像素画、非照片、非电影立绘 |
| 人体 | 25岁成年中性外观、普通偏瘦、5.5头身；黑发小发髻，短刘海；无胡须/妆容/首饰/身份符号 |
| 镜头 | 正交投影，无近大远小；俯角55°是视线相对水平地面向下55°（距离垂直俯视35°）；所有图相机位置/俯角不动，只转人物 |
| 地面/轴 | 屏幕上方为北；N背向观察者，S面向观察者，E朝屏幕右，W朝屏幕左；斜向为45°中间方向 |
| 尺寸 | 原始每方向256×256 PNG；参考脚点(128,174)，人物从头顶到脚底约120像素；左右、头顶和持物留空，不裁切 |
| 姿势 | 双脚自然略分，双臂离身约10°，手自然放松；中立站姿；不做T字或A字建模立绘，不走路 |
| 光照 | 中性无方向柔光，左右明暗不互换；轻微体积阴影留在身体/衣物内；不画投在地面的影子 |
| 底图 | 浅灰无装饰贴身短衣＋齐膝贴身短裤＋深灰无饰贴脚布鞋；无裸露私密部位、无性特征强调；不要求人体裸体 |
| 身体色 | 暖灰肤色，深墨发色；常服灰度底便于引擎乘色，正式颜色由游戏实际衣着给出 |
| 背景 | 原生透明alpha最佳；不支持透明时用纯#FF00FF单色背景并原样返回；不要棋盘格、地面或环境 |
| 解剖左右 | 南向人物左手在画面右、右腰在画面左；北向相反。以角色本人左右为准，不以屏幕左右重命名 |
| 布局 | 单图一个方向一个人物，无文字无边框；可额外交八向总览，4列2行：N NE E SE / S SW W NW |
| 运行规范 | 导入前统一到96×96脚点(48,65)，实显约44–45像素高；**不要直接覆盖现行图集** |

总览1024×512的每格仍256×256，格间不留额外边距；模型若无法准确排格，交八张单图即可。尺寸/落点不准时保留原始内容，我们统一对齐，不让模型重复重画直到脸变了。

母版通过后，相同家族的所有衣服、发型、帽子与动作必须依附它。新建另一体型使用新family ID，不能把身高/胖瘦漂移当成同一角色的换装。

**图层合同：**身体打底层；可替换常服层（灰度含袖）；可替换帽子层；蓑衣前/后片；左手剑前/后片；右腰佩玉前/后片。合成图用于看效果，完整层用于换装；一个被遮挡物只剩可见碎片时，不能当成完整可替换资产。前/后分片属于同一原物，不是多件物品。

本包不要求图像模型输出数值深度图或猜出Godot JSON；我们在接图后制作/校验锚点、遮挡、帧表。图像层不能携带战斗属性、所有权或任职权限。
