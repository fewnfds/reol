# 可替换衣服与帽子：完整图层提示词

常服先附对应方向母版＋同方向已确认穿衣合成参考。**完整层不是把画面可见衣片直接抠出来**，被手、头或挂件遮住的衣服应有合理完整形状；合成遮挡在引擎处理。帽子另交整人预览，以防位置错误。

补全原本被手或挂件遮住的布料连接，不能留下手形或玉佩形的永久透明洞。领口和袖口真实开口可以透明；不能把衣服平铺、旋转、缩放或另排版。它应该能按原位置直接盖回母版，身体不需要移动。
