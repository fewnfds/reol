## 2. 应保留的分离

- **规则与显示**：TileMapLayer、人物Node和UI可卸载；原区域/物件/过程继续。不要把房屋温度或灵气只写到可见tile节点。
- **连续位置与格子**：连续身体承载运动/动作，格子承载地形索引/建造/路径。动画不改变碰撞或世界时间；不靠把动画帧拉高掩盖真实跳位。
- **事实与认识**：事件发生、谁看见、谁听说和谁相信分别成立；世界事件接口不能把私事广播给全世界。
- **实物与用途**：穿着/持剑是原物件的用途，视图部件不新增物品，也不授予身份/权限。
- **近远精度**：镜头卸载是渲染生命周期，远区求解是模拟策略；两个开关不能混为“玩家不在就冻结”。

## 3. 需要补稳的接缝

### 领域组合

`RegionalSimulation`已承担大量组合/候选顺序，增加领域要改多处capture/restore/boundary/身体互斥/库存scope。首步整理一个小的领域描述契约：稳定ID、版本、依赖、初始化、边界/结算、快照/候选校验。仅迁移实际重复处，保留各领域自己的规则和跨引用校验；不建立能执行任意未知状态的万能插件平台。

候选需先建完整依赖图，再独立校验，最后一次提交；不能在前一个领域已替换活世界后发现后一个失败。共同时间不同阶段的结算顺序须明确，避免当天新建屋顶替过去整天挡雨、新敷药回填过去两分钟恢复。

### 身体占用

诊治/教学/搬运/穿衣都有相同身体排他需求，现在多处手动检查。后续逐步收拢`try_acquire/release/owns`小接口，支持一个事务占用多人及移动/行动/通信通道，原领域仍拥有过程。取消/失控/死亡/读档都要清楚责任。不要先另存一套会与原actor.active冲突的“总任务”。

### 统一空间查询

保留TileGrid坐标约定；把静态地形、持久修改、建筑/大身体动态占地、屋面与环境查询分清。空间查询可共同组合，但不把所有数据挤进TileSet custom data；同一tile定义资源可被多格共享。拓扑改变产生局部版本/失效范围，寻路/房间/温度/灵流分别重算相应缓存。

当前`SimConstruction._reindex()`重建围合，房间没有稳定实体ID；后续余热/灵机按固定空间键保存，房间只是求解聚合。先按旧布局结算到变更时刻，再改拓扑；隔房/拆墙与近远精度转换都须保存量和舍入余数，不能随房间重编号丢失或复制。

### 事件引用与可观察性

领域ID＋本地事件ID＋世界时刻/来源构成明确引用。待执行事件、已提交影响、观察线索与消息分离。对原事件做轻量统一封装，比先造一个全局“事件表”复制全部真值更稳。社会事件与环境每分钟采样要分级，不能让百万条温度变化淹没人物记忆或存档。

### 年级快进与规模

双聚落原型的每分环境脉冲不代表百万格/跨年已经能高效推演。先建立稳定段积分、局部激活、源/边界守恒、事件必要阈值与预算测量，维持原欠算而不丢时间。扩展到12–24区或数百人目标前，要有对应压力场景和存读证据。

## 4. 本次确定的下一层设计

[世界环境方案](plans/world_environment.md)规定：唯一时间→历法/气候→局地物性→真实生命/材料响应；五行亲和与可消耗灵机分开，风水由实际山水/建筑/源流产生，不做全局吉凶条。先寒雨/衣屋/热源，再植物/地形修改、五相的两用途竞争、局地堪舆。

[八方向外观方案](plans/eight_direction_appearance.md)规定：原生2D八向分层图集、统一相位、解剖左右锚点、逐朝向/动作相位遮挡。左手剑/右腰玉佩保持身体侧别。不是四向/五向后全体flip，也不靠装一个移动插件自动补足美术。[免费工具/许可核查](../design/research/eight_direction_sources.md)列出Godot原生、FLARE、LPC与离线烘焙候选。

这些是后续实施合同。没有新增环境或动画领域代码，没有安装新插件或导入第三方资源；不要求用户再决定常规算法与参数。

实施前另已明确旧档启用合同：新气候/冷热/生态/灵源记录规则版本与启用时刻，保留旧雨相剩余时段、湿衣/湿床和真实已收雨水；新增作用不追补迁移前历史。拓扑存量与旧档边界的具体验收见环境方案，不算已经实现或测试过。

后续实施更新：E1历法/室外冷热与A1真八向技术样本已分别验收，见[环境QA](qa/20261103_calendar_temperature.md)、[外观QA](qa/20261103_eight_direction_sample.md)。本页表格保留审查当时快照，最新已实现范围以FEATURES/BASELINE为准。外部素材提示词见[制作包](art/character_generation/README.md)，没有安装第三方候选。
