> 历史交付记录（2026-11-02）：以下功能、限制、测试与试玩入口描述当时版本。当前完整清单见[FEATURES](FEATURES.md)，最新构建/格式见[BASELINE](BASELINE.md)；后续已接功能不从本页旧未完成项推断。

日期：2026-11-02。对应[连续性要求](../design/systems/world_continuity.md)。首版已接入主场景。

## 试玩

右下“离场与归来”：点击“前往河湾”，玩家沿可走的地形路径花时间移动，镜头随行；WASD 可中断，空格暂停，1/2/4 倍速。到达后点击可见居民查看活动；点击“返回山门”再观察原聚落。离场不初始化人物，返回可以接上早已开始的行动。

“中断 / 恢复运粮道路”是开发期场景控制，直接改变运输路线状态，验证在途暂停和续行；它不代表已经实现玩家破坏/修路玩法，也不阻断玩家脚下的地形路。“记下 / 读取两地近况”覆盖双方状态、货物、消息、玩家行程和时钟。原有存读入口也走相同流程。

山门五名 NPC 和河湾六名居民拥有独立实例 ID、身体、行动、记忆、库存和账目。河湾复用已有角色定义，名字是测试内容。玩家取食、报工和求助仍属于山门服务；河湾暂提供观察和往返验证。玩家仍需安排生活，长时间旁观快进会消耗饱食和精力。

## 实现

| 文件 | 职责 |
|---|---|
| `scripts/sim/regional_simulation.gd` | 共同时间、区域边界、运粮去返、在途容器、延迟消息、快照 |
| `scripts/runtime/world_continuity_runtime.gd` | 双聚落装配、玩家行程、远区表现接续、联合存读 |
| `scripts/sim/village_simulation.gd` / `action_executor.gd` | 同一生活规则的细算和稳定区间批算 |
| `scripts/ui/world_continuity_panel.gd` | 行程、当地见闻、存读、道路测试入口 |
| `data/scenarios/world_continuity.json` | 位置、库存差异、运输条件、消息时延、名字 |
| `tests/sim/test_village_batch.gd` | 批算、预算续推、外部变化、粗细一致 |
| `tests/sim/test_regional_simulation.gd` | 无人区生活、运输、竞争、消息、阻塞、满仓、存读 |
| `tests/runtime/test_world_continuity_runtime.gd` | 地形往返、表现接续、可见信息、联合存读 |

近区逐分钟推进。远区在关键变化、跨区作用、入场或存档时补齐稳定区间；下次行动边界始终限制共同世界时间，不会漏过必要决定。当前仍保留格路径，批算省去无变化分钟的重复结算，尚未做宏观路网。

精确查询远区使用 `synchronize_region(id)`；直接提交外部状态变化后使用 `invalidate_region(id)` 更新预测。切换执行精度保留同一模拟实例。预算不足保留待推进目标，可继续结算。

缺粮方根据当地库存摘要发出请求；供给方收到延迟消息后，根据可用库存和留粮底线派单。运粮人有稳定 ID、精力、路径进度和货单，粮食实际从源仓移到在途容器，再交付目标仓；空车也要花时间返回。封路保留进度与货物；满仓原地等卸货。该版本是机构供给的最小规则，尚未包含办事人的完整私人动机。

发送、到达和听说分别计时。地区公开消息与人物私人记忆分开。保存补齐共同提交点；读取先独立验证世界、资源、引用、时钟和地形路径，再整体替换。材料预约使用稳定顺序，JSON 键排序不会改变续跑。

## 验证

- `python tools/godot.py check`：**37 组、1,082 断言、0 失败**，包含原测试。最终日志：`logs/check-test-20261102-191224.log`。
- 无人输入推进 600 分钟：远区产生 47 条人物事实、6 次运货出发。
- 标准运输：13 分钟发货、61 分钟到货；目的地 25 分钟才听说发货。封路保留已走的 9 分钟和原货物，恢复续行。
- 两人竞争、满仓等待、预算续推、同刻下令再离场均有回归；等待卸货也可存读。
- 平地运行时玩家往返 168 游戏分钟，身份与未完行动连续。玩家/货物途中存读后继续，完整世界状态一致。非法玩家/远区路径和时钟快照拒绝，当前世界不受污染。
- 安静远区 240 分钟用 **4 次细算 + 236 分钟批算**；自主生活 3 游戏日用 **1,636 次细算 + 2,684 分钟批算**，与逐分钟完整状态一致。这是结算次数比较，不等于帧率或大世界性能承诺。
- Python 工具测试 **7 条通过**；场景引用 **403 文件，0 错误 / 0 警告**。
- Godot AI 实际运行：山门到河湾、封路、两地存读、居民选中；检查了 1280×720 画面，[河湾现场](qa/world_continuity_20261102.png)。约 32 FPS，未验证 60 FPS 性能目标。

## 边界

这是两个小聚落、单一运粮通路的连续性验证。远区战斗、人员迁居、人口世代、完整政治/经济演化和大型世界性能未实现或验证。

河湾表现节点离场释放、入场重建；山门旧节点保留，离场隐藏且不更新人物视图。玩家数据暂归山门，身体 HUD 对稳定区间只读投影，避免唤醒整村。访客当地服务和统一跨区归属留待后续。

地区公开消息尚非完整逐人跨区传闻网络。历史未压缩；存档要求同一配置和地形种子，双聚落模式拒绝旧单聚落档，不隐式补造。迷雾探索、地形变化与未来建筑仍不在完整世界存档范围。
