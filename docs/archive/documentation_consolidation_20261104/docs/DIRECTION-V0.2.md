## 最终结论的适用范围

2026-11-03最新侧重点：修仙世界优先支持超凡者的能力、战斗/法器、学习功法、冒险与组织行动；凡人生产先维持世界循环，不继续扩复杂农场。事件化远区保持续状态与人物来源，不能只随机播报。当前顺序见[超凡者优先](plans/transcendent_focus.md)，不从早期生活阶段推断需要先完成全产业链。

| 早期选择 | 现在仍采用的部分 | 后续修订 |
|---|---|---|
| 2D正交俯视 | 固定视角、平移/缩放、正方形格与数据高度 | 连续身体位置已接；格子不要求动作逐格跳转，正式像素尺度/美术待测 |
| 单机模拟网游感 | 远处持续运行、人物有自己生活 | 双聚落已验证；完整多区/战争不是既有功能 |
| 实时与暂停 | 玩家可停下来观察/安排 | 当前只有动作对练样本；完整战斗与高阶慢放待做 |
| 杂役切片起点 | 原人身仍为一个开局 | 已新增雀身/残识短开局；多种生命为长期方向 |
| 脚本/规则先行 | 无模型也能成立的世界 | 未来AI可理解/对话/提计划；不再限定只能风味文本，结果仍由规则执行 |
| 先玩法后美术 | 可读性、统一风格、有限资源预算 | 早期色盘/贴图规格是建议，不是最终资源承诺 |

早期“WoW式统一阵营声望”已由个人/组织/阵营分层、机构记录与信息流取代；“普通NPC不保存”不适用于当前持久世界；“人形装备/固定技能表”不作为所有生命的底层法则。后续世界、人生、环境和交互规则见[世界总纲](../design/systems/self_consistent_world.md)、[最新交互原则](../design/systems/world_interaction_principles.md)及[决策记录](DECISIONS.md)。
