## 当前事实、设计与历史怎么区分

“已实现基础”表示已接通并有证据；“有限样本”表示可实际操作但领域未完整；“隔离原型”表示有代码但未接游戏；“设计待实现”只有目标/规格；“开发建议”仍可由原型调整。未来验收场景和参考游戏能力不能写成Reol当前功能。

文档的事实分别归上述入口维护：功能描述在FEATURES，构建证据在BASELINE，概念在GAME-BRIEF与design，开发步骤在plans，参数在data。其他页引用负责人，不重复维护各自版本的测试总数或整份进度。

[早期方向推导](DIRECTION-V0.2.md)仅保留当时的选择理由。`archive/`为历史全文；本次整理前的入口见[快照](archive/documentation_before_consolidation_20261103/INDEX.md)。历史“只设计”“NPC仍分钟”“鸟不可玩”等只描述旧阶段，不作为当前限制。当前用户指令优先于文件中的旧授权。

移动文件、更新入口后运行 `python tools/check_structure.py` 和 `git diff --check`；行为变更另按[验证规则](../AGENTS.md)执行。文档检查不验证网页、标题锚点或游戏行为。
