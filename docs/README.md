# 文档路由

先读所需入口，再按其中链接深入。本文不维护授权、版本、测试总数或下一工作包，避免产生第二份当前状态。

| 要解决的问题 | 唯一入口 | 何时继续读 |
|---|---|---|
| 当前允许做什么、停在哪里 | [HANDOFF](HANDOFF.md) | 恢复会话或任务切换 |
| 游戏概念与用户已定边界 | [GAME-BRIEF](GAME-BRIEF.md) | 改体验/规则前，按链接读领域设计 |
| 现在能怎么玩 | [FEATURES](FEATURES.md) | 查操作与样本边界 |
| 哪个版本经过什么验证 | [BASELINE](BASELINE.md) | 验收、存档兼容、判断未提交工作 |
| 真实代码依赖/状态所有者 | [ARCHITECTURE](ARCHITECTURE.md) | 改跨域状态、时间、位置或存读 |
| 当前格式、旧版支持与退役 | [COMPATIBILITY](COMPATIBILITY.md) | 改存档/生成器兼容或清理历史分支 |
| 文件放哪里 | [PROJECT-STRUCTURE](PROJECT-STRUCTURE.md) | 新建或迁移文件 |
| 下一层依赖与长期出口 | [ROADMAP](ROADMAP.md) | 不用路线图中的目标代替恢复授权 |
| 实施规格 | [plans索引](plans/README.md) | 当前世界引擎执行页和相关分项；旧包按需查 |
| 领域规则与理论依据 | [design索引](../design/README.md) | 选一个领域，不整读研究库 |
| 决策原因/旧提案是否有效 | [DECISIONS](DECISIONS.md) | 先查当前适用性，再查原始理由 |
| 工具配置、维护、审查 | [TOOLCHAIN](TOOLCHAIN.md)、[AI工作流](AI-WORKFLOW.md) | 当前实装与历史选型分开 |
| 过去的验收证据 | [QA索引](qa/README.md) | 只证明所列样本/提交，不继承旧“下一步” |
| 全部Markdown路径与类别 | [CATALOG](CATALOG.md) | 找漏项/专题；不是常驻上下文 |
| 文档冲突取舍与维护办法 | [文档治理](DOCUMENTATION.md) | 新增/合并/改状态或处理冲突 |
| 旧版本全文 | [archive索引](archive/README.md) | 追溯来源；不作为当前指令 |

工程规则在根[AGENTS.md](../AGENTS.md)，技能按任务读取。概念、代码、证据与目标是不同维度，具体用法见[治理页](DOCUMENTATION.md)。
